# 机器人控制与规划 — 教程架构

> **主题**：Robot Control & Planning（运动规划、最优控制与伺服控制）
> **状态**：10 章全部完成 ｜ 主线：RRT/RRT*、Crocoddyl、PETS、Khatib/Hogan、CBF、PPO/SAC

本文件是控制与规划教程的**架构规划**：先为每章定下问题场景锚点与推导产出清单，
后续各章按 [CONSTRAINTS.md §3.4](../../CONSTRAINTS.md) 五步法
（问题场景 → 解决方法 → 选型理由 → 理论依据 → 完整推导）展开写作。

## 教程主线（一句话）

机器人拿到"去抓那个杯子"的任务后，控制栈要回答四个层次的问题：
**去哪**（任务/运动规划）→ **怎么走最好**（轨迹优化与 MPC）→ **如何贴合执行**（操作空间/阻抗控制）
→ **如何保证安全与适应扰动**（CBF 与学习式控制）——本教程沿这条栈自上而下，
把每层的核心算法推导讲透，并与 [SLAM 教程](../slam/README.md)（感知输入）、
[RoboTwin 教程](../robotwin/README.md)（仿真落地）衔接。

## 各章架构明细

### 01｜控制与规划全景

- **问题场景**：从"抓起杯子"到电机力矩：任务规划（哪个抓取、什么顺序）→ 运动规划
  （无碰撞路径）→ 轨迹优化（时间参数化）→ 伺服控制（力矩级跟踪）；每层都在丢信息也都在加约束。
- **解决方法概览**：分层栈 vs 端到端（RL）的谱系；感知-规划-控制的接口约定。
- **选型理由**：为什么工业界仍是分层栈（可验证、可调试）；端到端的代价（安全/泛化证据不足）。
- **理论依据**：最优控制与运动规划综述；[papers/control_planning/](../../papers/control_planning/README.md)。
- **推导产出**：任务栈的形式化——每层的输入/输出/约束三元组；位姿流形上的路径 vs 轨迹
  （$q: [0,1] \to \mathcal{C}$ vs $q(t)$）之辨。

### 02｜运动学控制：关节空间与任务空间

- **问题场景**：末端要沿世界 z 轴直线下压——关节速度该怎么解？在奇异位形附近逆解爆炸怎么办。
- **解决方法概览**：正运动学 → 几何雅可比 → 伪逆/阻尼最小二乘逆运动学；速度级 IK 与
  二次型任务优先级（任务堆叠）。
- **选型理由**：解析 IK 快但只对特定构型存在；数值 IK 通用但需初值与正则——DLS 的阻尼
  在奇异附近的取舍（精度换连续性）。
- **理论依据**：Craig《机器人学导论》ch4-6、Siciliano《Robotics》ch3。
- **推导产出**：几何雅可比 $J = \partial x/\partial q$ 的构造（每个关节轴的运动旋量）；
  伪逆 $J^+ = J^\top(JJ^\top)^{-1}$ 最小范数解推导；DLS $J^* = J^\top(JJ^\top + \lambda^2 I)^{-1}$
  的推导与 $\lambda$ 的物理意义；任务优先级的零空间投影 $N = I - J^+J$。

### 03｜运动规划 I：采样式规划

- **问题场景**：高维构型空间中基于网格的搜索指数爆炸；解析方法只适用于低维简单几何。
- **解决方法概览**：PRM（多查询：建图+查询）与 RRT（单查询：从起点快速探索）；RRT*
  在 RRT 上加"选父+重布线"获得渐近最优。
- **选型理由**：多查询 vs 单查询（重复规划频率）；最优性 vs 可达性的取舍；
  采样策略（均匀 / 诱导偏置 / 学习偏置——引出第 09 章 MPNet）。
- **理论依据**：LaValle《Planning Algorithms》ch5；RRT*（Karaman & Frazzoli, IJRR 2011，
  本地 classics/arXiv-1105.1186）。
- **推导产出**：RRT 的概率完备性论证（覆盖引理概要）；RRT* 渐近最优的核心引理
  （重布线的代价单调下降 + 收缩球半径 $\gamma(\log n / n)^{1/d}$ 的推导）；PRM 的
  可视图性质。

### 04｜轨迹优化与最优控制

- **问题场景**：RRT 给出折线路径——机器人执行会抖动、能耗高；需要时间参数化的光滑轨迹。
- **解决方法概览**：把轨迹写成决策变量的泛函：直接法（打靶/配点）与间接法（Pontryagin）；
  iLQR/DDP 用二次近似递推解 Bellman 方程；微分平坦（最小 snap）直接在输出空间优化。
- **选型理由**：直接法鲁棒但需大量配点；DDP 收敛快但实现复杂（Crocoddyl 工程化的价值）；
  微分平坦把约束"吸收"进参数化，但只对特定系统存在平坦输出。
- **理论依据**：Bellman 最优性原理、变分法（Euler-Lagrange）；Crocoddyl（Mastalli et al.,
  ICRA 2020，本地 frontier/arXiv-1909.04947）；最小 snap（Mellinger & Kumar, ICRA 2011）。
- **推导产出**：连续最优控制的必要条件（Euler-Lagrange / HJB 概览）；iLQR 的前向-反向
  递推完整推导（值函数二次近似 + 增益求解）；最小 snap 的多项式参数化推导（为何 snap：
  加加速度约束推到四阶导）。

### 05｜模型预测控制 MPC

- **问题场景**：预排好的最优轨迹一遇模型误差/外力就失效；机器人需要在每个控制周期
  重新求解"从当前状态出发的最优未来"。
- **解决方法概览**：滚动时域——每步解有限时域 OCP、执行首步、移位重解；学习动力学
  模型（PETS：概率集成模型 + 不确定性传播 + CEM 采样优化）。
- **选型理由**：MPC 用"反复重解"买鲁棒性（反馈内嵌于重解）；代价是实时算力——
  显式 MPC / 温启动 / 简化动力学 各自怎么省；学习模型 vs 物理模型的互补。
- **理论依据**：递推可行性（terminal cost/constraint 的作用）；PETS（Chua et al.,
  NeurIPS 2018，本地 frontier/arXiv-1805.12114）。
- **推导产出**：MPC 与 LQR 的关系推导（线性无约束时 MPC 退化为 LQR 的论证）；
  terminal cost 保证稳定性的 Lyapunov 论证概要；PETS 的集成方差如何进入 CEM 的
  奖励上界（乐观-悲观权衡）。

### 06｜操作空间控制与阻抗控制

- **问题场景**：刚度伺服在自由空间表现完美，一接触物体就产生巨大接触力——擦桌子、
  插孔、装配这类"必须接触"的任务要求把力也纳入控制。
- **解决方法概览**：Khatib 操作空间动力学（把 Newton-Euler 投影到任务坐标）；Hogan
  阻抗控制（把关节/末端建模为"质量-弹簧-阻尼"，目标阻抗而非目标轨迹）。
- **选型理由**：位置控制 vs 力控制 vs 阻抗/导纳控制谱系——阻抗控制以"可调刚度"统一
  自由运动与接触任务；代价是需要动力学模型与力矩级接口。
- **理论依据**：Khatib (1987, JRA)、Hogan (1985, J-DSC)（延伸阅读，见论文库 README）。
- **推导产出**：操作空间动力学 $\Lambda(\mathbf{x})\ddot{\mathbf{x}} + \mu + \mathbf{p} = \mathbf{F}$
  的完整推导（关节动力学经雅可比一致性投影、动力学一致性 $\bar J^\top = (J M^{-1} J^\top)^{-1} J M^{-1}$）；
  阻抗律 $\mathbf{F} = K(\mathbf{x}_d - \mathbf{x}) + D(\dot{\mathbf{x}}_d - \dot{\mathbf{x}})$ 的
  稳定性（无源）论证；导纳 vs 阻抗的对偶（位置接口 vs 力接口）。

### 07｜安全控制：控制屏障函数

- **问题场景**：RL 学到的策略或优化出的轨迹性能好，但没有任何"永不碰撞/不超关节限位"
  的硬保证——部署需要一层形式化安全滤波。
- **解决方法概览**：把安全集写成 $h(\mathbf{x}) \ge 0$，要求 $\dot h \ge -\alpha h$（CBF 条件），
  在每个控制周期解一个 QP：在满足 CBF 的控制里找最接近期望控制的那个。
- **选型理由**：硬约束 QP 滤波 vs 软惩罚 vs 形状函数重训练——QP 滤波零训练、可叠加
  已有控制器；代价：依赖 $h$ 的设计、可能过度保守、可行性与非线性 $h$ 的求解实时性。
- **理论依据**：Ames et al. CBF 综述（ECCV 2019，本地 classics/arXiv-1903.11199）、
  Nagumo 定理（前向不变性）。
- **推导产出**：前向不变性与 Nagumo 定理的表述；$\dot h \ge -\alpha(h)$ 保证
  $\{h \ge 0\}$ 不变的证明；QP-CBF 的构造与"最小侵入"解释；与 CLF 的组合
  （CLF-CBF-QP）概要。

### 08｜学习式控制：强化学习

- **问题场景**：手工动力学永远缺项（摩擦、柔性、间隙）；任务越精细，建模误差越致命——
  能否让机器人从数据里自己学出控制律。
- **解决方法概览**：MDP 形式化 → 策略梯度 → PPO（截断代理目标 + 优势估计）；
  off-policy 路线 SAC（最大熵 + 双 Q）；仿真大规模训练 + sim-to-real。
- **选型理由**：on-policy（PPO：稳定、样本贵）vs off-policy（SAC：样本高效、超参敏感）；
  模型基（MPC+学习模型，第 05 章）vs 无模型——数据效率与最终性能的权衡。
- **理论依据**：策略梯度定理；PPO（Schulman et al. 2017，本地 frontier/arXiv-1707.06347）、
  SAC（Haarnoja et al. 2018，本地 frontier/arXiv-1801.01290）。
- **推导产出**：策略梯度定理完整推导（log-导数技巧）；GAE 的 $\lambda$ 折扣优势推导；
  PPO 截断目标为何能限制策略更新步（替代 KL 约束的论证）；SAC 的软 Bellman 方程与
  最大熵目标的等价推导。

### 09｜前沿：学习式规划与腿式控制

- **问题场景**：采样规划在高维空间秒级-分钟级、MPC 依赖模型精度——腿式机器人每秒
  要面对地形突变，"先规划再执行"的时间尺度跟不上。
- **解决方法概览**：MPNet：神经先验给出候选路径 + 采样回退兜底（任何时刻保留完备性）；
  Rapid Locomotion：特权教师（看到地形真值）离线训练 → 蒸馏出只用本体感知的盲学生策略。
- **选型理由**：学习先验 + 经典兜底的混合结构是当前工程范式——保留形式保证（完备性/
  安全层）的同时把"快"交给网络；特权蒸馏解决"仿真有真值、真机没有"的信息不对称。
- **理论依据**：MPNet（Qureshi et al., ICRA 2019，本地 frontier/arXiv-1806.05767）、
  Rapid Locomotion（Margolis et al., RSS 2022，本地 frontier/arXiv-2205.02824）。
- **推导产出**：MPNet 的混合规划框架（神经采样分布 + RRT* 回退的完备性论证概要）；
  蒸馏目标（学生模仿教师的动作分布）与特权信息如何只进教师；域随机化与
  sim-to-real 的关系（回引 [RoboTwin 教程](../robotwin/README.md)）。

### 10｜控制栈实战：与 RoboTwin 衔接

- **问题场景**：前面九章的模块如何拼成完整机器人栈？RoboTwin 仿真里策略学习
  （Diffusion Policy / ACT / VLA）与本章控制模块怎么分工——"策略出动作、控制器出力矩"。
- **解决方法概览**：全栈对应表（任务 → 规划 → 优化 → 控制各层可用的论文/教程/代码）；
  RoboTwin 的动作空间（关节位置增量）为何绕过了力矩级控制；sim-to-real 缺口的
  三种补法（域随机化 / 系统辨识 / 阻抗接口）。
- **理论依据**：与 [RoboTwin 教程](../robotwin/README.md) 第 07-09 章、[SLAM 教程](../slam/README.md) 第 10 章衔接。
- **推导产出**：分层栈 vs 端到端的选型矩阵（可验证性/数据需求/接触丰富度/部署难度）；
  关节位置增量动作空间下"隐式 P 控制" $u = k_p(q_{cmd} - q)$ 的稳定性分析。
