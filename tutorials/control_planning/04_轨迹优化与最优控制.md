# 第 04 章｜轨迹优化与最优控制

第 03 章的 RRT* 给出一条"能走"的路径——但它是一串构型路标连成的折线，直接交给伺服执行会抖动、超调、费电。本章把路径升级为"走得好"的轨迹：在时间参数化上求解最优控制问题（optimal control problem, OCP），让"时间、能耗、平滑"进入同一个目标函数。三个知识点递进：变分法给出 OCP 的必要条件并暴露间接法的困难（04.1）；iLQR/DDP 用"二次化 + 动态规划递推"成为压轴的求解器（04.2）；微分平坦为四旋翼这类系统提供一条绕开 OCP 的快车道——最小 snap（04.3）。本章产出的标称轨迹与反馈增益，正是第 05 章模型预测控制"滚动重解"的素材。

## 04.1 从路径到轨迹的变分观点

**① 问题场景** 手头有：第 03 章 RRT* 返回的构型路标序列——由 steer 步长 $\epsilon$ 决定的折线（(3.3)），拐点处方向跳变。缺的是**可执行性**：让伺服直接跟踪折线，速度与加速度在拐点跳变，电机电流冲击、末端超调震荡，能耗高、机构磨损快。想要的：一条时间参数化的光滑轨迹 $\mathbf{x}(t)$，在"时间短 / 能耗低 / 平滑"的度量下尽可能好，且每一步都满足机器人动力学。

**② 解决方法** 把"轨迹"写成决策变量的泛函，解最优控制问题：状态 $\mathbf{x} = (q, \dot q)$，控制 $\mathbf{u}$（力矩级或加速度级），动力学 $\dot{\mathbf{x}} = f(\mathbf{x}, \mathbf{u})$，

$$
\min_{\mathbf{x}(\cdot),\, \mathbf{u}(\cdot)} \ \int_0^T \ell\big(\mathbf{x}(t), \mathbf{u}(t)\big)\, \mathrm{d}t + \ell_f\big(\mathbf{x}(T)\big) \qquad \text{s.t.} \quad \dot{\mathbf{x}} = f(\mathbf{x}, \mathbf{u}), \quad \mathbf{x}(0) = \mathbf{x}_0
\tag{4.1}
$$

（阶段代价 $\ell$ 可编码时间、能耗 $\lVert \mathbf{u} \rVert^2$、控制量惩罚；$\ell_f$ 编码终端目标。）第 03 章的路径用于两处：给 $\mathbf{x}(0), \mathbf{x}(T)$ 定端点、给迭代求解器当初值。

**③ 选型理由** 备选方案：对路标做样条插值——光滑有了，但**无最优性**（插值不问"这样走省不省力"），也不保证动力学可行；(4.1) 的价值在于把全部 desiderata 统一进一个泛函，光滑性、能耗、时间都是 $\ell$ 的设计选项。代价：要解一个泛函极值问题——怎么解，正是本章其余部分的内容。

**④ 理论依据** 变分法（Euler-Lagrange 方程）；Pontryagin 极小值原理（Pontryagin et al., 1962）；Bellman 最优性与 HJB 方程（其"递推最优性"内核在第 05 章 MPC 展开）。

**⑤ 完整推导**（连续 OCP 的必要条件，Euler-Lagrange 路线）

**拉格朗日量。** 把动力学约束用乘子 $\boldsymbol{\lambda}(t)$（协态，costate）并入被积函数：

$$
\mathcal{L}\big(\mathbf{x}, \dot{\mathbf{x}}, \mathbf{u}, \boldsymbol{\lambda}\big) = \ell(\mathbf{x}, \mathbf{u}) + \boldsymbol{\lambda}^\top \big( f(\mathbf{x}, \mathbf{u}) - \dot{\mathbf{x}} \big)
\tag{4.2}
$$

则 $J = \int_0^T \mathcal{L}\, \mathrm{d}t + \ell_f(\mathbf{x}(T))$（依据：约束优化的 Lagrange 乘子法在泛函上的推广）。极值解对任意变分 $\delta \mathbf{x}, \delta \mathbf{u}$ 满足一阶变分 $\delta J = 0$。

**对 $\mathbf{x}$ 的变分：分部积分。** $\delta J$ 中含 $\delta \dot{\mathbf{x}}$ 的项无法直接与 $\delta\mathbf{x}$ 的系数合并——分部积分（依据：$\int \boldsymbol{\lambda}^\top \delta\dot{\mathbf{x}}\, \mathrm{d}t = \big[\boldsymbol{\lambda}^\top \delta\mathbf{x}\big]_0^T - \int \dot{\boldsymbol{\lambda}}^\top \delta\mathbf{x}\, \mathrm{d}t$）。边界项 $\big[\boldsymbol{\lambda}^\top \delta\mathbf{x}\big]_0^T$ 中 $\delta\mathbf{x}(0) = 0$（起点固定）；$\delta\mathbf{x}(T)$ 自由，但它与终端代价变分 $\delta\ell_f = \ell_{f,x}^\top \delta\mathbf{x}(T)$ 合并处理（见 (4.4) 的横截条件）。对任意 $\delta\mathbf{x}(t)$（$t \in (0,T)$）令 $\delta J = 0$，由变分法基本引理（依据：$\delta\mathbf{x}$ 任意 ⇒ 被积系数逐点为零）得：

$$
\frac{\partial \mathcal{L}}{\partial \mathbf{x}} - \frac{\mathrm{d}}{\mathrm{d}t} \frac{\partial \mathcal{L}}{\partial \dot{\mathbf{x}}} = 0 \ \Longrightarrow\ \ell_x + f_x^\top \boldsymbol{\lambda} + \dot{\boldsymbol{\lambda}} = 0
\tag{4.3}
$$

（依据：$\partial\mathcal{L}/\partial\mathbf{x} = \ell_x + f_x^\top\boldsymbol{\lambda}$、$\partial\mathcal{L}/\partial\dot{\mathbf{x}} = -\boldsymbol{\lambda}$ 代入整理。）

**对 $\mathbf{u}$ 的变分。** $\mathcal{L}$ 不含 $\dot{\mathbf{u}}$，无需分部积分，同理得平稳性（stationarity）$\ell_u + f_u^\top \boldsymbol{\lambda} = 0$。

**Pontryagin 极小值原理的表述。** 定义哈密顿量（把 (4.2) 中 $-\dot{\mathbf{x}}$ 项的贡献分离）：

$$
H(\mathbf{x}, \mathbf{u}, \boldsymbol{\lambda}) = \ell(\mathbf{x}, \mathbf{u}) + \boldsymbol{\lambda}^\top f(\mathbf{x}, \mathbf{u}); \qquad \dot{\mathbf{x}} = \tfrac{\partial H}{\partial \boldsymbol{\lambda}}, \quad -\dot{\boldsymbol{\lambda}} = \tfrac{\partial H}{\partial \mathbf{x}}, \quad \tfrac{\partial H}{\partial \mathbf{u}} = 0, \quad \boldsymbol{\lambda}(T) = \ell_{f,x}
\tag{4.4}
$$

（协态方程即 (4.3) 改写；$\partial H/\partial \mathbf{u} = 0$ 即平稳性，$H$ 对 $\mathbf{u}$ 凸时等价于"$\mathbf{u}^*$ 极小化 $H$"——Pontryagin 原理的极小条件；末式为横截条件，依据：边界项 $-\boldsymbol{\lambda}(T)^\top \delta\mathbf{x}(T)$ 与 $\ell_{f,x}^\top\delta\mathbf{x}(T)$ 对任意 $\delta\mathbf{x}(T)$ 求和为零。）PMP 给出的是**必要条件**；值函数视角的充分刻画是 HJB 方程——其动态规划内核留待第 05 章。

**间接法的困难。** (4.4) 是**两点边值问题**（two-point boundary value problem）：$\mathbf{x}(0)$ 已知、$\boldsymbol{\lambda}(T)$ 已知，但两者分处时间轴两端——数值上只能对未知的 $\boldsymbol{\lambda}(0)$ 打靶迭代；协态沿时间指数放大，打靶对初值极其敏感（病态，定性）。这把实用求解器推向两条路：**直接法**（把 (4.1) 离散成大规模 NLP，交给通用求解器）与**DDP**（利用动力学链式结构递推）——下一节。

## 04.2 iLQR / DDP（压轴）

**① 问题场景** (4.1) 数值上必须离散：把 $[0,T]$ 切成 $N$ 段。间接法已因两点边值退出实用；剩下的选择是"交给通用 NLP 求解器，还是利用问题的链式结构"。手头有：可微动力学模型 $f$（能求雅可比）、第 03 章路径加时间分配充当初值；想要：每个控制周期毫秒级收敛、并且**顺手给出反馈增益**的求解器——执行时状态总会偏离标称，纯开环轨迹一遇扰动就废。

**② 解决方法** iLQR / DDP：在标称轨迹处把 OCP **二次化**，用动态规划递推（Bellman 最优性逐级回代）求局部**仿射反馈策略** $\delta\mathbf{u} = \mathbf{k} + K\,\delta\mathbf{x}$，再前向滚动更新标称，迭代至收敛。反向扫一遍得到全时域增益，前向扫一遍得到新轨迹——两次 $O(N)$ 的结构化扫描替代一次通用 NLP。

**③ 选型理由** 三个候选对比。(a) **直接打靶**（direct shooting）：决策变量只有控制序列 $\mathbf{u}_{0:N-1}$，状态由模拟产生——变量最少，但代价对早期控制的梯度要穿过整条动力学链传播，雅可比病态、对初值敏感（早期一步错，处处错）；且反馈增益要事后另解一个沿轨迹的 LQR。(b) **配点法**（direct collocation）：状态与控制**都是**决策变量，动力学离散化写成等式约束（梯形/Hermite–Simpson 格式）——问题大但约束稀疏、数值鲁棒，通用 NLP（如 IPOPT）成熟；代价是规模 $O(N(n_x + n_u))$，且同样不直接给反馈。(c) **DDP/iLQR**：递推利用"状态只依赖上一状态"的链式结构，每步只解一个 $(n_x + n_u)$ 维的小线性系统，总计 $O(N)$ 个——比通用 NLP 的整体 $O\big((N n_x)^3\big)$ 量级友好；局部二次收敛（本质是沿轨迹的 Newton 法）；**反向扫天然产出全时域反馈增益 $K_i$**——MPC（第 05 章）与执行层都要用。代价：只保证局部最优、导数实现易错。工程落地见 Crocoddyl（④）。

**④ 理论依据** DDP：Mayne (1966) 奠基、Jacobson & Mayne, *Differential Dynamic Programming*, 1970；iLQG：Tassa, Erez, Todorov, ICRA 2012；控制受限形式：Tassa, Mansard, Todorov, ICRA 2014。Crocoddyl：Mastalli et al., *Crocoddyl: An Efficient and Versatile Framework for Multi-Contact Optimal Control*, ICRA 2020（本地 [frontier/arXiv-1909.04947_Crocoddyl.pdf](../../papers/control_planning/frontier/arXiv-1909.04947_Crocoddyl.pdf)）——稀疏**解析导数**（基于 Pinocchio 的刚体动力学解析雅可比，避免有限差分的 $D$ 次模拟与数值噪声）+ **多接触** OCP（接触/冲量作为阶段模型进同一递推）+ FDDP 全局化；论文展示毫秒级求解跳跃、前空翻等高动态机动。

**⑤ 完整推导**（iLQR 主线；DDP 的二阶差异单独标注）

**离散化与记号。** 欧拉离散（$\Delta t$ 并入 $\ell$，定性）：

$$
\mathbf{x}_{i+1} = f(\mathbf{x}_i, \mathbf{u}_i), \qquad J = \sum_{i=0}^{N-1} \ell(\mathbf{x}_i, \mathbf{u}_i) + \ell_f(\mathbf{x}_N)
\tag{4.5}
$$

标称轨迹 $(\hat{\mathbf{x}}_i, \hat{\mathbf{u}}_i)$ 精确满足动力学（前向 rollout 保证）；扰动 $\delta\mathbf{x}_i = \mathbf{x}_i - \hat{\mathbf{x}}_i$、$\delta\mathbf{u}_i = \mathbf{u}_i - \hat{\mathbf{u}}_i$。以下各雅可比均在标称处取值，$V'$ 表示下一时刻的值函数量。

**值函数二次近似。** 在标称处 Taylor 展开（依据：多元函数 Taylor 展开，$V_{xx}$ 对称）：

$$
V(\delta\mathbf{x}) = V_x^\top \delta\mathbf{x} + \tfrac{1}{2}\, \delta\mathbf{x}^\top V_{xx}\, \delta\mathbf{x} + \text{const}
\tag{4.6}
$$

**Q 函数（Bellman 回代一步）。** 依据 Bellman 最优性，"本步代价 + 后续最优"可折叠为：

$$
Q(\delta\mathbf{x}, \delta\mathbf{u}) = \ell\big(\hat{\mathbf{x}} + \delta\mathbf{x},\, \hat{\mathbf{u}} + \delta\mathbf{u}\big) + V\big( f(\hat{\mathbf{x}} + \delta\mathbf{x},\, \hat{\mathbf{u}} + \delta\mathbf{u}) \big)
\tag{4.7}
$$

动力学一阶展开 $f \approx \hat{\mathbf{x}}' + f_x\,\delta\mathbf{x} + f_u\,\delta\mathbf{u}$（标称精确在轨，常数项归零），与 (4.6) 一起代入 (4.7)，保留至二阶（依据：链式法则逐项展开；四个块的每一项都是"阶段量 + 动力学线性映射搬运下一时刻值函数量"）：

$$
Q_x = \ell_x + f_x^\top V_x' \qquad Q_u = \ell_u + f_u^\top V_x'
\tag{4.8}
$$

$$
Q_{xx} = \ell_{xx} + f_x^\top V_{xx}'\, f_x \qquad Q_{ux} = \ell_{ux} + f_u^\top V_{xx}'\, f_x \qquad Q_{uu} = \ell_{uu} + f_u^\top V_{xx}'\, f_u
\tag{4.9}
$$

**DDP 相对 iLQR 的二阶项差异。** (4.9) 只用了一阶动力学展开——这正是 **iLQR**（"LQR 化"）的取舍。DDP 把 $f$ 展开到**二阶**，由复合函数二阶导法则（外层 Hessian 项 + 内层 Hessian 以外层梯度加权），(4.9) 各块额外增加：

$$
Q_{xx} \supset \sum_j V'_{x,\,j}\, f_{xx,\,j} \qquad Q_{ux} \supset \sum_j V'_{x,\,j}\, f_{ux,\,j} \qquad Q_{uu} \supset \sum_j V'_{x,\,j}\, f_{uu,\,j}
\tag{4.10}
$$

（依据：$\partial^2 V(f)/\partial z^2 = f_z^\top V_{xx}' f_z + \sum_j V'_{x,j}\, \partial^2 f_j / \partial z^2$ 的复合求导；$z$ 依次取 $\mathbf{x}, \mathbf{u}$。标志性差异项是 $Q_{xx}$ 中的 $f_{xx} V_x'$。）二阶项带来更快的局部收敛，代价是动力学的 Hessian 实现成本——Crocoddyl 的解析导数正是为消掉这一痛点。

**对 $\delta\mathbf{u}$ 极小化。** (4.7) 是 $(\delta\mathbf{x}, \delta\mathbf{u})$ 的二次型，驻点条件 $\partial Q/\partial\delta\mathbf{u} = Q_u + Q_{uu}\,\delta\mathbf{u} = 0$（依据：矩阵微积分 $\partial(g^\top z)/\partial z = g$、$\partial(z^\top H z)/\partial z = 2Hz$）解出**仿射反馈策略**：

$$
\delta\mathbf{u}^* = \mathbf{k} + K\, \delta\mathbf{x}, \qquad \mathbf{k} = -Q_{uu}^{-1} Q_u, \qquad K = -Q_{uu}^{-1} Q_{ux}
\tag{4.11}
$$

（依据：二次函数极小，需 $Q_{uu} \succ 0$——不正定时正则化，见 (4.14)。）$\mathbf{k}$ 是前馈修正、$K$ 是反馈增益——**打靶法与配点法都没有的副产品**。

**反向递推。** 把 (4.11) 代回 (4.6) 的极小化结果 $V = \min_{\delta\mathbf{u}} Q$，对 $\delta\mathbf{x}$ 求梯度与 Hessian（依据：复合二次型求导；再代入 $Q_u = -Q_{uu}\mathbf{k}$、$Q_{ux} = -Q_{uu}K$ 化简）：

$$
V_x' = Q_x + Q_{ux}^\top \mathbf{k} + K^\top Q_u + K^\top Q_{uu}\, \mathbf{k} = Q_x - K^\top Q_{uu}\, \mathbf{k}
\qquad V_{xx}' = Q_{xx} - K^\top Q_{uu}\, K
\tag{4.12}
$$

单步代价改善（前向线搜索的预期量）：$\Delta V = -\tfrac{1}{2} Q_u^\top Q_{uu}^{-1} Q_u \le 0$（$Q_{uu} \succ 0$ 时；依据：配方法）。沿 $i = N-1, \dots, 0$ 反向扫一遍，(4.8)–(4.12) 逐级递推。

**前向 rollout。** 用 (4.11) 的策略重新滚动轨迹：

$$
\tilde{\mathbf{x}}_{i+1} = f\big( \tilde{\mathbf{x}}_i,\ \mathbf{u}_i + \alpha\, \mathbf{k}_i + K_i (\tilde{\mathbf{x}}_i - \hat{\mathbf{x}}_i) \big), \qquad \alpha \in (0, 1]
\tag{4.13}
$$

（依据：线搜索步长 $\alpha$ 缩放前馈；反馈项 $K_i(\tilde{\mathbf{x}}_i - \hat{\mathbf{x}}_i)$ 使 rollout 对中间偏离鲁棒——这是打靶法线性更新所没有的结构。）接受准则：实际代价下降应逼近预期下降 $\alpha \Delta V$ 量级（依据：Tassa 2012/2014 的 Armijo 型条件，定性）。"反向递推 (4.8)–(4.12) → 前向滚动 (4.13)"构成一次迭代，循环至代价收敛。

**正则化。** 远离最优或动力学病态时 $Q_{uu}$ 可能不正定，(4.11) 不可解。改用阻尼逆：

$$
\mathbf{k} = -\big( Q_{uu} + \mu I \big)^{-1} Q_u, \qquad K = -\big( Q_{uu} + \mu I \big)^{-1} Q_{ux}
\tag{4.14}
$$

（依据：与 [SLAM 教程第 08 章](../slam/08_后端-ii图优化与-ba.md)的 Levenberg–Marquardt 阻尼 (8.6) **完全同构**——$(Q_{uu} + \mu I)$ 的最小特征值 $\ge \mu > 0$（(8.7) 同理），线性系统恒可解且更新方向恒为下降方向；$\mu$ 的自适应（失败增大、成功减小）即信赖域逻辑。）同一阻尼技巧在后端优化与轨迹优化中重复出现——"二次近似 + 阻尼信赖域"是非线性优化的通用骨架。

## 04.3 微分平坦与最小 snap

**① 问题场景** 四旋翼穿越一串走廊航点：用 04.2 的 DDP 全套求解，需要完整动力学模型、初值与毫秒级算力，而飞控里位置轨迹每秒就要重算。手头有航点序列与四旋翼的动力学结构；想要：一个把动力学约束"预先吸收"、能写成凸问题毫秒级求解的轨迹参数化。

**② 解决方法** 微分平坦（differential flatness）：若存在**平坦输出** $\mathbf{y}$ 与整数 $s$，使全状态与控制可由 $\mathbf{y}$ 及其有限阶导数**代数地**表出：

$$
\mathbf{x} = \Phi\big(\mathbf{y}, \dot{\mathbf{y}}, \dots, \mathbf{y}^{(s)}\big), \qquad \mathbf{u} = \Psi\big(\mathbf{y}, \dot{\mathbf{y}}, \dots, \mathbf{y}^{(s)}\big)
\tag{4.15}
$$

则"轨迹满足动力学"等价于"$\mathbf{y}(t)$ 足够光滑"——动力学等式约束 (4.1) 被参数化**吸收**，剩余约束（节点连续性、走廊）都是系数的线性约束。四旋翼的平坦输出：$\mathbf{y} = (p_x, p_y, p_z, \psi)$（位置 + 偏航）。把轨迹设为分段多项式，以"最小化 snap（四阶导）"为目标、连续性为约束，得到一个 QP。

**③ 选型理由** vs DDP：平坦性把 (4.1) 从"带等式约束的非凸泛函极小"降为**凸 QP**——快、且凸性带来全局最优与可预测的求解时间；代价有二：平坦性是**系统专属**的结构性质（四旋翼有、一般机械臂与腿式平台没有），且只能优化 $\mathbf{y}$ 上可表达的代价（接触力等不进目标）。工程范式因此分工：四旋翼走廊轨迹用最小 snap，接触丰富的腿式/机械臂任务用 Crocoddyl 式 DDP——两者不竞争，按系统结构选。

**④ 理论依据** 微分平坦：Fliess, Lévine, Martin, Rouchon (1995)；系统化表述见 Murray, Rathinam & van Nieuwstadt (1998)（延伸阅读）；最小 snap：Mellinger & Kumar, *Minimum Snap Trajectory Generation and Control for Quadrotors*, ICRA 2011（延伸阅读，论文库未收录）。

**⑤ 完整推导**

**四旋翼的平坦性映射（为什么是位置 + yaw）。** 质心动力学（依据：牛顿第二定律，$\mathbf{e}_3$ 竖直向上，$f$ 为总推力、$R$ 为姿态）：

$$
m\, \mathbf{a} = f\, R\, \mathbf{e}_3 - m g\, \mathbf{e}_3 \ \Longrightarrow\ f\, R\, \mathbf{e}_3 = m\big(\mathbf{a} + g\, \mathbf{e}_3\big)
\tag{4.16}
$$

即推力**方向**由 $\mathbf{a}$ 确定（$R\mathbf{e}_3 = (\mathbf{a} + g\mathbf{e}_3)/\lVert \mathbf{a} + g\mathbf{e}_3 \rVert$）、推力**大小**由 $\lVert \mathbf{a} + g\mathbf{e}_3 \rVert$ 确定；yaw $\psi$ 固定绕竖直轴的自转自由度——$SO(3)$ 的三个自由度恰好被 $(\mathbf{a}, \psi)$ 参数化（依据：旋转矩阵列向量由"推力方向 + 绕其转角"决定）。继续求导：推力方向单位向量 $\mathbf{r}$ 的变化率由机体角速度实现（依据：旋转运动学 $\dot{\mathbf{r}} = \boldsymbol{\omega} \times \mathbf{r}$），故 $\boldsymbol{\omega}$ 由 **jerk**（$\dot{\mathbf{a}}$）确定；机体力矩由牛顿–欧拉 $\boldsymbol{\tau} = I\dot{\boldsymbol{\omega}} + \boldsymbol{\omega} \times I\boldsymbol{\omega}$ 给出，故 $\boldsymbol{\tau}$ 由 **snap**（$\ddot{\mathbf{a}}$）确定——全状态与控制均由 $(\mathbf{p}, \psi)$ 的前四阶导数代数表出，(4.15) 成立（完整映射表见 Mellinger & Kumar 2011）。

**为什么最小化 snap（逐阶论证）。** 每一阶"必须连续"都有物理依据：

1. **位置连续**——刚体不能瞬移（物理依据：刚体性）。
2. **加速度连续**——(4.16) 表明加速度直接给出推力向量：$\mathbf{a}$ 跳变 ⟺ 推力瞬间跳变，而电机推力带宽有限、物理上做不到（物理依据：执行器带宽）。
3. **jerk 连续**——jerk 决定角速度 $\boldsymbol{\omega}$：jerk 跳变 ⟺ 角速度指令跳变，超出 rate-loop 带宽与陀螺仪测量能力（物理依据：姿态环带宽）。
4. **snap 最小化**——snap 决定机体力矩 $\boldsymbol{\tau}$：力矩是电机的**直接指令**，其跳变意味着电流冲击与机体柔性模态激励（物理依据：Mellinger & Kumar 2011 的平坦性映射）。故取目标 $\min \int \lVert \mathbf{p}^{(4)}(t) \rVert^2 \mathrm{d}t$——推到四阶导、最小化 snap，就是"逐阶满足执行器物理，到最后一阶取平方积分最小"。

**多项式参数化。** 每段每轴 $p_i(t) = \sum_{j=0}^{n} c_{ij}\, t^j$，$t \in [0, T_i]$（依据：多项式任意阶可导，导数仍是多项式——与"逐阶连续"的要求匹配）。若要求 $p, v, a, \mathrm{jerk}$（0 至 3 阶导）在段间节点连续，每段在两端各提供 $m = 4$ 个边界条件，共 $2m = 8$ 个（依据：Hermite 插值计数），次数 $2m - 1 = 7$ 恰好提供 8 个系数；工程上常取 9 次以同时约束 snap 连续（Mellinger 常用，定性）：

$$
\text{段间连续：}\quad p_i^{(k)}(T_i) = p_{i+1}^{(k)}(0), \qquad k = 0, 1, 2, 3
\tag{4.17}
$$

（依据：多项式在端点的求值与求导是系数的**线性**运算——这是约束"线性"的来源。）

**最终 QP。** 把上面的 snap 积分写成系数二次型并编号（依据：多项式四阶导的平方积分有闭式，$Q$ 块对角且解析可积）：

$$
J = \sum_{\text{轴}} \sum_{i} \int_0^{T_i} \big\lVert p_i^{(4)}(t) \big\rVert^2\, \mathrm{d}t = \mathbf{c}^\top Q\, \mathbf{c}
\tag{4.18}
$$

$$
\min_{\mathbf{c}}\ \mathbf{c}^\top Q\, \mathbf{c} \quad \text{s.t.} \quad A_{\text{eq}}\, \mathbf{c} = \mathbf{b} \ \big(\text{(4.17) + 端点边界}\big), \quad A_{\text{in}}\, \mathbf{c} \le \mathbf{d} \ \big(\text{走廊 / 速度上限，可选}\big)
\tag{4.19}
$$

（依据：各轴经平坦映射解耦——$x/y/z$ 互不耦合，代价与约束按轴分块，可分轴求解。）只有等式约束时 KKT 条件是线性方程组，有**闭式解**（Mellinger 的做法）；含走廊等不等式时是标准 QP，毫秒级。注意各段时长 $T_i$ 是外层参数：固定后问题为凸 QP；$T_i$ 本身用搜索/启发式给定（时间分配改变凸性，定性）。

## 本章要点

- 轨迹优化 = 时间参数化上的 OCP (4.1)：$\min \int \ell\, \mathrm{d}t + \ell_f$ s.t. $\dot{\mathbf{x}} = f$；第 03 章路径供端点与初值。
- 变分法必要条件 (4.2)–(4.4)：$H = \ell + \boldsymbol{\lambda}^\top f$、$-\dot{\boldsymbol{\lambda}} = \partial H/\partial\mathbf{x}$、$\partial H/\partial\mathbf{u} = 0$、横截 $\boldsymbol{\lambda}(T) = \ell_{f,x}$；间接法因此是两点边值问题——病态，退出实用。
- iLQR 主线：值函数二次化 (4.6) → $Q$ 的四块展开 (4.8)–(4.9) → 增益 $\mathbf{k}, K$ (4.11) → 反向递推 (4.12) → 前向 rollout (4.13)；副产品是全时域反馈增益。
- DDP 与 iLQR 的差异是二阶动力学导数项 $f_{xx} V_x'$ 等 (4.10)：收敛更快、实现更贵；Crocoddyl 用解析导数 + 多接触阶段模型把它工程化（毫秒级高动态机动）。
- $Q_{uu}$ 不正定时用 $(Q_{uu} + \mu I)^{-1}$ (4.14)——与 SLAM 第 08 章 LM 阻尼 (8.6) 同构，"二次近似 + 阻尼信赖域"是通用骨架。
- 打靶（变量少但病态）vs 配点（大而稳）vs DDP（结构化 + 反馈增益）：按规模、算力与是否需要反馈选。
- 微分平坦 (4.15)：四旋翼平坦输出 = 位置 + yaw；推力、角速度、力矩分别由加速度、jerk、snap 决定 (4.16)——最小化 snap 的逐阶物理链即"满足执行器物理到最后一阶"。
- 最小 snap = 多项式系数 QP (4.17)–(4.19)：连续性是线性约束、各轴解耦、等式约束下有闭式解；段时长是外层参数。
