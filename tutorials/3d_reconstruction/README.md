# 3D 重建 — 教程架构

> **主题**：3D Reconstruction（从二维图像恢复三维结构与外观）
> **状态**：10 章全部完成 ｜ 主线论文：COLMAP、KinectFusion、MVSNet、DeepSDF、NeuS、3DGS、DUSt3R

本文件是 3D 重建教程的**架构规划**：先为每章定下问题场景锚点与推导产出清单，
后续各章按 [CONSTRAINTS.md §3.4](../../CONSTRAINTS.md) 五步法

## 教程主线（一句话）

手头只有一组二维图像（偶尔带深度），想要机器人能查询的三维模型——
重建因此分成两级：先从多视图几何中**估计**相机位姿与深度（SfM / MVS），
再把多次带噪观测**融合**成统一表示（TSDF → 网格；或直接学出隐式场 / 3D 高斯）；
现代前馈方法（DUSt3R 等）则把"估计 + 融合"一并交给网络一次推理完成。

## 各章架构明细

### 01｜3D 重建问题与表示全景

- **问题场景**：给机器人扫一圈照片/深度图，它需要一张能回答"点 x 处有没有表面、
  法向朝哪、离多远"的模型；不同下游任务（渲染 / 碰撞 / 抓取）对表示的要求不同。
- **解决方法概览**：把重建形式化为"图像集 → 表面 S（或场 f：$\mathbb{R}^3 \to \mathbb{R}$）"；
  给出表示谱系：显式（点云 / 体素 / TSDF / 网格 / 3D 高斯）与隐式（SDF / 占据 / 辐射场），
  按"内存 / 可微性 / 查询方式 / 编辑性"四维对比。
- **选型理由**：没有万能表示——渲染选 3DGS/隐式场，碰撞查询选 SDF/TSDF，编辑选网格；
  本教程按"几何估计 → 融合 → 提取 / 学习"的历史主线组织章节。
- **理论依据**：综述与教材（[papers/3d_reconstruction/](../../papers/3d_reconstruction/README.md)）。
- **推导产出**：重建问题的形式化定义；SDF 的符号约定与正负号判定；TSDF 查询线性插值公式。

### 02｜多视图几何与 SfM

- **问题场景**：上百张无序照片，相机内外参、三维点全部未知——先有相机才能三角化点，
  先有点才能标定相机，又一处"鸡生蛋"。
- **解决方法概览**：增量式 SfM：两视图初始化 → 三角化 → PnP 注册新视图 → 局部/全局 BA 循环。
- **选型理由**：为何增量式而非全局式 / 层级式——鲁棒、可逐步验证；代价是漂移与重复初始化。
- **理论依据**：对极几何（回引 [SLAM 教程第 05 章](../slam/05_视觉里程计-i特征点法.md)）、
  光束法平差（回引 [第 08 章](../slam/08_后端-ii图优化与-ba.md)）。
- **推导产出**：三角化（中点法 / DLT）的完整推导；BA 目标函数在此处的形式；
  增量式 SfM 的可行图（scene graph）生长逻辑。

### 03｜多视图立体重建 MVS

- **问题场景**：位姿已知，仍缺稠密深度：稀疏点云之间的表面在哪？逐像素立体匹配如何跨多视图一致。
- **解决方法概览**：传统路线（COLMAP）：深度假设上算光度一致性 → 视图选择 → 深度图融合；
  学习路线（MVSNet）：平面扫描代价体 + 3D 卷积正则 + 软 argmin 回归深度。
- **选型理由**：光度一致性在弱纹理 / 反射面失效，学习先验补足；代价体显存的代价与正则的收益。
- **理论依据**：平面扫描的单应几何、NCC 匹配代价、方差正则（MVSNet, Yao et al., ECCV 2018）。
- **推导产出**：平面扫描的深度—单应变换推导；NCC 代价；软 argmin 的可微性论证；
  深度图融合为点云/TSDF 的几何依据（法向一致性）。

### 04｜RGB-D 融合与 TSDF

- **问题场景**：每帧深度图带噪、只覆盖局部、位姿还有误差；逐帧独立存点云必然重复与冲突。
- **解决方法概览**：KinectFusion 管线：ICP 跟踪 → TSDF 融合 → 光线投射；BundleFusion 加入
  稀疏特征 + 全局回环（surface reintegration）。
- **选型理由**：TSDF 把"多帧融合"变成"加权平均"这一 Streaming 友好操作，GPU 实时；
  代价是固定体积网格的内存墙（引出八叉树 / 哈希表 / 逐场景优化各路线）。
- **理论依据**：截断符号距离函数（Curless & Levoy, SIGGRAPH 1996）、点到面 ICP。
- **推导产出**：TSDF 定义与截断宽度 $\mu$ 的推导（为何截断：可见性 + 噪声模型）；
  加权融合公式的推导（两帧观测的最小方差融合）；点到面 ICP 的线性化求解；
  光线投射的步长推进推导。

### 05｜从体素到网格：表面提取

- **问题场景**：TSDF 体素与点云都不是可渲染 / 可碰撞的连续表面，游戏与仿真引擎要的是网格。
- **解决方法概览**：Marching Cubes 在等值面 $f=0$ 上生成三角片；Poisson 重建把"带法向的点云"
  变成指示函数的梯度场问题，全局求解。
- **选型理由**：MC 局部快但有拓扑歧义；Poisson 全局一致、抗噪，代价是求解规模与光滑偏置。
- **理论依据**：等值面提取（Lorensen & Cline, SIGGRAPH 1987）、散度定理与指示函数梯度
  （Kazhdan et al., SGP 2006）。
- **推导产出**：MC 的 256 case 与等值线插值；Poisson 方程 $\nabla \cdot \nabla \chi = \nabla \cdot \vec V$
  从"指示函数梯度 = 法向场"的完整推导。

### 06｜学习式形状表示：SDF 与占据

- **问题场景**：单视图 / 稀疏扫描欠约束——看不见的背面必须"猜"；手工正则猜不准，数据里藏着先验。
- **解决方法概览**：用神经网络拟合 $f_\theta(x) \to$ SDF / 占据概率；DeepSDF 用自解码器把
  形状压进隐空间，Occupancy Networks 把占据判别改为连续隐函数。
- **选型理由**：SDF/占据是"查询即得"的连续表示，比体素省内存、比点云/网格易微分；
  代价是 Eikonal 约束与训练技巧（引出第 07 章）。
- **理论依据**：符号距离函数的 Eikonal 方程 $|\nabla f| = 1$、自编码器 / 隐空间（DeepSDF,
  CVPR 2019；Occupancy Networks, CVPR 2019）。
- **推导产出**：SDF 定义与 Eikonal 方程推导；DeepSDF 损失函数各项含义；占据概率与
  Lambert-W 饱和技巧（ONet）。

### 07｜神经隐式表面重建

- **问题场景**：NeRF 体渲染只优化外观，密度 $\sigma$ 不等于几何表面，深度/法向提取质量差。
- **解决方法概览**：NeuS 设计"SDF → 渲染权重"的转换：以 SDF 零水平集为表面，用
  logistic 密度分布构造权重，使权重在表面处无偏；Neuralangelo 用多分辨率哈希 + 数值梯度恢复大尺度平滑几何。
- **选型理由**：无偏性是"渲染最小化 ⇒ 表面正确"的充分条件；对比 VolSDF 的另一种转换
  （指数密度）的偏差来源。
- **理论依据**：体渲染（回引 [NeRF 教程第 03 章](../nerf/03_数学原理与渲染方程.md)）、
  NeuS（Wang et al., NeurIPS 2021）。
- **推导产出**：logistic 密度分布 $\rho(t)$ 定义；权重函数 $w(t)$ 的推导与两个性质
  （无偏性 / 遮挡感知）的完整证明；Eikonal 正则项的作用推导。

### 08｜3D 高斯泼溅

- **问题场景**：NeRF 级渲染每帧数十万次网络查询，实时机器人场景不可接受；需要显式、
  光栅化友好、可微的原语。
- **解决方法概览**：各向异性 3D 高斯 + 仿射投影到 2D + 排序 alpha 混合 + 梯度驱动的
  自适应致密化/剪枝。
- **选型理由**：显式原语把"求交积分"换成"排序合成"，速度快两个量级且可编辑；
  代价是原语数量爆炸、对初始化（SfM 点云）敏感。
- **理论依据**：各向异性高斯的 EWA splatting（Zwicker et al., 2001）、3DGS
  （Kerbl et al., SIGGRAPH 2023）。
- **推导产出**：3D 协方差的 $R S S^\top R^\top$ 参数化（为何不直接学 $\Sigma$）；
  投影 Jacobian $J$ 与 2D 协方差 $\Sigma' = J W \Sigma W^\top J^\top$ 完整推导；
  alpha 混合（回引 NeRF 离散形式）与致密化的梯度判据。

### 09｜哈希编码与前馈重建

- **问题场景**：逐场景优化小时级、MLP 亿级查询，机器人等不及；能否"前馈"一次推理直接出几何。
- **解决方法概览**：Instant-NGP 用多分辨率哈希网格把网络缩小 10 倍、训练快 60 倍；
  DUSt3R/MASt3R 把两视图重建回归成 pointmap，跳过 SfM 标定。
- **选型理由**：哈希编码用"查表 + 冲突容忍"换掉巨型 MLP；前馈回归用海量数据先验
  换掉逐场景优化——两者是"更快"的两条互补路线（缓存 vs 先验）。
- **理论依据**：多分辨率哈希（Instant-NGP, Müller et al., SIGGRAPH 2022）、
  pointmap 表示（DUSt3R, CVPR 2024；MASt3R, ECCV 2024）。
- **推导产出**：哈希插值公式与冲突容忍论证；pointmap 的定义与两视图对齐
  （Procrustes / MASt3R 交叉注意力）推导概要。

### 10｜机器人场景中的重建实战与选型

- **问题场景**：机械臂要抓取：需要表面/法向/可抓取区域的可查询模型，还要与仿真、
  策略训练（RoboTwin）衔接——表示选错，下游全错。
- **解决方法概览**：机器人最常用的三级管线：RGB-D + TSDF（实时、可查询）→
  ESDF（碰撞）或网格（抓取采样）→ 学习先验补全（GraspNet 类）。
- **选型理由**：以"查询延迟 / 精度 / 更新频率 / 可微性"四维做选型矩阵；
  与 SLAM 教程（位姿从哪来）、NeRF 主题（外观从哪来）交汇。
- **理论依据**：TSDF→ESDF（Voxblox/FIESTA 路线）、抓取质量度量（GraspNet-1Billion,
  CVPR 2020；DexGraspNet, NeurIPS 2022）。
- **推导产出**：TSDF 梯度→ESDF 的推导；GraspNet 的抓取表示（7-DoF 夹爪位姿 + 碰撞体积）
  与评分回归概要；重建 → 抓取 → 仿真回流（RoboTwin 数字孪生）的完整管线图。
