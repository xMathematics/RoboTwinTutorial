## 1. 论文信息与一句话贡献

- **题目**：DeepSDF: Learning Continuous Signed Distance Functions for Shape Representation
- **作者**：Jeong Joon Park（华盛顿大学）、Peter Florence（MIT）、Julian Straub、Richard Newcombe、Steven Lovegrove（Facebook Reality Labs）
- **发表**：CVPR 2019；arXiv:1901.05103v1（本地 PDF 共 19 页 = 正文 8 页 + 补充材料 A–N 节，主文式 (1)–(10)、补充材料式 (11)–(19)——本文式号已逐条对照 PDF 排版核实）
- **一句话贡献**：用**隐码条件化**的连续带符号距离函数（Signed Distance Function, SDF）$f_\theta(\mathbf{z}, \mathbf{x})$ 表示**整个形状类别**——以自解码器（auto-decoder，无编码器）方案联合优化网络参数与每形状隐码，clamp 截断 L1 损失把容量集中在表面薄壳内，测试时对隐码做最大后验（MAP）优化即可从部分观测**补全**形状——连续、可微、带解析法向，模型仅 7.4 MB（其 Table 1：0.0074 GB），同时拿下复杂拓扑、闭合表面与定向法向三项体素 / 参数化方法无法兼得的性质。

## 2. 问题与动机

**要解决什么**（§1）：给"渲染、重建、机器人"一个**高保真、高效、可微**的 3D 形状表示。深度卷积网络直接推广到 3D 时空费内存；三角网格 / 四边形网格这类经典表面表示在训练上有难题（拓扑未知、顶点数不定），逼得多数学习方法退回体素或点云。

**既有表示的缺口**（§2，对照[第 01 章](../01_3D重建问题与表示全景.md) (1.5)–(1.8) 谱系）：
- **体素 / 八叉树体素**：立方内存墙（至多 $512^3$ 且视觉并不"高保真"）；离散 SDF 版内存更贵、分辨率更低。
- **点云**：不描述拓扑，出不了水密网格。
- **网格（模板 / 变形 / 学习图卷积）**：拓扑受限或需模板；AtlasNet 一类参数化补丁会撕裂、带洞。
- **自编码器学习隐空间**：编码器把"表示学习"的力气花在压缩上；对测试时"给定观测找码"（补全）这个真问题，训练好的编码器是否是计算资源的最佳用法存疑（§4.1）。

**DeepSDF 的两个关键决定**（§3–4）：其一，直接**回归连续 SDF**——一个查询点一个值，距离 + 法向（$\partial f_\theta/\partial \mathbf{x}$ 解析可得）+ 内外一体回答（[第 01 章](../01_3D重建问题与表示全景.md) (1.3) 三问）；其二，用**自解码器**学形状隐空间——每个训练形状配一个可学习隐码，与 $\theta$ 联合训练；测试时**优化隐码**而非过编码器。论文自称是"第一个把自解码器引入 3D 学习社区的工作"（§4.2，思路承 Tan et al. 的 Optimizing Latent Vectors）。

### 4.1 SDF 定义、零水平集与"距离"语义的边界（论文式 (1)–(3)）

论文式 (1)（PDF 第 3 页排版核对）：

$$SDF(\mathbf{x}) = s : \mathbf{x} \in \mathbb{R}^3,\ s \in \mathbb{R} \tag{1}$$

表面由**零水平集**（iso-surface $SDF(\mathbf{x}) = 0$）隐式表示（原文 §3 第一段）——与[第 01 章](../01_3D重建问题与表示全景.md) (1.13) 的定义一致：带符号**最近**欧氏距离、外正内负；其微分推论即 Eikonal 方程 $\|\nabla s\| = 1$（[教程 (6.1)](../06_学习式形状表示SDF与占据.md)，推导见 6.1 ⑤）。

**真 SDF ≠ 任意"看起来像距离"的场**（clamp 有效性的来源，无跳步论证）：
- 理想 SDF 沿法向每走单位长度值变 1（[教程第 06 章](../06_学习式形状表示SDF与占据.md) 6.1 ⑤ 第一步），故 $|s(\mathbf{x})|$ 恰是 $\mathbf{x}$ 到表面的欧氏距离；
- 但**学习到的** $f_\theta$ 只在损失有定义且非平凡的位置被拉向真值——4.2 将证明这是 $|s| \le \delta$ 的薄壳；壳外真值端被 clamp 成 $\pm\delta$ 的常数（不再携带距离信息）、预测端被 clamp 后梯度恒为零——$f_\theta$ 在壳外**既不保证 $\|\nabla f_\theta\| = 1$、也不保证 $|f_\theta|$ 等于真实距离**，甚至不保证在正确一侧更远处更大；
- 论文对此的处理不是加正则（**全文无 Eikonal / 梯度罚**），而是把"带外不携带信息"显式写进训练目标——这正是 clamp 有效性的来源：与其让网络在无监督区自由发挥、再被下游误读为距离，不如约定"只有薄壳内的值可信"。代价：下游把 $|f_\theta(\mathbf{z},\mathbf{x})|$ 当碰撞距离、把 $\nabla f_\theta$ 当避障方向时，只有薄壳内可靠（[第 01 章](../01_3D重建问题与表示全景.md) ③ 判据；与 ONet 对比见 §7）。

**单形状版本（式 (2)(3)）**：给定目标形状，准备训练对 $X := \{(\mathbf{x}, s) : SDF(\mathbf{x}) = s\}$（式 (2)），训练多层全连接网络 $f_\theta$ 使其在目标域 $\Omega$ 上逐点逼近（式 (3)）：

$$f_\theta(\mathbf{x}) \approx SDF(\mathbf{x}), \quad \forall \mathbf{x} \in \Omega \tag{3}$$

推理时查询零水平集即可（光线投射或 Marching Cubes）；法向由 $\partial f_\theta(\mathbf{x})/\partial \mathbf{x}$ 反传解析计算（原文 §3 末段）——在薄壳内 $f_\theta \approx s$，$\nabla f_\theta \approx \nabla s$，归一化后即单位法向（依据：[第 01 章](../01_3D重建问题与表示全景.md) (1.3) 的水平集梯度即法向）。

### 4.2 clamp 截断 L1 损失（论文式 (4)：注意是 L1 而非 L2）

论文式 (4)（PDF 第 4 页排版核对，逐字符核对为 **L1 范数**）：

$$\mathcal{L}\big(f_\theta(\mathbf{x}), s\big) = \big|\,\mathrm{clamp}(f_\theta(\mathbf{x}), \delta) - \mathrm{clamp}(s, \delta)\,\big| \tag{4}$$

$$\mathrm{clamp}(x, \delta) := \min\big(\delta,\ \max(-\delta,\ x)\big)$$

**逐项语义推导**：
- **真值端 clamp**：当 $|s| > \delta$，$\mathrm{clamp}(s,\delta) = \pm\delta$ 与 $s$ 的具体数值无关（依据：min/max 的饱和性）——带外真值只携带"至少 $\delta$ 远"的信息，表面的凹凸细节本就不写在远处距离值里；这与 TSDF 截断 [第 01 章](../01_3D重建问题与表示全景.md) (1.14) 的"截断换鲁棒"完全同构（$F = \mathrm{clamp}(s/\mu, 1)$，截断不动零点）。
- **预测端 clamp**：对预测求梯度，$\frac{\partial}{\partial f_\theta}\mathrm{clamp}(f_\theta, \delta) = \mathbb{1}[|f_\theta| < \delta]$（依据：$\min/\max$ 分段线性，饱和段导数为零）——带外预测**不产生梯度**，网络容量被自动集中到表面薄壳。
- **δ 的权衡**（原文 §3）：大 $\delta$——每个样本都提供"安全步长"信息 → 光线投射步进快、且物理仿真 / 机器人运动规划需要更大的度量 SDF 区域（补充材料 D.2）；小 $\delta$——更小的逼近域、更高的绝对精度，容量集中在表面细节。原文正文示例取 $\delta = 0.1$；补充材料 D.2 称"所有实验取 $\delta = 0.01$"（两处不一致，见 §7 偏离注记；物理含义不随取值变）。

**L1 与 L2 的差异**（教程 (6.4) 写成平方形式并加了事实注记；本精读以论文 L1 为准）：记残差 $r = \mathrm{clamp}(f_\theta,\delta) - \mathrm{clamp}(s,\delta)$：
- L1 对预测的（次）梯度为 $\mathrm{sign}(r)$（依据：$|r|$ 的分段线性），**幅值恒为 1**——远离最优处不放大、单个大残差样本也不会主导批次梯度（对离群采样 / 距离真值噪声更鲁棒，定性）；
- 平方损失梯度为 $2r$（依据：链式法则），正比残差——近表面处推动力变小（可能过早就近收敛），坏样本处以二次方放大；
- 概率视角（原文式 (8) 论述）：平方损失对应"SDF 值带高斯噪声"的似然假设，L1 对应重尾的拉普拉斯型假设——对网格非水密、双面剔除后近表面近似带来的粗大误差更稳健（定性）。clamp 后两种范数在带内的行为差异只在"远处残差的衰减速度"，教程由此在其 (6.4) 用平方形式统一记号并注明此差异。

### 4.3 形状空间：条件隐函数与自解码器（论文式 (5)–(7)、Fig. 3–4）

把单个形状的逼近（式 (3)）升级为**一族形状**：第 $i$ 个形状由隐码 $\mathbf{z}_i$ 索引（式 (5)）：

$$f_\theta(\mathbf{z}_i, \mathbf{x}_i) \approx SDF^i(\mathbf{x}) \tag{5}$$

训练对按形状组织为 $X_i = \{(\mathbf{x}_j, s_j) : s_j = SDF^i(\mathbf{x}_j)\}$（式 (6)）。**为何不需要编码器**（§4.1–4.2，"auto-decoder" 命名依据）：
- 自编码器用编码器把输入压进瓶颈——学的是"压缩"；而补全任务的推理形态是"给定观测、搜码"，编码器在测试时未必是最佳用途（原文 §4.1）；
- 自解码器做法：给每个训练形状随机初始化一个隐码 $\mathbf{z}_i$，与 $\theta$ 一起经标准反传联合优化（Fig. 4b）；推理时 $\theta$ 冻结、只搜 $\mathbf{z}$——把"编码"推迟到测试时按需进行，观测可以是**任意数量、任意分布**的 SDF 样本（4.5）。

**概率骨架（论文式 (7)）**：编码形状下，给定 $X_i$ 的隐码"后验"分解为：

$$p_\theta(\mathbf{z}_i \mid X_i) = p(\mathbf{z}_i) \prod_{(\mathbf{x}_j, s_j) \in X_i} p_\theta(s_j \mid \mathbf{z}_i; \mathbf{x}_j) \tag{7}$$

严格读法（补充材料 H 节给全推导）：这是**联合分布**的分解 $p_\theta(X_i, \mathbf{z}_i) = p_\theta(X_i \mid \mathbf{z}_i)\,p(\mathbf{z}_i)$（补充材料式 (13)），其中似然在"给定 $\mathbf{z}_i$ 各 SDF 样本条件独立"下分解为 $p_\theta(X_i \mid \mathbf{z}_i) = \prod_j p_\theta(s_j \mid \mathbf{z}_i; \mathbf{x}_j)$（补充材料式 (16)）；两者与"后验"差一个与 $\mathbf{z}$ 无关的归一化常数 $p(X_i)$（依据：贝叶斯法则 $p(\mathbf{z}\mid X) = p(X\mid\mathbf{z})p(\mathbf{z})/p(X)$），对 MAP 不产生影响。

### 4.4 先验、似然与联合训练目标（论文式 (8)–(9)）

**先验**：隐码取零均值球形高斯 $p(\mathbf{z}_i) = \mathcal{N}(\mathbf{0}, \sigma^2 I)$（原文：编码"形状码应聚集"的先念，经验上给出紧凑的形状流形并帮助收敛）。取负对数（依据：多元高斯密度 $\log p = -\frac{d}{2}\log 2\pi - d\log\sigma - \frac{\|\mathbf{z}\|^2}{2\sigma^2}$；与 $\mathbf{z}$ 无关的常数丢弃）：

$$-\log p(\mathbf{z}_i) = \frac{\|\mathbf{z}_i\|^2}{2\sigma^2} + \mathrm{const}$$

**似然（论文式 (8)）**：把损失指数化成似然（依据：原文"without loss of generality, assume that the likelihood takes the form"）：

$$p_\theta(s_j \mid \mathbf{z}_i; \mathbf{x}_j) = \exp\big(-\mathcal{L}(f_\theta(\mathbf{z}_i, \mathbf{x}_j),\, s_j)\big) \tag{8}$$

取负对数（依据：$\log$ 与 $\exp$ 相消）：$-\log p_\theta(s_j\mid\mathbf{z}_i;\mathbf{x}_j) = \mathcal{L}(\cdot) + \mathrm{const}$。若取 $\mathcal{L}$ 为平方损失，式 (8) 恰是高斯噪声似然（差一个可并入的温度常数）；实践取式 (4) 的 clamp L1（原文，理由见 4.2）。

**联合训练目标（论文式 (9)）**：MAP 的负对数表述，对 $\theta$ 与全部隐码联合最小化（PDF 第 5 页排版核对）：

$$\arg\min_{\theta, \{\mathbf{z}_i\}_{i=1}^N}\ \sum_{i=1}^{N}\left(\ \sum_{j=1}^{K} \mathcal{L}\big(f_\theta(\mathbf{z}_i, \mathbf{x}_j),\, s_j\big) + \frac{1}{\sigma^2}\|\mathbf{z}_i\|_2^2\ \right) \tag{9}$$

**推导链（每步依据）**：(i) 各形状的 $(X_i, \mathbf{z}_i)$ 独立同构 → 联合负对数按形状求和（依据：式 (7)/(13) 的分解）；(ii) 每形状内 $-\log p(X_i\mid\mathbf{z}_i) = \sum_j \mathcal{L}$（第三步 + 式 (16) 条件独立）；(iii) $-\log p(\mathbf{z}_i) = \|\mathbf{z}_i\|^2/(2\sigma^2)$（先验负对数）——**论文在此把系数写成 $1/\sigma^2$（无 $1/2$）**；由于 $\sigma$ 本是自由超参（实验 $\sigma = 10^{-2}$），差一个常数因子 2 可被 $\sigma$ 的标定吸收（$\sigma \leftarrow \sqrt{2}\,\sigma$），[教程 (6.5)](../06_学习式形状表示SDF与占据.md) 保留严格的 $1/(2\sigma^2)$ 记法——两种写法同一族目标，引用时对齐即可。补充材料式 (15) 还给出双层次视角：$\hat\theta = \arg\max_\theta \sum_i \max_{\mathbf{z}_i}\big(\log p_\theta(X_i\mid\mathbf{z}_i) + \log p(\mathbf{z}_i)\big)$（依据：先对每形状最大化隐码、再对参数最大化边际），实践中直接联合 SGD。

### 4.5 测试时优化：补全 = 对隐码的 MAP 推断（论文式 (10)）

训练完成、$\theta$ 冻结后，对任意观测 $X$ 估计隐码（PDF 第 5 页排版核对）：

$$\hat{\mathbf{z}} = \arg\min_{\mathbf{z}}\ \sum_{(\mathbf{x}_j, s_j) \in X} \mathcal{L}\big(f_\theta(\mathbf{z}, \mathbf{x}_j),\, s_j\big) + \frac{1}{\sigma^2}\|\mathbf{z}\|_2^2 \tag{10}$$

即式 (9) 去掉对 $\theta$ 的优化、只留一个形状的项（依据：式 (9) 取 $i$ 为待补全的单个形状、$\theta$ 固定）。**实现**（原文）：Adam 优化器，$\mathbf{z}$ 从 $\mathcal{N}(0, 0.01^2)$ 随机初始化，与 $\theta, \mathbf{x}$ 拼接后送入第一层、并在第四层再次注入。

**"任意数量与分布的样本皆可用"的论证**（原文紧接着式 (10) 的论断）：目标对 $\mathbf{z}$ 的梯度是各样本梯度的**和**（依据：求和的梯度 = 梯度的求和，逐项可算）——样本数与分布只改变求和的项数与权重，不改变可行性；因此深度图、部分点云、稀疏 SDF 采样都能直接喂进同一个目标。对比编码器路线：编码器期望"与训练分布同构的输入"（[ONet 精读](./OccupancyNetworks_CVPR2019.md) §6）。

**补全实验的具体化（§6.3）**：单视图深度图 → 对每个深度观测沿表面法向估计在其两侧各取距 $\eta$ 的一点，用 $\pm\eta$ 近似其 SDF 值（依据：距离场沿法向以单位速率变化——[教程第 06 章](../06_学习式形状表示SDF与占据.md) 6.1 ⑤ 第一步的局部线性化），并以 $\eta$ 为 clamp 值解式 (10)；再采样"表面到相机之间的空旷点"，加**空旷损失**：若 $f_\theta(\mathbf{z},\mathbf{x}_j) < 0$ 则罚 $|f_\theta(\mathbf{z},\mathbf{x}_j)|$、否则为 0（原文——即 $\max(-f_\theta, 0)$，只罚"把观测为空的地方判成内部"）。

### 4.6 架构与数据细节（§3、补充材料 C/D/F/G）

- **网络**：8 层全连接、内部 512 维、ReLU + dropout、输出 tanh；batch norm 不稳定，改用 weight normalization（原文）。补充材料 D.1：无跳跃连接时 4 层后训练损失进入平台，带跳跃（隐码注入第 1 层与中间层）后到 12 层仍在降——取 8 层折中（Fig. 13/14）。
- **数据生成（补充材料 F）**：形状归一化进单位球（留 1/1.03 余量）；100 个虚拟相机渲染、反投影得带法向表面点（约 25 万，按三角形面积加权），每个表面点再沿各轴加 $\sigma = 0.0025$ 与 $0.00025$ 两档高斯扰动、生成两个样本——合计约 50 万个表面样本（主文口径 "500,000 spatial points"），另在单位球内均匀采约 2.5 万个体点；非水密网格会先剔除双面三角形超 2% 者；每点符号由 KD-tree 最近表面点法向与 $(\mathbf{x} - \mathbf{y})$ 的点积判定（依据：外点与外法向夹角小于 90°）。
- **训练超参（补充材料 G）**：正负 SDF 样本各半（平衡内外类）；decoder 学习率 $10^{-5} \times B$（$B$ 为批内形状数）、隐码学习率 $10^{-3}$；$\sigma = 10^{-2}$；每形状每批采 16384 样本；8 块 GPU 约 8 小时 1000 轮；重建实验隐码 256 维、补全 128 维。
- **截断距离消融（补充材料 D.2）**：$\delta$ 增大 → 表面精度中度下降（更大逼近域更难达到同等绝对精度，定性）但度量 SDF 区域更大 → 光线投射更快、对物理仿真与运动规划更有用；这把"δ 的物理含义"从超参经验升格为可解释的权衡曲线（Fig. 15）。

## 5. 实验与结果解读

- **表示能力总览（Table 1）**：对比 3D-EPN（体素 SDF，$32^3$）、OGN（八叉树，$256^3$）、AtlasNet / AtlasNet-Sphere（参数化补丁）：只有 DeepSDF 同时勾选**复杂拓扑 + 闭合表面 + 定向法向**；离散化一栏为 "none"（连续）；模型 0.0074 GB（正文换算 7.4 MB，不到一张 $512^2$ 32 位高度图 16.8 MB 的一半）；推理 9.72 s（对比 OGN 前向 0.33 s；结论一节自认 auto-decoding 因需对隐码显式优化而明显更费时）。
- **记忆已知形状（§6.1，Table 2，ShapeNet 汽车，Chamfer $\times 10^3$、3 万点）**：DeepSDF **0.084（中位 0.058）**，约为 OGN（0.16/0.127）与 AtlasNet-25（0.157/0.149）的一半；EMD（500 点）上与 OGN 打平（0.043 vs 0.043）——原文解释：500 点采样不足以分辨更高的几何精度，Chamfer 大点数才量得出差距。
- **泛化到未知形状（§6.2，Table 3，5 类）**：Chamfer 均值上 DeepSDF 在 chair / plane / lamp / sofa 四类最佳（如 sofa 0.132 vs AtlasNet 系 0.411–0.445），仅 table 类略逊 AtlasNet-25（0.553 vs 0.328）；Chamfer 中位数、EMD、网格精度（mesh accuracy）则**五类全部最佳**（定性 + 已核数字）。定性上（Fig. 6）：AtlasNet 在椅背细节处糊掉、沙发和平面出现洞。
- **形状补全（§6.3，Table 4，单视图深度，对比 3D-EPN）**：Chamfer / EMD 大幅领先（如 plane 类 Chamfer 均值 1.16 vs 2.19），网格精度、网格完整度（mesh completion）、法向余弦相似度亦全面占优（chair 0.766 vs 0.752、plane 0.823 vs 0.710、sofa 0.810 vs 0.742）——**背面完全是先验"画"出来的**：解出的 $\hat{\mathbf{z}}$ 索引训练流形上与观测最吻合的形状，其未观测区域即先验猜测（与[教程 (6.5)](../06_学习式形状表示SDF与占据.md) 的直觉一致）。
- **隐空间性质**：插值平滑连续、中间形状有意义（Fig. 1）；补充材料 B：对深度图加逆向深度高斯噪声，补全质量的退化**远慢于**输入点云本身的退化——先验在起正则作用（Fig. 10–11，定性）；补充材料 E 在 MNIST 上对比自解码器与 VAE / AE：自解码器隐空间更紧凑光滑、按码优化解码不输端到端训练的 VAE/AE——为"auto-decoder 值得"提供的 2D 旁证。

## 6. 局限与后续影响

- **"距离"解释弱**：无 Eikonal 正则（全文无梯度罚项），clamp 又有意放弃带外——$f_\theta$ 只保证（薄壳内的）零水平集对，$\|\nabla f_\theta\| = 1$ 与壳外距离值皆不可依赖。后续工作沿两条路补足：显式加 Eikonal 罚——SIREN 一系把 $\|\nabla f\| = 1$ 作为正则项、NeuS 把 SDF 接入体渲染并以 Eikonal 罚（[教程第 07 章](../07_神经隐式表面重建.md) (7.9)，即 [教程 (6.1)](../06_学习式形状表示SDF与占据.md) 的训练化）保证 $\nabla f$ 是单位法向；NeuS 的精读暂未收录于本仓库 `精读/`（PDF 已在 `papers/3d_reconstruction/classics/arXiv-2106.10689_NeuS.pdf`）。
- **隐空间无显式结构**：先验只是训练正则；与 VAE 不同，没有编码器 / 解码器的概率一致性保证，插值与采样靠经验（原文补充材料 E 自比 VAE）。生成方向的完整化要等占据 / SDF 与扩散模型的结合（后续文献，此处不展开）。
- **推理时延**：补全要对 $\mathbf{z}$ 做迭代优化（其 Table 1 报 9.72 s/形状；结论一节把"换 Gauss-Newton 类二阶方法"列为未来工作）——与 ONet 编码器路线"一次前向"的取舍见 §7。
- **规范位姿假设**：模型假设 canonical pose；wild 场景需要额外的 $SE(3)$ 变换层（结论一节自列）。
- **数据制备贵**：监督需水密网格的距离变换（50 万采样点 / 网格 + 双面三角形剔除），这正是占据路线"标签最便宜"论点的另一面。
- **后续影响**：自解码器 + 隐码 MAP 的范式被补全、生成、机器人抓取（SDF 碰撞查询）广泛沿用；"连续隐函数 + 可微提取"与 ONet 一起奠定神经隐式表示的函数空间视角（[第 06 章](../06_学习式形状表示SDF与占据.md) 6.4 的"演进链"叙事）。
