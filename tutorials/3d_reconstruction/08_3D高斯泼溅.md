# 第 08 章｜3D 高斯泼溅

上一章把几何"逼"对了，但 NeuS/NeRF 每渲染一个像素都要沿光线查询网络几十上百次——机器人闭环控制等不起。本章换成显式原语：场景 = 一组各向异性 3D 高斯（anisotropic 3D Gaussians），渲染 = 投影 + 排序 + alpha 混合，全程解析可微、能吃满 GPU 光栅化硬件，这就是 3D 高斯泼溅（3D Gaussian Splatting, 3DGS）。本章压轴是投影与 alpha 混合的完整推导（EWA splatting 路线）；它与第 07 章的体渲染公式同构，读通一处即可互通两章。

**记号约定**：高斯 $\mathcal{G}(\mathbf{x};\boldsymbol\mu,\Sigma)$；旋转 $R$（单位四元数 $\mathbf{q}$）、缩放 $S=\operatorname{diag}(\mathbf{s})$；相机平面投影 $\boldsymbol\pi$、雅可比 $J$；透射式合成中的不透明度 $\alpha_k$。世界→相机变换沿用架构 README 的 $T_{cw}\in SE(3)$。

## 8.1 3D 高斯基元

**① 问题场景**：NeRF 级渲染每帧数十万次网络查询——[NeRF 教程第 03 章](../nerf/03_数学原理与渲染方程.md) §3.6 的估算：单张 800×800 图约 1.5~2 亿次 MLP 查询，NeuS 还要叠加 Eikonal 梯度。机器人场景要求实时（几十 fps 起步）甚至端侧算力，逐光线步进 + 逐点查询的范式不可接受。手头：带位姿照片 + SfM 稀疏点云（第 02 章的副产品）；缺：一个显式、光栅化友好、可微的场景表示；想要：渲染快两个量级、且仍能用梯度继续优化的表示。

**② 解决方法**：场景 = 一组各向异性 3D 高斯 $\{\mathcal{G}(\mathbf{x};\boldsymbol\mu_k,\Sigma_k)\}$，每个原语带可学习的不透明度 $o_k$ 与球谐函数（Spherical Harmonics, SH）系数表达的视角相关颜色。渲染 = 把每个高斯投影成屏幕上的 2D 椭圆（splat，"抛洒"）→ 按深度排序 → alpha 混合成像（8.2 节）；训练 = 渲染损失反传到每个原语的位置、协方差、不透明度、SH 系数（8.3 节），并以自适应致密化增删原语。$\boldsymbol\mu_k$ 用 SfM 点云初始化。

**③ 选型理由**：与三条替代路线对比。(a) 隐式场 + 加速编码（Instant-NGP，第 09 章详述）：查询仍是逐点的，用不上 GPU 光栅化管线，且隐式场难以局部编辑（增删一个物体 = 重训）；(b) 点云 splatting：点无面积，放大即走样；高斯有"软面积"，投影、求值、求导全部解析；(c) 三角网格：离散、拓扑变化不可微，逆渲染需光线–三角形求交；高斯连续可微、原语可自由增删。高斯的代价：原语数量大（几十万到百万级）、无网格拓扑（表面需后处理提取）、依赖初始化与致密化策略。本场景（实时优先、静态场景）值得。

**④ 理论依据**：各向异性高斯的投影理论来自 EWA splatting（Zwicker et al.，SIGGRAPH 2001 的 Surface Splatting 及其期刊扩展版 *"EWA Splatting"*, IEEE TVCG 2002）；方法本体 = Kerbl et al., *"3D Gaussian Splatting for Real-Time Radiance Field Rendering"*, SIGGRAPH 2023（本地 PDF [../../papers/3d_reconstruction/frontier/arXiv-2308.04079_3D-Gaussian-Splatting.pdf](../../papers/3d_reconstruction/frontier/arXiv-2308.04079_3D-Gaussian-Splatting.pdf)，其 Eq.4/5/6 即本章 (8.1)(8.8)(8.2)）。

**⑤ 完整推导**：

高斯原语定义（3DGS 论文 Eq.4）：

$$\mathcal{G}(\mathbf{x})=\exp\!\Big(-\frac{1}{2}(\mathbf{x}-\boldsymbol\mu)^\top\Sigma^{-1}(\mathbf{x}-\boldsymbol\mu)\Big), \tag{8.1}$$

乘以不透明度 $o$ 后参与 alpha 混合（8.2 节）。

**协方差参数化的必要性**——优化变量不能是 $\Sigma$ 的 6 个独立元素，推导如下。

第一步：$\Sigma$ 必须对称正定。依据：把 (8.1) 看作未归一化密度，其指数项要求 $\Sigma^{-1}$ 正定——若存在方向 $\mathbf{v}$ 使 $\mathbf{v}^\top\Sigma^{-1}\mathbf{v}\le 0$，则沿该方向指数不衰减甚至增长，$\mathcal{G}$ 沿此方向能量无界，不构成空间局域的"软原语"。

第二步：直接加性优化 $\Sigma$ 不可行。梯度步给出的更新 $\Sigma+\Delta$ 不保证半正定（半正定矩阵集对加性更新不封闭——负曲率方向上的增量立即越界），每步都要投影回可行域，开销大且投影处梯度失真。

第三步：分解参数化天然可行。令

$$\Sigma=R\,S\,S^\top R^\top, \tag{8.2}$$

$R\in SO(3)$ 为旋转、$S=\operatorname{diag}(\mathbf{s})$ 为对角缩放（$\mathbf{s}\in\mathbb{R}^3_{\ge 0}$）。对任意 $\mathbf{v}$（依据：转置恒等式 $(AB)^\top=B^\top A^\top$ 与 $S^\top=S$）：

$$\mathbf{v}^\top\Sigma\,\mathbf{v}=\mathbf{v}^\top R S S^\top R^\top\mathbf{v}=\bigl(S R^\top\mathbf{v}\bigr)^\top\bigl(S R^\top\mathbf{v}\bigr)=\bigl\|S R^\top\mathbf{v}\bigr\|^2\ \ge\ 0. \tag{8.3}$$

（依据：末式是向量与自身的内积，恒非负；$R$ 正交、$S$ 对角非负保证分解对任意参数取值合法。）故 (8.2) 自动半正定，无需投影；反之由实对称矩阵谱定理，任何半正定 $\Sigma$ 都可写成该形式——参数化不损失表达力。

第四步：梯度可传导到 $(\mathbf{q},\mathbf{s})$。实际优化变量是单位四元数 $\mathbf{q}$（4 参数、单位化后 3 自由度，对应 $SO(3)$）与 $\mathbf{s}$（经激活函数保证非负）；链式路径为"损失 → $\Sigma$ → $R\to\mathbf{q}$"与"损失 → $S\to\mathbf{s}$"（依据：链式法则；3DGS 论文附录 A 推导了显式解析梯度以绕开自动微分的反向图开销，教程不展开）。

## 8.2 投影与 alpha 混合（压轴）

**① 问题场景**：屏幕是 2D 像素网格——必须回答"每个 3D 高斯对每个像素贡献多少不透明度"。麻烦在于：透视投影除以深度 $Z$ 是非线性映射，3D 高斯的像一般不再是 2D 高斯；逐像素做光线–椭球求交则回到"每像素多次求值"的老路。想要：解析、可微、一次算好每个 splat 的屏幕 footprint 的投影方法。

**② 解决方法**：EWA（Elliptical Weighted Averaging，椭圆加权平均）两步走：(i) 在视锥局部把透视投影线性化（仿射近似），把 3D 协方差解析传播成 2D 协方差——"高斯经过仿射仍是高斯"；(ii) 对像素直接解析求值 2D 高斯。渲染采用 tile 化光栅化：按深度排序后逐块并行 alpha 混合。

**③ 选型理由**：(a) 精确透视投影：像不再是高斯，须数值积分/查表，失去解析性（Mip-NeRF 用锥形积分抗走样，但同样嵌在逐点 MLP 里）；(b) 逐像素逆投影：等价于逐光线处理，无法复用光栅化并行；(c) EWA 仿射近似：视锥局部透视接近仿射，误差随高斯尺寸增大而增大（已知局限：极端近景/广角下 footprint 失真），换来下面 (8.5)–(8.8) 的全解析管线；排序 + alpha 混合复用图形学光栅化思路，GPU 友好。

**④ 理论依据**：EWA splatting 的局部仿射近似与协方差传播（Zwicker et al. 2001/2002）；概率论的协方差线性变换公式（本节引理）。

**⑤ 完整推导**（每步注明依据）：

(a) 局部仿射投影。世界系高斯先做刚体变换到相机系（依据：README 记号 $T_{cw}$，$W$ 为其旋转块、$\mathbf{t}$ 为平移；此步是精确变换，近似发生在下一步）：

$$\mathbf{x}_{cam}=W\mathbf{x}+\mathbf{t}. \tag{8.4}$$

针孔投影（依据：相机内参 $K$ 的定义；记 $\mathbf{x}_{cam}=(X,Y,Z)^\top$）：

$$\boldsymbol\pi(\mathbf{x}_{cam})=\Bigl(f_x\,\frac{X}{Z}+c_x,\;\; f_y\,\frac{Y}{Z}+c_y\Bigr).$$

在参考点 $\tilde{\mathbf{x}}_{cam}$（取该高斯中心的相机系坐标 $\boldsymbol\mu_{cam}$）处一阶泰勒展开（依据：多元函数一阶泰勒公式；视锥局部 $\mathbf{x}_{cam}$ 离 $\tilde{\mathbf{x}}_{cam}$ 很近，高阶项可略）：

$$\mathbf{u}\approx\boldsymbol\pi(\tilde{\mathbf{x}}_{cam})+J\,(\mathbf{x}_{cam}-\tilde{\mathbf{x}}_{cam}). \tag{8.5}$$

逐元素求 $J=\partial\boldsymbol\pi/\partial\mathbf{x}_{cam}$（依据：投影 $\boldsymbol\pi$ 的偏导 + 链式法则）：$\partial u_1/\partial X=f_x/Z$（$X$ 线性出现）；$\partial u_1/\partial Y=0$；$\partial u_1/\partial Z=\partial(f_xX/Z)/\partial Z=-f_xX/Z^2$（依据：商的求导法则）；第二行由 $u_2$ 与 $u_1$ 的对称性同法可得：

$$J=\begin{bmatrix} f_x/Z & 0 & -f_xX/Z^2\\[2pt] 0 & f_y/Z & -f_yY/Z^2 \end{bmatrix}, \tag{8.6}$$

在各高斯自己的 $\tilde{\mathbf{x}}_{cam}=\boldsymbol\mu_{cam}$ 处取值（即以该高斯的 $X,Y,Z$ 代入）。

(b) 协方差传播。引理（随机向量仿射变换的协方差）：若 $\mathbf{y}=A\mathbf{x}+\mathbf{b}$，则 $\Sigma_y=A\Sigma_xA^\top$。从定义出发推导：

$$\Sigma_y=E\bigl[(\mathbf{y}-\bar{\mathbf{y}})(\mathbf{y}-\bar{\mathbf{y}})^\top\bigr]=E\bigl[A(\mathbf{x}-\bar{\mathbf{x}})(\mathbf{x}-\bar{\mathbf{x}})^\top A^\top\bigr]$$

（依据：仿射下中心化差的恒等式 $\mathbf{y}-\bar{\mathbf{y}}=A(\mathbf{x}-\bar{\mathbf{x}})$，代入定义），

$$=A\;E\bigl[(\mathbf{x}-\bar{\mathbf{x}})(\mathbf{x}-\bar{\mathbf{x}})^\top\bigr]\,A^\top=A\,\Sigma_x\,A^\top \tag{8.7}$$

（依据：$A$ 为常数矩阵，由期望的线性提出）。

应用两次（依据：(8.5) 在局部是仿射映射，线性部分为 $J$）：应用一取 $A=W$，得相机系协方差 $\Sigma_{cam}=W\Sigma W^\top$；应用二取 $A=J$，得屏幕系 2D 协方差。合并：

$$\Sigma'=J\,W\,\Sigma\,W^\top J^\top. \tag{8.8}$$

（3DGS 论文 Eq.5；$J$ 为 $2\times 3$，故 $\Sigma'$ 为 $2\times 2$。）实践中在 $\Sigma'$ 的对角上加小量低通项（EWA 传统，约 0.3 像素量级），避免亚像素高斯在放大时闪烁/走样——实现细节，不展开。

(c) 排序与 alpha 混合。像素 $\mathbf{p}$ 处第 $k$ 个 splat 的不透明度（依据：(8.1) 的 2D 版本在像素中心求值，乘学习的不透明度 $o_k$；$\boldsymbol\mu'_k=\boldsymbol\pi(\boldsymbol\mu_{cam,k})$ 为 2D 中心）：

$$\alpha_k=o_k\exp\!\Big(-\frac{1}{2}(\mathbf{p}-\boldsymbol\mu'_k)^\top\,\Sigma_k'^{-1}\,(\mathbf{p}-\boldsymbol\mu'_k)\Big). \tag{8.9}$$

按深度从前到后排序后合成颜色：

$$C=\sum_{k}\mathbf{c}_k\,\alpha_k\prod_{j<k}\bigl(1-\alpha_j\bigr). \tag{8.10}$$

与 NeRF 离散体渲染（NeRF 论文 Eq.3，见 [NeRF 教程第 03 章](../nerf/03_数学原理与渲染方程.md) §3.5：$\hat C=\sum_i T_i(1-\mathrm{e}^{-\sigma_i\delta_i})\mathbf{c}_i$，$T_i=\prod_{j<i}(1-\alpha_j)$）逐项对照：三因子结构完全相同——"到达（透射连乘）× 该处挡住（$\alpha$）× 颜色"。区别仅在 $\alpha$ 的来源与求值方式：NeRF 的 $\alpha_i=1-\mathrm{e}^{-\sigma_i\delta_i}$ 是光线小段上的积分不透明度（每像素 $N$ 次网络查询 + 数值积分），3DGS 的 $\alpha_k$ 是解析 2D 高斯的点求值（(8.9)，无网络、无积分）；"沿光线的连续积分"被"屏幕平面上的解析 splat + 排序合成"替代——积分变求和、查询变乘加。3DGS 论文正是以其 Eq.2/Eq.3 的对照说明两种图像形成模型同源。

实现要点（操作步骤，不含理论）：把屏幕划成 16×16 tile；每个高斯按 (8.8) 的 footprint 复制到覆盖的 tile；全局按深度一次排序后逐 tile 并行前向混合，反向传播时缓存 $\alpha$ 逐 tile 回扫。CUDA 工程细节见论文 §6 与开源实现。

## 8.3 优化与自适应致密化

**① 问题场景**：SfM 稀疏点云（每视图几千点）只够给 $\boldsymbol\mu_k$ "点个名"。固定原语数量的优化很快暴露结构问题：有的区域一个大糊团盖住本该分开的细节（过重建），有的区域原语太稀、永远拟不上（欠重建），还有贴着相机的漂浮片（floaters，局部极小：把 $\alpha$ 提到 1 就"看不见误差"）。需要"边训边改结构"的机制。

**② 解决方法**：全参数可微优化，损失

$$\mathcal{L}=(1-\lambda)\,\mathcal{L}_1+\lambda\,\mathcal{L}_{\text{D-SSIM}}, \tag{8.11}$$

（$\lambda$ 权衡逐像素项与结构相似度项，论文经验取值 $\lambda=0.2$）。训练中周期性执行自适应密度控制（adaptive density control）：分裂（split）、克隆（clone）、剪枝（prune），并周期性重置全部不透明度。以下阈值均为论文实现细节中的**经验规则（经验规则非推导）**：位置梯度阈值 $\tau_p$（$2\times 10^{-4}$ 量级）、分裂缩放因子（约 1.6）、剪枝的 $\alpha$ 下限（约 0.005）、致密化间隔（约每 100 步）与重置间隔（约每 3000 步）。

**③ 选型理由**：对比 (a) 固定容量优化：欠重建区域永远糊；(b) 按像素误差图驱动加原语：误差受视角/曝光影响、噪声大且无参数指向性。位置梯度是"移动该原语能否继续降损"的一阶信号，直接指向容量不足处。代价：阈值需手调、原语数量可能爆炸（须设上限）。

**④ 理论依据**：Kerbl et al. 2023 §5（自适应密度控制为经验规则，非定理——本节 ⑤ 是启发性论证）；$\mathcal{L}_1$ 与 SSIM/D-SSIM 为标准图像质量度量（SSIM 从亮度、对比、结构三因子度量局部结构相似度，此处直接采用标准结论，推导见图像质量评估文献）。

**⑤ 推导/论证**（启发性论证，非定理）：

损失各项：$\mathcal{L}_1$ 逐像素稳健、对个别离群像素不敏感；D-SSIM 补足 $\mathcal{L}_1$ 对低频结构差异不敏感的短板，二者加权兼顾像素与感知。

梯度判据：若某区域渲染与真像有差、且移动其中原语的位置能显著降损，则 $\nabla_{\boldsymbol\mu}\mathcal{L}$ 大；区域已拟合好则梯度趋零（依据：梯度 = 损失对参数的一阶敏感性；优化收敛的必要条件是梯度趋零）。故"视空间位置梯度均值超过 $\tau_p$"标记容量不足的区域（判据在视空间统计，因为渲染误差以像素为单位度量）。

处理规则（经验规则）：该原语尺度大 ⟹ 过重建 → **分裂**：复制两份、缩放除以经验因子、按原高斯分布采样重摆位置；尺度小 ⟹ 欠重建 → **克隆**：原样复制并沿梯度方向平移。$\alpha$ 低于下限 ⟹ 该原语在 (8.10) 中的贡献项趋零、却仍占显存与计算 → **剪枝**。

不透明度重置的论证：训练早期常出现贴着相机的大 $\alpha$ 漂浮片（局部极小：挡住视线即可消除误差信号）；周期性把所有 $o_k$ 清零，迫使优化回到位置/尺度的几何解释上重建，同时暴露并清除漂浮片（经验上有效，成本低）。

SfM 点云重初始化不适用后的策略（简述）：SfM 点云只在训练开始时可用一次（中途为"再要一批更密的点"而重跑 SfM/MVS 代价高，且相机位姿已定），因此 3DGS 不依赖中途重初始化，而是用上述闭环让原语集合自我生长（梯度探测 + 克隆/分裂）与自我清理（剪枝 + 重置）——原语数量成为训练的因变量（上限受控）。

## 8.4 3DGS vs NeuS：隐式场与显式原语的选型（简短对比）

**① 问题场景**：机器人要抓取物体，重建结果须支持表面/法向/可抓取性查询——第 07 章的 NeuS 路线和本章的 3DGS 路线怎么选？

**② 解决方法**（结论）：按"查询延迟 / 几何精度 / 可编辑性 / 初始化依赖"四维对照。速度：3DGS 对逐点 MLP 查询的隐式路线快约两个量级（实时 vs 秒级每帧，定性）；可编辑性：显式原语可直接增删改、导出与交互编辑，隐式场改一处即重训。几何精度：NeuS 的 $f$ 与 $\nabla f$ 直接给出 SDF 值与法向，表面连续、查询干脆；3DGS 的几何是体积软原语——各向异性高斯的最优解趋向把最薄轴压扁以贴合表面（"扁平化"），其深度/法向查询与网格提取需后处理（如 TSDF/泊松融合，第 04–05 章；后续工作如 2DGS 专治此点）。依赖：3DGS 依赖 SfM 初始化点云且原语数量爆炸（几十万到百万级）；NeuS 无需初始化点云但逐场景优化慢。

**③ 选型理由**：不存在全能表示（第 01 章表示谱系视角的回响）：要实时外观与交互选 3DGS；要高精度可查询表面选 NeuS/隐式场；机器人抓取同时要求低延迟与表面查询，常落在 TSDF/ESDF 或混合路线上。

**④ 理论依据**：两篇论文的公开实验结论（本章只做定性转述，具体数字见论文与第 10 章）。

**⑤ 论证**：把四维排成选型矩阵即可见分野：3DGS 在"延迟/可编辑性"占优、在"几何精度/原语规模"让步；NeuS 恰好相反。机器人落地（低延迟 + 可查询表面 + 更新频率 + 与仿真回流）的最终权衡与管线选型，在第 10 章以完整矩阵展开。

## 本章要点

- 场景 = 各向异性 3D 高斯集合；协方差参数化 $\Sigma=RSS^\top R^\top$（(8.2)），半正定性由 $\|SR^\top\mathbf{v}\|^2\ge 0$（(8.3)）天然保证——直接优化 $\Sigma$ 六元素不可行，因加性更新不保持半正定。
- EWA 投影链：刚体变换 (8.4) → 局部一阶泰勒 (8.5) → 雅可比 (8.6) → 协方差传播引理 (8.7) → $\Sigma'=JW\Sigma W^\top J^\top$（(8.8)）。
- alpha 混合 (8.10) 与 NeRF 离散体渲染（NeRF 论文 Eq.3）同构；差别 = $1-\mathrm{e}^{-\sigma\delta}$ 换成解析 2D 高斯求值 (8.9)——积分变求和、查询变乘加。
- 损失 = L1 + D-SSIM（(8.11)）；自适应密度控制（位置梯度阈值 $\tau_p$ 的分裂/克隆、$\alpha$ 剪枝、周期重置）是论文经验规则，非推导。
- 位置梯度均值超阈 ⟺ 容量不足区域的一阶探测器；大高斯分裂、小高斯克隆。
- 选型：3DGS 快约两个量级、显式可编辑；代价 = 扁平化几何、SfM 初始化依赖、原语规模爆炸——机器人落地选型见第 10 章。
