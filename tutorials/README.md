## 目录约定

- 章节文件命名：`数字_标题.md`（如 `01_论文速览与背景.md`）
- 每个主题以 `README.md` 作为导航入口
- 主题总览（论文/教程/代码三者的关系）放在 `OVERVIEW.md`
- 对应论文见 [`../papers/`](../papers/)，对应代码见 [`../projects/`](../projects/)

## 写作规范

遵循根目录 [CONSTRAINTS.md](../CONSTRAINTS.md) 的文档规范：中文撰写、术语首现给英文对照、公式用 LaTeX、代码块标注语言。
