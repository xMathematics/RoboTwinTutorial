# 第 16 章｜近似 POMDP 技术

第 15 章的精确 POMDP 输给了指数爆炸（线数 $|\Gamma|^{|Z|}$ 级增长）。本章给出三个近似算法，它们在 **MDP ↔ POMDP 光谱**上各占一站，每一站都以一种**不同的方式**扔掉一部分置信信息：**QMDP** 假设"下一步之后状态变得完全能观测"（扔掉未来的感知不确定性）；**AMDP** 把整个置信压缩成低维充分统计量（最可能状态 + 熵）（扔掉分布的形状）；**MC-POMDP** 用粒子集近似置信并用学习算法表示值函数（扔掉精确性换任意状态空间）。三者的共同底色（也是原书 16.5 的收官结论）：**近似的账再粗糙，也远好于对状态不确定性装瞎**——"即使状态向量里只增加一个衡量全局不确定性的新元素，机器人性能也有巨大差异"。

> 原书锚点：第 16 章，书 421–437 页（PDF 439–455 页）。QMDP 的高估性、老虎问题的病理策略为本教程自拟数值演示（基于第 15 章已验证的算例与习题 1 的老虎参数）；程序 16.2/16.3 逐行讲解。

## 16.1 光谱上的三个位置（原书 16.1）

| | 保留 | 丢弃 | 计算量 | 适用 |
|---|------|------|--------|------|
| **QMDP** | MDP 最优值函数 | 一步之后的全部感知不确定性 | 与 MDP 相同（多项式） | 不确定性"温和"、行动即观测的场景 |
| **AMDP** | 置信的（模式, 熵）摘要 | 分布形状 / 多峰结构 | 介于两者（低维值迭代 + 预学习） | "困惑程度"主导决策的导航 |
| **MC-POMDP** | 粒子近似的完整置信 | 值函数的精确表示 | 最不成熟、最难调 | 连续状态/行动/测量的任意空间 |

## 16.2 QMDP：一步可观测假设（原书 16.2）

**① 思想**：先解一个 MDP（状态完全能观测的最优值函数 $V$），再把它**按期望推广**到置信空间（原书式 16.1–16.3）：

$$V_{\mathrm{QMDP}}(b) = E_b[V(x)] = \sum_i p_i V(x_i) \qquad \text{（整个置信空间上只有一条线性约束！）}. \tag{16.1}$$

策略：$Q(x_i, u) = r(x_i,u) + \gamma\sum_j V(x_j)P(x_j \mid u, x_i)$，取 $\arg\max_u \sum_i p_i Q(x_i, u)$（原书程序 16.1）。**隐含假设**：执行一步之后状态变得完全能观测——于是当前决策无需为"将来看不清"买单。

**② 高估性（教程自拟数值演示）**：把 QMDP 套在第 15 章两状态算例上。$V^{\mathrm{MDP}}(x_1) = V^{\mathrm{MDP}}(x_2) = 100$（各自都有 +100 的目标行动），$Q(\cdot, u_3) = -1 + 100 = 99$：QMDP 在 $p_1 = 0.5$ 处给出 **99**，而精确 POMDP 值为 $V_1 = 25.0$、$V_2 = 46.0$、$V_8 = 70.2$（感知价值随视界累积）——**高估 1.4–4 倍**，且方向恒为乐观（假设可见 = 假设无风险）。原书 16.5 的"QMDP 值函数通常高估"在此获得具体数字。

**③ 老虎问题上的病理（教程自拟演示）**：用第 15 章习题 1 的参数（开对 +10、开错 −20、听 −1、精度 0.85，γ = 0.9）。$V^{\mathrm{MDP}} = +10$（老虎在门后时开另一扇门），于是 $Q(\cdot, \text{listen}) = -1 + 0.9 \times 10 = 8 > Q(\text{开固定门}) = 0.5(-20) + 0.5(+10) = -5$——**QMDP 的策略是"永远听下去"**，其真实折扣回报 $-1/(1-\gamma) = -10$，而"听一次再开"的真实值是 $+4.5$（第 15 章习题 1c 已算）。病理机制：高估假设使"听"显得既免费又必然通向 +10，于是策略陷入永不行动的循环。**这条演示同时是习题 2 的答案铺垫**：让听测完全准确（$p = 1$），"一步可观测"假设成真，QMDP 恰好最优。

**④ 混合扩展**（原书 16.2 末）：$V^{\mathrm{MDP}}$ 可作为 POMDP 备份的**初始化**——先做 $T$ 步真 POMDP 备份（覆盖近期信息收集），再落回 QMDP 假设——策略在 $T$ 步内会收集信息，之后按"可观测"收尾。$T$ 越大越接近全 POMDP 解，计算量仍远小于精确解。

## 16.3 AMDP：置信的充分统计量（原书 16.3）

**① 思想**：把置信 $b$ 压缩为低维统计（原书式 16.4–16.5）

$$f(b) = \big(\arg\max_x b(x),\ H_p(x)\big), \qquad H_p(x) = -\int b(x)\log b(x)\,dx, \tag{16.2}$$

——"我现在最可能在哪 + 我有多糊涂"，然后在**增广状态空间**上做普通值迭代。合法性假设（原书式 16.6）：$V(b) = V(f(b))$，即 $f$ 是充分统计量——原书坦言"实际上这个假设很少有效"，但明智的控制选择仍可能足够好。复杂度从置信空间的指数级降为增广空间的多项式。

**② 两个障碍与"从仿真学习"**（原书 16.3.2，程序 16.2 两阶段）：其一，熵是置信参数的非线性函数 → 增广空间上的精确备份不可得 → **离散化 + 查表**；其二，增广空间上的转移/报酬函数没有现成公式 → **蒙特卡罗学习**：对每个（增广状态, 行动）组合采 $n$ 次（生成匹配统计量的对称高斯信念 → 采位姿 → 采后继 → 采测量 → 贝叶斯滤波 → 统计 $f(b')$ 与报酬），频率计数填表 $P(\hat b, u, \hat b')$、$\hat r(\hat b, u)$，然后查表值迭代。**学习阶段的阿喀琉斯之踵**（原书 16.3.3 坦言）：`generate b with f(b) = b̂` 是不适定问题——同一统计量对应无数信念，原版 AMDP 用对称高斯搪塞；更合理的替代是**仿真完整置信轨迹**、用相邻对做统计（与 MC-POMDP 汇合）。

**③ 海岸导航**（原书 16.3.4）：AMDP 使机器人在行动选择时计入**当前 + 未来的"困惑水平"**——穿越无特征开阔区熵升（$p(b' \mid u, b)$ 高似然地增加熵）、贴近特征区熵降。图 16.1：MDP 走最短路穿 40 m 开阔区，AMDP 贴障碍绕行（第 01 章海岸导航的正式实现——"海岸导航"之名的出处即此节）；图 16.2：目标处熵随传感器量程的对比，短量程时 AMDP 优势显著、长量程时差异消失（传感器够强则不惧迷路）。学习统计量版本（图 16.3）：六维学习表示下的入侵者清剿策略——"先扫走廊一段、卡住房间出口、再速清房间"的复杂时序策略。

## 16.4 MC-POMDP：粒子化的置信空间（原书 16.4）

**① 表示难题**（原书 16.4.1）：值函数定义在**粒子集**上 $V: X \to \mathbb{R}$（原书式 16.10）——这是全书唯一不需要有限状态空间的算法；但 $M$ 粒子集的空间是 $M$ 维的、且任何集合不会被观测两次 → 值函数必须靠**学习算法**外推：最近邻 + KL 距离（粒子集与固定协方差高斯卷积成混合密度后量 KL）+ **Shepard 插值**（原书式 16.11）：

$$V(X_{\mathrm{query}}) = \sum_k \lambda_k V_k, \qquad \lambda_k = \frac{1/d_k}{\sum_j 1/d_j}. \tag{16.3}$$

**② 算法**（原书程序 16.3）：双层循环——内层对当前粒子集做蒙特卡罗备份（每行动采 $n$ 次：采样后继与测量 → 粒子滤波得新置信 → $\tilde Q(u) \mathrel{+}= \frac1n\gamma[r + V(X')]$）；取 $\max_u \tilde Q$ 更新 $V$（近邻按插值权重分摊，原书式 16.12；距离超阈值则新建参考点）；外层按贪婪行动仿真推进（偶尔随机探索），回合制重复直至收敛。**三重近似**（原书 16.4.3 明示）：粒子集近似、学习表示近似、蒙特卡罗备份近似——收敛性无人担保。

**③ 实战与评价**（原书 16.4.4–16.5）：抓取任务（物体初始在感知范围外）的三阶段策略——**旋转搜索 → 对准走近 → 抓取**（主动感知 + 目的行动的组合）；4000 次迭代（低端机 2 小时）后成功率稳定在 80%。原书评语：三种近似算法中**最不成熟、最高效难调**（值函数平滑度、粒子数、距离阈值都要伺候）。

## 16.5 选型表与收官结论

| | QMDP | AMDP | MC-POMDP |
|---|------|------|----------|
| 近似对象 | 未来的感知不确定性 | 置信 → (模式, 熵) | 置信 → 粒子集 + 学习值函数 |
| 值的偏向 | **高估**（乐观） | 依赖统计充分性 | 无保证 |
| 经典病理 | 老虎"永听"循环 | 统计别名（同 (模式,熵) 异信念） | 平滑度/参数敏感 |
| 信息收集能力 | 无（信息无价值化） | 有限（熵进状态） | 有（完整置信在环） |
| 计算量 | = MDP | 低维值迭代 + 预学习 | 最重 |
| 状态空间 | 有限 | 有限 | **任意（连续亦可）** |

收官结论（原书 16.5 原话精神）：**近似的谱系再粗糙，也碾压对不确定性装瞎**——AMDP 只往状态里加了一个熵标量，就换来海岸导航对最短路径规划的决定性优势。这句话是概率机器人规划部分的中心思想，也是第 17 章主动探测的引言。

## 16.7 小结、术语表与书后习题全解

**要点回顾**：

1. QMDP = MDP 值函数的置信期望 (16.1)，一步可观测假设 → 高估（99 vs 46/70 实测）与病理策略（永听 −10 vs 可达 +4.5）；与 POMDP 备份可混合（16.2）；
2. AMDP = (模式, 熵) 增广 + 蒙特卡罗学表 + 查表值迭代；充分性假设少有效；海岸导航落地（16.3）；
3. MC-POMDP = 粒子置信 + 最近邻/Shepard 值函数学习；任意状态空间、最不成熟（16.4）；
4. 中心结论：任何程度的不确定性建模都显著优于装瞎（16.5）。

**术语表（本章新增）**：QMDP、增广 MDP / 增广状态空间（AMDP / augmented state space）、充分统计量（sufficient statistic，again）、MC-POMDP、Shepard 插值（Shepard's interpolation）、海岸导航（coastal navigation，正式命名处）。

**书后习题全解指导**（原书 16.7 节，书 436–437 页）：

**习题 1（12 状态迷宫的 AMDP 设计）**——(a) 最低限度增广状态：初始均匀 → 无观测（缓冲器只在撞墙时触发且方向不可感知）→ 置信完全由**动作历史**决定。最小编码：用"位置集合 + 朝向约束"计数；按题目给定的几何数格子即可（要点：初始 12 元均匀置信是 1 个状态，每条动作序列终结于一个确定子集）。(b) 可达状态 = 全部历史序列产生的不同子集数（≤ 动作序列的等价类数）。(c) 从状态 2 出发 4 动作内的转移图：对四个方向枚举撞墙（置信不缩的分支）与不撞（剔除不可能位置）两种结局画有向图。(d) **无噪声情形的更紧凑表示**：置信永远是"均匀分布于某个位置集合"——充分统计就是**集合本身**（位形格位图），甚至就是**动作历史**（历史 ↔ 集合一一对应）——比 (模式, 熵) 保留更多结构且同样有限。(e) **让 AMDP 失败的构造**：制造两个 (模式, 熵) 相同但最优动作相反的信念——例如"质量集中在 1 与 2（等权，熵 = 1 bit）"与"均匀散布在 4 个格子（熵 = 2 bit）"调到等熵，前者该朝 1 走、后者该先探测——(模式, 熵) 无法区分，AMDP 必错。这题与第 08 章 KLD 采样"直方格只度量体积不影响分布"的教义互为镜像。

**习题 2（老虎问题的 QMDP 修正）**——使 QMDP 恰好的修正（多解）：①**听测改为完全准确**（$p = 1$）——"一步之后可观测"假设成真，QMDP 的值与策略精确；②**删掉隐藏变量**（老虎位置已知）——问题退化为 MDP 本身；③**报酬改造**使"不收集信息直接开"成为最优（如老虎惩罚足够小/宝物足够大，使先验期望开箱优于任何探测）——此时信息无价值，QMDP 的"信息无价值化"盲点恰好无害。三案共同点：**让 QMDP 的假设或盲点与真问题的结构对齐**。

**习题 3（10 个场景的可达置信空间大小）**——本教程逐格推理（$N = 3$ 状态 → 单形为 2 维）：

| # | 设定 | 可达置信空间 | 理由 |
|---|------|--------------|------|
| 1 | 完美传感器 + 无噪声 + 已知 | **1 个点** | 置信恒为 δ 函数（且始终同一状态） |
| 2 | 完美传感器 + 噪声转移 + 已知 | **3 个点**（δ 函数集） | 每步观测揭示状态，置信总在 δ 之间跳 |
| 3 | 无噪声传感器 + 无噪声 + 均匀未知 | **有限 ≤ 8 点** | 置信 = "与观测史一致的状态集上的均匀分布"，子集数 ≤ 2³ |
| 4 | 噪声传感器 + 无噪声 + 已知 | 无限（**1 维轨迹族**） | 每步贝叶斯更新沿确定性轨迹推进，动作分叉成可数无穷个点 |
| 5 | 噪声传感器 + 无噪声 + 均匀未知 | 无限（**2 维单纯形区域**） | 初始即铺开、更新连续 → 填充单纯形 |
| 6 | 无传感器 + 无噪声 + 均匀未知 | **1 个点** | 置信恒为均匀分布 |
| 7 | 无传感器 + 噪声转移 + 已知 | 无限（可数） | 置信 = 预测分布，随动作序列分叉（每序列一个点） |
| 8 | 1 维连续 + 完美传感器 + 噪声 + 已知 | **1 维连续统**（δ 函数族） | 置信恒为 δ，位置连续 |
| 9 | 1 维连续 + 双噪声 + 已知 | **无限维** | 每个置信是 1 维状态上的完整分布（函数） |
| 10 | 2 维连续 + 双噪声 + 均匀未知 | **无限维** | 同上且初始即铺开 |

判据三条：完美传感器 → δ 函数；无噪声 → 有限/可数（分布由离散事件唯一决定）；连续状态 + 噪声 → 函数级置信 → 无限维。这张表回答了"为什么第 15 章说连续状态的置信空间是无限维连续统"。

**习题 4（AMDP 学习模式的三类失效，小组讨论提纲）**——①**采样偏差**：`generate b with f(b) = b̂` 不适定，对称高斯填料覆盖不了真实信念流形 → 学到的 $P(\hat b, u, \hat b')$ 在流形外区域是编造的（原书 16.3.3 自认的"噩梦"）；②**统计别名**：充分性假设失效 → 异信念同统计共享一条值/策略，系统性次优（习题 1(e) 的构造）；③**学习噪声的迭代放大**：频率计数表带采样噪声，值迭代把局部误差沿 Bellman 备份传播到全空间，且**无一致性修正机制**（不像粒子滤波有渐近正确性）——外加一条工程性失效：策略改变访问分布 → 学习表来自"旧策略的分布" → 离策略偏差累积。
