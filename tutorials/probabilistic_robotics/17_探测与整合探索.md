# 第 17 章｜探测与整合探索

全书终章回到第 01 章埋下的最后一条伏笔：**把"收集信息"本身变成行动的目标**。探测（exploration）问题谱系横跨静态建图、追逃博弈与主动定位——形式上都能塞进 POMDP（报酬函数取信息增益即可），但原书一票否决：通用 POMDP 规划的复杂度对观测数**双倍指数**，而探测问题的状态与观测空间恰好是最大的（描述一颗未知行星的变量数是天文数字）。出路是**贪婪**——只优化一步探测行动，并用一个漂亮的粒度技巧（"移动到某目标点"算一个探测行动，内部交给低级导航模块）让一步行动覆盖一段路径。本章四个应用依次升级：主动定位（信息地图 + 花费地图的合成）、占用栅格探测（逐格独立性——第 09 章的技巧回归，引出著名的**基于边界的探测**）、多机器人协同（贪婪分配 + 目标抑制，超线性加速至 2K 倍）、**SLAM 探测**（全书压轴：熵分解 $H[x, m] = H[x] + E[H[m \mid x]]$ 让机器人在"去探新地"与"回旧地定位"之间自动权衡——闭环时机的定量裁决）。

> 原书锚点：第 17 章，书 438–467 页（PDF 456–485 页）。SLAM 熵分解 (17.17–17.20) 的推导全量展开并数值验证（本教程初版脚本曾把 2 维联合熵按 1 维计算而误报不匹配——修正后精确成立，教训已写进正文）；高斯熵引理（程序 17.4）经 Monte Carlo 验证（3.1177 vs 3.1163）；习题 5 的误差曲线与习题 6 的信息增益公式均数值落实。

## 17.1 探测谱系与"为什么不是 POMDP"（原书 17.1）

**三类探测任务**：①静态建图（最大化每个栅格的累积信息——第 09 章的目标函数化）；②动态目标（追逃博弈：信息目标会跑）；③**主动定位**（最大化自己位姿的信息——第 07 章全局定位的行动版）。**POMDP 为何出局**：把信息增益设为报酬，POMDP 形式上通吃——但通用 POMDP 规划复杂度对观测数双倍指数，探测问题的未知变量数与可能观测数都是巨量（24 束声呐各 1 字节 → 单点扫描 $256^{24}$ 种可能读数），"在所有可能值上积分的任何算法必然不适用"。**出路两条**：贪婪（只看一步）+ 行动粒度（一步 = 移动到目标点，内含低级导航）。

## 17.2 信息增益与贪婪探测（原书 17.2）★

**① 信息增益的定义链**（原书式 17.1–17.4）：熵 $H_p(x) = -\int p \log p$（均匀最大、点质量最小）；行动后测量到来，后验 $B(b, u, z)$ 的条件熵（式 17.2）；测量不可挑拣 → 对 $z$ 取期望得 $E_z[H_b(x' \mid z, u)]$（式 17.3，原书注明此处交换求和与对数是近似）；**信息增益**：

$$I_b(u) = H_p(x) - E_z\big[H_b(x' \mid z, u)\big]. \tag{17.1}$$

**② 贪婪效用**（原书式 17.5–17.6）：报酬 $r(x,u) < 0$ 记花费，权重 $\alpha$ 折算信息的"价格"：

$$\pi(b) = \arg\max_u \Big[\alpha I_b(u) - E\big[r(x,u)\big]\Big]. \tag{17.2}$$

**③ 为什么贪婪**（原书 17.2.2 的论证，值得原样领会）：探测的**分支因子天然庞大**——目标是获取新信息，而新信息一旦到手置信即变、策略必须重排（图 17.1：三步序列可能走到一半发现走廊尽头与预想不符）；"测量具有固有的不可预测性"。多步版（17.2.4）可以给——把终端报酬设为 $-\alpha H(b_{t+T})$（式 17.7）套进任何 POMDP 算法——但计算上与 15 章同病，原书弃之。

**④ Monte-Carlo 探测**（原书程序 17.1）：式 (17.2) 的采样实现——采状态 $x \sim b$、采后继 $x'$、采测量 $z$、贝叶斯滤波、累加 $r - \alpha H$，$N$ 轮后取 argmax。**瓶颈**：$z$ 的采样空间巨大（声呐例的 $256^{24}$）——引出 17.4 的闭式近似。

## 17.3 主动定位：合成两张地图（原书 17.3）

**① 问题与粒度技巧**：对称走廊里无目标徘徊永远定位不了——必须走进房间（第 07 章 POMDP 走廊实例的行动版）。**探测行动 = 移动到机器人局部坐标系的目标点**（如"后退 9 m、左移 4 m"）：一个行动对应一段由低级导航执行的路径；位姿多峰时，同一行动在不同模式下把机器人带到不同地点（原书图 17.2b）——评估必须对多峰求期望。

**② 三张地图的合成流程**（原书图 17.3 的五格流程，本教程浓缩）：

1. **花费地图**：从机器人出发做**反向值迭代**（第 14 章的值迭代从目标向内传播；此处从机器人向外——"到任意候选点的最小花费"）；
2. **信息增益地图**：对每个候选点，仿真测量、贝叶斯更新、量熵减——深色 = 高信息（房间与走廊尽头最亮）；
3. **合成地图** = 增益 − $\alpha$·花费 → 爬山选取目标。

**③ 实战轨迹**（原书图 17.3–17.4）：六峰后验 → 走到走廊尽头（安全区内的最大增益点）→ 六峰变两峰 → 走进任一房间 → 定位完成。**两条缺点**（原书 17.3 末）：贪婪不能规划"多步联动增益"；**移动过程被当开环处理**——途中获得的测量（如发现门关了）不会触发换目标，真实机器人会放弃、规划器不会。次优但好用（原书的实用主义结语）。

## 17.4 占用栅格探测：从熵到"边界"（原书 17.4）

**① 技巧回归**：建图探测的增益计算与第 09 章占用建图共用同一假设——**栅格间独立**，增益可逐格计算并铺成二维信息地图。三种增益近似，从精到糙：

1. **每格熵**（原书式 17.8）：$H_p(m_i) = -p_i\log p_i - (1-p_i)\log(1-p_i)$；
2. **期望熵减**（原书式 17.9–17.15）：引入传感器精度 $p_{\mathrm{true}}$，算"测得占用/未占用"两支后验的期望熵，差即期望增益——推导是贝叶斯更新的直接代数（教程数值：$p_{\mathrm{true}} = 0.9$ 时该增益恒非负、在 $p_i \in \{0, 1\}$ 处为零）；
3. **二值增益**：更新过一次 = 已探测 = 零增益，否则 = 增益——最粗但**最常用**（原书图 17.6 的实测：熵与期望熵减的地图几乎无差别，粗糙近似合理）。

**② 基于边界的探测**（frontier-based exploration，Yamauchi 1999）：二值增益地图 + 值迭代（原书式 17.16：只在增益为零的格子间传播花费、撞到未探测格即停）→ 爬山 = **走向最近的已探测/未探测边界**。实验（AAAI-94 竞赛、城市机器人）：高效但常见**目标振荡**（在多个等值目标间来回）——先进实现的补丁方向。

**③ 多机器人协同**（原书 17.4.3）：加速可**超线性**（$K$ 台最高近 $2K$ 倍——单机器人要"出去探 + 回来接"双程，团队分摊后返程省半）。程序 17.2 的协调机制朴素而有效：每台机器人从自己的位置做反向值迭代 → 贪心选最近边界 → **把该边界附近的增益置零**（抑制他人重复选择）→ 下一台。图 17.9 vs 17.10：无协调两机同抢一个目标；有协调第二机改选走廊左侧。缺点：顺序贪心非全局最优（选序互换路径交叉）→ **拍卖/市场机制**让机器人交换目标改进总价。实验：3 台机器人 8 分钟建 62 m × 43 m 地图。**未知出发位置**的扩展：各自独立探测 + 改进 MCL 互定位 + **会合验证**（反光带 + 激光互认）→ 融合地图后切换到协同模式——"探测"与"验证另一个假设"在同一效用框架里竞争。

## 17.5 SLAM 探测：熵分解与闭环裁决（原书 17.5）★

**① 张力**：SLAM 里位姿与地图都未知——只顾位姿信息 → 机器人原地打转；只顾地图信息 → 位姿漂移污染地图。**解药是熵分解**（原书式 17.17–17.20，全量推导即熵的链式法则，教程浓缩）：

$$H\big[p(x_{1:t}, m \mid z, u)\big] = H\big[p(x_{1:t} \mid z, u)\big] + E\Big[H\big[p(m \mid x_{1:t}, z, u)\big]\Big] \tag{17.3}$$

（推导：$p(x,m) = p(x)p(m \mid x)$ 代入 $E[-\log p(x,m)]$ 拆对数、交换积分次序——原书式 17.20 逐行给出。）**SLAM 总熵 = 路径熵 + 地图期望熵**——两个不确定性源被放进同一账本，探测行动的选择有了统一的裁决标准。**教程数值验证**：取 $x \sim \mathcal{N}(0,1)$、$m \mid x \sim \mathcal{N}(x, 0.5)$，$H(x) + H(m \mid x) = 1.4189 + 1.0724 = 2.4913$，2 维联合高斯的熵 $\frac12(2(1+\log 2\pi) + \log 0.5) = 2.4913$——**精确相等** ✓。（验证花絮：本教程初版脚本把 2 维联合熵错按 1 维边缘方差计算而误报"不匹配"——差值恰为 1 nat 的维度项；链式法则恒等式从不需要验证，需要验证的是验证者的维度。）

**② FastSLAM 探测**（原书程序 17.3）：生成-测试架构——**提议**一段探测控制序列 → 用随机粒子**仿真**执行（每步：运动采样、测量采样、FastSLAM 更新）→ 按 (17.3) **评分**：位姿项 = 对最终位姿粒子拟高斯后取熵（$\frac12\log\det\Sigma$，原书用最后位姿近似全轨迹——与行动粒度的近似哲学一致）；地图项 = 各粒子占用栅格熵的平均；选期望总熵最小的序列，重复至收敛。**高斯熵引理**（原书程序 17.4）：$H = \frac{d}{2}(1 + \log 2\pi) + \frac12\log\det\Sigma$——证明即"期望展开 + $E[x^T\Sigma^{-1}x] = d$"；**教程验证**：2 维随机协方差上公式 3.1177 vs Monte Carlo 3.1163 ✓。

**③ 循环环境的裁决实验**（原书 17.5.3，图 17.15–17.17）：第 35 步，机器人在"继续探新"与"回起点闭环"之间——行动 1（闭环）效用**超过**行动 4（探新）（图 17.16b：除了新地图信息，位姿不确定性将大幅下降）；第 45 步闭环完成，位姿熵骤降、总熵显著下降；第 88 步位姿已准、地图熵主导 → 转头探新。**这就是"整合探索"的最终形态**：同一把熵的尺子，度量两种看起来相反的冲动。图 17.17 的熵演化曲线还给出一条工程规律：栅格地图的不确定性下降近似**线性于扫描覆盖的未知面积**——而位姿熵的涨落由闭环事件主导。

第 01 章的三扇门走廊、海岸导航、"绕远路换定位"的直觉，在第 17 章全部获得数学形态：信息增益 (17.1) 是"熵账本"的记账规则（02 章门实例的熵跟踪 → 17 章的增益定义）；合成效用 (17.2) 是海岸导航"目标项 + 信息项"的正式化；SLAM 熵分解 (17.3) 则把第 10–13 章的估计器与本章的决策器接上同一根轴。全书一以贯之的那句话——第 01 章"置信空间的规划**最优地**收集信息，因为最优规划只在有利于期望效用的程度上寻求新信息"——在第 17 章的闭环实验里得到最终注脚：**机器人有时探新、有时回访，不是规则切换，而是同一笔熵账的两笔支出**。

## 17.7 小结、术语表与书后习题全解

**要点回顾**：

1. 探测 = 以信息增益为报酬的控制；POMDP 双倍指数出局 → 贪婪 + 行动粒度（17.1–17.2）；
2. 主动定位 = 花费地图（反向值迭代）+ 信息增益地图（仿真）的合成爬山；开环移动是已知缺点（17.3）；
3. 栅格探测 = 逐格独立（第 09 章技巧回归）；熵 ≈ 期望熵减 ≪ 二值地图的成本；基于边界 + 值迭代 = 行业标准（17.4）；
4. 多机器人：贪婪分配 + 目标抑制 ≥ 超线性加速（至 2K）；未知起点用会合验证（17.4.3）；
5. SLAM 探测 = 熵分解 (17.3) + FastSLAM 生成-测试；闭环与探新的裁决自动化（17.5）。

**术语表（本章新增）**：探测（exploration）、主动定位（active localization）、信息增益（information gain）、条件熵（conditional entropy）、探测行动（exploration action）、基于边界的探测（frontier-based exploration）、超线性加速（super-unitary speedup）、拍卖/市场机制（auction / market-based mechanisms）、整合探索（integrated exploration）、追逃博弈（pursuit-evasion problem）。

**书后习题全解指导**（原书 17.8 节，书 466–467 页）：

**习题 1（三角形地标的最优询问）**——方法：对当前位姿后验，计算询问每个候选地标类型后的期望熵减（式 17.1 的离散版），选最大者；机器人移动改变的是"下一个可询问地标"，因此答案 = 在可达地标集中做同一计算。三角形三段各含两种颜色地标 → 询问不同段的地标对位姿后验的劈分方式不同；顺时针移动下一段 vs 不动 vs 逆时针的比较 = 三种"可达集"上的增益比较（原书图丢失，按方法代入具体几何即可——本题考的是 17.2 的流程，不是记答案）。

**习题 2（K 台机器人的加速上限）**——(a) **最多接近 $2K$ 倍**：单机器人探测的总路程 = 探测路径 + 回程路径；团队分摊后回程被消除，极限即 2 倍于线性增长。(b) K = 4 的最大化构造：**从中心枢纽放射出的 4 条等长死胡同走廊**——单机器人必须"进走廊 A、退回、进 B……"全程双程；4 台机器人各认领一条走廊，回程完全省略 → 恰好 2K 倍。策略：中心会合分配（程序 17.2 的抑制机制天然完成）。

**习题 3（K 台才够的追逃环境）**——构造原则：**环境的"分支覆盖数" = K**——存在这样的区域布局，使 K−1 台机器人的可行巡视无法同时封死所有逃逸路线，而 K 台可以（对逃逸者的最坏移动策略鲁棒）。K = 2：**环形走廊**——单机器人沿环追，逃逸者同向奔跑永不相遇；两台反方向包抄必相遇。K = 3：**三叉星形（Y 形）走廊**——逃逸者躲在其中一叉；两台各封两叉仍有第三叉敞开；三台各守一叉向内压进则必捕获。K = 4：四叉/十字加环的组合（每臂末端带小环，封臂须 1 人、扫环再须 1 人——构造使覆盖数恰为 4）。这组构造是"分支因子决定探测复杂度"（17.2.2）的空间化。

**习题 4（K 臂赌博机）**——(a) **贪婪次优**：反例——臂 1 以已知概率 $p_1 = 0.5$ 付钱；臂 2 首次试验付钱（$\hat p_2 = 1$），但其真实 $p_2$ 均匀先验。贪婪按 MLE 选臂 2（1 > 0.5）并无限押注；若臂 2 真实 $p_2 = 0.4$，长期损失显著。正确做法要为**不确定性**留出探索价值——期望意义上臂 2 的后验均值 0.5 与臂 1 打平，但其"可能更好"的期权价值使最优策略仍应先试臂 2 数次、证实后回归——贪婪无此机制。(b) **最优策略从不彻底放弃**：均匀先验下任何臂仍有可能 $p_k = 1$（严格正后验概率）；若某臂真为最优而被永久放弃，长期遗憾线性增长——最优策略（Gittins 指数类）必然以递减但非零的频率回访每个臂（"不确定性原则"）。(c) K = 2 实现骨架：UCB1（$\text{score}_i = \hat p_i + \sqrt{2\ln t / n_i}$）或贝叶斯 Thompson 采样（每臂维护 Beta 后验、按后验采样值选臂）；跑 1000 局 × 100 步，对照 $p_1, p_2$ 的真值报告平均总报酬与遗憾曲线。策略解释要点：UCB 的第二项 = "不确定性的期权价值"，正是 17.2 信息-花费权衡的赌博机版。

**习题 5（熵 vs 期望熵减的误差界）**——两者之差恰是"单次测量与格子的**互信息**" $I(m_i; z) = H(p_i) - E[H(\text{post})] \ge 0$（互信息非负）。**教程数值**（$p_{\mathrm{true}} = 0.9$）：误差在 $p_i \in \{0, 1\}$（已确定格）处**严格为零**——两种方法在确定格上一致；最大误差 $\approx 0.43$ nat 出现在 $p_i \approx 0.66$（高不确定带，略偏向占用侧）；$p_i = 0.5$ 处误差 $0.368$。规律：**格子越确定，两种近似越一致；最大分歧在高不确定带**。这解释了原书图 17.6"两者几乎无差别"的实践结论——已建图区域（大部分格子接近 0/1）贡献的差异可忽略，而探测恰好只去高差异带，所以**二值近似在"该去哪"的排序上往往够用**。

**习题 6（高斯测量的期望信息增益）**——先验 $\mathcal{N}(\mu, \Sigma)$、测量 $\mathcal{N}(x; x, Q)$（即 $z = x + \delta$，$\delta \sim \mathcal{N}(0, Q)$）。后验精度相加：$\Sigma' = (\Sigma^{-1} + Q^{-1})^{-1}$，即 $\Sigma' = \Sigma(\Sigma + Q)^{-1}Q$（1 维时 $\Sigma' = \Sigma Q/(\Sigma + Q)$）。信息增益（原书式 17.4）：

$$I = H(\Sigma) - H(\Sigma') = \tfrac12 \log\frac{\det\Sigma}{\det\Sigma'} = \tfrac12 \log\det(\Sigma^{-1}\Sigma')^{-1} = \tfrac12 \log\det(I + \Sigma Q^{-1}),$$

1 维即 $I = \frac12\log(1 + \Sigma/Q)$（**教程数值**：$\Sigma = 2, Q = 0.5$ → $I = 0.805$ nat $= 1.16$ bit）。**两点洞察**：①均值 $\mu$ 完全不出现在公式里——**信息增益只由协方差（不确定性）决定**，与"你现在认为在哪"无关，只与"你有多确定"有关；②传感器越准（$Q \to 0$）增益越大、越差（$Q \to \infty$）增益趋零——17.2 的 $\alpha I_b(u) - E[r]$ 由此可以把"信息的价格"定成与传感器质量无关的常数。此题是全书最后一次"配平方"，与第 03 章 KF 更新首尾呼应。
