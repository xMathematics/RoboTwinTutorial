# 第 14 章｜马尔可夫决策过程

前十三章回答"世界是什么样的"（估计），从本章起回答"该做什么"（行动选择）。原书用 3 个动机场景开场（乱序抓件机械臂 / 冰下潜航器 / 多机器人探星），并把不确定性切成两刀：**行动效果的不确定**（"我按指令走，结果未必是我想的"）与**感知的不确定**（"我看不清现在是什么状态"）。本章处理**只有前一种**的情形——**马尔可夫决策过程**（MDP，状态完全能观测 + 随机转移），核心对象从分布换成**策略** $\pi: x \to u$（覆盖所有可能局面的行动映射，而非开环动作序列），核心算法是**值迭代**——全书最古老（Bellman 1957）也最长寿的算法，它是第 15 章 POMDP 置信空间值迭代的直接母体。本章的方法论红线一句话：**把"目标"与"代价"折算成同一币种（报酬），把"未来"折算成几何级数（折扣），然后在贝尔曼方程的不动点上等最优策略**。

> 原书锚点：第 14 章，书 374–393 页（PDF 392–411 页）。值迭代的**压缩映射收敛性证明**原书从略（仅断言"γ<1 收敛"），本章补全并数值验证（随机 20 状态 MDP 上实测每步收缩率 0.8998 ≤ γ = 0.9，误差始终在理论界内）。

## 14.1 两类不确定性与问题阶梯（原书 14.1–14.2）

**① 对称走廊的阶梯演示**（原书 14.2 的贯穿实例）：对称环境、目标在远端，有近而窄与远而宽两条路。三级阶梯：

1. **确定性规划**（无不确定性）：开环动作序列即可，窄路必胜——但这只是教学基准，"没有不确定性就没必要写这本书"（原书原话）；
2. **MDP**（行动随机 + 状态完全能观测）：开环序列不再够——必须为**所有可能局面**预备行动，即计算**策略** $\pi: x \mapsto u$（控制策略 / 导航函数 / 通用规划，同一物的三个名字）。运动噪声调大后，最优策略自动放弃窄路改走宽路（原书图 14.2a vs b）——**不确定性进入了规划器，而不是事后打补丁**（对比传统"规划 + 反馈避障模块"的拼接：避伤的代价是减速，窄路反而更慢）；
3. **POMDP**（两种不确定性都有）：机器人不知道自己朝左还是朝右、且无传感器告知到达目标——任何直线策略都有 50% 失败率。最优策略是**先绕到角落消除方向歧义，再奔目标**（原书图 14.3）。

**② 阶梯 3 的两个关键论断**：其一，"对各种可能环境求均值解不出来"——两个假设情形的最优策略各自是"直奔目标"，均值策略却应该是"先去角落"；**最优性在置信空间里不线性**。其二，置信空间维度 = 状态数（有限状态时）或无限（连续状态）——代价的来源。原书由此定调全书后半段的立场：**置信空间里的最优规划"最优地"收集信息——只在有利于期望效用的程度上收集**（第 17 章探测的种子）。

## 14.2 报酬、策略与折扣（原书 14.3.1）

**① 报酬函数：目标与代价的同一种货币**。二元表述（"达到目标了吗" + "花了多少"）统一为单一标量（原书式 14.1）：

$$r(x, u) = \begin{cases} +100 & \text{控制 } u \text{ 使机器人到达目标} \\ -1 & \text{其他} \end{cases} \tag{14.1}$$

统一的深层理由（原书明示）：不确定性下"是否达标"本身是概率事件，**"多花力气提高达标概率值不值"** 必须在同一账本上结算——这正是第 01 章海岸导航"目标项 + 信息项"效用的正式化。

**② 策略与累积报酬**：策略 $\pi$ 把（历史或状态）映射为控制（原书式 14.2/14.3/14.8，完全能观测时退化为 $\pi: x \to u$）。优化对象是**期望累积折扣报酬**（原书式 14.4）：

$$R_T = E\Big[\sum_{\tau=0}^{T} \gamma^\tau r_{t+\tau}\Big], \qquad \gamma \in [0, 1]\ \text{为折扣因子}. \tag{14.2}$$

**③ 三种规划视界**（原书 14.3.1 的精细辨析，各自藏着坑）：

| 视界 | 定义 | 陷阱与用途 |
|------|------|-----------|
| 贪婪 $T=1$ | 只优化下一时刻报酬 | 多步后果不可见（退化），但多项式时间可解——许多场合的唯一现实选项；对 γ 不变（要求 γ > 0） |
| 有限 $T$ 有限 | 无折扣 γ = 1 | **最优策略随剩余步数变化**（视界远端与近端的最优行动不同）→ 必须为每个 T 分别维护策略，复杂度爆炸 |
| 无限 $T = \infty$ | 折扣 γ < 1 必需 | 剩余步数处处相同 → 策略平稳；无折扣则 $+\infty$ vs $+\infty$ 无从比较（每小时 1 美元 vs 100 美元的机器人例子） |

**④ 折扣的收敛保证**：报酬有界（$|r| \le r_{\max}$）时几何级数给出（原书式 14.5）：

$$R_\infty \le \sum_{\tau=0}^{\infty} \gamma^\tau r_{\max} = \frac{r_{\max}}{1-\gamma}. \tag{14.3}$$

（最大化**平均**报酬是另一条技术路线，原书声明不做研究。）策略之间的比较随之良定义：$R^\pi(x) = E[\sum \gamma^\tau r_{t+\tau} \mid \pi]$，取期望报酬更高者（原书式 14.6–14.7）。

## 14.3 贝尔曼最优性与值迭代（原书 14.3.2–14.3.3）★

### 14.3.1 递归结构与贝尔曼方程

最优策略与值函数按视界递归定义（原书式 14.9–14.14）：$T = 1$ 时 $\pi_1(x) = \arg\max_u r(x, u)$、$V_1(x) = \gamma\max_u r(x, u)$；一般地

$$\pi_T(x) = \arg\max_u \Big[r(x,u) + \int V_{T-1}(x')\, p(x' \mid u, x)\, dx'\Big], \qquad V_T(x) = \gamma \max_u \Big[r(x,u) + \int V_{T-1}(x')\, p(x' \mid u, x)\, dx'\Big]. \tag{14.4}$$

无限视界下值函数趋于**平衡**（原书式 14.15）：

$$V(x) = \gamma \max_u \Big[r(x,u) + \int V(x')\, p(x' \mid u, x)\, dx'\Big] \qquad \text{（贝尔曼方程）}. \tag{14.5}$$

原书断言：满足式 (14.15) 的值函数对构造最优策略**既必要又充分**——"无需证明"的这句，本教程补上证明（14.3.3）。

### 14.4.2 值迭代算法（原书程序 14.1）

```text
Algorithm MDP_discrete_value_iteration():
    for all states x_i: V(x_i) = r_min                        # 初始化为最小瞬时报酬
    repeat until convergence:
        for all x_i:
            V(x_i) ← max_u [ r(x_i, u) + Σ_j V(x_j) P(x_j | u, x_i) ]   # 备份步骤 (backup step)
    return V

Algorithm policy_MDP(V, x):  return argmax_u [ r(x,u) + Σ_j V(x_j) P(x_j | u, x) ]
```

"备份"之名：值按**反时序**从后继状态回流到当前状态（这个词汇将统治第 15 章的置信空间备份）。状态更新顺序无关紧要（只要每个状态被无限次更新）。收敛后，对最终 $V$ 的贪婪策略（式 14.18）即最优。

### 14.3.3 收敛性证明：压缩映射（原书从略，教程补全）

**定义算子**（贝尔曼备份算子）：$(TV)(x) = \gamma\max_u [r(x,u) + \int V(x')p(x'\mid u,x)dx']$。值迭代就是 $V \leftarrow TV$ 的迭代。三条性质：

1. **$T$ 是 γ-压缩映射**：对任意两个值函数 $V_1, V_2$，记 $\Delta = \|V_1 - V_2\|_\infty$。对每个 $(x, u)$：

$$\Big|\int (V_1 - V_2)p(x'\mid u,x)dx'\Big| \le \int |V_1 - V_2|\,p\,dx' \le \Delta \quad (\text{积分保序，概率和为 1})，$$

$$|(TV_1)(x) - (TV_2)(x)| = \gamma\Big|\max_u[\cdot\, V_1] - \max_u[\cdot\, V_2]\Big| \le \gamma \max_u \Big|\int (V_1-V_2)p\,dx'\Big| \le \gamma\Delta$$

（第二步用 $\max_a f - \max_a g \le \max_a (f - g)$）。对 $x$ 取上确界：$\|TV_1 - TV_2\|_\infty \le \gamma \|V_1 - V_2\|_\infty$。$\blacksquare$

2. **Banach 不动点定理**：完备度量空间上的压缩映射有唯一不动点 $V^*$，且从任意 $V_0$ 出发 $V_k = T^kV_0 \to V^*$，误差几何衰减：

$$\|V_k - V^*\|_\infty \le \frac{\gamma^k}{1-\gamma}\,\|V_1 - V_0\|_\infty. \tag{14.6}$$

**教程数值验证**（随机 20 状态、4 动作 MDP，γ = 0.9）：实测每步收缩率 0.8998 ≤ 0.9，各步误差全部位于界 (14.6) 之下（k=1: 6.58 ≤ 9.88；k=12: 2.00 ≤ 3.10）。

3. **不动点即最优、贪婪即最优**：①唯一性 → 值迭代收敛到的就是贝尔曼方程的解；②对 $V^*$ 的贪婪策略 $\pi^*(x) = \arg\max_u[r + \int V^* p]$ 达到该式右端的最大值 → $\pi^*$ 满足贝尔曼最优性 → 最优（"必要且充分"补全）。$\blacksquare$

**工程注脚**：误差界 (14.6) 也是**停止准则**——想要 $\varepsilon$-最优值函数，迭代到 $\|V_{k+1} - V_k\|_\infty \le \varepsilon(1-\gamma)/\gamma$ 即可（每步差与真误差差一个 $\gamma/(1-\gamma)$ 因子）。

## 14.4 机器人应用：配置空间上的值迭代（原书 14.4）

**两个近似**把算法推向实战：①**状态/控制空间离散化**（第 04 章直方图思想的复用；查表即策略；维数灾难限制在低维——高维要靠参数化值函数/学习算法，原书一并点名）；②**均值后验替身**（原书式 14.19）：$x_t = E[p(x_t \mid z_{1:t}, u_{1:t})]$——**只在定位保持局部时合法**；全局定位或绑架场景失效（第 07 章均值后验的失败案例在此正式入册，POMDP 的必要性第二次论证）。

**环形机器人**：配置空间 = 工作空间障碍物膨胀机器人半径（第 05 章式 (5.13) 附近的配置空间概念落地）；值函数铺满全状态空间 → **无论机器人在哪里都能给出行动**（随机环境下"处处有答案"是策略相对路径的本质优势）；工程上 2D 近似（忽略转向代价与速度维）+ 快速反应避障模块兜底，5 维全状态值迭代在 PC 上数秒。**2-DOF 机械臂**（肩 + 肘）：轴角编码器使式 (14.19) 成立（该假设罕见的合法场景）；配置空间的自由区/碰撞区分解后值迭代；**确定性与概率运动模型的对比**（原书图 14.7 vs 14.8）：确定性模型给出的路径在噪声执行下贴着障碍走，概率值迭代自动给出"离墙更远"的路径——MDP 阶梯的机械臂版。

## 14.5 与全书主线的汇合

本章把第 01 章的三条承诺兑现了一半：海岸导航的"目标 + 信息"效用有了正式容器（报酬函数），"主动收集信息"被识别为置信空间规划的性质（POMDP 的任务）。均值替身 (14.19) 的失效边界与第 07 章全局定位失败遥相呼应。值迭代本身在书中反复回响：第 15 章的**置信空间值迭代**（备份算子作用在信念上）、第 17 章的**信息增益**进入报酬。最后照录原书的定位声明：值迭代不是最快的规划算法（A*、直接策略搜索、分层/实时变体见文献综述），选它做基底只因它是 POMDP 场景下最可理解的技术——教学的诚实。

## 14.6 小结、术语表与书后习题全解

**要点回顾**：

1. 两类不确定性分阶梯：确定性规划 → MDP（策略替代开环序列）→ POMDP（置信空间规划）；均值化不可解对称歧义（14.1）；
2. 报酬函数统一目标与代价；折扣因子驯服无限视界；三种视界各有陷阱（有限视界的时变策略）（14.2）；
3. 贝尔曼方程 + 压缩映射 → 值迭代几何收敛、贪婪策略最优（收敛性证明为本教程增量，已数值验证）（14.3）；
4. 均值后验替身只在局部定位合法；配置空间 + 空间离散化是机器人化的两件套（14.4）。

**术语表（本章新增）**：行动选择（action selection）、信息收集任务（information gathering tasks）、完全/部分能观测（fully/partially observable）、控制策略/导航函数/通用规划（policy / navigation function / universal plans）、报酬函数（payoff function）、折扣因子（discount factor）、规划视界（planning horizon）、贪婪/有限/无限视界（greedy / finite-horizon / infinite-horizon）、值函数（value function）、贝尔曼方程（Bellman equation）、值迭代（value iteration）、备份步骤（backup step）、压缩映射（contraction mapping）、配置空间（configuration space）、近似单元分解（approximate cell decomposition）。

**书后习题全解指导**（原书 14.7 节，书 392–393 页）：

**习题 1（"最可能状态决策"何时完全错误）**——构造：两个房间 $A$、$B$ 由一扇窄门相连；机器人 99% 可能在 $A$（最可能状态），1% 在 $B$；行动"向右走"在 $A$ 中安全抵达目标、在 $B$ 中**坠崖**（报酬 $-1000$）。按最可能状态决策 → 选"向右走" → 期望报酬 $0.99\,r_{\text{goal}} + 0.01 \times (-1000)$，可能为负；而按**期望效用**决策会选先确认位置或向左走的动作。原理：**决策依据应是期望报酬（对整个分布加权），而非分布的众数**——众数忽略尾部风险，且报酬函数对状态高度非线性时（灾难状态）尾部主导期望。这道题是第 01 章"0.983 还不够好"与"剩余风险交还决策层"的习题版。

**习题 2（花费函数改变后继续迭代）**——(a) **取决于变化方向**。值迭代收敛到 $V^* = \lim T^k V_0$；若花费**增加**（报酬整体下调），新的 $V^*_{\text{new}} \le V^*_{\text{old}}$（逐点），以旧值函数热启动的迭代从"上方"单调下降逼近——合法且通常加速（初始误差小于冷启动）；若花费**减少**，新 $V^*_{\text{new}} \ge V^*_{\text{old}}$，热启动从"下方"逼近，同样合法（压缩映射与起点无关），但"继续迭代"的次数可能不省——旧值函数里存储的"地形信息"部分作废。(b) **可以更高效**：利用变化的结构性。①**局部性**：若只有 $S_0 \subset S$ 的报酬变了，价值变化从 $S_0$ 出发以每步 $\gamma$ 的速度向外传播——用**优先级排队/异步值迭代**（Gauss–Seidel + 前驱图）只更新受影响的状态，复杂度正比于"受影响球"的大小而非全空间；②**差分热启动**：以 $V_{\text{old}} - V^*_{\text{old}}$ 的残差做初值修正；③变化很小时直接做一次**策略迭代式**收敛（策略通常不变，只需验证 $V^{\pi_{\text{old}}}$ 仍满足贝尔曼方程）。②③的前提（变化稀疏/策略不变）不满足时，无从超越全量重迭代——算法下界由"需要重估的状态数"决定。

**习题 3（"天堂还是地狱"：单隐藏变量的动态规划）**——迷宫：起点 $S$，两个对称目标格 $H$（一个 +100、一个 −100，各 50% 概率；到达即终局），移动花费 −1，另有格子 $X$（读取后即知哪个 $H$ 是"天堂"）。**(a) 确定性运动 + 无 X**：任何策略的到达分布对两个 $H$ 对称 → 期望报酬 $0.5(+100) + 0.5(-100) = 0$ 减去路程成本 → **值迭代给出的最优策略 = 直奔最近的 $H$**（最小化路程），$S$ 处的值 = $-d_{\min}$（$\gamma = 1$ 时；折扣版为 $-d_{\min}$ 的折扣和）。直白地说：**不知情时天堂与地狱对冲，唯一能优化的是路费**。(b) 概率运动（90% 执行指令、10% 随机）：同构计算，只是备份步骤换概率转移；$S$ 的值进一步下降（随机漂移增加路程期望），策略倾向"贴墙走"以限制漂移面。(c) **加入 X**：策略翻转为**先去 $X$ 读牌、再直奔天堂格**——期望 = $+100 - (\text{路程}_{S\to X} + \text{路程}_{X\to H^+})$。它优于 (a) 当且仅当绕道成本 $< 100 - d_{\min}$（避开地狱的期望收益减去直达节省）。**"先绕路获取信息更优"——第 14.1 节 POMDP 走廊实例的迷宫版**。(d) 修改值迭代：把隐藏变量并入**置信空间**——状态增广为（格子，$b$），$b \in \{\text{不知情}, \text{已知情}(H^+ = \text{左})\}$ 等离散信念；转移规则里 $X$ 格把"不知情"确定性地映到"已知情"、$H$ 格在"不知情"下按 50/50 分叉到两种"已知情"终局；在增广状态上跑普通值迭代。这**就是 POMDP 置信空间值迭代的最小实例**（信念只有两个取值所以精确可解）——第 15 章 15.3 节有限环境压缩的思想预演。(e) 实现按 (d) 约化（两信念状态 × 迷宫格），起始值与最优策略由读者代入具体迷宫几何；判据公式已给于 (c)。
