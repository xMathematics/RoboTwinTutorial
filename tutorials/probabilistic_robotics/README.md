# probabilistic_robotics/ — 《概率机器人》逐章精读教程

底本：Sebastian Thrun / Wolfram Burgard / Dieter Fox《概率机器人》中文版
（机械工业出版社 2017，全书 4 部分 17 章，本地 PDF：[`../../book/概率机器人-中文.pdf`](../../book/概率机器人-中文.pdf)，
页码换算：**PDF 页 = 书页 + 18**）。

教程目标：**逐章给出比原书更细的中文讲解**——每个核心知识点按
[问题导向五步法](../../CONSTRAINTS.md)展开（问题场景 → 解决方法 → 选型理由 → 完整公式推导 → 反直觉点/适用边界），
重点补足原书从略的推导中间步与代数细节。
