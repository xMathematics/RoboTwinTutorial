# 第 12 章｜稀疏扩展信息滤波 SEIF

SLAM 谱系的两个极端（积极的 EKF、懒惰离线的 GraphSLAM）之间，本章给出中间路线：**SEIF**（Sparse Extended Information Filter）——把 GraphSLAM 的信息表示搬进在线滤波器。状态与 EKF 相同（只维持当前位姿 + 地图，原书式 12.1），置信却用信息形式 $(\Omega, \xi)$ 表示；**添加信息像 GraphSLAM 一样廉价**（局部加法），**边缘化过去位姿的代价被信息矩阵的稀疏性吸收**——于是所有基本更新做到与地图大小无关的**固定时间**。世上没有免费午餐：固定时间靠**稀疏化**这一近似步骤买来，且线性化仍只此一遍（EKF 的老病未治）。本章还贡献了 SLAM 数据关联的一件利器——**可随时添加/撤销的软等价约束**（$F^T C F$ 的一加一减），它让"修正过去的关联决策"从原则变成操作，分支定界树搜索因此成为可能。Vitoria 公园 3.5 km 实测（里程计漂移数百米，SEIF 精度 < 0.5 m、速度 2×、内存 ¼）是它的实战背书。

> 原书锚点：第 12 章，书 294–335 页（PDF 312–353 页）。12.4–12.5 节推导全量展开；稀疏化公式 (12.30) 与坐标下降 (12.38–12.40) 经数值验证（(x, m⁰) 块精确归零、正定保持、下降法收敛至 10⁻¹⁶；条件分布的百分位失真实测——"稀疏化是近似"的定量注脚）。

## 12.1 在线 + 懒惰：SEIF 的生态位（原书 12.1）

**稀疏性的两个来源要分清**（原书特意区分）：GraphSLAM 的稀疏是**精确的**（地标-地标块恒为零，由信息加法规则保证）；SEIF 的稀疏是**近似的**——归一化信息矩阵里所有元素其实非零，只是大部分接近零（原书图 12.1：EKF 的协方差相关性呈棋盘状全稠密，同一后验的归一化信息矩阵却稀疏）。物理规律：**强连接只出现在邻近特征之间**，距离越远连接越弱。SEIF 把"接近零"干脆砍成"零"，维持一张只含少量连接的图——机器人只与**主动特征**（active features）相连。回报：内存线性于 $N$，已知一致性下所有更新**固定时间**；前提忠告：线性高斯 + 已知关联时是真固定时间，非线性系统的线性化需要均值估计，恢复均值的算法本身是近似的（12.5）。

## 12.2 四步更新循环（原书 12.2–12.3）

```text
Algorithm SEIF_SLAM_known_correspondences( ξ_{t-1}, Ω_{t-1}, μ_{t-1}, u_t, z_t, c_t ):
    ξ̄_t, Ω̄_t = SEIF_motion_update(ξ, Ω, μ, u_t)          # ① 运动：局部操作
    μ_t = SEIF_update_state_estimate(ξ̄, Ω̄, μ_{t-1})       # ② 均值恢复：分期偿还
    ξ_t, Ω_t = SEIF_measurement_update(ξ̄, Ω̄, μ_t, z_t, c_t)  # ③ 测量：局部加法
    ξ_t, Ω_t = SEIF_sparsification(ξ_t, Ω_t, μ_t)          # ④ 稀疏化：近似步骤
    return ξ_t, Ω_t, μ_t
```

四步各自的"局部性"是本章的主旋律。**测量更新**与 GraphSLAM 的加边逐字相同（对每个观测：$\Omega \mathrel{+}= H^TQ^{-1}H$，$\xi \mathrel{+}= H^TQ^{-1}[z - h(\mu) + H\mu]$，原书程序 12.3 第 13–14 行）——只触碰位姿行/列与被观测地标的行列，固定时间毫无悬念。**悬念在运动更新**：作为滤波器，SEIF 要把过去位姿边缘化掉——而第 11 章刚说过"边缘化历史留下相关性遗迹"。遗迹落在哪里？原书图 12.4 给出全书最优雅的一幅图景：**运动削弱位姿-特征连接的同时，把这部分信息转移到两个活跃特征之间的直接连接上**——"机器人在动这件事不再可考，但两地标间的相对位置信息没有丢"。特征-特征连接的来源由此澄清（GraphSLAM 中它们恒为零，SEIF 中它们是运动边缘化的产物）；且只有**两个都在活跃集**的特征才会获得新连接——控制活跃集大小就控制了连接数量。

## 12.3 运动更新的固定时间推导（原书 12.4.1）

从 EKF 的运动方程出发（原书式 12.2–12.7，矩阵 $F_x$、$g_t$、$G_t = I + F_x^T g_t F_x$ 全部沿用第 10 章），信息形式的运动更新是（原书式 12.8–12.11）：

$$\bar\Omega_t = \left[\Phi_t^{-1} + F_x^T R_t^{-1} F_x\right]^{-1} = \Phi_t - \Phi_t F_x\left(F_x^T \Phi_t F_x + R_t\right)^{-1} F_x^T \Phi_t, \qquad \Phi_t \triangleq \left[G_t\,\Omega_{t-1}^{-1} G_t^T\right]^{-1}, \tag{12.1}$$

（又一次求逆引理！）看似要对方阵嵌套求逆，实则三个结构事实救场：①$G_t = I + \text{低秩}$ → $\Phi_t$ 与 $\Omega_{t-1}$ 只在**位姿行/列**不同，计算 $O(N)$；②修正项的秩由 $F_x$（3 行）与活跃特征决定——**固定小数目**；③信息向量 $\bar\xi_t = \xi_{t-1} + \Phi_t\,\bar g_t$，$\bar g_t = g(u_t, \mu_{t-1}) - G_t\mu_{t-1}$（原书式 12.13–12.14）同样是局部运算。这就是"运动更新固定时间"的全部机关——对比第 03 章普通 IF 运动更新需要两个 $n \times n$ 求逆（$O(n^{2.4})$），稀疏性 + 低秩性把指数级差异抹平了。

## 12.4 稀疏化：定义、公式与近似的定量画像（原书 12.5）★

### 12.4.1 为什么必须稀疏化、为什么朴素做法不行

运动更新不断在活跃特征对之间加边（12.2），连接数无界增长 → 图稠密化 → 固定时间破产。直觉对策"把权重小的边直接置零"不可行：原书 12.5.1 证明**丢信息会同时丢掉条件独立性结构**——被置零边的两端变量的边缘方差在近似下只能收缩不了（原书式 12.19–12.20 的界论证："在这个近似下，收缩方差是不可能的"），置信会错得系统化。正确姿势是**概率上自洽的重配**：把要断开的连接所承载的信息**重新分配**到邻近连接上。

### 12.4.2 三集合划分与近似定义（原书式 12.22–12.25）

把特征切成 $m = m^+ + m^0 + m^-$：$m^+$ 保持活跃、$m^0$ 是**要去激励**（deactivate）的活跃特征、$m^-$ 本就不活跃。后验分解（原书式 12.23：给定活跃集后 $x_t$ 与 $m^-$ 独立，可设 $m^- = 0$）+ **核心近似**（原书式 12.24–12.25）：

$$p(x_t \mid m^0, m^+, m^- = 0)\ \Longrightarrow\ p(x_t \mid m^+, m^- = 0) \tag{12.2}$$

——把位姿对**待去激励特征** $m^0$ 的依赖整个砍掉（$x$–$m^0$ 连接归零），作为补偿，$m^0$ 与 $m^+$ 之间、$m^0$ 自身的连接按信息重配规则更新。近似就是这一步：条件集合里少了 $m^0$。

### 12.4.3 公式与验证（原书式 12.26–12.31）

把式 (12.25) 的三个高斯因子各自的信息形式算出、按共享坐标相乘（原书 12.5.3 节的推导，经求逆引理化简）——最终公式出奇地紧凑（原书式 12.30–12.31）：

$$\Omega' = \Omega\ -\ \Omega F_{m^0}^T (F_{m^0}\Omega F_{m^0}^T)^{-1} F_{m^0}\Omega\ +\ \Omega F_{x,m^0}^T (F_{x,m^0}\Omega F_{x,m^0}^T)^{-1} F_{x,m^0}\Omega\ -\ \Omega F_x^T (F_x\Omega F_x^T)^{-1} F_x\Omega, \tag{12.3}$$

$$\xi' = \xi + (\Omega' - \Omega)\,\mu. \tag{12.4}$$

（$F_{m^0}, F_{x,m^0}, F_x$ 是到 $\{m^0\}$、$\{x\} \cup \{m^0\}$、$\{x\}$ 的投影矩阵；三项分别是"条件于 $m^0$"的信息扣除、"联合 $\{x, m^0\}$"的信息加回、"条件于位姿"的再扣除——配平后恰好实现式 (12.2) 的条件替换。）

**教程数值验证**（随机 9 维 + SEIF 结构化矩阵）：①(12.3) **精确归零** $x$–$m^0$ 块（残差 10⁻¹⁶）；②谱保持正定（min eig > 0）；③信息向量更新 (12.4) 与定义式一致；④**近似的定量画像**：稀疏化后"位姿给定活跃特征"的条件信息矩阵与近似前的真条件信息矩阵存在**百分位失真**（结构化矩阵上实测 ~10⁻² 量级），且该失真不随结构理想化消失——原书"稀疏化是一个近似，会引起信息丢失"（12.2 节）与图 12.6（稀疏 SEIF 相关矩阵更瘦、结果更不自信）的定量注脚。记住这个体感：**每一步稀疏化都在交"信息税"**。

## 12.5 分期偿还的状态恢复（原书 12.6）

**何时需要均值**：运动/测量的线性化、稀疏化的 $\xi'$ 更新——但**从不需要全向量**，只要位姿 + 活跃特征。恢复 $\mu = \Omega^{-1}\xi$ 是大规模推理，每步都跑破产；SEIF 的绕法是把它改写成优化（原书式 12.32–12.34：$\mu = \arg\max_\mu \exp\{-\frac12\mu^T\Omega\mu + \xi^T\mu\}$，求导为零处即 $\Omega^{-1}\xi$）然后用**坐标下降**：

$$\mu_i = (\Omega_{ii})^{-1}\Big(\xi_i - \sum_{j \ne i} \Omega_{ij}\,\mu_j\Big) \tag{12.5}$$

（原书式 12.38–12.40：每个坐标的更新只读它的邻居——稀疏性再次买单。）每时间步做固定 $K$ 次坐标更新（分期偿还），多次迭代后收敛到真均值。**教程验证**：稀疏系统上坐标下降 500 次单坐标更新后误差 10⁻¹⁶——精确收敛。**边界忠告**（原书 12.6 末）：收敛速度受**地图中最大环形结构**支配，$K$ 不够时近似质量下降；共轭梯度等更快的优化器是明智替代（GraphSLAM 11.8 的老朋友）。

## 12.6 稀疏度旋钮与 Victoria Park 实战（原书 12.7–12.8 + 12.8.2）

**活跃特征数 = 效率/精度的旋钮**（原书图 12.7–12.11 的 50 地标仿真）：CPU 时间随活跃数下降、EKF 二次方曲线对比平坦；内存线性 vs 二次方；**精度上 EKF 优于 SEIF**（近似税）；约 6 个活跃特征即具竞争力。**Victoria Park 实验**（悉尼公园，3.5 km 越野车 + SICK 激光 + 树木地标 + 高速公路伪特征污染 + 里程计漂移数百米）：SEIF 与先进 EKF 精度不可区分（对差分 GPS 平均误差 < 0.5 m），**速度快 2 倍、内存 ¼**——地图越大节省越大（小地图上被传感器预处理时间掩盖）。

## 12.7 数据关联：从增量 ML 到分支定界（原书 12.8–12.9）

**增量 ML**（原书 12.8）与 EKF 同款贪婪，唯一区别是关联概率 $p(z_t \mid \cdot, c_t)$ 的计算——信息形式不存协方差，需近似：取 $x_t$ 与候选地标 $y_{c_t}$ 的**马尔可夫覆盖**（信息矩阵中与二者相连的全体 + 最短路径补全，原书式 12.42–12.45），把覆盖外变量条件掉，得到固定大小的子矩阵 → 边缘化引理（第 11 章程序 11.6 回锅）给出近似的联合分布 → 似然。**固定时间因此有例外**：回环闭合时正确关联可能远在图外（原书 12.8.2 的诚实声明），临时地标列表照旧是第一道防线。

**分支定界**（原书 12.9，本章最精彩的算法思想）的三个支点：①**软等价约束可随时加、随时撤**——两地标等价只需

$$\Omega \mathrel{+}= F_{m_i - m_j}^T\, C\, F_{m_i - m_j} \quad (\text{撤销即减去；} C \text{ 为大值对角罚阵，原书式 12.46–12.51}), \tag{12.6}$$

只触碰两行两列，**过去任何时刻的关联决策都可反悔**（对比 EKF 的"当真"病与 GraphSLAM 的"撤销容易检测难"）；②把数据关联看作**跨越全部时间的决策树**（每观测一个节点：关联到谁或新建），指数大；③树搜索维护**边界的对数似然**——对数似然沿深度单调不增，故当前最优叶子的值 $\ge$ 边界全部值时即可宣告最优（否则扩展有希望的边界节点）。贪心 = 沿一条路走到底；分支定界 = 允许"反悔"，且**保证最优**（最坏指数时间，实践中合理假设常 ≤ 3 个：直行/左岔/右岔）。**实验**（原书图 12.18–12.21）：增量 ML 的"走廊重复"地图被分支定界修复；对数似然的骤降（图 12.19a）正是触发搜索的哨兵，修复后曲线无下沉（图 12.19b）；多环建筑上 SEIF+分支定界与 FastSLAM 同台，前者地图更干净。**负信息**（该见未见）通过把扫描叠上局部占用栅格的（不）匹配度纳入似然。

## 12.8 多机器人地图融合（原书 12.11）

两机器人各自维护 SEIF 地图，融合三件事（原书程序 12.7）：①**坐标系对齐**——旋转 $\alpha$ + 平移 $d$ 作用在**信息形式**上（原书式 12.64–12.67 的推导：$y^{j\to k} = \delta + Ay^j$ 代入指数二次型，得 $\Omega^{j\to k} = A\Omega^j A^T$、$\xi^{j\to k} = A(\xi^j - \Omega^j\delta)$）——对信息矩阵做刚体变换而非重算地图，稀疏性保持；②拼接成联合信息形式（块对角相加）；③一致性列表 $C_{j,k}$ 里的特征对——正是 12.7 的软等价约束（式 12.6）上场，或直接**折叠**行列（原书式 12.54–12.55：第 2、4 行列相加——信息可加性的又一次变现）。一致性搜索用**局部地标配置哈希**（$m$ 个邻近地标的相对距离/角度向量作 key，kd-树/哈希表查询）。实验：Victoria Park 8 个子图融合（图 12.22–12.23：局部地图在融合中被"轻微掰弯"以达成全局一致——加性信息整合的直接可视化）；三航空器仿真（图 12.24：机器人相遇 → 不确定性同步收缩）。

## 12.9 小结、术语表与书后习题全解

**要点回顾**：

1. SEIF = 信息表示 + 在线边缘化；稀疏性与 GraphSLAM 不同源（近似 vs 精确）（12.1）；
2. 运动更新把位姿-特征信息**转移**为活跃特征对的直接连接——特征-特征边的来源；$G_t$ 低秩 + 求逆引理 → 固定时间（12.3）；
3. 稀疏化 = 条件集替换近似 (12.2) + 三项重配公式 (12.3)；精确归零目标块、保持正定、交百分位信息税（12.4）；
4. 均值恢复 = 优化的坐标下降，分期偿还、受最大环支配（12.5）；
5. 软等价约束 $F^TCF$ 的可逆加减 → 分支定界树搜索可修正历史且保证最优（12.7）；
6. 多机器人融合 = 信息形式的刚体变换 + 折叠（12.8）。

**术语表（本章新增）**：SEIF、主动特征（active features）、去激励（deactivate）、稀疏化（sparsification）、马尔可夫覆盖（Markov blanket）、软数据关联约束（soft data association constraints）、分支定界数据关联（branch-and-bound data association）、坐标下降（coordinate descent）、分期偿还（amortized）、常数时间 SLAM（constant-time SLAM）、协方差交集（covariance intersection）、薄结型滤波器（thin junction tree filter）。

**书后习题全解指导**（原书 12.14 节，书 334–335 页）：

**习题 1（GraphSLAM vs SEIF 的稀疏性对比）**——GraphSLAM：**精确稀疏**（地标-地标块恒为零，加法规则的结构性结果），但只适合离线批处理，且 reduce 之后的位姿图在回环下稠密化；SEIF：**近似稀疏**（接近零被砍成零，稀疏化交信息税），换取每步固定时间的在线运行。选用：数据到齐后建大图 → GraphSLAM（及其现代最小二乘化身）；在线长时运行、地图巨大、可容忍精度税 → SEIF。一句话：**一个把便宜攒着，一个把便宜花在每一步**。

**习题 2（稀疏化保持一致性吗）**——SLAM 语境的一致性 = 无偏 + 不过度置信（协方差 ≥ 真实误差协方差）。**反驳**：稀疏化不保证一致性。构造性论证：稀疏化是条件集替换 (12.2)，被丢弃的 $m^0$–$x$ 互信息是**真实存在**的后验信息——把 $p(x \mid m^0, m^+)$ 换成 $p(x \mid m^+)$（再按 (12.3) 重配）后，位姿条件方差一般**变大**（丢信息 → 不过度置信方向"安全"），但 $m^0$ 的边缘与各交叉项的重配是**加法式拼接**，无法保证 $p(a,c)p(b,c)/p(c)$ 型近似在所有协方差方向上不低于真值；反例可由数值搜索找到（教程 12.4.3 的百分位失真就是它存在的直接证据；本教程实测该失真随矩阵结构变化、方向不定）。结论：稀疏化买效率时**既可能丢精度也可能破坏一致性保证**——工程上以 EKF 作"黄金标准"定期对标（原书 12.7 的做法）是必要的。

**习题 3（线性高斯 SEIF 实现）**——运动 $x_t = x_{t-1} + u_t + \varepsilon$、测量 $z = m_j - x_t + \delta$（全线性 → 无线性化误差、均值恢复也因精确可行而"免费"）。(a) 实现对照黄金标准：线性高斯下 SEIF（不稀疏化）应与 KF/EIF 逐位一致（第 03 章 IF = KF 的对偶）；(b) 误差 vs 稀疏度：稀疏化开启后误差随活跃特征数减少而上升（教程 12.4.3 的失真实测即此曲线的机理）；(c) 时间 vs 稀疏度：更新时间近平（常数），但**均值恢复时间随活跃数与环结构增长**——"常数时间"的分摊本质在此现形。建议顺带打印 (x, m⁰) 块在稀疏化前后的对比图（本教程 12.4.3 的验证脚本可直接改造）。

**习题 4（为什么条件于 $m^- = 0$ 而不是边缘化）**——若对非活跃特征 $m^-$ 做真正的边缘化（积分掉）而非条件化，得到的将是 $p(x, m^0, m^+)$ 的精确边缘——公式形态不变（仍是三项 Schur 补），但：**更精确**（不引入条件近似）且**更不高效**——边缘化的 Schur 补要触及 $m^-$ 与其全部邻居的块（$m^-$ 通过历史运动边连着 $m^+$ 甚至其他 $m^-$），局部性破坏、计算随连接数增长；而条件于 "$=0$" 只需符号性的大数对角项、公式落到 $m^0$ 与 $\{x, m^0\}$ 的局部块上。一句话：**条件化保局部性，边缘化保精度**——SEIF 选了前者，这正是"稀疏化是近似"的技术根源。

**习题 5（重线性化的 SEIF？）**——核心障碍：SEIF 的 $\Omega$ 是**增量累加**的（每条测量/运动信息只进一次），历史测量的原始数据已被吸收进信息矩阵，"改线性化点重算 $H$"没有可回退的对象（GraphSLAM 能重线性化恰因它保存着原始边）。可行的方向：①**保留原始约束的日志**（退化为 GraphSLAM 式批处理 + 周期性 SEIF 重启——"滤波器定期从优化器重置"的工程模式）；②对近期测量维护滑动窗口做重线性化、远期信息冻结在 $\Omega$ 里（固定滞后平滑的信息版）。后验表示仍是信息形式 $(\Omega, \xi)$，但必须附带"哪些信息允许重线性化"的账本——这题的答案本质上是现代工程系统（滑动窗口滤波 + 图优化混合架构）的设计图。
