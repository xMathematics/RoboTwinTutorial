# 第 04 章｜非参数滤波：直方图与粒子

第 03 章的 Gaussian 家族买到了闭式与效率，代价是**单峰**——走廊里三扇门的后验，高斯只能给一个"平均位置"。本章给出两条挣脱单峰的路线，它们不假设后验的函数形状，用**有限个值**近似任意分布，且随参数个数趋于无穷一致收敛到正确后验：**直方图滤波**把状态空间切成区域、每格存一个累积概率；**粒子滤波**用随机样本（粒子）铺满高似然区。前者是第 08 章栅格定位与第 09 章占用建图的直接前置（04.2 的 log-odds 二值滤波是第 09 章的核心公式）；后者是第 08 章 MCL、第 13 章 FastSLAM 的母体。本章同时交代粒子滤波的四个实战陷阱（采样方差、重采样退化、偏差、粒子缺乏）——第 08 章的增强 MCL 与 KLD 采样全部是对这些陷阱的正式回应。

> 原书锚点：第 4 章，书 64–87 页（PDF 82–105 页）。4.1.3 节直方图近似的推导（书 67–69 页）与 4.3.3 节粒子滤波推导（书 77–78 页）本章全量展开；4.3.4 节实战部分（书 79–85 页）逐条给出对策。

## 04.1 直方图滤波：把积分变成求和（原书 4.1）

### 04.1.1 离散贝叶斯滤波（程序 4.1）

**① 问题场景**：第 02 章的门状态估计其实已经是这个算法——有限状态空间下预测积分天然退化为有限求和。把它正式化，作为一切网格类方法的基座。

**② 解决方法**：

```text
Algorithm Discrete_Bayes_filter( {p_{i,t-1}}, u_t, z_t ):
    for all k do
        p̄_{k,t} = Σ_i  p(x_t = x_k | u_t, x_{t-1} = x_i) · p_{i,t-1}   # 预测：矩阵-向量积
        p_{k,t} = η · p(z_t | x_t = x_k) · p̄_{k,t}                     # 更新：逐格似然加权
    endfor
    return {p_{k,t}}
```

程序 2.1 的积分 → 求和；置信 = 每个状态一格概率 $\{p_{k,t}\}$。这就是隐马尔可夫模型（HMM）的正向传递（forward pass）——信号处理界的同一算法。

### 04.1.2 连续状态：区域分解与"探针"近似（原书 4.1.2–4.1.3）

**① 问题场景**：连续空间必须先离散化才能用上表。把定义域切成凸区域（栅格是最常用的分解，原书式 4.1），每格只存一个数，则后验被近似为**分段常数密度**：

$$p_{k,t}(x) = \frac{p_{k,t}}{|X_{k,t}|}, \qquad x \in X_{k,t} \tag{4.1}$$

（$|X_{k,t}|$ = 区域体积；每格内部不再携带任何分布信息。）但滤波需要的是**逐点**密度 $p(z_t \mid x)$ 与 $p(x_t \mid u_t, x_{t-1})$——怎么从"格"得到"点"？

**② 解决方法——探针（probing）**：区域足够小且尺寸相近时，用区域代表（如均值，原书式 4.3）近似内部所有点：

$$p(z_t \mid x_{k,t}) \approx p(z_t \mid \bar x_{k,t}), \qquad p(x_{k,t} \mid u_t, x_{i,t-1}) \approx \eta\, |x_{k,t}|\, p(\bar x_{k,t} \mid u_t, x_{i,t-1}). \tag{4.3}$$

**③ 这两个近似为什么合理——完整推导**（原书 4.1.3 展开）：

**测量侧**（原书式 4.6–4.7）。对格 $x_{k,t}$ 在"内部均匀"模型（式 4.1）下计算**精确**的平均似然：

$$p(z_t \mid x_{k,t}) = \frac{\int_{X_{k,t}} p(z_t \mid x)\,\underbrace{p(x)}_{=\;p_{k,t}/|X_{k,t}|}\,dx}{p(x_{k,t})} = \frac{\tfrac{p_{k,t}}{|X_{k,t}|}\int_{X_{k,t}} p(z_t \mid x)\,dx}{p_{k,t}} = \frac{1}{|X_{k,t}|}\int_{X_{k,t}} p(z_t \mid x)\,dx. \tag{4.4}$$

（分子分母的先验质量 $p_{k,t}$ 消掉——平均似然只依赖似然在格内的均值。）现在把格内 $p(z_t \mid x)$ 用其在代表点的值代替：$\int_{X_{k,t}} p(z_t\mid x)dx \approx |X_{k,t}|\,p(z_t \mid \bar x_{k,t})$，代回 (4.4) 恰得 $p(z_t \mid \bar x_{k,t})$——(4.3) 左式成立，且能看清它是"分段常数模型下平均似然的零阶近似"，误差由似然在格内的变化量决定。

**转移侧**（原书式 4.8–4.10）。这次区域出现在条件与被条件两侧，稍复杂：

$$p(x_{k,t} \mid u_t, x_{i,t-1}) = \frac{\int_{X_{k,t}}\!\!\int_{X_{i,t-1}} p(x_t \mid u_t, x_{t-1})\,\underbrace{p(x_{t-1} \mid u_t)}_{=\,p(x_{t-1})}\,dx_{t-1}dx_t}{\int_{X_{i,t-1}} p(x_{t-1})\,dx_{t-1}} = \frac{1}{|X_{i,t-1}|}\int_{X_{k,t}}\!\!\int_{X_{i,t-1}} p(x_t \mid u_t, x_{t-1})\,dx_{t-1}dx_t, \tag{4.5}$$

（马尔可夫假设：$u_t$ 不影响已发生的 $x_{t-1}$，故 $p(x_{t-1} \mid u_t) = p(x_{t-1})$；分母的置信质量化为体积。）对内层两个变量做与 (4.4) 相同的"平均 + 探针"两步：

$$p(x_{k,t} \mid u_t, x_{i,t-1}) \approx \eta\, |X_{i,t-1}|^{-1}\, p(\bar x_{k,t} \mid u_t, \bar x_{i,t-1})\,|X_{k,t}|\,|X_{i,t-1}| = \eta\, |X_{k,t}|\, p(\bar x_{k,t} \mid u_t, \bar x_{i,t-1}). \tag{4.6}$$

**关键注脚**（原书特别强调）：因子 $|X_{k,t}|$ 只有在**所有格子等尺寸**时才能并入 $\eta$（它对不同 $k$ 取值不同，本不该被一个常数吸收）。等尺寸栅格下，(4.6) 与程序 4.1 第 3 行逐字对应；此时中间量 $\bar p_{k,t}$ 不是归一化分布，但第 4 行的 $\eta$ 会补上——最终输出仍是合法概率。

**④ 分解技术：静态 vs 动态**（原书 4.1.4）：

- **静态分解**：先选好固定栅格，不管后验形状——易实现、浪费（无概率区域照占内存）；
- **动态分解**：按后验形状在线调节分辨率——**密度树**（概率低的区域粗、高的区域细，同等内存下精度高几个量级，代价是树查找 $O(\log)$）；**选择性更新**（只更新概率超过阈值的格子——等价于"细栅格 + 一个装下其余所有格子的粗桶"的混合分解，可省几个数量级计算，是高维栅格可行的前提）；
- **拓扑 vs 度量**：拓扑表示用环境结构建图节点（交叉口、丁字路），分辨率粗；度量栅格不依赖环境、分辨率细（第 07 章实例用到 10 cm 级栅格）。二者是分辨率-语义的折中而非对立。

## 04.2 静态二值贝叶斯滤波：log-odds（原书 4.2）

**① 问题场景**：估计一个**不随时间变化的二值量**（门开着/关着、栅格被占/空闲）。状态静态 → 控制流消失（原书式 4.11：$\mathrm{bel}_t(x) = p(x \mid z_{1:t})$），只剩测量流。工程上真正的痛点：概率会被反复乘到接近 0 或 1，浮点下溢截断，之后任何反方向证据都拉不回来。

**② 解决方法——概率对数（log-odds）**：

$$\mathrm{odds}(x) = \frac{p(x)}{1 - p(x)}, \qquad l(x) = \log \frac{p(x)}{1-p(x)}, \qquad p(x) = \frac{1}{1 + e^{-l(x)}}. \tag{4.7}$$

（$l \in (-\infty, \infty)$，无截断问题；最后是 sigmoid 反变换，原书式 4.14。）更新算法（原书程序 4.2）：

```text
Algorithm binary_Bayes_filter( l_{t-1}, z_t ):
    l_t = l_{t-1} + log[ p(x | z_t) / p(¬x | z_t) ] − log[ p(x) / p(¬x) ]
    return l_t
```

**③ 一个必须辨析的名词——"反演测量模型"**：算法用的不是前向模型 $p(z_t \mid x)$，而是**反演模型** $p(x \mid z_t)$。为什么？测量空间往往远比二值状态复杂：描述"所有显示门为关的相机图像的分布 $p(z \mid x)$"几乎不可行，而写一个"从图像算门关概率的函数 $p(x \mid z)$"容易得多（原书的原话论证）。**注意**：这里的"反演"是指"以测量为条件、以状态为变量"这个方向，**不是**前向模型的数学逆（贝叶斯反转还差一个先验因子）——第 09 章会再次强调这一点。

**④ 推导**（原书式 4.15–4.20 展开）：对 $x$ 与 $\neg x$ 各写一遍贝叶斯更新再**相除**——分母 $p(z_t \mid z_{1:t-1})$、公因子 $p(z_t)$ 全部消掉：

$$\frac{p(x \mid z_{1:t})}{p(\neg x \mid z_{1:t})} = \frac{p(x \mid z_t)}{p(\neg x \mid z_t)} \cdot \frac{p(x \mid z_{1:t-1})}{p(\neg x \mid z_{1:t-1})} \cdot \frac{p(\neg x)}{p(x)}. \tag{4.8}$$

取对数：

$$l_t = \underbrace{\log\frac{p(x \mid z_t)}{p(\neg x \mid z_t)}}_{\text{反演模型项}} + \underbrace{l_{t-1}}_{\text{上一步置信}} - \underbrace{\log\frac{p(x)}{p(\neg x)}}_{\text{先验 log-odds}}. \tag{4.9}$$

两处理解要点：其一，**先验只该入账一次**——它已含在初始 $l_0$ 里，而反演模型项 $p(x \mid z_t)$ 内部又含一次先验，所以每步必须减掉，否则同一先验被重复计入、置信随时间无界漂移（这是第 09 章算法 9.1 里 $l_0$ 那一行的来历）；其二，反演形式与**前向形式**逐字等价——对 (4.8) 的第一因子用贝叶斯准则展开：

$$\log\frac{p(x \mid z_t)}{p(\neg x \mid z_t)} - \log\frac{p(x)}{p(\neg x)} = \log\frac{p(z_t \mid x)\,p(x)\,p(z_t \mid \neg x)}{p(z_t \mid \neg x)\,p(x)\,p(z_t \mid x)} \cdot \frac{p(z_t)}{p(z_t)} = \log\frac{p(z_t \mid x)}{p(z_t \mid \neg x)},$$

于是算法亦可写成无减法的 $l_t = l_{t-1} + \log\frac{p(z_t \mid x)}{p(z_t \mid \neg x)}$（第 02 章习题 1 用的就是它，$l_N = l_0 + N\log 3$）。两式各有用场：**能写前向模型用前向式（少一项、不易错），只能写反演模型（如视觉判门）用程序 4.2 式（别忘减先验）**。

**⑤ 选型理由**：对乘法链，log 域把"连乘"变"累加"——数值稳定（概率 $10^{-300}$ 在 log 域只是 $-690$）、增量计算、正负证据对称（$+|\Delta l|$ 与 $-|\Delta l|$）。代价：只适用于二值（多值状态没有单一 log-odds）；且静态假设在被违反时（门其实会动）置信会**过度收敛**——对策见第 09 章正演模型 MAP 建图。

## 04.3 粒子滤波（原书 4.3）

### 04.3.1 基本算法（程序 4.3）

**① 问题场景**：直方图的精度-维数矛盾（栅格数随维数指数增长）。想要一种"把计算花在刀刃上"的表示：概率高的地方多放点、概率低的地方不放点。

**② 解决方法**：用 $M$ 个**随机样本**（粒子 $X_t = \{x_t^{[1]}, \dots, x_t^{[M]}\}$，$M$ 常取 1000）表示 $\mathrm{bel}(x_t)$，理想性质（原书式 4.23）：粒子落在区域内的密度 ∝ 后验概率。

```text
Algorithm Particle_filter( X_{t-1}, u_t, z_t ):
    X̄_t = X_t = ∅
    for m = 1 to M do
        sample x_t^{[m]} ~ p(x_t | u_t, x_{t-1}^{[m]})      # ① 运动模型采样（从每个旧粒子前向推演）
        w_t^{[m]} = p(z_t | x_t^{[m]})                      # ② 重要性权重 = 似然
        add <x_t^{[m]}, w_t^{[m]}> to X̄_t
    endfor
    for m = 1 to M do
        draw i with probability ∝ w_t^{[i]}                 # ③ 重采样：按权重有放回抽 M 个
        add x_t^{[i]} to X_t
    endfor
    return X_t
```

三步读法：①预测——从**每个旧粒子**出发按运动模型撒一个新粒子，$\bar X_t$ 表示 $\overline{\mathrm{bel}}(x_t)$；②加权——把测量变成每个粒子的"得分"；③重采样——按得分有放回抽 $M$ 个替换全集，低权粒子死亡、高权粒子多子。原书称之为达尔文"适者生存"的概率实现：**把计算资源集中到状态空间中高后验概率的区域**。若省略③，用乘法权重 $w_t^{[m]} = p(z_t \mid x_t^{[m]})\,w_{t-1}^{[m]}$（原书式 4.24）的加权粒子集同样近似后验——只是低权粒子越积越多，需要更大的 $M$（何时该重采样见 04.3.4）。

### 04.3.2 重要性采样：权重的合法性（原书 4.3.2）

**① 问题场景**：目标分布 $f$（这里 = $\mathrm{bel}(x_t)$）**无法直接采样**（$p(z_t|x_t)p(x_t|u_t,x_{t-1})$ 不是标准分布）；但存在可采样的建议分布（proposal）$g$。如何用 $g$ 的样本算 $f$ 的期望？

**② 解决方法与推导**（原书式 4.25）：对任意集合 $A$（更一般地任意可积函数），把 $f$-期望改写成 $g$-期望：

$$E_f[\mathbb{1}(x \in A)] = \int f(x)\,\mathbb{1}(x \in A)\,dx = \int \frac{f(x)}{g(x)}\,g(x)\,\mathbb{1}(x \in A)\,dx = E_g\big[w(x)\,\mathbb{1}(x \in A)\big], \qquad w(x) = \frac{f(x)}{g(x)}. \tag{4.10}$$

合法性条件只有一条：**支撑包含** $f(x) > 0 \Rightarrow g(x) > 0$（$g$ 撒不到的区域 $f$ 也不该有概率）。样本上的实现（原书式 4.26–4.28）：粒子 $x^{[m]} \sim g$，按 $w^{[m]} = f(x^{[m]})/g(x^{[m]})$ 加权后，归一化权重和收敛到真积分：

$$\frac{\sum_m \mathbb{1}(x^{[m]} \in A)\, w^{[m]}}{\sum_m w^{[m]}} \longrightarrow \int_A f(x)\,dx, \qquad \text{收敛速率典型为 } O(M^{-1/2}), \tag{4.11}$$

常数因子取决于 $f$ 与 $g$ 的相似度——**建议分布越贴合目标，权重方差越小、浪费的样本越少**（这句话在第 13 章 FastSLAM 2.0 会变成一个具体的改进公式）。

**③ 粒子滤波的建议分布**（原书式 4.29）：$X_{t-1}$ 的粒子近似服从 $\mathrm{bel}(x_{t-1})$，预测采样"每个旧粒子过一遍运动模型"恰好从乘积分布

$$g(x_t) = p(x_t \mid u_t, x_{t-1})\,\mathrm{bel}(x_{t-1})$$

采样。于是权重 $w = f/g$ 中运动模型部分**恰好相消**，只剩（第 02 章式 2.12 的）似然 $w_t^{[m]} = p(z_t \mid x_t^{[m]})$——程序 4.3 第 5 行的来历。这个"最省事的建议分布"的缺点同样是 $f/g$ 失配的来源：它在见到 $z_t$ **之前**就撒好了点，若测量信息量突然变大（似然很尖），绝大多数粒子落在低权区——第 13 章把 $z_t$ 提前纳入建议分布正是治这个病。

### 04.3.3 粒子滤波的数学推导（原书 4.3.3 全展开）

**推导技巧**：把每个粒子看作**状态序列**的样本 $X_t^{[m]} = x_{0:t}^{[m]}$（原书式 4.30），从而目标从 $\mathrm{bel}(x_t)$ 换成**全轨迹后验**（原书式 4.31）：

$$\mathrm{bel}(x_{0:t}) = p(x_{0:t} \mid u_{1:t}, z_{1:t}).$$

序列空间巨大、实打实用粒子覆盖它并不聪明——但这个设定让推导干净（原书明言仅为推导目的）。递归展开（原书式 4.32）：

$$p(x_{0:t} \mid z_{1:t}, u_{1:t}) = \eta\, p(z_t \mid x_{0:t}, z_{1:t-1}, u_{1:t})\, p(x_{0:t} \mid z_{1:t-1}, u_{1:t}) \quad (\text{贝叶斯})$$
$$= \eta\, p(z_t \mid x_t)\, p(x_t \mid x_{0:t-1}, z_{1:t-1}, u_{1:t})\, p(x_{0:t-1} \mid z_{1:t-1}, u_{1:t}) \quad (\text{拆出 } x_t)$$
$$= \eta\, p(z_t \mid x_t)\, p(x_t \mid x_{t-1}, u_t)\, p(x_{0:t-1} \mid z_{1:t-1}, u_{1:t-1}) \quad (\text{两条马尔可夫条件独立}). \tag{4.12}$$

**注意没有积分**——第 02 章推导里把历史边缘化掉的那一步，这里因为保留全部状态而不需要；(4.12) 就是"轨迹后验 = 似然 × 转移 × 上一时刻轨迹后验"的连乘结构。

**归纳**：基例 $X_0 \sim p(x_0)$。归纳假设 $X_{t-1}^{[m]} \sim \mathrm{bel}(x_{0:t-1})$。算法第 4 行的采样分布 = 建议分布 = $p(x_t \mid x_{t-1}^{[m]}, u_t)\,\mathrm{bel}(x_{0:t-1}^{[m]})$；重要性权重（原书式 4.34）：

$$w_t^{[m]} = \frac{\text{目标}\ \ p(x_t \mid x_{t-1}^{[m]}, u_t)\,\mathrm{bel}(x_{0:t-1}^{[m]})}{\text{建议}\ \ p(x_t \mid x_{t-1}^{[m]}, u_t)\,\mathrm{bel}(x_{0:t-1}^{[m]})}\ \text{两侧按 (4.12) 代入后} \ \propto p(z_t \mid x_t^{[m]}). \tag{4.13}$$

重采样以 $\propto w_t^{[m]}$ 的概率复制粒子，故重采样后的粒子分布 = 权重 × 建议（原书式 4.35）：

$$\eta\, p(z_t \mid x_t^{[m]})\; p(x_t \mid x_{t-1}^{[m]}, u_t)\, \mathrm{bel}(x_{0:t-1}^{[m]}) \ \propto\ \mathrm{bel}(x_{0:t}) \quad \checkmark$$

归纳完成。$\blacksquare$ 诚实声明（原书原话）：推导在 $M \to \infty$ 才严格——归一化常数的处理是松弛的；有限 $M$ 的误差来源在 04.3.4 逐一拆解。

### 04.3.4 四个实战陷阱与对策（原书 4.3.4）

**陷阱一：采样方差（sampling variance）**。有限随机样本的统计量本身随机——同一机器人同一动作，两次运行的粒子云不同（原书图 4.6：25 样本的核密度估计彼此差异显著，250 样本明显收敛）。对策朴素而有效：**加大 $M$**（成本线性）；以及下一个陷阱的对策间接有帮助。

**陷阱二：重采样退化（重采样抹掉多样性）**。思想实验（原书原例）：静止机器人 + 无传感器 + 确定性转移。预测步不产生新状态，重采样却每轮随机"抽签复制"——不中的粒子永久消失，幸存者全部变成同一个粒子的副本，**以概率 1** 发生。旁观者会看到滤波器"完全确定"地输出一个位置，而事实上它一无所知。对策两条：

1. **少重采样**：静态场景（$x_t = x_{t-1}$）直接跳过；一般场景把权重存下来乘法更新（原书式 4.36），按**权重方差**触发重采样——权重齐（方差≈0）不必采，权重集中于少数粒子（方差高）必须采。（这个"有效样本数"思想在第 08 章 KLD 采样中被量化为自适应粒子数，且现代实现普遍用 $N_{\mathrm{eff}} = 1/\sum_i (\tilde w^{[i]})^2$ 作触发器。）
2. **低方差采样**（原书程序 4.4）：重采样仍要做时，只抽**一个**随机数 $r \in [0, M^{-1})$，以固定步长 $M^{-1}$ 扫过权重累积区间（$U = r + (m-1)M^{-1}$，粒子 $i = \arg\min_m \sum_{k \le m} w^{[k]} \ge U$；原书式 4.37）。三重优点：有序覆盖样本空间（避免同一轮重复抽走同一粒子）；权重均匀时**一个粒子都不丢**；$O(M)$ 复杂度（朴素独立采样 $O(M \log M)$）。分层采样（stratified）是它的进一步精细化。

**陷阱三：采样偏差（bias）**。$M = 1$ 的极端情形最诚实：重采样按权重抽 1 个，而单粒子的权重归一化后恒为 1（原书式 4.38）——**测量被完全忽略**，粒子滤波退化为纯运动模型预测 $p(x_t \mid u_{1:t})$。机制：非归一化权重住在 $M$ 维空间，归一化后只剩 $M - 1$ 维自由度；$M$ 大时损失可忽略。教训：粒子数不是"越多越好一点"，而是**存在系统偏差随 $M$ 减小**。

**陷阱四：粒子缺乏（particle deprivation）**。哪怕 $M$ 很大，运气不好的随机数也可能把真值附近的粒子全部抽光；每轮发生概率非零，故**运行足够久必然发生**。对策：重采样后注入少量纯随机粒子（简单、微小偏差代价——"最后手段"，原书原话），或用更聪明的机制——**第 08 章增强 MCL（按权重历史自适应注入）就是正式答案**。

**密度提取**（需要连续估计时）：粒子云 → 密度的四种办法——高斯近似（单峰够用、最便宜）、k-means 聚类 + 混合高斯（多峰）、直方图（任意点密度查询 $O(1)$、内存指数）、核密度估计（每个粒子放一个核，平滑但逐点查询 $O(M)$）。选哪种取决于下游：控制只要均值 → 不提取；主动定位要不确定性结构 → 直方图/混合；多机器人密度乘积 → 密度树/核（原书 4.3.4 开头）。

## 04.4 三种置信表示总览

| | 高斯（ch3） | 直方图（ch4.1–4.2） | 粒子（ch4.3） |
|---|---|---|---|
| 参数 | $(\mu, \Sigma)$，$O(n^2)$ 个 | 每格一个数，格数随维数**指数** | $M$ 个样本 + 权重 |
| 峰数 | 单峰 | 任意（受格分辨率限） | 任意 |
| 精度调节 | 无（形状锁死） | 栅格粒度（事前/密度树） | 粒子数（在线、任意时间 any-time） |
| 计算焦点 | 全空间均匀花费 | 分解决定 | 自适应集中于高似然区 |
| 主要风险 | 单峰失真、线性化误差 | 维数灾难、格化偏差 | 退化/偏差/缺乏（04.3.4 四陷阱） |
| 后续章节 | 07 EKF 定位、10 EKF SLAM | 08 栅格定位、09 占用建图 | 08 MCL、13 FastSLAM |

三种表示在"参数放哪里"上互补：高斯把参数花在**形状**上，直方图花在**覆盖**上，粒子花在**重要性**上。机器人系统的真实栈常常混用（如第 08 章 MCL 用粒子做全局定位、内部用高斯 landmark 估计——第 13 章的 Rao-Blackwell 化正是"粒子 + 高斯"的组合技）。

## 04.5 小结、术语表与书后习题全解

**要点回顾**：

1. 离散贝叶斯滤波 = 积分变求和（HMM 正向传递）；探针近似 (4.4)(4.6) 的合法性来自"分段常数模型下的精确平均 + 零阶近似"，等尺寸栅格才能吸收 $|X_{k,t}|$ 因子（04.1）；
2. 静态二值滤波的 log-odds 形式把乘法链变加法链；反演模型 ≠ 前向模型的数学逆；**先验只入账一次**（公式里体现为减 $l_0$ 项）——第 09 章的核心公式（04.2）；
3. 粒子滤波 = 建议分布采样 + 重要性权重 + 重采样；建议分布取运动模型时权重恰好只剩似然；推导的关键是"轨迹后验无积分"的连乘结构（04.3.3）；
4. 四个陷阱各有对策：采样方差→加 $M$；退化→少重采样 + 低方差采样；偏差→认识到归一化的自由度损失；缺乏→随机注入（最后手段，正式答案在第 08 章）（04.3.4）；
5. 三种表示互补，真实系统常混用（04.4）。

**术语表（本章新增）**：离散贝叶斯滤波（discrete Bayes filter）、直方图滤波（histogram filter）、分段常数密度（piecewise constant density）、探针（probing）、静态/动态分解（static/dynamic decomposition）、密度树（density tree）、选择性更新（selective updating）、拓扑/度量表示（topological/metric representation）、静态二值贝叶斯滤波（static binary Bayes filter）、概率对数（log odds ratio）、反演测量模型（inverse measurement model）、粒子（particle）、重要性因子/权重（importance factor/weight）、建议分布（proposal distribution）、目标分布（target distribution）、重采样/重要性采样（resampling/importance sampling）、低方差采样（low variance sampling）、分层采样（stratified sampling）、采样方差/偏差（sampling variance/bias）、粒子缺乏（particle deprivation）、密度提取（density extraction）、核密度估计（kernel density estimation）。

**书后习题全解指导**（原书 4.6 节，书 86–87 页）：

**习题 1（线性系统的直方图滤波）**——把第 03 章习题 1 的 $(x, \dot x)$ 双积分器搬上二维栅格：(a) 预测步 = 把每格概率按 $A$ 平移、按 $BB^T$ 噪声摊开（对格做离散卷积；卷积核即 $p(x_t \mid u_t, x_{t-1})$ 在格上的离散化）。若初始为高斯 $\mathcal{N}(0, 0)$（点质量），栅格足够细时 $t$ 步预测应逐格逼近第 03 章的 $\mathcal{N}(0, \Sigma_t)$（$\Sigma_5 = \begin{pmatrix} 41.25 & 12.5 \\ 12.5 & 5\end{pmatrix}$）——这是检验实现正确性的黄金标准；(b) $t=5$、$z=5$ 的测量更新 = 逐格乘似然 $p(z \mid x) = \mathcal{N}(z; x, 10)$ 后归一化，结果应收敛到第 03 章的 $\mathcal{N}\big((4.02, 1.22)^T, \begin{pmatrix} 8.05 & 2.44 \\ 2.44 & 1.95 \end{pmatrix}\big)$。**本题的真正教学点**：直方图与 KF 在线性高斯问题上答案一致，差别只在精度/内存折中；而非线性问题上（下一题）二者分道扬镳。

**习题 2（非线性系统的直方图滤波：香蕉回来了）**——系统同第 03 章习题 4（前向走 $d$，$(x,y,\theta) \to (x + d\cos\theta, y + d\sin\theta, \theta)$），但初始 $\Sigma = \mathrm{diag}(0,\ 0.01,\ 10000)$——方向角几乎全无知（$10000\ \mathrm{rad}^2$ 高斯近似均匀）。(a) 初始直方图：$x, y$ 用单格点质量（方差 0），$\theta$ 轴铺满全程均匀格；(b) 预测步是**确定性映射**（无噪声时每格概率整体搬运）：$(0,0,\theta) \to (d\cos\theta, d\sin\theta, \theta)$，概率沿圆弧铺开——得到真实的**弧形多峰/流形后验**，EKF 的竖直线段近似在它面前一败涂地（对照 03.7 习题 4）。分辨率教训（题目问点）：$\theta$ 格宽决定弧上的"珠子"间距，$x\text{-}y$ 格宽决定弧的厚度；维数 3 尚可全程铺格，维数再高就必须动态分解（04.1.4）；(c) $x$ 坐标测量 $z$（$Q = 0.01$）：似然 $p(z \mid x_{\text{位置}})$ 对弧上每点加权——**在 $\theta$ 轴上它关于 $\cos\theta$ 多峰**（同一 $x$ 值对应多个 $\theta$），加权后直方图正确保留多个假设峰，而 EKF 只能给一个高斯。本题是"非参数表示的表达力"最直观的一次亮相。

**习题 3（$M=2$ 的粒子滤波）**——有偏差，且比 $M=1$ 更隐蔽。机制一（归一化自由度，原书 4.3.4"采样偏差"的延伸）：$M=2$ 时归一化权重只剩 1 个自由度 $(w, 1-w)$。具体反例：两个粒子代表两个对称假设（走廊里两扇门），权重 0.9 与 0.1——重采样一轮，0.9 的粒子以 90% 概率被复制、0.1 的以 10% 概率存活；连续重采样下，弱假设在几轮内**以高概率永久消失**，而其真实后验概率（0.1）远非可忽略——滤波器输出的"收敛"是重采样随机性制造的假象，不是证据积累的结果。机制二：两个粒子的经验分布对真后验的逼近误差 $O(M^{-1/2})$ 在 $M=2$ 时巨大。结论：粒子滤波的渐近正确性是 $M \to \infty$ 的性质，小 $M$ 下偏差与方差都不是小扰动。

**习题 4（线性系统的粒子滤波）**——实现程序 4.3 替换习题 1 的直方图。预期现象（建议逐一验证）：$M \to \infty$ 时粒子云的均值/协方差收敛到 KF 精确解；有限 $M$ 下出现 04.3.4 的全部症状——$M$ 小时重采样后粒子迅速坍缩成少数副本（退化），测量更新看似"卡住"；改用低方差采样 + 降低重采样频率后明显改善。本题给出一条可复现的标尺：**同一问题、两种表示，误差随 $M$ 的衰减曲线**。

**习题 5（非线性系统的粒子滤波）**——习题 2 的粒子版：预测 = 每个粒子过一遍确定性圆弧映射；测量 = 似然加权。粒子数研究预期：$M$ 足够大时弧形后验与多峰测量更新都正确呈现（直方图需要 $N_\theta \times N_x \times N_y$ 格，粒子只需把点撒在弧附近——**内存从指数降回线性**，这正是粒子表示对高维问题的根本优势）；$M$ 不足时弧上出现"珠串断裂"（粒子缺乏），随机注入粒子可救急但有偏差。与习题 2 对照：直方图赢在"任意点密度可查"，粒子赢在"参数跟着后验复杂度走"——两条路线在此正面对比。
