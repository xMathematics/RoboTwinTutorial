# 第 06 章｜机器人感知模型

第 05 章造好了滤波器的第一份燃料（运动模型），本章造第二份：测量模型 $p(z_t \mid x_t, m)$——"机器人在位姿 $x_t$、地图为 $m$ 时，测到 $z_t$ 的概率"。原书按物理保真度递减、实用度递增的顺序给出四个模型：**波束模型**（最接近物理：射线投射 + 四分量噪声混合，含 EM 参数学习全推导）、**似然域模型**（放弃物理解释换取光滑与高效——实践首选）、**地图匹配**（相关性打分）、**路标特征模型**（SLAM 各章的工作马，数据关联变量 $c_t$ 在此登场）。本章与第 05 章合成完整的滤波输入侧：第 07 章 EKF 定位吃"运动闭式 + 路标闭式"，第 08 章 MCL 吃"运动采样 + 似然域"，第 09 章占用建图的重演模型也以本章的噪声分类为底版。

> 原书锚点：第 6 章，书 112–141 页（PDF 130–159 页）。6.3.3 节 EM 推导（书 121–126 页）本章全量展开并配合成数值复现；似然域的坐标变换 (6.32) 逐项拆解。

## 06.1 测量模型与地图（原书 6.1–6.2）

**① 问题场景**：传感器从不直接告诉你状态。声呐打在光滑墙面上发生**镜面反射**（specular reflection）——回波射向别处，传感器读出过大的距离或干脆超量程；串扰、动态行人、吸光表面各自制造不同类型的错误。任何单一"噪声方差"都无法概括——**必须区分错误的类型**，这正是本章建模的主线。

**② 测量束的独立性假设**：一次扫描含 $K$ 个束（原书式 6.1），模型按独立噪声分解（原书式 6.2）：

$$p(z_t \mid x_t, m) = \prod_{k=1}^{K} p(z_t^k \mid x_t, m). \tag{6.1}$$

诚实声明（原书明示）：相邻束的噪声常常**相关**（行人同时挡住数束、地图误差影响所有束）——违反独立性使滤波器**过度自信**（02.5 的老话题）；对策见 06.2.4 的"抽束"与"信息衰减"。

**③ 地图的两种形态**（原书 6.2）：$m = \{m_1, \dots, m_N\}$（式 6.3）。**基于特征**：$m_n$ = 地标属性 + 全局坐标——只描述"有什么"，紧凑、便于增删（SLAM 各章用）；**基于位置**：索引即坐标（$m_{x,y}$）——**体积式**（volumetric），连"哪里是空的"都编码（占用栅格，第 09 章主角，导航必需）。约定俗成：测量以地图为条件（严格说测量由物理物体而非地图引起——原书自嘲"淡化世界与地图的区别"）。

## 06.2 波束模型：四分量混合（原书 6.3）

### 06.2.1 四类误差的物理来源与密度

对单束 $z_t^k$，先用射线投射（ray casting）算出"该束下地图给出的真距离" $z_t^{k*}$，然后把误差分成四类，每类一个密度：

| 分量 | 物理来源 | 密度 | 支撑 |
|------|----------|------|------|
| $p_{\mathrm{hit}}$ | 真命中 + 测量噪声（分辨率、大气） | $\eta \cdot \mathcal{N}(z;\ z_t^{k*}, \sigma_{\mathrm{hit}}^2)$（原书式 6.4–6.6） | $[0, z_{\max}]$ |
| $p_{\mathrm{short}}$ | **意外障碍**（地图没有的人/物——只能更近不能更远） | $\eta\, \lambda_{\mathrm{short}} e^{-\lambda_{\mathrm{short}} z}$（式 6.7） | $[0, z_t^{k*}]$ |
| $p_{\mathrm{max}}$ | **检测失败**（镜面反射、吸光、强光）→ 恒报 $z_{\max}$ | 点质量 $\mathbb{1}(z = z_{\max})$（式 6.10） | $\{z_{\max}\}$ |
| $p_{\mathrm{rand}}$ | **无法解释的读数**（多次反弹、串扰幻读） | 均匀 $1/z_{\max}$（式 6.11） | $[0, z_{\max}]$ |

两个归一化细节：$p_{\mathrm{hit}}$ 的高斯要截断在 $[0, z_{\max}]$，$\eta = \left(\int_0^{z_{\max}} \mathcal{N}\right)^{-1}$；$p_{\mathrm{short}}$ 截断在 $[0, z_t^{k*}]$，由积分（原书式 6.8）得

$$\eta = \left(1 - e^{-\lambda_{\mathrm{short}} z_t^{k*}}\right)^{-1}. \tag{6.2}$$

$p_{\mathrm{short}}$ 的"随距离衰减"有 probabilistic 论证（原书的两人例子）：两人等概率出现在感知域内，测到近者只需近者出现，测到远者需要"远者出现**且**近者缺席"——事件概率随距离指数衰减，故用指数分布。

**混合**（原书式 6.12；权值非负、和为 1）：

$$p(z_t^k \mid x_t, m) = z_{\mathrm{hit}}\, p_{\mathrm{hit}} + z_{\mathrm{short}}\, p_{\mathrm{short}} + z_{\mathrm{max}}\, p_{\mathrm{max}} + z_{\mathrm{rand}}\, p_{\mathrm{rand}}. \tag{6.3}$$

**算法**（原书程序 6.1）：对每束做射线投射得 $z^{k*}$ → 按式 (6.3) 打分 → 各束似然连乘（独立性假设）。六个固有参数 $\Theta = \{z_{\mathrm{hit}}, z_{\mathrm{short}}, z_{\mathrm{max}}, z_{\mathrm{rand}}, \sigma_{\mathrm{hit}}, \lambda_{\mathrm{short}}\}$ 待定。

### 06.2.2 固有参数的极大似然学习：EM 全推导（原书 6.3.2–6.3.3）

**① 问题场景**：手头有标定数据集 $Z = \{z_i\}$（配已知位姿 $x_i$ 与地图 $m$，故 $z_i^{i*}$ 可算），想让 $p(Z \mid X, m, \Theta)$ 最大（ML 估计）。难点：混合模型的对数似然里，"每个样本来自哪个分量"未知——直接求导无闭式。

**② 已知对应时的闭式解**（推导骨架，原书式 6.14–6.23 展开）。引入**对应变量** $c_i \in \{\mathrm{hit}, \mathrm{short}, \mathrm{max}, \mathrm{random}\}$，把数据分成四个不相交子集。若 $c_i$ 已知：

- **混合权值** = 各子集占比（归一化计数，原书式 6.14）：$z_{\mathrm{hit}} = |Z_{\mathrm{hit}}|/|Z|$ 等；
- **$\sigma_{\mathrm{hit}}$**：$Z_{\mathrm{hit}}$ 的对数似然（原书式 6.16–6.17）

$$\log p(Z_{\mathrm{hit}} \mid X, m, \Theta) = -|Z_{\mathrm{hit}}|\log\sqrt{2\pi} - |Z_{\mathrm{hit}}|\log\sigma_{\mathrm{hit}} - \frac{1}{2\sigma_{\mathrm{hit}}^2}\sum_{z_i \in Z_{\mathrm{hit}}}(z_i - z_i^{i*})^2,$$

对 $\sigma_{\mathrm{hit}}$ 求导置零（原书式 6.18）：

$$\sigma_{\mathrm{hit}}^2 = \frac{1}{|Z_{\mathrm{hit}}|}\sum_{z_i \in Z_{\mathrm{hit}}}(z_i - z_i^{i*})^2 \qquad \text{（就是子集内的样本方差！）} \tag{6.4}$$

- **$\lambda_{\mathrm{short}}$**：$\log p(Z_{\mathrm{short}}) = |Z_{\mathrm{short}}|\log\lambda - \lambda \sum_{z_i \in Z_{\mathrm{short}}} z_i$（指数分布忽略截断归一化时的经典形式；原书式 6.20–6.22），求导置零：

$$\lambda_{\mathrm{short}} = \frac{|Z_{\mathrm{short}}|}{\sum_{z_i \in Z_{\mathrm{short}}} z_i} \qquad \text{（= 1 / 样本均值，指数分布的 ML 解）}. \tag{6.5}$$

（单变量高斯/指数的 ML 解是教科书结果——混合模型的技巧全在"如何分配样本到子集"。）

**③ 对应未知 → EM 两步迭代**（原书式 6.24–6.31）。把硬分配 $c_i$ 换成软分配（期望），交替：

- **E 步**（固定 $\Theta$，算各分量对每个样本的"责任"）：

$$e_{i,\mathrm{hit}} = \eta\, p_{\mathrm{hit}}(z_i \mid x_i, m), \quad \dots, \quad e_{i,\mathrm{rand}} = \eta\, p_{\mathrm{rand}}(z_i \mid x_i, m), \qquad \eta = \Big[\sum_{\mathrm{XXX}} p_{\mathrm{XXX}}(z_i \mid x_i, m)\Big]^{-1}. \tag{6.6}$$

（四责之和为 1——这就是"第 $i$ 个读数由 XXX 引起"的后验概率。）

- **M 步**（固定责任，更新 $\Theta$）：混合权值 = 期望计数（原书式 6.29）：$z_{\mathrm{hit}} = \frac{1}{|Z|}\sum_i e_{i,\mathrm{hit}}$；闭式解 (6.4)(6.5) 中的硬计数换成软加权（原书式 6.30–6.31）：

$$\sigma_{\mathrm{hit}}^2 = \frac{\sum_i e_{i,\mathrm{hit}}(z_i - z_i^{i*})^2}{\sum_i e_{i,\mathrm{hit}}}, \qquad \lambda_{\mathrm{short}} = \frac{\sum_i e_{i,\mathrm{short}}}{\sum_i e_{i,\mathrm{short}}\, z_i}. \tag{6.7}$$

迭代至收敛（原书经验：十几次即可）。这是 EM 的标准骨架——E 步"猜标签"，M 步"按猜好的标签做闭式 ML"，单调不减地爬对数似然。**选型理由**：相比手工盯图调参（原书也认可的合法手段），EM 有原则、可复现、随传感器/环境变化可重标定。

**教程数值复现**：本教程用合成数据（真值 $z_{\mathrm{hit}} = 0.7$、$z_{\mathrm{short}} = 0.1$、$z_{\mathrm{max}} = 0.1$、$z_{\mathrm{rand}} = 0.1$、$\sigma_{\mathrm{hit}} = 0.2$、$\lambda = 2$，$N = 20000$ 样本，初值全部取 0.25/$\sigma_0 = 0.25$/$\lambda_0 = 1.5$）跑通式 (6.6)–(6.7)：10 轮内即接近真值（$\hat z_{\mathrm{hit}} = 0.689$、$\hat\sigma_{\mathrm{hit}} = 0.195$、$\hat\lambda = 2.36$），验证了推导与算法骨架。两个诚实的观察：①$\hat z_{\mathrm{short}}$ 轻微低估、$\hat\lambda$ 后期缓慢漂移（30 轮到 2.67）——**重叠混合物的可辨识性极限**（short 与 rand 都在小区间堆积质量），EM 只保证收敛到局部最优；②严格说式 (6.7) 的 $\lambda$ 更新是**无截断**指数的 ML 解（原书推导式 6.20–6.23 同样忽略了式 6.9 的截断归一化 $\eta$），因此这是"广义 EM"，对数似然的单调上升在此设置下不被严格保证（本教程复现中亦观察到微小的非单调步）——工程上无碍，但值得知道自己在用什么。

### 06.2.3 实用技巧与两条局限（原书 6.3.4–6.3.5）

1. **抽束**：每扫描只融合少量等间隔束（如 360 取 8）——省射线投射，且**顺带降低相邻束的相关噪声**（一石二鸟）；
2. **信息衰减**：用 $p(z_t \mid x_t, m)^a$（$a < 1$）替换原似然——对数域就是乘 $a$，等比例弱化每束话语权，治"独立性被违反 → 过度自信"，且不引入额外方差（原书 6.7 节将其列为降信息的首选，优于特征化）；
3. **预缓存**：射线投射是计算大头；在三维位姿栅格（原书经验：15 cm 分辨率、20 m 量程）上预计算 $z^{k*}$，运行时查表，约 10 倍提速——代价是三维表格的内存；
4. **局限一：不光滑**。杂乱环境（桌椅腿）下位姿微变 → 射线投射真值剧变 → $p(z_t \mid x_t, m)$ 高度不连续（航向 $\theta$ 尤甚）。两个后果：近似置信可能"错过"真状态（邻近位姿似然天差地别）；爬坡法搜最可能位姿陷入局部极大。
5. **局限二：计算**（已由预缓存部分缓解）。

## 06.3 似然域模型（原书 6.4）——实践首选

**① 问题场景**：要光滑性（治 06.2.3 局限一）与便宜的预计算（二维代替三维）。

**② 解决方法**：原书坦承这是 **ad hoc** 模型——不对应任何物理生成过程——但效果好。思想：不看"射线打在哪"，看"测量**终点**落在地图障碍物的多近处"。测量终点经坐标变换投到全局系（原书式 6.32，逐项拆解）：

$$\begin{pmatrix} x_{z_t} \\ y_{z_t} \end{pmatrix} = \begin{pmatrix} x \\ y \end{pmatrix} + \begin{pmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{pmatrix} \begin{pmatrix} x_{k,\mathrm{sens}} \\ y_{k,\mathrm{sens}} \end{pmatrix} + z_t^k \begin{pmatrix} \cos(\theta + \theta_{k,\mathrm{sens}}) \\ \sin(\theta + \theta_{k,\mathrm{sens}}) \end{pmatrix}, \tag{6.8}$$

（机器人位姿平移 + 传感器在机体系内的偏移旋转 + 沿束方向前进 $z_t^k$。）然后：

$$\mathrm{dist} = \min_{(x', y') \in\ \text{占用}(m)} \sqrt{(x_{z_t} - x')^2 + (y_{z_t} - y')^2}, \qquad p_{\mathrm{hit}} = \mathrm{prob}(\mathrm{dist},\ \sigma_{\mathrm{hit}}) = e^{-\frac{\mathrm{dist}^2}{2\sigma_{\mathrm{hit}}^2}}, \tag{6.9}$$

混合（原书式 6.34）**没有 $p_{\mathrm{short}}$ 项**——终点贴近任何障碍（不管是意外的墙前人还是地图墙）都给高似然，动态物体被"隐性容忍"；$z_{\max}$ 读数直接丢弃（它们的终点无物理意义，但仍通过 $p_{\max}$ 项在混合里占权重——原书式 6.34 的 $z_{\max} p_{\max}$）：

$$p(z_t^k \mid x_t, m) = z_{\mathrm{hit}}\, p_{\mathrm{hit}} + z_{\mathrm{rand}}\, p_{\mathrm{rand}} + z_{\mathrm{max}}\, p_{\mathrm{max}}. \tag{6.10}$$

**算法**（原书程序 6.3）：逐束——超量程跳过 → 变换 (6.8) → 查最近障碍距离 → 式 (6.10) 打分连乘。最近邻查询贵 → **预计算似然域**（二维栅格存"到最近障碍的距离"），运行时 = 坐标变换 + 查表。**光滑性来源**：$\mathrm{dist}$ 是位姿的连续函数（位姿微动 → 终点微移 → 距离微变），杂乱环境也不再跳变。

**③ 三条固有缺陷**（原书 6.4.2，诚实清单）：①动态障碍（人）不能显式建模——短读数被"温柔地"解释成贴墙；②**能"看穿墙"**——最近邻搜索不检查视线是否被遮挡，墙后的假想位姿也可能得分（对照 05.4 的"终点一致性"近似，同病）；③不建模地图自身的不确定性（未探测区域无差别）。补救：三分类地图（占用/空闲/未知，未知区给常数似然）；用扫描自身构成局部似然域做**扫描匹配**（原书图 6.11，第 07 章会用）。

## 06.4 地图匹配：相关性打分（原书 6.5）

把连续若干扫描织成**局部占用地图** $m_{\mathrm{local}}$，与全局地图 $m$ 对齐后算归一化互相关（原书式 6.35–6.37）：

$$\rho_{m, m_{\mathrm{local}}, x_t} = \frac{\sum_{x,y}(m_{x,y} - \bar m)\,[m_{x,y,\mathrm{local}}(x_t) - \bar m]}{\sqrt{\sum_{x,y}(m_{x,y} - \bar m)^2 \sum_{x,y}(m_{x,y,\mathrm{local}}(x_t) - \bar m)^2}} \in [-1, 1], \qquad p = \max\{\rho, 0\}. \tag{6.11}$$

（$\bar m$ 为两图重叠区的均值；对齐用式 (6.8) 的同一套坐标变换。）**优点**：显式利用了**自由空间边界**——似然域只用"扫描终点"，地图匹配把"哪里没东西"也算票。**缺点**：无物理解释（相关系数 ≠ 传感器噪声模型）；局部地图常画得比实际感知范围大 → "穿墙视物"副作用；对位姿不光滑（可用高斯核卷积地图补救）。

## 06.5 路标特征模型（原书 6.6）——SLAM 的工作马

**① 特征化**：从原始测量提取特征 $f(z_t)$（墙线、墙角、门框；视觉的边/角/图案），把高维测量压到低维——推断成本降几个数量级。**路标**（landmark）：与物理物体对应的特征。距离-方位传感器的单次观测 = 三元组（原书式 6.38）：

$$f_t^i = (r_i,\ \phi_i,\ s_i)^T \qquad (\text{距离、方位、签名/signature})， \tag{6.12}$$

多特征条件独立（原书式 6.39，同式 (6.1) 的逻辑）。

**② 已知对应的测量模型**：地标 $m_j = (m_{j,x}, m_{j,y}, s_j)$，机器人位姿 $(x, y, \theta)$，无噪声预测（原书式 6.40 的可读重排）：

$$\hat r = \sqrt{(m_{j,x} - x)^2 + (m_{j,y} - y)^2}, \qquad \hat\phi = \mathrm{atan2}(m_{j,y} - y,\ m_{j,x} - x) - \theta, \tag{6.13}$$

$$p(f_t^i \mid c_t^i = j,\ x_t, m) = \mathrm{prob}(r_i - \hat r,\ \sigma_r^2)\cdot \mathrm{prob}(\phi_i - \hat\phi,\ \sigma_\phi^2)\cdot \mathrm{prob}(s_i - \hat s_j,\ \sigma_s^2), \tag{6.14}$$

（$\phi$ 差同样要归一化到 $(-\pi, \pi]$。）**对应变量** $c_t^i \in \{1, \dots, N, N+1\}$：观测 $i$ 对应地图中哪个地标；$N + 1$ = "都不对应"（虚假地标/新地标——第 10 章地图管理的伏笔）。**数据关联问题**（data association）：$c$ 未知时如何定 $c$——是第 07 章（马氏距离门限）、第 10 章（EKF SLAM 一致性检验）的核心剧情，本章先把"已知 $c$ 怎么算"备好（原书程序 6.4 三行：算 $\hat r, \hat\phi$ → 三路高斯连乘）。对 $(\hat r, \hat\phi)$ 求位姿雅可比即得 EKF 更新所需的 $H_t$——第 07 章直接取用。

**③ 位姿采样：环与螺旋**（原书 6.6.4，程序 6.5）。均匀先验下贝叶斯反转：$p(x_t \mid f_t^i, c_t^i, m) = \eta\, p(f_t^i \mid c_t^i, x_t, m)$（原书式 6.41）。采样算法的几何本质：单次距离-方位观测只给三维位姿**两维约束**——机器人必在以地标为心、半径 $r_i$ 的**圆周**上，方位再砍掉一半自由度，剩下的圆周角 $\gamma$ 均匀采样：

```text
γ = rand(0, 2π);  r̂ = r_i + sample(σ_r²);  φ̂ = φ_i + sample(σ_φ²)
x = m_{j,x} + r̂·cos γ;  y = m_{j,y} + r̂·sin γ;  θ = norm(γ − π − φ̂)   # (γ+π 与 γ−π 同义)
```

后验映射到 $x\text{-}y$ 平面是围绕地标的**环**，三维里沿 $\theta$ 展开成**螺旋**（原书图 6.13）——"一个观测不足以定位"的几何可视化。此采样器在第 07 章全局定位中用于制造初始位姿假设。

**④ 信息代价**（原书 6.6.5，值得原样领会）：特征**不是**测量的充分统计量（原书式 6.42 的定义）——从 dense 测量压到几个特征，丢失的信息恰恰是数据关联与全局定位最需要的（原书的内省例子：睁眼看全景即可定位，只记门框相对位置则不能）。随着算力增长，先进系统回归 dense 测量 + 位置地图；但特征表示仍是教学的最佳载体——对应变量、一致性检验这些概念在低维下最清晰。

## 06.6 四模型选型总览

| | 波束模型 | 似然域 | 地图匹配 | 路标特征 |
|---|---|---|---|---|
| 物理保真 | 高（四类误差各有来源） | 无（ad hoc） | 无（相关系数） | 中（几何真 + 高斯噪声） |
| 光滑性 | 差（杂乱环境跳变） | **好** | 差（可卷积补救） | 好 |
| 预计算维度 | 3（位姿空间） | **2**（地图平面） | — | 无需 |
| 动态障碍（人） | 显式（$p_{\mathrm{short}}$） | 隐性容忍 | 部分 | — |
| 遮挡/穿墙 | 正确处理 | 穿墙 | 局部图越界穿墙 | — |
| 典型用途 | 教学、高保真仿真 | **MCL/定位实践标配** | 少用 | EKF SLAM、 FastSLAM（ch10–13） |

经验法则（原书 6.7）：模型越精确越好，但"物理真实"不是唯一标准——**对下游算法友好的性质（光滑、可预计算）同等重要**；需要削减信息量时，$p^a$ 衰减优于特征化（不引入额外方差）；参数应适度**夸大**不确定性以对冲未建模相关性导致的过度自信。

## 06.7 小结、术语表与书后习题全解

**要点回顾**：

1. 测量模型 = 按误差**类型**分解的混合分布；波束模型四分量（hit/short/max/rand）各有物理故事，两个截断归一化 (6.2) 别漏（06.2.1）；
2. 混合模型参数学习 = EM：E 步算"责任"、M 步把闭式 ML 解的计数换成软计数；$\sigma_{\mathrm{hit}}^2$ 与 $\lambda_{\mathrm{short}}$ 的 M 步就是加权样本方差与加权倒数均值（06.2.2）；
3. 似然域放弃物理换来光滑 + 二维预计算，是实践首选；代价是穿墙与动态模型缺失（06.3）；
4. 地图匹配用自由空间边界补票，但无物理解释（06.4）；
5. 路标模型引入对应变量 $c$（含 $N{+}1$ 虚假项）——数据关联问题的舞台；单观测的后验是环/螺旋（06.5）；
6. 信息衰减 $p^a$ 是治过度自信的首选（06.6）。

**术语表（本章新增）**：测量模型（measurement model）、镜面反射（specular reflection）、射线投射（ray casting）、波束模型（beam model）、似然域（likelihood field）、地图匹配（map matching）、局部地图（local map）、特征提取（feature extraction）、路标（landmark）、签名（signature）、对应变量（correspondence variable）、数据关联（data association）、固有参数（intrinsic parameters）、极大似然估计（ML estimator）、期望最大化（EM）、距离-方位传感器（range-bearing sensor）、充分统计量（sufficient statistic）。

**书后习题全解指导**（原书 6.10 节，书 139–141 页）：

**习题 1（天花板视觉标记的投影几何）**——设定：标记在天花板、高 $h$；相机在机器人处；针孔投影把水平位移 $d$ 映射为 $\frac{f}{h}d$（相似三角形）；约定图像 $x$ 轴对齐机器人航向。记旋转矩阵 $R(\theta)$。(a) **期望标记位置**（机器人位姿 + 图像观测 → 全局标记）：
$$x_m = x_r + \tfrac{h}{f}(x_i\cos\theta_r - y_i\sin\theta_r), \quad y_m = y_r + \tfrac{h}{f}(x_i\sin\theta_r + y_i\cos\theta_r), \quad \theta_m = \theta_r + \theta_i.$$
(b) **正演图像**（机器人 + 标记 → 图像）：$\Delta = R(-\theta_r)\,(x_m - x_r,\ y_m - y_r)^T$，$x_i = \tfrac{f}{h}\Delta_x$，$y_i = \tfrac{f}{h}\Delta_y$，$\theta_i = \theta_m - \theta_r$。(c) **逆解机器人**：$\theta_r = \theta_m - \theta_i$（方向先锁定），再 $x_r = x_m - \tfrac{h}{f}(x_i\cos\theta_r - y_i\sin\theta_r)$，$y_r$ 同理——**单标记即闭式定位**（天花板标记的优势正在于此：高度 $h$ 已知消除了距离尺度歧义；这也是题目问"为什么装天花板"的一半答案，另一半是视野开阔、不易被遮挡）。(d) **对称标记的代价**：$k$ 重对称使 $\theta_i$ 只能测到 $\bmod\ (360°/k)$ → 单标记的 $\theta_r$（连带位姿）只剩 $k$ 个离散假设，**不唯一**；再放一个标记后，两标记的相对几何（三角测量 + 一致性核对）在通用配置下唯一锁定位姿——**2 个足够**（论证要点：单标记败于对称歧义；双标记的对应歧义 $2!$ 与对称歧义都可由几何一致性检验排除）。

**习题 2（误差协方差的传播）**——方法：一阶泰勒（雅可比传播）$\Sigma_y = J\,\Sigma_x\,J^T$。本题的巧妙之处：因方向**无噪声**（$\theta_i, \theta_r$ 精确），三张映射 (a)(b)(c) 关于噪声变量 $(x_i, y_i)$ 全是**线性**的——(a) 的协方差 = $\left(\tfrac{h}{f}\right)^2 R(\theta_r)\,\Sigma_i\,R(\theta_r)^T$（旋转不变性：迹相同，主轴随 $\theta_r$ 旋转）；(b) 就是 $\Sigma_i$ 本身（正演对 $(x_i,y_i)$ 是恒等）；(c) = $\left(\tfrac{h}{f}\right)^2 R(\theta_r)\,\Sigma_i\,R(\theta_r)^T$（负号在协方差中消失）。**何时真需要泰勒**：若图像方向 $\theta_i$ 也有噪声，$R(\theta_r)$ 中的 $\theta_r = \theta_m - \theta_i$ 变成随机量，映射非线性 → 对 $\theta_i$ 取一阶展开、把 $\partial J/\partial\theta_i$ 的高阶项并入（题面"最好是采用泰勒级数展开"即为此情形留的口子）。这份"线性 / 需线性化"的判别练习，正是第 07 章 EKF 的思维热身。

**习题 3（sample_marker_model 采样器）**——构造：由 (c) 的逆解 + 图像噪声注入：重复 {采 $n \sim \mathcal{N}(0, \Sigma_i)$ 加到 $(x_i, y_i)$；$\theta_r = \theta_m - \theta_i$；再对对称标记把 $\theta_i$ 换成 $\theta_i + k\cdot(360°/k_{\mathrm{sym}})$ 的随机代表} → 输出机器人位姿样本。五组参数的预期图形：(1) 图像 (0,0)、$\sigma^2 = 0.1$ cm² → 机器人紧贴标记正下方的小团；(2) 图像 (1,0) cm、$h/f = 200/200 = 1$ → 团心平移约 1 cm（方向按 $\theta_r$ 旋转）；(3) $\theta_i = 45°$ → **四簇结构**（4 重对称 → $\theta_r$ 四个假设 → 位置簇随旋转散开）；(4) $\sigma^2 = 1$ cm² → 簇胀成云；(5) 任意配置 → 单一斜置团（+对称四重影）。画图时标注坐标轴与单位，"方向可忽略"指 $x\text{-}y$ 投影。

**习题 4（声呐对平整墙的检测频率）**——物理机制：入射角 $\varphi$（波束 vs 墙面法线）超过锥半角时，镜面反射把回波送离接收锥 → 检测失败报 $z_{\max}$。仿真配方：对每个 $(d, \varphi)$ 组合，模拟发射锥内多条射线，按镜面定律（反射角 = 入射角）算回波方向，统计落入接收锥的比例 ≈ 检测频率。预期规律：$\varphi = 0$（垂直入射）检测率接近 1 且随 $d$ 缓变（仅衰减）；$\varphi$ 增大检测率下降，且跌落点约在 $\varphi \approx$ 锥半角处转陡——与 06.2.1 中 $p_{\mathrm{max}}$ 分量"镜面反射是检测失败主因"的论断互为印证。此题是"波束模型各分量从哪来"的最小物理实验。
