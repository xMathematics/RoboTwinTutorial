# 第 13 章｜FastSLAM

SLAM 三重奏的终章走的是完全不同的路线：不换表示（高斯/信息），而是**换分解**。**Rao-Blackwell 因式分解**——全 SLAM 后验可以**精确地**（不是近似！）写成"路径后验 × 每个地标一个条件后验"的乘积——把 $O(N^2)$ 的联合高斯拆成 $M(N{+}1)$ 个低维滤波器：**粒子管路径，每个粒子自带 N 个独立小 EKF 管地标**。奖励清单：复杂度 $O(M \log N)$（树实现）；每粒子独立的**数据关联假设**（错误关联不再致命，只是让粒子变瘦）；同时解决在线与全 SLAM（推导按全后验走，更新只用最新位姿）。账单也清楚：**闭环收敛慢**——相关性靠粒子多样性隐式维持，重采样终会剪掉共同历史，新观测无法修正"坍缩点之前"看到的地标。本章还是全书"建议分布设计"的毕业典礼：FastSLAM 1.0 → 2.0 的一字之差（采样时是否看测量 $z_t$）正是第 04 章"建议-目标失配"理论的教科书级应用。

> 原书锚点：第 13 章，书 336–373 页（PDF 354–391 页）。13.2.1 因式分解归纳证明与 13.4 节推导全量展开；建议分布 (13.33)–(13.34)、权重协方差 (13.53)、1.0 权重 (13.25) 全部经 Monte Carlo 独立数值验证（误差在采样精度内；验证过程中我方测试脚本的三处缺陷已排除——网格分母漏了地标方差、OCR 误读多出一项、符号约定混淆，均不涉及原书错误）。

## 13.1 粒子表示：一条路径 + N 个小 EKF（原书 13.1）

每个粒子（原书式 13.11）：

$$Y_t^{[k]} = \big(x_{1:t}^{[k]},\ \mu_{1,t}^{[k]}, \Sigma_{1,t}^{[k]},\ \dots,\ \mu_{N,t}^{[k]}, \Sigma_{N,t}^{[k]}\big), \tag{13.1}$$

路径采样 + 每个地标一个 2 维高斯。$M$ 个粒子共 $M(N{+}1)$ 个滤波器（1 个粒子滤波 + $MN$ 个 2 维 EKF）。**存储 $O(MN)$**——与 EKF 的 $O(N^2)$ 在 $M < N$ 时已占优。

## 13.2 Rao-Blackwell 因式分解：FastSLAM 的全部数学（原书 13.2）★

**定理**（原书式 13.1）：

$$p(x_{1:t}, m \mid z_{1:t}, u_{1:t}, c_{1:t}) = p(x_{1:t} \mid z_{1:t}, u_{1:t}, c_{1:t}) \prod_{n=1}^{N} p(m_n \mid x_{1:t}, z_{1:t}, c_{1:t}). \tag{13.2}$$

**为什么对**（两层理解）：

- **图论直觉**（原书图 13.3 的 DBN）：给定**整条路径**，任何两个地标之间不存在绕开路径变量的依赖通路——"知道 $m_1$ 的精确位置对预测 $m_2$ 毫无帮助"。条件独立严格成立。
- **归纳证明**（原书 13.2.1 全展开，教程浓缩为两情形一合并）：对 $t$ 归纳。新测量到来时对每个地标 $m_n$：
  - **未被观测**（$c_t \ne n$）：后验原样继承（原书式 13.4）——$m_n$ 与新测量无关；
  - **被观测**（$c_t = n$）：贝叶斯准则展开，分子分母的 $p(z_t \mid x_t, m_{c_t}, c_t)$ 保留、其余因子经条件独立消解（原书式 13.5–13.6），新后验 = 似然 × 旧后验（就是单地标 EKF 更新的概率版）；
  - 归纳假设代入后，$m = m_{c_t}$ 与"其余全部"整齐分开（原书式 13.9），再乘上路径后验（原书式 13.10）——分解在 $t$ 步保持。

**一个不能省的条件**（原书特别强调，习题 3 的考点）：条件变量必须是**整条路径** $x_{1:t}$——只条件于最新位姿 $x_t$ 不充分，因为"通过以前的位姿可能出现相关性"（两个地标的不确定性都源自过去某段位姿误差，掐掉历史这个公共源头，相关性就死了）。

**Rao-Blackwell 的红利**：分解是精确的，但每个因子的表示要选——路径后验非高斯 → 粒子；给定路径后每个地标是**线性高斯问题** → EKF 闭式。这正是第 04 章 4.4 预告的"粒子 + 高斯组合技"：**粒子维数从位姿空间承担，地标连续分布交给解析滤波**。

## 13.3 FastSLAM 1.0：三步更新（原书 13.3）

```text
Algorithm FastSLAM_1.0_known_correspondence( z_t, c_t, u_t, Y_{t-1} ):
    for k = 1 to M:
        取出粒子 k；采样 x_t^{[k]} ~ p(x_t | x_{t-1}^{[k]}, u_t)        # ① 运动模型采样
        j = c_t
        if 地标 j 从未见:                                              # 初始化
            μ = h^{-1}(z_t, x_t)；Σ = (H^{-1}) Q (H^{-1})^T；w = p0
        else:                                                          # ② 单地标 EKF 更新
            ẑ = h(μ_{j,t-1}, x_t)；H = h'(·)；Q̃ = HΣH^T + Q
            K = Σ H^T Q̃^{-1}；μ ← μ + K(z − ẑ)；Σ ← (I − KH)Σ
            w = |2πQ̃|^{-1/2} exp{−½(z−ẑ)^T Q̃^{-1} (z−ẑ)}              # ③ 重要性权重
        其余地标原样复制
    重采样 M 个（∝ w）                                                # ④
    return Y_t
```

**权重公式 (13.24)–(13.25) 的来历**：目标 = 路径后验、建议 = 运动模型（原书式 13.19–13.21），商化简后只剩测量似然 $p(z_t \mid x_t^{[k]}, c_t)$——它是对地标位置 $m_{c_t}$ 的**积分**（原书式 13.23）：$\int \mathcal{N}(z; h(m, x), Q)\,\mathcal{N}(m; \mu, \Sigma)\,dm$。线性化 $h$ 后用高斯卷积闭式求解：

$$w_t^{[k]} \propto \mathcal{N}(z_t;\ \hat z_t,\ \tilde Q_t), \qquad \tilde Q_t = H_t \Sigma_{t-1} H_t^T + Q_t \tag{13.3}$$

——"预测测量 + 不确定性相加"，与第 07 章 EKF 定位的测量似然 (7.9) 同构。**教程验证**：Monte Carlo 积分（40 万样本）给出协方差对角 (0.351, 0.350) vs 公式 $\tilde Q = \Sigma + Q = 0.35$ ✓。**新地标初始化**用 $h$ 的逆（距离-方位可逆；纯方位场合回到第 10 章习题 2 的射线初始化）。**时间/内存与 $t$ 无关**——更新只用最新位姿，过去位姿可安全丢弃（"FastSLAM 同时是全 SLAM 与在线 SLAM 的解"的机制所在）。

## 13.4 FastSLAM 2.0：建议分布纳入测量（原书 13.4）

**① 病灶**（原书图 13.6 的诊断）：1.0 的建议分布只看控制 $u_t$，与目标的失配由测量 $z_t$ 单方面承担——**测量噪声 ≪ 运动噪声时**，少量高似然粒子漂浮在大片低似然样本中，重采样后多样性崩塌。诊断法（原书 13.9.1 的妙招）：人为放大测量噪声模型，若误差反而下降，就该换 2.0。

**② 建议分布**（原书式 13.26–13.36）：改为从 $p(x_t \mid x_{t-1}^{[k]}, u_{1:t}, z_{1:t}, c_{1:t})$ 采样——贝叶斯展开后是"测量似然对地标的积分"× 运动模型的乘积（原书式 13.27）。线性化 $h$（在 $(\mu_{c_t,t-1}, x_{t-1}^{[k]})$ 处，原书式 13.28–13.32）后，积分给出高斯 $\mathcal{N}(z;\ \hat z_t + H_x(x_t - x_{t-1}^{[k]}),\ \tilde Q_t)$（卷积定理，原书式 13.36），与运动先验 $\mathcal{N}(x_t;\ x_{t-1}^{[k]}, R_t)$ 相乘——配平方得**改进建议分布**：

$$\Sigma_t^{\prime[k]} = \big(H_x^T \tilde Q_t^{-1} H_x + R_t^{-1}\big)^{-1}, \qquad \mu_t^{\prime[k]} = \Sigma_t^{\prime[k]} H_x^T \tilde Q_t^{-1}\big(z_t - \hat z_t\big) + x_{t-1}^{[k]} \tag{13.4}$$

（原书式 13.33–13.34；$\hat z_t = h(\mu_{c_t,t-1}, x_{t-1}^{[k]})$。）**教程验证**：对同一算例，Monte Carlo 重要性重采样的样本均值 (0.470, 0.311) vs 公式 (0.474, 0.313)——独立方法在采样精度内吻合 ✓。（验证过程中我方网格检查一度报错，排查为网格表达式符号笔误与漏掉 $m$ 的方差贡献，Monte Carlo 裁决后排除。）

**③ 权重**：建议已含 $z_t$，权重 = 式 (13.27) 的归一化常数之逆（原书式 13.49–13.52），线性化后（原书式 13.53）：

$$w_t^{[k]} \propto \mathcal{N}(z_t;\ \hat z_t,\ L_t), \qquad L_t = H_x R_t H_x^T + H_m \Sigma_{t-1} H_m^T + Q_t \tag{13.5}$$

——**三项协方差之和**（位姿先验、地标估计、测量噪声各自穿透雅可比）。**教程验证**：Monte Carlo 协方差对角 (0.749, 0.747) vs 公式 0.75 ✓。对比 1.0 的 (13.3)：$L$ 多了 $H_xRH_x^T$ 项——位姿不确定性现在留在权重里而不是被采样扔掉，这正是 2.0 样本效率的来源。**④ 特征更新**在采样后的 $x_t^{[k]}$ 处重线性化（原书式 13.46–13.48），比 1.0 略复杂但更准。

## 13.5 每粒子数据关联与地图管理（原书 13.5–13.6）

**每个粒子自备一套关联假设** $c_{1:t}^{[k]}$——这是 FastSLAM 与高斯 SLAM 族的分水岭（第 07/10/12 章都是"全滤波器一张票"）。两种机制：**逐粒子 ML**（原书式 13.55）与**数据关联采样器 DAS**（按似然采样，原书式 13.56–13.57，新地标以 $\eta p_0$ 的概率被"发明"）。似然计算即式 (13.3) 的 $\mathcal{N}(z; \hat z_j, \tilde Q_j)$ 对候选地标逐个打分（原书式 13.58–13.59）。**错误的关联不再致命**：被它污染的粒子地图不一致 → 未来的重采样自然淘汰它——**多样性就是容错**。**地图管理**（原书 13.6）：存在概率 log-odds 计数器（观测 +1 / 该见未见 −1 / 阈值除名）；临时列表在此用处不大（每粒子每地标本来就有独立估计）；签名照常并入观测向量。

## 13.6 高效实现：让重采样不再复制地图（原书 13.8）

朴素实现 $O(MN)$：重采样复制整张地图 + 关联遍历全图。**树结构**：粒子共享地图的公共子树，重采样只挂新指针——更新降到 $O(M \log N)$（内存实验：原书图 13.9 的线性 vs 对数曲线）；关联搜索限位在邻域 kd 树。变体谱系：bk-tree（Procopiuc 2003）、DP-SLAM 的祖先树（Eliazar & Parr 2003）。树使 FastSLAM 能处理 $10^9$ 级特征（原书小结）。

## 13.7 实战、短板与栅格版（原书 13.9–13.10）

**Victoria Park 特征版**（原书 13.9.1）：$M = 100$、4 km 轨迹 RMSE 刚过 4 m；**把里程计换成布朗运动模型，误差统计上不可区分**——鲁棒性的震撼展示（信息主要来自测量而非控制）。负信息（存在计数器）砍掉 **44%** 虚假特征。**与 EKF 对垒**（图 13.12）：$M \ge 10$ 后精度与 EKF 统计不可分，而参数少一个数量级。**1.0 vs 2.0**（图 13.13）：测量噪声大时两者相当；噪声小时 1.0 明显掉队（建议失配发作）。

**短板：闭环**（原书 13.9.2，与高斯 SLAM 的正面对决）：高斯法靠协方差交叉块显式维持相关性；FastSLAM 靠**粒子多样性**隐式维持——重采样终使全体粒子共享某点之后的共同历史，**新观测无法修正坍缩点之前看到的地标**。加大 $M$ 把坍缩点向后推（图 13.15：2.0 的多样性维持到回环起点而 1.0 半路断流；图 13.16a：同粒子数下 2.0 闭更大的环）；图 13.16b：$M$ 越大收敛越快、渐近 EKF——"缺乏长程相关性是 FastSLAM 最有争议的弱点"（原书原话）。**栅格版**（原书 13.10，程序 13.4）：每粒子一张占用栅格（第 09 章算法逐粒子运行），权重 = 测量对该粒子地图的似然；28 m × 28 m、491 m 轨迹、500 粒子成功双回环（图 13.18 纯里程计地图的惨状 vs 图 13.19 的修正）——"蒙特卡罗定位 + 占用建图"的字面拼装，思想上是 DP-SLAM 的近亲。

## 13.8 小结、术语表与书后习题全解

**要点回顾**：

1. Rao-Blackwell 分解精确成立，条件变量必须是**整条路径**（13.2）；
2. 粒子管路径、每粒子 N 个 2 维 EKF 管地标；更新只用最新位姿 → 在线与全 SLAM 双修（13.1、13.3）；
3. 1.0 权重 $\mathcal{N}(z; \hat z, \tilde Q)$、2.0 建议 $\mathcal{N}(\mu', \Sigma')$ + 权重 $\mathcal{N}(z; \hat z, L)$（三项和）——建议分布理论的毕业应用（13.3–13.4）；
4. 每粒子独立数据关联 = 多样性即容错；树实现 $O(M\log N)$（13.5–13.6）；
5. 短板：闭环收敛受粒子多样性支配，重采样剪共同历史（13.7）。

**术语表（本章新增）**：FastSLAM 1.0 / 2.0、Rao-Blackwell 化（Rao-Blackwellization）、因式分解 SLAM 后验（factorized SLAM posterior）、条件独立（给定路径）、改进建议分布（improved proposal distribution）、数据关联采样器（DAS）、存在概率计数器、祖先树（ancestry tree）、DP-SLAM、共同历史坍缩（common history collapse）。

**书后习题全解指导**（原书 13.13 节，书 372–373 页）：

**习题 1（三种 SLAM 各三个独特优点）**——EKF：①在线增量、随时可读估计；②协方差显式维持长程相关（闭环信息传播最快，图 13.16b 的收敛冠军）；③实现与理论成熟、小地图上精度黄金标准。GraphSLAM：①批处理可反复重线性化与修正关联（精度上限最高）；②稀疏信息形式 + 现代最小二乘 → $10^8$ 特征级地图；③天然给出全 SLAM 后验（路径不确定性可直接用于事后分析）。FastSLAM：①每粒子独立关联假设——错误关联自愈；②$O(M\log N)$ 可伸缩 + 在线/全 SLAM 双修；③对运动模型粗糙极度鲁棒（布朗运动实验）。

**习题 2（1.0 不收敛而 2.0 收敛的情形）**——构造：**测量远精于运动**（如 $\sigma_{\mathrm{motion}} = 1$ m、$\sigma_{\mathrm{meas}} = 1$ cm）且地标观测频繁。1.0 的建议 = 运动模型，1 m 级散布中只有 ~1% 落入 1 cm 级高似然区；每步重采样约 99% 多样性蒸发，数十步后全部粒子共享历史（图 13.6 机制），错误锁定后无法恢复 → 依概率 1 不收敛到正确地图（粒子数有限时）。2.0 的建议把样本直接聚到 $\mathcal{N}(\mu', \Sigma')$（式 13.4），高似然区粒子密度充足 → 标准粒子滤波的渐近收敛条件满足。这正是图 13.13 左端"1.0 掉队"的极端版。

**习题 3（为什么必须条件于整条路径）**——反例构造：机器人在 $t_1$ 时刻位姿不确定（椭圆大），同时首次观测地标 $m_a$ 与 $m_b$。给定 $m_a$ 的精确位置 → 反推 $x_{t_1}$ 被钉死 → $m_b$ 的位置也随之钉死（共享同一位姿源头）。若只条件于"最新位姿 $x_t$"，这条经由 $x_{t_1}$ 的依赖链仍在后验中活着——$p(m_a, m_b \mid x_t, z, u) \ne p(m_a \mid x_t, \cdot)p(m_b \mid x_t, \cdot)$。形式化：DBN 中 $m_a \leftarrow x_{t_1} \rightarrow m_b$ 的路径不含 $x_t$（$t_1 < t$），故条件于 $x_t$ 不阻断；条件于 $x_{1:t}$ 才阻断。**这也是图 13.15"共同历史"现象的概率根源**。

**习题 4（M 张地图合并成单一估计）**——已知关联情形：地图即路径的条件期望，合并 = 对粒子加权平均每地标的 $(\mu, \Sigma)$——但注意**跨粒子平均地标会引入虚假相关性**（不同粒子的 $\mu$ 各自条件于不同路径，加权平均的协方差须加"均值间散布"项 $\sum_k w_k(\mu^{[k]} - \bar\mu)(\mu^{[k]} - \bar\mu)^T$，混合高斯的矩匹配公式）。未知关联情形：先聚类（哪些粒子的哪些地标互相对应——可用 11.5 的 $\Delta = 0$ 概率做亲和度），再在簇内做上述矩匹配；簇间不可合并时输出混合高斯而非单高斯（保持多峰诚实）。

**习题 5（MCL 2.0：把改进建议分布搬回定位）**——设计：定位的 1.0 建议 = $p(x_t \mid u_t, x_{t-1})$（第 08 章 MCL）。"2.0 版"对每个候选假设引入测量：对路标地图 + 已知关联，建议改为
$$p(x_t \mid x_{t-1}^{[i]}, u_t, z_t, c_t) \approx \mathcal{N}\big(\mu_t',\ \Sigma_t'\big), \qquad \Sigma' = \big(H^T\tilde Q^{-1}H + R^{-1}\big)^{-1},\ \mu' = \Sigma'H^T\tilde Q^{-1}(z - \hat z) + \bar x_t,$$
（$\bar x_t$ = 运动预测均值，$\tilde Q = H\Sigma_{t-1}H^T + Q$——与式 (13.4) 逐字同构，只是"地标估计"换成定位先验）；权重用三项和 $L$（式 13.5）。适用边界照搬 13.4：测量噪声 ≪ 运动噪声时收益最大——**这正是第 08 章"完美传感器使 MCL 失效"悖论的解药**（建议分布看测量后，尖似然不再是采样事故而是采样目标）。

**习题 6（树实现的数据结构）**——设计：路径用**链表 + 写时复制**：重采样复制粒子时只复制头指针；地标按空间 kd 树组织，每节点记录"创建该节点的粒子代数"；更新地标 = 路径写时复制到叶 + 沿树补路径（惰性，$\log N$）；丢失计数器随节点存储。更新方程：观测命中 → 沿根-叶路径克隆分支、叶上做 EKF 更新；重采样 → 新粒子集共享未克隆分支。指标：插入/查询/克隆均 $O(\log N)$，总更新 $O(M \log N)$。

**习题 7（验证相关性被隐式维护）**——实验设计：线性高斯 SLAM 上跑 FastSLAM 1.0 与 EKF，比较**地标-地标互相关**：EKF 的归一化协方差随时间趋于全相关（第 10 章图 10.4）；FastSLAM 无联合协方差，用**粒子间协方差**替代——对同一地标跨粒子取 $\mathrm{Cov}(\{\mu_n^{[k]}\})$、对不同地标取 $\mathrm{Cov}(\{\mu_a^{[k]}, \mu_b^{[k]}\})$。预期：两者同步增长且在回环时骤降（信息经重采样蔓延）——但衰减点受"共同历史坍缩"限制，比 EKF 慢。这个实验把 13.9.2 的定性讨论变成可测量。
