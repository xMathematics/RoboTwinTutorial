# 第 05 章｜机器人运动模型

第 02 章的贝叶斯滤波有两个输入依赖（02.4 末尾）：转移概率 $p(x_t \mid u_t, x_{t-1})$ 与测量概率 $p(z_t \mid x_t)$。前四章把"滤波机器"造好了，本章开始造**燃料**：给定控制 $u_t$ 与上一时刻位姿 $x_{t-1}$，位姿 $x_t$ 的后验怎么写？本章为平面移动机器人建立两个互补的运动模型——**速度模型**（输入是电机速度指令，可用于规划）与**里程计模型**（输入是走完后才有的测距读数，实践上更准，用于估计）；每个模型都给出**闭式计算**（算概率，需解逆运动学）与**采样算法**（产生样本，只需前向仿真）两套实现——EKF 定位吃前者、粒子滤波吃后者，这个分工在第 07、08 章兑现。最后把两个模型升级为地图条件版本，并剖析其近似本质（"穿墙"问题）。本章的方法论只有一句话：**把确定性运动学方程加上噪声项，就是概率运动模型**——同样的套路可迁移到自行车、全向底盘乃至机械臂。

> 原书锚点：第 5 章，书 88–111 页（PDF 106–129 页）。5.3.3 节（书 94–99 页）与 5.4.3 节（书 104–105 页）的推导本章全量展开；原书一句"推导遵循简单的三角学"跳过的圆弧几何，教程补全。

## 05.1 位姿与概率运动学（原书 5.2）

**① 问题场景**：滤波器需要 $p(x_t \mid u_t, x_{t-1})$，但机器人学给我们的传统遗产是**确定性**运动学——"给定速度，位姿怎么变"。差距在哪里、怎么补？

**② 基本记号**：平面刚体机器人的位姿（pose）

$$x_t = (x,\ y,\ \theta)^T \qquad (\text{平面坐标 + 航向角})\text{，无方向的 }(x, y)^T \text{ 称位置（location）}. \tag{5.1}$$

**③ 概率化**：运动模型就是第 02 章的状态转移概率（原书式 5.3）：对 $x_{t-1}$ 执行控制 $u_t$ 后，位姿的**后验分布**。构造路径：写出无噪声运动学 $x_t = f(u_t, x_{t-1})$，再把"控制不可精确执行"建模为噪声。

**④ 两种运动信息的分工**（原书 5.2.2 的关键论断）：

| | 速度模型 | 里程计模型 |
|---|---|---|
| 输入 $u_t$ | 速度指令 $(v, \omega)$ | 里程计读出的相对运动 |
| 可得时机 | 执行**前**（可预测） | 执行**后**（事后才有） |
| 精度 | 较差（实际运动控制器与数学模型失配） | 较好（轮编码器直接计量，但仍有漂移/打滑） |
| 用途 | **概率运动规划**（防撞等必须预测） | **估计/滤波**（定位、SLAM 的主力） |

——同一个 $p(x_t \mid u_t, x_{t-1})$，规划与估计各自偏爱不同实例。原书还有一句工程忠告：成功的模型往往**高估**不确定性，这反而让算法对马尔可夫假设的违反（02.5）更鲁棒——"模型的确切形状没那么重要，对不确定结果有所准备才重要"。

## 05.2 速度运动模型（原书 5.3）

控制为平移速度与旋转速度 $u_t = (v, \omega)^T$（前向为正、逆时针为正；原书式 5.4）。适用于差分驱动、阿克曼驱动、同步驱动；**不**适用于无非完整约束的驱动（麦克纳姆轮、腿式）——它们能侧移，$(v,\omega)$ 不足以刻画。

### 05.2.1 理想运动学：圆弧闭式解（推导补全）

**常速假设下的轨迹是圆**。半径由圆周运动的一般关系给出：

$$r = \frac{v}{\omega} \qquad (\omega = 0 \Leftrightarrow r = \infty\text{，即直线}), \tag{5.2}$$

**圆心**：圆心在初始航向的垂线上（原书式 5.7–5.8）：

$$x_c = x - r\sin\theta, \qquad y_c = y + r\cos\theta. \tag{5.3}$$

**教程推导**（原书一句带过处）：验证机器人相对圆心的初始方位角——$x - x_c = r\sin\theta$、$y - y_c = -r\cos\theta$，即机器人位于圆心的"角 $\theta - \pi/2$"方向上，且该方位随机器人航向**锁定**（这是圆周运动的定义：速度始终垂直于半径）。经 $\Delta t$ 后航向转过 $\omega\Delta t$，机器人沿圆弧前进 $v\Delta t = r\omega\Delta t$，新位置 = 圆心 + 旋转后的径向向量：

$$\begin{pmatrix} x' \\ y' \\ \theta' \end{pmatrix} = \begin{pmatrix} x - \dfrac{v}{\omega}\sin\theta + \dfrac{v}{\omega}\sin(\theta + \omega\Delta t) \\[2mm] y + \dfrac{v}{\omega}\cos\theta - \dfrac{v}{\omega}\cos(\theta + \omega\Delta t) \\[2mm] \theta + \omega\Delta t \end{pmatrix}. \tag{5.4}$$

一致性自查：位置对时间的导数满足 $|\dot{(x,y)}| = r\omega = v$ ✓、$\dot\theta = \omega$ ✓。**非恒速情形**：真实控制从不恒定，实用做法是取小 $\Delta t$ 分段常速、把圆弧段连起来（原书明言此近似）。

### 05.2.2 噪声模型与"最终旋转"项（原书 5.3.3 前半）

**① 噪声加在哪里**：真实速度 = 指令速度 + 零均值噪声（原书式 5.10）：

$$\begin{pmatrix} \tilde v \\ \tilde\omega \end{pmatrix} = \begin{pmatrix} v \\ \omega \end{pmatrix} + \begin{pmatrix} \varepsilon_1 \\ \varepsilon_2 \end{pmatrix}, \qquad \varepsilon_1 \sim b^2(\alpha_1 v^2 + \alpha_2 \omega^2), \quad \varepsilon_2 \sim b^2(\alpha_3 v^2 + \alpha_4 \omega^2). \tag{5.5}$$

记号 $b^2(\sigma^2)$ 表示"零均值、方差 $\sigma^2$ 的噪声变量"（密度可用正态或三角形，见 05.2.3）。**方差正比于速度的平方**——即噪声的**标准差正比于速度**：开得越快/转得越急，执行误差越大。$\alpha_1..​\alpha_4$ 是机器人特定的误差参数（越大越不精确）。

**② 为什么还要第三个噪声 $\gamma$（"最终旋转"）**——这是本章最重要的建模洞察：式 (5.4) 代入噪声速度后，$x_t$ 只由**两个**噪声变量驱动，后验的支撑集是三维位姿空间里的一个**二维曲面**（所有终点都落在"由 $\tilde v, \tilde\omega$ 张成的圆弧族"上）。概率密度退化会 serious 地伤害滤波（03 章的 KF 假设满协方差）。物理上圆弧假设本身不真（轮子打滑、地面不平都带来额外的平面内旋转误差），于是模型追加一项独立的最终旋转噪声（原书式 5.14–5.15）：

$$\theta' = \theta + \tilde\omega\Delta t + \gamma\Delta t, \qquad \gamma \sim b^2(\alpha_5 v^2 + \alpha_6 \omega^2). \tag{5.6}$$

完整的速度模型采样方程（原书式 5.16）= (5.4) 用 $(\tilde v, \tilde\omega)$ 代入 + (5.6)。**六个噪声参数 $\alpha_1..\alpha_6$ 到此配齐**：平移误差（$\alpha_1 v^2 + \alpha_2\omega^2$）、旋转误差（$\alpha_3 v^2 + \alpha_4\omega^2$）、最终旋转误差（$\alpha_5 v^2 + \alpha_6\omega^2$）。

### 05.2.3 两套实现：采样（前向）与闭式（逆） 

**采样算法**（原书程序 5.3）——粒子滤波用：

```text
Algorithm sample_motion_model_velocity( u_t, x_{t-1} ):
    v = v̂ + sample(α₁v̂² + α₂ω̂²)          # 平移速度加噪
    ω = ω̂ + sample(α₃v̂² + α₄ω̂²)          # 旋转速度加噪
    γ = sample(α₅v̂² + α₆ω̂²)              # 最终旋转噪声
    x' = x − (v/ω)sin θ + (v/ω)sin(θ + ωΔt)
    y' = y + (v/ω)cos θ − (v/ω)cos(θ + ωΔt)
    θ' = θ + ωΔt + γΔt
    return x_t = (x', y', θ')ᵀ
```

**噪声密度的两种选择**（原书程序 5.2/5.4）：正态 $\mathcal{N}(a; 0, b^2)$，或**三角形分布**

$$\mathrm{tri}(a) = \max\left\{0,\ \frac{1}{\sqrt6\,b} - \frac{|a|}{6b^2}\right\} \quad (\text{支撑集} = [-\sqrt6\,b, \sqrt6\,b])\text{，方差同为 } b^2. \tag{5.7}$$

三角形的卖点：支撑有限（采样永不产出离谱离群值）且**采样零成本**——两个均匀分布之和缩放即为三角分布（原书程序 5.4：$\frac{\sqrt6}{2}[\mathrm{rand}(-b,b) + \mathrm{rand}(-b,b)]$，方差恰为 $b^2$，05.6 习题 8 给出证明）。正态采样若无数学库，用中心极限定理：**12 个均匀数取平均**（支撑 $[-2b, 2b]$ 的近似正态，原书程序 5.4）。

**闭式算法**（原书程序 5.1）——EKF 定位用。它实现的是**逆模型**：给定假想终点 $x_t$，反解"能产生这个终点的等效控制 $(\hat v, \hat\omega, \hat\gamma)$"，再给误差打分：

1. **反解圆心**（原书式 5.17–5.19）：圆心受两条约束——在初始航向的垂线上（$(x^* - x)\cos\theta + (y^* - y)\sin\theta = 0$）且在弦 $(x,y)\text{-}(x',y')$ 的中垂线上。参数化中垂线并代入第一约束（教程补全代数；符号已按数值往返验证：圆心须同时垂直于初始与最终航向的半径）：

$$\mu = \frac12 \cdot \frac{(x - x')\cos\theta + (y - y')\sin\theta}{(y - y')\cos\theta - (x - x')\sin\theta}, \qquad x^* = \frac{x + x'}{2} + \mu\,(y - y'), \quad y^* = \frac{y + y'}{2} + \mu\,(x' - x). \tag{5.8}$$

2. **反解速度**（原书式 5.20–5.25）：半径 $r^* = \sqrt{(x - x^*)^2 + (y - y^*)^2}$；航向变化 $\Delta\theta = \mathrm{atan2}(y' - y^*, x' - x^*) - \mathrm{atan2}(y - y^*, x - x^*)$（atan2 定义域 $(-\pi, \pi]$，原书式 5.22）；弦长沿弧 $\Delta\mathrm{dist} = r^*\Delta\theta$；于是
$$\hat v = \Delta\mathrm{dist}/\Delta t, \qquad \hat\omega = \Delta\theta/\Delta t, \qquad \hat\gamma = (\theta' - \theta)/\Delta t - \hat\omega. \tag{5.9}$$

3. **误差打分**（原书式 5.26–5.32）：三路误差 $v_{\mathrm{err}} = \hat v - v$、$\omega_{\mathrm{err}} = \hat\omega - \omega$、$\gamma_{\mathrm{err}} = \hat\gamma$，按 (5.5)(5.6) 的方差独立打分相乘：

$$p(x_t \mid u_t, x_{t-1}) = \mathrm{prob}\big(v_{\mathrm{err}},\ \alpha_1v^2 + \alpha_2\omega^2\big)\cdot \mathrm{prob}\big(\omega_{\mathrm{err}},\ \alpha_3v^2 + \alpha_4\omega^2\big)\cdot \mathrm{prob}\big(\gamma_{\mathrm{err}},\ \alpha_5v^2 + \alpha_6\omega^2\big). \tag{5.10}$$

**反直觉点**：为什么闭式必须反解出 $\hat\gamma$？若不设第三路误差，对几乎所有的 $(x_{t-1}, u_t, x_t)$ 组合，概率**精确为零**——终点几乎从不恰好落在指令圆弧上（原书原话："如果不考虑最终旋转，运动概率很容易为零"）。这就是 05.2.2 退化问题在闭式算法里的直接后果。

**工程选型一句话**：采样只需前向仿真（物理模型直接可用），闭式需要解逆运动学——**粒子滤波天然吃采样版，这是它实现上的最大吸引力**（原书 5.3.2 明言）。

## 05.3 里程计运动模型（原书 5.4）

**① 问题场景**：大多数商业平台以固定间隔（如 0.1 s）输出里程计位姿估计。里程计在技术上是传感器测量，若按测量处理，贝叶斯滤波必须把"真实速度"增广进状态（维数膨胀）。工程折中（原书明言）：**把里程计读数当控制用**——它携带的正是状态变化信息（02.2 已有此分类），当今最好的概率机器人系统大多建于此。

**② 相对运动的三段分解**：里程计不知道全局坐标（否则定位问题已解决！），只提供内部坐标系下两位姿的**相对差** $u_t = (\bar x_{t-1}, \bar x_t)^T$（原书式 5.33）。关键洞察：任意一对位姿间的相对运动可由**旋转—平移—旋转**三步唯一重现（原书图 5.7）：

$$\delta_{\mathrm{rot1}} = \mathrm{atan2}(\bar y' - \bar y,\ \bar x' - \bar x) - \bar\theta, \qquad \delta_{\mathrm{trans}} = \sqrt{(\bar x' - \bar x)^2 + (\bar y' - \bar y)^2}, \qquad \delta_{\mathrm{rot2}} = \bar\theta' - \bar\theta - \delta_{\mathrm{rot1}}. \tag{5.11}$$

**③ 噪声模型**（原书式 5.37–5.39）：三个参数各自被独立噪声污染——

$$\hat\delta_{\mathrm{rot1}} = \delta_{\mathrm{rot1}} - \varepsilon \sim b^2(\alpha_1\delta_{\mathrm{rot1}}^2 + \alpha_2\delta_{\mathrm{trans}}^2), \quad \hat\delta_{\mathrm{trans}} = \delta_{\mathrm{trans}} - \varepsilon \sim b^2(\alpha_3\delta_{\mathrm{trans}}^2 + \alpha_4\delta_{\mathrm{rot1}}^2 + \alpha_4\delta_{\mathrm{rot2}}^2), \quad \hat\delta_{\mathrm{rot2}} = \delta_{\mathrm{rot2}} - \varepsilon \sim b^2(\alpha_1\delta_{\mathrm{rot2}}^2 + \alpha_2\delta_{\mathrm{trans}}^2). \tag{5.12}$$

$\alpha_1..​\alpha_4$ 四个参数即可——**没有退化问题**（三路独立噪声，三维支撑自动保证；原书特别指出这正是里程计模型比速度模型"多一个参数"换来的好处）。注意噪声的结构化含义：**旋转误差不仅随转角增长，还随平移距离增长**（$\alpha_2\delta_{\mathrm{trans}}^2$ 项——走过越远，轮子打滑积累的角度误差越大）；平移误差同理耦合旋转（$\alpha_4$ 两项）。

**④ 采样算法**（原书程序 5.6，滤波用）：

```text
Algorithm sample_motion_model_odometry( u_t, x_{t-1} ):
    δ_rot1  = atan2(ȳ′−ȳ, x̄′−x̄) − θ̄                    # 从里程计读数分解三段
    δ_trans = √((x̄′−x̄)² + (ȳ′−ȳ)²)
    δ_rot2  = θ̄′ − θ̄ − δ_rot1
    δ̂_rot1  = δ_rot1  − sample(α₁δ_rot1² + α₂δ_trans²)  # 三段各自加噪
    δ̂_trans = δ_trans − sample(α₃δ_trans² + α₄δ_rot1² + α₄δ_rot2²)
    δ̂_rot2  = δ_rot2  − sample(α₁δ_rot2² + α₂δ_trans²)
    x′ = x + δ̂_trans·cos(θ + δ̂_rot1)
    y′ = y + δ̂_trans·sin(θ + δ̂_rot1)
    θ′ = θ + δ̂_rot1 + δ̂_rot2
    return (x′, y′, θ′)ᵀ
```

**闭式算法**（原书程序 5.5，EKF 类滤波用）：对**假想位姿** $x_t$ 相对 $x_{t-1}$ 用同样的 (5.11) 算出 $(\hat\delta_{\mathrm{rot1}}, \hat\delta_{\mathrm{trans}}, \hat\delta_{\mathrm{rot2}})$，与里程计读数的 $(\delta_{\mathrm{rot1}}, \delta_{\mathrm{trans}}, \delta_{\mathrm{rot2}})$ 逐项作差、按 (5.12) 的方差打分、独立性假设下相乘（原书式 5.44–5.46 与程序第 8–11 行）。

**两个工程警告**：①**所有角度差必须归一化到 $(-\pi, \pi]$**（原书在程序 5.5 处专门警告"一个普通错误往往很难排除"）——$\delta_{\mathrm{rot2}}$ 尤其容易越界；②$\delta_{\mathrm{trans}}$ 反解出的可能带负号/方向歧义，实现时按 atan2 约定处理。两模型的关系（原书图 5.8 vs 5.9 对比）：**相邻测量间隔越短，两个模型越相似**——0.1 s 级更新的室内机器人几乎无差别。

## 05.4 地图条件下的运动模型（原书 5.5）

**① 问题场景**：真实机器人不会穿墙——占用地图 $m$ 明确区分可通行/不可通行区域，位姿必须落在自由区。把这一硬约束纳入：$p(x_t \mid u_t, x_{t-1}, m) \ne p(x_t \mid u_t, x_{t-1})$。严格计算需要枚举"存在一条自由路径"的概率——复杂到不可行。

**② 解决方法——终点一致性近似**（原书式 5.48）：只检查**终点**是否合法：

$$p(x_t \mid u_t, x_{t-1}, m) \approx \eta\, \frac{p(x_t \mid m)\, p(x_t \mid u_t, x_{t-1})}{p(x_t)}, \qquad p(x_t \mid m) = \begin{cases} 0 & x_t \text{ 落在（机器人半径膨胀后的）占用区} \\ \text{常数} & \text{否则}\end{cases}. \tag{5.13}$$

**推导**（原书式 5.49–5.51，辨析近似的本质）：对分子用贝叶斯准则展开——

$$p(x_t \mid u_t, x_{t-1}, m) = \eta\, p(m \mid x_t, u_t, x_{t-1})\, p(x_t \mid u_t, x_{t-1}),$$

再作核心近似（原书式 5.51）：

$$p(m \mid x_t, u_t, x_{t-1}) \approx p(m \mid x_t) \tag{5.14}$$

——丢掉 $(u_t, x_{t-1})$ 意味着**丢弃与路径有关的全部信息**，只问"终点本身合不合法"。（$p(m)$ 与 $p(x_t)$ 先验并入归一化，得 (5.13)。）副作用即"穿墙"：若起点终点都合法但连线穿过墙，近似仍给非零似然（原书图 5.11 的 $\ast$ 区域）。**补救是更新频率**：运动噪声有界时，足够高的更新率保证单步位移小于膨胀障碍的厚度，穿墙概率可忽略——原书由此点出一个常被忽视的系统性质：**更新频率不同的两个贝叶斯滤波，即使代码完全相同，也可能给出根本不同的结果**。

**③ 算法**（原书程序 5.7）：计算版 = $p(x_t \mid u_t, x_{t-1}) \cdot p(x_t \mid m)$ 直接乘；采样版 = 拒绝采样（do–until $p(x_t \mid m) > 0$）并返回带重要性因子 $p(x_t \mid m)$ 的**加权样本**（注意：不是无权样本）。实现时必须保证拒绝循环可终止。

## 05.5 小结、术语表与书后习题全解

**要点回顾**：

1. 概率运动模型 = 确定性运动学 + 噪声项；速度模型服务规划（事前可得）、里程计模型服务估计（更准、事后可得）（05.1）；
2. 速度模型：圆弧闭式解 (5.4)、六参数噪声、**最终旋转 $\gamma$ 治理二维支撑退化**——不设它，闭式概率几乎处处为零（05.2）；
3. 里程计模型：三段分解（rot1–trans–rot2）、四参数噪声（旋转误差耦合平移）、天然三维支撑；角度归一化是头号实现 bug（05.3）；
4. 地图条件模型 = 终点一致性近似，本质是丢弃路径信息；更新频率是隐形的算法参数（05.4）；
5. 闭式 = 逆模型（EKF 族用），采样 = 前向模型（PF 用）——实现难度与滤波选型直接挂钩。

**术语表（本章新增）**：运动学（kinematics）、构型（configuration）、位姿/位置（pose/location）、运动模型（motion model）、速度运动模型（velocity motion model）、里程计运动模型（odometry motion model）、最终旋转（final rotation）、逆运动模型（inverse motion model）、基于地图的运动模型（map-based motion model）、配置空间（configuration space）、非完整约束（nonholonomic constraints）、三角形分布（triangular distribution）。

**书后习题全解指导**（原书 5.8 节，书 110–111 页）：

**习题 1（一维动力学：单区间后验）**——状态 $(x, \dot x)$，控制加速度 $\ddot u$，噪声 $\ddot u = u + \varepsilon$、$\varepsilon \sim \mathcal{N}(0, \sigma^2)$，$\Delta t$ 内恒定。运动学积分：$\dot x' = \dot x + (u + \varepsilon)\Delta t$，$x' = x + \dot x\Delta t + \frac12 (u + \varepsilon)\Delta t^2$。给定 $(x, \dot x, u)$ 时 $(x', \dot x')$ 是二维高斯：
$$\mu = \begin{pmatrix} x + \dot x\Delta t + \tfrac12 u\Delta t^2 \\ \dot x + u\Delta t \end{pmatrix}, \qquad \Sigma = \sigma^2 \begin{pmatrix} \tfrac14\Delta t^4 & \tfrac12\Delta t^3 \\ \tfrac12\Delta t^3 & \Delta t^2 \end{pmatrix}.$$
**相关吗？相关——且相关系数恰为 1**：$\mathrm{Corr} = \tfrac12\Delta t^3 / \sqrt{\tfrac14\Delta t^4 \cdot \Delta t^2} = 1$。原因：单一区间只有**一个**噪声源 $\varepsilon$，位置误差 = $\tfrac{\Delta t}{2} \times$ 速度误差，二者严格线性相关（协方差秩 1）。

**习题 2（边缘化控制后的后验）**——不告诉你执行了什么加速度（$\ddot u$ 无先验信息、仅知噪声 $\sigma^2$）：$\ddot u + \varepsilon$ 整体 $\sim \mathcal{N}(0, \sigma^2)$，后验同上（均值去掉 $u$ 项）。**值得注意的是：后验退化**——协方差秩 1，$(x', \dot x')$ 被锁在一条直线上 $\dot x' = \dot x + \tfrac{2}{\Delta t}(x' - x - \dot x\Delta t)$：一个未知标量（净加速度）驱动两个输出，知道其一即知另一个。这不是 bug 而是物理：单区间动力学只有一维不确定性。

**习题 3（长时程的相关性极限）**——$T$ 内**每段独立**的随机加速度：速度做随机游走 $\mathrm{Var}(\dot x_T) \sim T\sigma^2\Delta t^2$；位置误差累积速度误差 $\mathrm{Var}(x_T) \sim T^3\sigma^2\Delta t^4/3$；协方差 $\sim T^2\sigma^2\Delta t^3/2$。相关：**是**；但 $T \to \infty$ 时 $\mathrm{Corr} \to \frac{T^2/2}{\sqrt{(T^3/3)\cdot T}} = \frac{\sqrt3}{2} \approx 0.866$——**不是完全相关**，谁也不是谁的确定函数（与第 03 章习题 1(e) 同一极限；单区间的"秩 1 相关"是习题 1–2 的特例，多段独立噪声把秩补回来了）。

**习题 4（自行车运动学模型）**——前轮转向角 $\alpha$、轴距 $l$、前轮速度 $v$。瞬时转动中心（ICC）在后轴延长线上、距后轴 $R = l/\tan\alpha$；后轴速度为 $v\cos\alpha$（沿车架方向）。取位姿为前轮中心 $(x, y, \theta)$：先更新后轴 $(x - l\cos\theta,\ y - l\sin\theta)$ 沿车架前进 $v\cos\alpha\,\Delta t$、航向转过 $\phi = \dfrac{v\sin\alpha}{l}\Delta t$，再换算回前轴：
$$\theta' = \theta + \frac{v\sin\alpha}{l}\Delta t, \qquad x' = x_{\mathrm{rear}}' + l\cos\theta', \qquad y' = y_{\mathrm{rear}}' + l\sin\theta'.$$
噪声：$v + \varepsilon_v$、$\alpha + \varepsilon_\alpha$（独立高斯）。**精确后验无闭式**——噪声穿过 $\sin/\tan$ 非线性，可行做法即 Monte Carlo 采样（习题 5）或一阶泰勒线性化（EKF 式，噪声小时可用）。

**习题 5（自行车采样实现）**——参数 $l = 100$ cm、$\Delta t = 1$ s、$\sigma_\alpha = 25°$、$\sigma_v = 50v$ cm/s（方差随速度缩放）；五组控制 $(\alpha, v)$ = $(25°, 20)$、$(-25°, 20)$、$(25°, 90)$、$(80°, 10)$、$(85°, 90)$ 的采样云：小角度+低速 → 近似圆弧的窄云；大角度 80°+低速 → 极小半径的原地密集转圈云；85°+90 cm/s → 转弯半径小但速度噪声大（$\sigma_v \propto v$），云沿切向拉长。注意 $\alpha$ 噪声经 $\tan$ 放大——大角度下横向散布显著超线性（此现象与 03.3 "局部非线性 × 不确定性"完全同构）。另注：轮径 $d$ 在此运动学模型中**不出现**（ bicycle kinematics 与轮径无关），它是干扰项。

**习题 6（自行车逆问题）**——给定 $(x, y, \theta)$ 与终点位置 $(x', y')$（无 $\theta'$），求最可能的 $(\alpha, v, \theta')$。教程给出**精确闭式**（瞬时转动中心 ICC 双直线交点法，已数值验证）：

1. **ICC 的两条轨迹约束**：自行车做圆弧运动时，ICC 同时 (i) 位于**前轴弦** $(x,y)\text{-}(x',y')$ 的中垂线上（圆心到两端等距），(ii) 位于**初始后轴线**上（过 $(x - l\cos\theta,\ y - l\sin\theta)$、方向 $(-\sin\theta, \cos\theta)$ 的直线——前轮转角再大，ICC 也不离开后轴线）。两条直线相交即得 ICC（平行时退化为直线运动，$\alpha = 0$）；
2. **恢复参数**：记 $R = \pm\|\mathrm{ICC} - \text{后轴起点}\|$（符号取 ICC 在后轴线方向的正负侧），$\alpha = \mathrm{atan2}(l, R)$ 并**归一到 $(-90°, 90°)$**（$\tan$ 周期 180°，$\alpha$ 与 $\alpha \pm 180°$ 给出同一圆——不归一会得到"前轮朝后"的非物理解，本教程数值验证踩过此坑）；前轴回转半径 $R_f = \|\mathrm{ICC} - (x,y)\|$；扫掠角 $\phi = \pm\,2\arcsin\!\big(\tfrac{\|(x'-x,\ y'-y)\|}{2 R_f}\big)$（符号随 ICC 侧向）；于是
$$\theta' = \theta + \phi, \qquad v = \frac{R_f\,|\phi|}{\Delta t}.$$
验证用例：$l = 1$、$\alpha = 25°$、$v = 0.2$、$\Delta t = 1$ 的精确圆弧积分终点，逆解恰返回 $(25.0000°,\ 0.200000,\ 0.084524)$；$\alpha = -25°$ 情形归一后同样精确。

**习题 7（全向机器人速度模型）**——控制三元组（前向 $v_f$、侧向 $v_s$、旋转 $\omega$；左移为正）：(a) 前向模型
$$x' = x + (v_f\cos\theta - v_s\sin\theta)\Delta t, \quad y' = y + (v_f\sin\theta + v_s\cos\theta)\Delta t, \quad \theta' = \theta + \omega\Delta t,$$
各控制独立加噪。(b) 闭式：旋转坐标变换反解 $v_f = \frac{(x'-x)\cos\theta + (y'-y)\sin\theta}{\Delta t}$、$v_s = \frac{-(x'-x)\sin\theta + (y'-y)\cos\theta}{\Delta t}$、$\omega = \frac{\theta' - \theta}{\Delta t}$，三路概率相乘——注意**三控制对三维位姿，无退化**，这是相对差速底盘的建模优势。(c) 采样：加噪后前向积分，与 (a) 逐行对应。

**习题 8（三角形分布的矩与采样）**——记半宽 $h = \sqrt6\,b$，密度 (5.7) 即 $\mathrm{tri}(a) = (h - |a|)/h^2$（$|a| \le h$）。均值：对称性 $\Rightarrow 0$。方差：
$$E[a^2] = 2\int_0^h a^2 \frac{h - a}{h^2}\,da = \frac{2}{h^2}\left[\frac{h a^3}{3} - \frac{a^4}{4}\right]_0^h = \frac{2}{h^2}\cdot\frac{h^4}{12} = \frac{h^2}{6} = b^2.\ \checkmark$$
采样器 $\frac{\sqrt6}{2}[U_1 + U_2]$（$U_i \sim U(-b, b)$ 独立）：$S = U_1 + U_2$ 是 $[-2b, 2b]$ 上的三角分布（卷积），方差 $2 \cdot \frac{b^2}{3}$；缩放 $c = \frac{\sqrt6}{2}$ 后方差 $c^2 \cdot \frac{2b^2}{3} = b^2$ ✓；密度逐段整理恰为 (5.7)（教程已代为核对：$\frac{1}{c}\cdot\frac{2b - |a|/c}{4b^2} = \frac{1}{\sqrt6 b} - \frac{|a|}{6b^2}$）。
