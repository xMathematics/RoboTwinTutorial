# 第 15 章｜部分能观测马尔可夫决策过程

第 14 章把感知不确定性挡在门外（均值后验替身），本章把它请回来——代价是问题性质的根本改变：**状态不可直接观测，决策必须在整个后验分布（置信）上做**。值迭代的形式一字不变地搬进置信空间（$V_T(b) = \gamma\max_u[r(b,u) + \int V_{T-1}(b')p(b' \mid b, u)db']$），但置信空间是 $N{-}1$ 维连续单纯形（哪怕状态只有 2 个）。奇迹在于**有限 POMDP 存在精确解**：值函数是**分段线性凸**的（PWLC）——期望的线性性给了"线性"，max 与"不同区域不同行动"给了"分段凸"——可以用有限组系数向量 $\Gamma = \{(\nu_1, \dots, \nu_N)\}$ 表示。惩罚在于**约束爆炸**：每次备份的线数按测量数的指数倍增长（原书 $T = 20$ 时未修剪 10,547,864 条 vs 修剪后 13 条）。本章沿"精确算法打样 → 复杂度摊牌 → 近似救场"三步走，PBVI（基于点的值迭代）以 1000 倍加速收尾，把 POMDP 从理论拖进机器人的低维实战。

## 15.1 置信空间值迭代：同一递归，换一个宇宙（原书 15.1）

把第 14 章式 (14.14) 的状态 $x$ 换成置信 $b$（原书式 15.2–15.3）：

$$V_T(b) = \gamma\max_u\Big[r(b,u) + \int V_{T-1}(b')\,p(b' \mid b, u)\,db'\Big], \qquad \pi(b) = \arg\max_u[\cdot], \tag{15.1}$$

**三个直接后果**：①报酬对状态取期望 $r(b,u) = \sum_i b(x_i)r(x_i, u)$——线性于 $b$；②置信空间是连续单纯形（$N$ 状态 → $N{-}1$ 维；连续状态 → 无限维）——MDP 的有限值集合变成连续统；③式 (15.1) 要对**分布上的分布**积分——计算上最险的一步。有限 POMDP 的出路：值函数 PWLC，一切在有限组超平面上进行。

## 15.2 两状态算例：全手算与数值复现（原书 15.2）★

**设定**：状态 $\{x_1, x_2\}$；行动 $u_1, u_2$（终点目标，报酬两两相反：$r(x_1,u_1) = -100, r(x_2,u_1) = +100$；$r(x_1,u_2) = +100, r(x_2,u_2) = -50$）；$u_3$ = "感知 + 等待"（花费 $-1$，状态以 0.8 概率翻转）；传感器 0.7/0.3。置信由 $p_1 = b(x_1)$ 参数化。**困境**：状态信息直接决定哪个目标行动是对的——这就是"信息值钱"的最小舞台。

### 15.2.1 第一步：期望报酬与 $V_1$（原书 15.2.2）

$$r(b,u_1) = 100 - 200p_1, \qquad r(b,u_2) = 150p_1 - 50, \qquad r(b,u_3) = -1. \tag{15.2}$$

### 15.2.2 第二步：感知的价值（原书 15.2.3）

若行动前可感知，须对两个测量取期望（原书式 15.23）：$V_1(b) = \sum_z p(z)\,V_1(b \mid z)$，其中后验 $b \mid z$ 的 $p_1' = \frac{p(z \mid x_1)p_1}{p(z \mid b)}$。直接代入会得到**非线性**函数（$p_1'$ 含分母）——但乘回去的技巧救场：$p_1' \cdot p(z \mid b) = p(z \mid x_1)\,p_1$ 是线性的！于是每条线乘 $p(z)$ 后**仍是线**（原书式 15.25–15.26；本教程逐条验算：$z_1$ 分支的 $u_1$ 线 $= 30 - 100p_1$、$u_2$ 线 $= 85p_1 - 15$；$z_2$ 分支 $70 - 100p_1$ 与 $65p_1 - 35$，全对）。两个 max 之和再用"**和-最大 → 最大-和**"技巧展开成 4 条组合线（原书式 15.28），本教程复现的组合系数与书一致：

## 15.3 有限环境 POMDP 算法（原书 15.3）

值函数用**系数向量集合** $\Gamma = \{(\nu_1, \dots, \nu_N)\}$ 表示，每条线（α-向量）定义置信空间上的一个线性函数（原书式 15.35–15.37）：

$$V(b) = \max_{(\nu_1,\dots,\nu_N) \in \Gamma} \sum_{i=1}^N \nu_i p_i. \tag{15.4}$$

程序 15.1 的骨架是**五层嵌套**，逐层看：

```text
Algorithm POMDP(T):
    Γ = {(0, 0, …, 0)}                                   # T=0：零值函数（1 条线）
    for τ = 1 to T:                                      # ① 视界循环
        Γ' = ∅
        for all 旧线 (ν_1,…,ν_N) ∈ Γ:                     # ② 遍历旧线
            for all 行动 u:                               # ③ 遍历行动
                for all 测量 z:                           # ④ 遍历测量
                    for j = 1 to N:                       # ⑤ 线的每个坐标
                        ν'_{τ,u,z,j} = γ Σ_i p(z|x_i) p(x_j|u,x_i) ν_{τ-1,i}    # 行 9：系数更新（式 15.56）
        for all 行动 u:                                    # 组合：跨测量的线相加
            for all 组合 (k(1),…,k(M)) ∈ Γ^M:              # 行 15：K^M 个组合——爆炸的源头
                新线 ν_i = r(x_i,u) + Σ_z ν'_{τ,u,z,k(z),i}
                加入 Γ'
        可选：修剪 Γ'                                       # 行 22
        Γ = Γ'
    return Γ
```

三个读懂它的要点：①**行 9** 是把贝叶斯滤波 $B(b,u,z)$ "塞进旧线"的代数（15.4.3 推导），每支测量把每条旧线映成一条新线；②**行 15** 的组合按"和-最大-和 → 最大-和-和"技巧（15.4.3）展开——每轮的线数从 $|\Gamma|$ 膨胀到 $|\Gamma|^{|Z|}$（乘上行动数），这就是指数爆炸的机制所在；③策略提取（程序 15.2）廉价得出奇：对给定 $b$ 遍历全部线取 argmax，argmax 命中的线所登记的行动即最优行动。

## 15.4 数学推导（原书 15.4 全量展开）

### 15.4.1 化解"分布上的分布"（式 15.38–15.45）

$p(b' \mid u, b)$ 是分布上的分布——但**固定测量 $z$ 后，贝叶斯滤波给出唯一后验**（点质量）：$p(b' \mid u, b) = \int p(b' \mid u, b, z)p(z \mid u, b)dz$（原书式 15.39），其中 $B(b, u, z)$ 恰是第 02 章的贝叶斯滤波更新（原书式 15.42 的归一化形式）。置信上的积分坍缩为**测量上的求和**（有限测量集，原书式 15.48）：

$$V_T(b, u) = r(b,u) + \gamma\sum_z V_{T-1}\big(B(b,u,z)\big)\,p(z \mid u, b), \qquad V_T(b) = \max_u V_T(b, u). \tag{15.3}$$

### 15.4.2 PWLC 表示与归纳保持（式 15.46–15.47）

表示：单线 $V(b) = \sum_i \nu_i p_i$（期望线性性）；PWLC $V(b) = \max_k \sum_i \nu_i^k p_i$（max 保凸、保分段线性、保连续）。归纳的目标：$V_{T-1}$ PWLC ⟹ $V_T$ PWLC。

### 15.4.3 逐式推导：从备份算子到线更新公式（式 15.48–15.61）★

**第一步：有限和备份**（式 15.48–15.49）。测量空间有限时，式 (15.3) 的求和形式：

$$V_T(b,u) = \gamma\Big[r(b,u) + \sum_z V_{T-1}\big(B(b,u,z)\big)\,p(z \mid u,b)\Big], \qquad V_T(b) = \max_u V_T(b,u). \tag{15.5}$$

**第二步：信念更新的逐坐标形式**（式 15.50–15.51）。把式 (15.42) 的积分换成有限和，置信 $B(b,u,z)$ 的第 $j$ 个参数：

$$p'_j = \frac{p(z \mid x_j)\sum_i p(x_j \mid u, x_i)\,p_i}{p(z \mid u, b)}. \tag{15.6}$$

**第三步：旧线在新信念上的取值**（式 15.52–15.54 的整理）。设 $V_{T-1} = \max_k \sum_j \nu_{T-1,j}^k p_j$。在 $B(b,u,z)$ 上取值时代入式 (15.6)——**分母 $p(z \mid u,b)$ 与求和号外的 $p(z \mid u,b)$ 相乘后恰好抵消**（这一步是全部魔法的核心）：

$$V_{T-1}\big(B(b,u,z)\big)\,p(z \mid u,b) = \max_k \sum_j \nu_{T-1,j}^k\, p(z \mid x_j) \sum_i p(x_j \mid u, x_i)\, p_i = \max_k \sum_i p_i \underbrace{\Big[\sum_j \nu_{T-1,j}^k\, p(z \mid x_j)\, p(x_j \mid u, x_i)\Big]}_{\text{新线的第 } i \text{ 个系数}}. \tag{15.7}$$

**线更新公式**（原书式 15.56）：对每个（行动 $u$，测量 $z$，旧线 $k$）三元组，新线的第 $i$ 个系数为

$$\nu^{\prime}_{T,u,z,i} = \gamma \sum_{j} \nu_{T-1,j}^k\; p(z \mid x_j)\; p(x_j \mid u, x_i). \tag{15.8}$$

**教程数值验证**（第 15 章两状态算例，$u_3$ 含状态翻转，旧线取 $r(b,u_1)$ 即 $\nu = (-100, 100)$、$z = z_1$）：式 (15.8) 给 $\nu'_1 = (-100)(0.7)(0.2) + (100)(0.3)(0.8) = 10$，$\nu'_2 = (-100)(0.7)(0.8) + (100)(0.3)(0.2) = -50$；直接计算 $p(z_1 \mid b)\,V_{T-1}(B(b,z_1))$ 在 $p_1 = 1$ 与 $p_1 = 0$ 两点分别得 10.03 与 $-49.97$——逐点吻合 ✓。**坐标约定辨析**：若按"感知先行、转移后行"的次序（15.2 节算例的分解方式——先感知更新、转移留给预测步），转移因子退化为恒等，式 (15.8) 简化为 $\nu'_i = \gamma\,\nu_i\,p(z \mid x_i)$：代入学例数据即 $(\nu_1, \nu_2) = (-100, 100) \to (-70, 30)$——与原书式 (15.25) 的第一条线逐字一致 ✓。两式是同一引理在两种事件次序下的实例。

**第四步："和-最大-和" → "最大-和-和"**（式 15.57–15.60）。备份式 (15.5) 中测量求和作用于 max 的结果，形如 $\max\{a_i\} + \max\{b_j\}$——不是线的 max。组合技巧：

$$\max_i a_i(x) + \max_j b_j(x) = \max_{i,j}\big[a_i(x) + b_j(x)\big], \tag{15.9}$$

（两行证明：右端每个 $a_i + b_j$ 都是左端的下界；而对任意 $x$，取各自的 argmax 对 $i^*(x), j^*(x)$ 即达左端——紧下界。）推广到 $M$ 支测量的和（原书式 15.59）：$\sum_z \max_{k}(\cdot) = \max_{k(z_1),\dots,k(z_M)} \sum_z (\cdot)$。

**第五步：最终形式**（式 15.61）。每个**组合** $\big(k(z_1), \dots, k(z_M)\big)$ 生成一条新线：

$$\nu_{T,u}^{k(1),\dots,k(M)}(x_i) = r(x_i, u) + \sum_{z} \nu^{\prime}_{T,u,z,i}{}^{k(z)}, \qquad V_T(b) = \gamma \max_{u,\,k(1),\dots,k(M)} \sum_i p_i\,\nu_{T,u}^{k(1),\dots,k(M)}(x_i). \tag{15.10}$$

有限线集的 max ⟹ **PWLC 归纳保持** $\blacksquare$。**代价表**：组合数 $|\Gamma|^{|Z|}$——每步备份线数乘 $|\Gamma|^{|Z|}$，原书 $T = 20$ 的 10,547,864 条由此而来。

### 15.5 实际考虑：三把剪刀（原书 15.5）

1. **修剪**（pruning）：被支配的线（处处 $\le$ 某线）对 max 无贡献，安全删除——算例的 4 取 3；
2. **可达性**：值迭代对**全部**置信空间施工，但机器人实际可达的置信往往只是小小一角（两道门的例子：知道第二道门状态后，"第二门已知 + 第一门未知"的置信不可达）；
3. **PBVI（基于点的值迭代）**：只维护典型置信点集 $B$，值函数只保留"至少在一点上恰好取到 max"的线（**约简值函数**）——从源头就不生成无支撑的线。原书图 15.7 的对照触目惊心：$T = 30$ 精确值函数修剪后仍需 **120 条**线（未修剪 10,561,012,337 条），PBVI 仅 **11 条**、快 **1000 倍**，控制性能几乎无差。置信点的选取启发式（POMDP 仿真可达集 + 远隔散布）+ 增量加点 = 任意时间（any-time）算法。**入侵者搜索实验**（22 状态约化 + 粒子滤波追踪投影为直方图）：机器人"先清小房间再扫走廊"的策略利用了"扫描房间时入侵者来不及穿廊"的时序——POMDP 规划真实落地的样板。

$V_2(b) = \max\{$上表 9 条 $+$ 旧三条$\}$。**验证锚点**：组合 **openR｜openL**（听一次、开没听到的那扇门）在 $b = 0.5$ 处恰为 $\mathbf{+4.5}$——与 (c) 的手算闭环期望精确互证 ✓。修剪后存活 5 条：openL、openR、openR｜openL、listen｜openL、openR｜listen（**纯 listen 线被淘汰**——视界延长后"只收集不行动"被"收集一次就行动"支配，这正是 (b) 与 (c) 落差的线空间写照）。(f) $T = 8$ 实现：继续听的条件是**证据保持含混**——左右交替的听觉序列（L,R,L,R,…）使后验在 0.5 附近震荡，开门的期望收益（$10p - 20(1-p)$ 型）仍低于再听一次的信息价值；只有连续同侧听觉把 $p$ 推过决策阈值才开门。实现时务必修剪（线数在 $T=8$ 已数千）。

**习题 2（证明式 15.26 型更新）**——对每条线 $(\nu_1, \nu_2)$：$p(z)V(B(b,u,z)) = \nu_1\,p(z)p'_1 + \nu_2\,p(z)(1-p'_1)$，而 $p(z)p'_1 = p(z \mid x_1)p_1$、$p(z)(1-p'_1) = p(z \mid x_2)(1-p_1)$ 都是 $p_1$ 的线性函数 → 乘积线仍线性，系数恰为 $\nu_1 p(z\mid x_1)$（$p_1$ 侧）与 $\nu_2 p(z \mid x_2)$（常数侧）。代数两行，正是"乘回去"技巧的形式化。

**习题 3（一步备份的最坏复杂度）**——$O\big(|A|\cdot|\Gamma|^{|Z|}\cdot N^2\big)$：对每个行动（$|A|$）与每个旧线组合（$|\Gamma|^{|Z|}$，跨测量叉积）、每条新线的 $N$ 个系数各需一次 $N$ 维内积（$O(N^2)$ 每线，稀疏转移可降）。指数在 $|Z|$ 上——修剪救的是常数与后续步，救不了本次生成的指数叉积（PBVI 从源头救）。

**习题 4（折扣因子）**——与第 14 章式 (14.2) 的 γ 完全相同（几何折扣未来报酬）。PWLC 保持：备份输出 = γ × (线集的 max)——常数乘线性线仍是线性线，max 仍 PWLC；归纳保持 ✓。

**习题 5（无限视界的三个性质）**——折扣无限视界（γ < 1）：**(a) 仍是 PWLC**——Sondik 的经典结果：最优值函数是备份算子的不动点，且可由**有限** α-向量集表示（算子把有限集映到有限集，不动点亦有限——证明走"存在有限表示的不动点"构造路线）；**(b) 连续** ✓（线性函数的逐点最大有限组合连续）；**(c) 凸** ✓（max 保凸，归纳同 15.4.3）。若去掉折扣（总报酬），$V$ 发散问题重现（第 14 章的机器人工资例子在置信空间重演）——反例无需构造，良定义性先丢了。

**习题 6（把 POMDP 装回第 02 章的门）**——设定：状态 $\{$开, 关$\}$；行动 go（终局：开 +10 / 关 −100）、do-nothing（−1）、push（−5，0.8 概率开门）；传感器 0.6/0.4、0.2/0.8（第 02 章原表）。方法：跑 15.2 的两状态值迭代（$T$ 到 10，修剪）。预期策略结构：**低 $p$(开) 区 → push**（花 5 买 80% 的开门概率，兼具"改变世界"与"改善估计"双重身份——它把 $p$(开) 推向 1，与纯信息行动 u3 的区别在此）；**高 $p$(开) 区 → go**；中间带 → do-nothing 收集观测（便宜的信息）。值函数随 $T$ 增长整体上移并在中间带出现感知抬升——第 15.2 节的哲学时刻在第 02 章老朋友身上的重演。此题是全章方法的收官练习：算例、代码结构、修剪全部可直接复用。
