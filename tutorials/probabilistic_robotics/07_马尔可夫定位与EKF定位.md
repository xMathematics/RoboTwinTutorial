## 07.1 定位问题的四维分类（原书 7.1）

**① 问题场景**："定位"不是一个问题而是一族问题——初始信息、环境、控制权、机器人数量都改变难度。选错问题等级的算法会安静地失败。

**② 分类学**（按难度递增）：

| 维度 | 档位 | 关键差异 |
|------|------|----------|
| 初始信息 | **位置跟踪**（position tracking）：初始位姿已知，只需吸收运动噪声 → 误差小、**单峰高斯够用** | **全局定位**（global localization）：初始未知 → 误差无界、需要**多峰**表示 → 包含位置跟踪 | **绑架机器人**（kidnapped robot）：运行中被瞬移——比全局定位更难，因为机器人**相信自己知道在哪**（错误的高置信） |
| 环境 | **静态**：只有机器人在动 | **动态**：人、门、家具持续变化——两种对策：把动态实体增广进状态（计算/建模代价）或滤除动态测量（第 08 章 8.4 节） |
| 控制权 | **被动**：定位只看数据 | **主动**：算法控制机器人以降低不确定性（第 01 章海岸导航、第 17 章系统化；对称走廊里"必须走进房间才能消除歧义"，被动等不如主动找） |
| 数量 | 单机器人 | 多机器人（可互相探测时联合定位更优） |

**③ 绑架问题的真实意义**（原书的洞见）：几乎没有机器人真被绑架，但**最先进的定位算法也不能保证永不失效**——绑架测试度量的正是"从全局定位失效中恢复的能力"，这是真自主性的必要条件。这一档位分类直接决定第 08 章的算法设计（增强 MCL 的随机粒子注入就是为绑架/失效恢复而生）。

## 07.2 马尔可夫定位：贝叶斯滤波换个名字（原书 7.2–7.3）

**马尔可夫定位**（Markov localization）就是程序 2.1 的贝叶斯滤波应用于定位：多传入一个地图 $m$，测量模型变成 $p(z_t \mid x_t, m)$（运动模型也常含 $m$）：

```text
Algorithm Markov_localization( bel(x_{t-1}), u_t, z_t, m ):
    for all x_t do
        bel̄(x_t) = ∫ p(x_t | u_t, x_{t-1}, m) bel(x_{t-1}) dx_{t-1}
        bel(x_t) = η p(z_t | x_t, m) bel̄(x_t)
    return bel(x_t)
```

初始置信按问题档位设定（原书式 7.1–7.3）：位置跟踪用**点质量**（已知 $x_0$）或窄高斯（近似已知，$\mathcal{N}(x_0; \bar x_0, \Sigma_0)$）；全局定位用**合法位姿空间上的均匀分布** $1/|\mathcal{X}|$；部分信息（"在门口开始""在走廊 3 里"）→ 相应区域的非均匀分布。第 01 章图 1.1 的三扇门走廊（此处图 7.4–7.5）就是它的一维演示：均匀 → 见门三峰 → 运动卷积摊平 → 再见门单峰。**表示无关**是马尔可夫定位的要义——高斯（07.3）、栅格（第 08 章）、粒子（第 08 章）都是它的实现。

## 07.3 EKF 定位：算法与完整推导（原书 7.4）

**设定**：基于特征的地图（点路标）；速度运动模型（第 05 章，$\Delta t$ 内恒定 $u_t = (v_t, \omega_t)$）；距离-方位-签名观测（第 06 章）；**一致性已知**（每扇门贴了唯一标签——先解最简单的情形）。

### 07.3.1 预测步：两组不确定性的叠加

运动模型分解为"无噪声部分 + 加性高斯"（原书式 7.6）：$x_t = g(u_t, x_{t-1}) + \mathcal{N}(0, R_t)$，其中 $g$ 就是第 05 章的圆弧方程 (5.4)。EKF 在 $\mu_{t-1}$ 处线性化：

$$\bar\mu_t = g(u_t, \mu_{t-1}), \qquad \bar\Sigma_t = G_t\,\Sigma_{t-1}\,G_t^T + V_t M_t V_t^T. \tag{7.1}$$

三个矩阵（已数值验证）：

$$G_t = \left.\frac{\partial g}{\partial x_{t-1}}\right| = \begin{pmatrix} 1 & 0 & -\frac{v_t}{\omega_t}\cos\mu_\theta + \frac{v_t}{\omega_t}\cos(\mu_\theta + \omega_t\Delta t) \\ 0 & 1 & -\frac{v_t}{\omega_t}\sin\mu_\theta + \frac{v_t}{\omega_t}\sin(\mu_\theta + \omega_t\Delta t) \\ 0 & 0 & 1 \end{pmatrix} \tag{7.2}$$

（位姿雅可比：旧协方差经 $g$ 的切向传播；第三列为航向对各坐标的影响。）

$$M_t = \begin{pmatrix} \alpha_1 v_t^2 + \alpha_2 \omega_t^2 & 0 \\ 0 & \alpha_3 v_t^2 + \alpha_4 \omega_t^2 \end{pmatrix} \quad (\text{控制空间噪声，式 7.10}), \tag{7.3}$$

$$V_t = \left.\frac{\partial g}{\partial u_t}\right| = \begin{pmatrix} \frac{-\sin\mu_\theta + \sin(\mu_\theta + \omega_t\Delta t)}{\omega_t} & \frac{v_t(\sin\mu_\theta - \sin(\mu_\theta + \omega_t\Delta t))}{\omega_t^2} + \frac{v_t\cos(\mu_\theta + \omega_t\Delta t)\,\Delta t}{\omega_t} \\[1mm] \frac{\cos\mu_\theta - \cos(\mu_\theta + \omega_t\Delta t)}{\omega_t} & \frac{v_t(-\cos\mu_\theta + \cos(\mu_\theta + \omega_t\Delta t))}{\omega_t^2} + \frac{v_t\sin(\mu_\theta + \omega_t\Delta t)\,\Delta t}{\omega_t} \\[1mm] 0 & \Delta t \end{pmatrix} \tag{7.4}$$

（控制雅可比：把控制空间的 $M_t$ 映射进状态空间——$R_t = V_t M_t V_t^T$ 与第 05 章采样算法的加噪位置完全一致。）**一个值得注意的细节**：EKF 定位的 $M_t$ 只有 $\alpha_1..\alpha_4$ 四个参数——第 05 章的"最终旋转" $\gamma$ 噪声（$\alpha_5, \alpha_6$）在这里**不需要**：那是治理粒子/闭式密度支撑集退化的装置，而 EKF 的高斯协方差天然满秩，没有退化问题。

原书 AIBO 实验（图 7.8）给出预测不确定性的几何直觉：$G\Sigma G^T$ 分量与噪声参数无关（各图相同的"遗传"椭圆）；$VMV^T$ 分量里，**平移噪声（$\alpha_1$ 大）→ 沿运动方向拉长**，**旋转噪声（$\alpha_4$ 大）→ 垂直运动方向拉长**——弧线运动的误差椭圆形状可以直接从这两个参数读出来。

### 07.3.2 更新步：逐特征的序列修正

对第 $i$ 个观测 $z_t^i = (r_i, \phi_i, s_i)$、对应地标 $j = c_t^i$，测量预测与雅可比（原书式 7.12–7.14；已数值验证）：

$$q = (m_{j,x} - \bar\mu_x)^2 + (m_{j,y} - \bar\mu_y)^2, \qquad \hat z_t^i = \begin{pmatrix} \sqrt{q} \\ \mathrm{atan2}(m_{j,y} - \bar\mu_y,\ m_{j,x} - \bar\mu_x) - \bar\mu_\theta \end{pmatrix}, \tag{7.5}$$

$$H_t^i = \begin{pmatrix} -\dfrac{m_{j,x} - \bar\mu_x}{\sqrt{q}} & -\dfrac{m_{j,y} - \bar\mu_y}{\sqrt{q}} & 0 \\[2mm] \dfrac{m_{j,y} - \bar\mu_y}{q} & -\dfrac{m_{j,x} - \bar\mu_x}{q} & -1 \\ 0 & 0 & 0 \end{pmatrix}, \qquad Q_t = \mathrm{diag}(\sigma_r^2, \sigma_\phi^2, \sigma_s^2). \tag{7.6}$$

（注意 $H$ 的第三列：方位对航向的偏导是 $-1$——转动机器人，所有方位角同步反向；第三行全零：**签名不依赖位姿**，在一致性已知的条件下签名观测对位姿零信息——不意外，但初学者常在此疑惑。）

序列修正（原书程序 7.2 第 9–19 行）：对每个观测依次

$$S_t^i = H_t^i\bar\Sigma_t (H_t^i)^T + Q_t, \qquad K_t^i = \bar\Sigma_t (H_t^i)^T (S_t^i)^{-1}, \qquad \bar\mu_t \leftarrow \bar\mu_t + K_t^i(z_t^i - \hat z_t^i), \qquad \bar\Sigma_t \leftarrow (I - K_t^i H_t^i)\bar\Sigma_t. \tag{7.7}$$

**合法性的代价是纪律**：多特征处理依赖条件独立假设 $p(z_t \mid x_t, c_t, m) = \prod_i p(z_t^i \mid x_t, c_t^i, m)$（原书式 7.16），序列更新等效于"零运动的多次更新"——**每处理一个特征必须立即更新 $\bar\mu$**，否则下一个特征的测量预测用的是旧位姿（原书特别警告这一点，程序 7.2/7.3 均在循环内更新）。

### 07.3.3 测量似然：外点检测的闸门

似然 $p(z_t^i \mid c_t, m, z_{1:t-1}, u_{1:t})$ 对更新本身非必需，但**没有它 EKF 定位是脆弱的**——高斯似然指数衰减，一个外点就能把估计拽飞。推导（原书式 7.17–7.21）：把预测置信 $\overline{\mathrm{bel}}(x) = \mathcal{N}(x; \bar\mu, \bar\Sigma)$ 与线性化测量 $z = h(\bar\mu) + H(x - \bar\mu) + \delta$ 代入积分

$$p(z_t^i \mid \cdot) = \int p(z_t^i \mid x, c_t^i, m)\,\overline{\mathrm{bel}}(x)\,dx. \tag{7.8}$$

这正是第 03 章式 (3.12) 的联合高斯边缘化构造：$x \sim \mathcal{N}(\bar\mu, \bar\Sigma)$，$z = h(\bar\mu) + H(x - \bar\mu) + \delta$ 是它的仿射变换加独立噪声，于是 $z$ 边缘分布为高斯（配平方或直接用矩传播引理）：

$$p(z_t^i \mid c_t, m, z_{1:t-1}, u_{1:t}) = \mathcal{N}\big(z_t^i;\ \hat z_t^i,\ S_t^i\big), \qquad S_t^i = H_t^i \bar\Sigma_t (H_t^i)^T + Q_t. \tag{7.9}$$

——新息的马氏距离即外点分数：$\|z - \hat z\|^2_{S^{-1}}$ 大则拒收（阈值法，原书 7.4.3 末；$\chi^2$ 门限的正式版在第 10 章 EKF SLAM 出场）。

### 07.3.4 程序 7.2 重构（扫描件横排表格，按推导复原）

```text
Algorithm EKF_localization_known_correspondences( μ_{t-1}, Σ_{t-1}, u_t, z_t, m ):
    μ̄  = g(u_t, μ_{t-1})                                  # 式(7.1)左
    G_t = ∂g/∂x |(u_t, μ_{t-1})                            # 式(7.2)
    V_t = ∂g/∂u |(u_t, μ_{t-1})                            # 式(7.4)
    M_t = diag(α₁v²+α₂ω², α₃v²+α₄ω²)                      # 式(7.3)
    Σ̄  = G_t Σ_{t-1} G_tᵀ + V_t M_t V_tᵀ                   # 式(7.1)右
    Q_t = diag(σ_r², σ_φ², σ_s²)
    for all observed features z_t^i = (r, φ, s):
        j = c_t^i
        ẑ = [√q; atan2(m_{j,y}−μ̄_y, m_{j,x}−μ̄_x) − μ̄_θ]    # 式(7.5)，q 同式
        H = 式(7.6)
        S = H Σ̄ Hᵀ + Q_t;   K = Σ̄ Hᵀ S⁻¹
        μ̄ = μ̄ + K (z_t^i − ẑ)                               # 循环内更新！
        Σ̄ = (I − K H) Σ̄
    return μ_t = μ̄,  Σ_t = Σ̄,  P_zt = N(z; ẑ, S)
```

## 07.4 未知一致性：极大似然关联（原书 7.5）

**① 问题场景**：真实地图的地标没有标签——观测到一扇门，它是地图里的哪一扇？**极大似然一致性**（maximum likelihood correspondence）：每个观测先独立选"最可能的地标"，然后**当作正确**喂给 EKF。这是最简单也最常用的策略（原书程序 7.3：对每个观测遍历地标 $k$，算 $\hat z, H, S$ 与似然，取 argmax 后走标准更新；工程上用"把观测投影到 $x\text{-}y$ 粗筛候选"加速几个数量级）。

**② 推导**（原书式 7.22–7.23）：目标是联合一致性向量的 ML

$$\hat c_t = \arg\max_{c_t} p(z_t \mid c_t, m, z_{1:t-1}, u_{1:t}), \tag{7.10}$$

候选数随观测数**指数增长**；条件独立假设 (7.16) 把它分解为逐特征的独立优化：

$$\hat c_t^i = \arg\max_{c_t^i} \mathcal{N}\big(z_t^i;\ h(\bar\mu, c_t^i, m),\ H_t\bar\Sigma_t H_t^T + Q_t\big), \tag{7.11}$$

——每个因子各自取最大即联合最大，指数搜索坍缩为线性。

**③ 脆弱性论证**（原书明示的两大后果）：(7.10) 以**先验一致性 $c_{1:t-1}$ 为条件**且把它们当真——这换来递归可计算，代价是**错误无法恢复**：一次错关联 → 估计被拽偏 → 下次关联更可能错（位姿错 → 马氏距离排序错）→ 发散。两条设计缓解：①选**相互独特且相距远**的地标；②**保持位姿不确定性小**。原书点破这对矛盾：独特而稀疏的地标意味着机器人经常看不见任何地标 → 不确定性膨胀 → 关联更易出错。地标的"密度-独特性"权衡是高斯定位系统的核心设计艺术（07.6）。

## 07.5 多假设跟踪 MHT：为关联错误买保险（原书 7.6）

**① 问题场景**：ML 关联只有一张票。当多个假设都合理（对称环境、初始不确定大）时，需要**并行保留多张票**。

**② 解决方法**：置信改用高斯混合（原书式 7.24）

$$\mathrm{bel}(x_t) = \sum_l w_{t,l}\,\mathcal{N}(x_t; \mu_{t,l}, \Sigma_{t,l}), \qquad \text{每个分量（"路线"track）绑定一条关联决策序列 } C_{1:t,l} \tag{7.12}$$

（分量 = 以特定关联历史为条件的局部置信 $\mathrm{bel}_l(x_t) = p(x_t \mid z_{1:t}, u_{1:t}, C_{1:t,l})$，原书式 7.25。）**理想算法**简单到一句话：每个旧分量按所有可能的关联向量分裂，新分量权重 = 旧权重 × 该关联下的测量似然（原书式 7.26，似然由 07.3.3 的式 (7.9) 直接给）——这是"关联为隐变量"的全贝叶斯实现。**缺陷**：分量数随时间指数爆炸。**MHT 的近似**：**剪枝**（pruning）——权重占比

$$\frac{w_{t,l}}{\max_m w_{t,m}} < \psi_{\min} \tag{7.13}$$

的分量终止（原书式 7.27），保住 $\psi_{\min}$ 量级的分量数。MHT 对关联错误比 EKF 鲁棒（错的假设只是权重衰减而非全局污染），代价是计算与实现复杂度；它同样受线性化近似影响（每个分量内部还是 EKF，也可换成 UKF）。第 03 章 03.3 的"多假设 EKF（高斯混合）"在此获得具体语义：**混合分量的分裂/剪枝 = 数据关联假设的生灭**。

## 07.6 UKF 定位：增广状态的 σ 点（原书 7.7）

**① 问题场景**：程序 3.4 的 UKF 把噪声协方差 $R, Q$ 在变换后**外加**——但噪声其实穿过非线性 $g, h$，外加是近似。定位场景能不能更精确？

**② 解决方法——增广状态**（原书程序 7.4，本扫描件完整可读）：把控制噪声与测量噪声作为**状态分量**并入 σ 点表示。维数 $L = 3 + 2 + 2 = 7$（位姿 3 + 控制 2 + 测量 2），增广高斯

$$\tilde\mu_{t-1} = (\mu_{t-1}^T,\ \mathbf{0}^T,\ \mathbf{0}^T)^T, \qquad \tilde\Sigma_{t-1} = \mathrm{blockdiag}(\Sigma_{t-1},\ M_t,\ Q_t), \tag{7.14}$$

取 $2L + 1 = 15$ 个 σ 点（原书式 7.28：每点含位姿/控制/测量三段），然后：

- 预测：$\bar X_t = g(u_t + X^u,\ x + X^x)$——**控制噪声分量被真正推过非线性 $g$**；矩匹配得 $\bar\mu, \bar\Sigma$；
- 测量：$\hat Z_t = h(\bar X^x) + X^z$——**测量噪声分量被推过 $h$**；得 $\hat z$、新息协方差 $S$、**互协方差** $\bar\Sigma^{xz}$；
- 更新：$K = \bar\Sigma^{xz} S^{-1}$，$\mu = \bar\mu + K(z - \hat z)$，$\Sigma = \bar\Sigma - K S K^T$。

**与 EKF 的两处微妙差别**（原书图 7.16 的实验要点）：①EKF 预测均值**恰好落在控制预测的位置**（$g(u, \mu_{t-1})$），UKF 均值是 σ 点的加权平均——非线性下两者不同，UKF 更贴近采样参考；②大不确定性实验（宽先验走圆弧）中 UKF 的协方差与 50 万级采样参考几乎重合，EKF 明显失真。**经验法则**（原书 7.8）：方位角标准差超过约 **5°** 时，线性化对 EKF 与 UKF 都可能失效——但实践中 UKF 的失效远比 EKF 温和。图 7.15 的三方对比（粒子滤波作参考解）：EKF 与 UKF 都贴近参考，UKF 稍近。

## 07.7 高斯定位的边界（原书 7.8）

原书 7.8 节的清单值得整段消化，本教程归纳为"五宗罪与四味药"：

**高斯表示的五条结构性限制**：①线性化只在展开点附近好（5° 法则）；②单峰——全局定位需多假设初始化（首次测量生成假设）或 MHT；③绑架问题需额外"假设槽位"（混合状态：一个分量专门表示"在哪都不知道"）；④硬空间约束（不可穿越区域）难编码，只能多高斯近似；⑤**负信息**（negative information）无法处理——"没看到本该看到的地标"是强证据（在巴黎没看到埃菲尔铁塔 → 你不在它附近），但它造成非高斯置信；EKF/UKF 直接忽略，MHT 可以用"衰减未见地标的分量权重"部分吸收。

**四味药**：高效候选搜索（投影粗筛）；**互斥**（mutual exclusion——同一图像抽出的两个特征不允许关联到同一地标，否则违反独立性假设的基础前提）；多特征优于少特征（但需互斥）；MHT（关联鲁棒性 ↑，计算 ↑）。

**一句话总结本章成败观**（原书原话精神）：高斯滤波对违反线性假设惊人地鲁棒，**成功定位的关键不在滤波器，而在成功的数据关联**——这句话是第 10 章 EKF SLAM、第 12 章 SEIF 数据关联剧情的预告。

## 07.8 小结、术语表与书后习题全解

**要点回顾**：

1. 定位四维分类（初始信息/环境/控制权/数量）；绑架问题 = 测"从失效中恢复"（07.1）；
2. 马尔可夫定位 = 贝叶斯滤波 + 地图，表示无关；初始化分布对应问题档位（07.2）；
3. EKF 定位：预测 $\bar\Sigma = G\Sigma G^T + VMV^T$（$M_t$ 只需 $\alpha_1..\alpha_4$，无 $\gamma$ 退化问题）；更新逐特征序列进行且**循环内必须更新 $\bar\mu$**；测量似然 $\mathcal{N}(z; \hat z, S)$ 由线性高斯边缘化一步得到，是外点闸门（07.3）；
4. ML 关联 = 逐特征 argmax + 当真使用；条件独立把指数搜索分解为线性；脆弱性来自"过去的关联永远正确"假设（07.4）；
5. MHT = 关联假设的并行谱系 + 按权重剪枝；UKF 定位 = 增广状态把噪声推过非线性（07.5–07.6）；
6. 负信息与硬约束是高斯表示的死角；成功定位的关键是数据关联（07.7）。

**术语表（本章新增）**：位置跟踪（position tracking）、全局定位（global localization）、绑架机器人问题（kidnapped robot problem）、马尔可夫定位（Markov localization）、EKF 定位（EKF localization）、极大似然一致性（maximum likelihood correspondence）、多假设跟踪（MHT / multi-hypothesis tracking）、路线（track）、混合权重（mixture weight）、剪枝（pruning）、互斥（mutual exclusion）、负信息（negative information）、增广状态（augmented state）、无迹卡尔曼滤波定位（UKF localization）。

**书后习题全解指导**（原书 7.11 节，书 176–178 页）：

**习题 1（全局定位需要几个地标才"高斯得起来"）**——(a) 单个距离-方位观测的位姿后验是**环/螺旋**（第 06 章图 6.13：距离给圆、方位砍一半自由度、绕角 $\gamma$ 均匀）——本质上非高斯，任何 $(\mu, \Sigma)$ 都失真。两个同步观测：两个圆相交至多两点、方位约束进一步砍——后验坍缩为**少数几个紧致团**，取权重最大者即被单个高斯很好地近似（多假设情形交给 MHT/混合高斯）。几何直觉：**每个观测是二维流形约束，三维位姿需要至少两个约束流形相交才能"团化"**。(b) 程序设计（均匀先验 + $K$ 个同步观测 → 高斯位姿估计）：①初始化——用第 06 章程序 6.5 的采样器从单观测后验撒 $M$ 个位姿样本，按其余 $K-1$ 个观测的似然加权（重要性加权，即用 07 章式 (7.9) 型似然打分）；②精化——对加权样本做**加权高斯矩匹配**得 $(\mu_0, \Sigma_0)$；③迭代精化（Gauss–Newton 两三步）——在线性化点处构造 $H_i$（式 7.6），解加权最小二乘 $\mu \leftarrow \mu + \big(\sum_i H_i^T Q^{-1} H_i\big)^{-1} \sum_i H_i^T Q^{-1}(z_i - \hat z_i)$；④输出 $\Sigma = \big(\sum_i H_i^T Q^{-1} H_i\big)^{-1}$。本习题是"采样初始化 + 线性化精化"混合范式的迷你预演——第 13 章 FastSLAM 2.0 的改进建议分布用的正是同一思路。

**习题 2（为全局定位设计最刁钻的环境）**——$n$ 条不相交线段 + 360 个**无误差**测距仪：一个后验模式 = 一组与扫描完全一致的位姿。结构化论证：把观测扫描"指派"给 $n$ 条线段的方式至多 $n!$ 种（每条被观测线段可扮演任意一条地图线段的角色），每种自洽指派生成至多一个位姿，故模式数 $\le n!$（$n = 3..8$ 时分别为 6, 24, 120, 720, 5040, 40320；构造最坏情形的思路：把 $n$ 条线段摆成旋转对称的等边多边形链，任意旋转重排都产生合法指派）。(b) 传感器**可出错**时指派不再受"完全一致"约束——被噪声"解释"的错位指派也能拿高似然，模式数可**超过** $n!$（构造：$n = 4$ 的方形房间 + 让扫描恰好等于"相邻边互换"后的形状的噪声扫描，则 $4! = 24$ 之外又多出一批近似匹配峰）。本题是"环境对称性 = 数据关联歧义"的定量演练，反向印证 07.4 的脆弱性论证。

**习题 3（水下机器人 EKF：纯距离信标）**——状态 $(x, y, z)$（方向由完美罗盘给定，不必估计）；控制 = 三轴设定速率 $\dot u_t = (\dot x, \dot y, \dot z)$，独立高斯噪声。**运动模型**（线性！无需求导）：$x_t = x_{t-1} + \dot u_t \Delta t + \varepsilon$，$A = I$，$B = \Delta t\, I$，$R = \Delta t^2\,\mathrm{diag}(\sigma_x^2, \sigma_y^2, \sigma_z^2)$。**测量模型**：信标声学信号 + 精确时钟 → 纯距离 $z_j = \|x - m_j\| + \delta$（到达时间 × 声速；发射时刻已知故无钟差项；身份已知故无关联问题）。预测：$\bar\mu = \mu + \dot u\Delta t$，$\bar\Sigma = \Sigma + R$。更新（对每个信标）：$\hat z_j = \|\bar\mu - m_j\|$，**雅可比是单位方向向量**
$$H_j = \frac{(\bar\mu - m_j)^T}{\|\bar\mu - m_j\|} \quad (1 \times 3), \qquad S_j = H_j \bar\Sigma H_j^T + \sigma_j^2, \quad K = \bar\Sigma H_j^T / S_j.$$
(b) 仿真研究的预期失效模式：**全局定位**——单信标等距面是球面，一次观测后验是球壳，EKF 高斯无法表示（观测前先要有合理初始）；两信标 → 圆；三信标 → 两点 → 可高斯化（对应习题 1 的三维版）。**位置跟踪**——工作良好，秩 1 的 $H$ 每次只收缩一个方向，需多信标轮流观测。**绑架**——EKF 无恢复能力（错误高置信吸住错误估计），须重启或引入多假设。此习题把本章全部概念移植到最小新场景，强烈建议实现（约 80 行 numpy）。

**习题 4–5（栅格环境开环定位策略）**——六幅环境图扫描件无法辨认，给方法与判据：状态 = 置信集（所有与"撞墙计数"一致的起始位姿），动作 = {L, R, M}。**开环规划 = 在置信集上做前向模拟**：执行动作序列，用"每次 M 的撞墙次数"更新一致集；序列可行当且仅当终态一致集坍缩到单一等价类（朝向可能仍歧义——位置"可预测"即可）。求解即对动作序列做 BFS（一致集状态空间有限）。习题 5 加步数感知后：M 的位移量可测 → 每步 M 都是一次"距离测量"，单步 M 在一般环境中已能定位（自由距离 = 起点行/列的函数；对称环境中仍需补一步转向破坏对称）。这两题本质是**置信空间规划**的最小实例——第 15 章 POMDP 与第 17 章主动定位的离散热身。
