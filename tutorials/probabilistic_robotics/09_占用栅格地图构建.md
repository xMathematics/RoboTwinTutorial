# 第 09 章｜占用栅格地图构建

第 07–08 章的定位都以"地图已知"为前提。本章问反问题：**位姿已知时，地图怎么从带噪声的测量里长出来**（mapping with known poses）。它看似是 SLAM 的"阉割版"，实则是 SLAM 的**后处理标配**——第 10–13 章的 SLAM 算法估计的是路标/轨迹，真正用于导航的稠密地图几乎都由本章的算法在 SLAM 给出的路径上重建（原书原话："没有哪个机器人里程计是完美的！占用栅格技术的主要功用在于后处理过程"）。本章三幕：**标准算法**（全地图后验因式分解成每格一个静态二值贝叶斯滤波——第 04 章 4.2 节的直接变现，log-odds 增量式）；**反演测量模型的系统化构建**（从"手写启发式"升级到"从正演模型采样 + 监督学习"，交叉熵损失完整推导）；**MAP 建图**（直面因式分解丢弃格子间依赖性的病灶，用正演模型 + 爬山法求全地图后验的众数——它能救回标准算法必丢的"敞开的门"）。

> 原书锚点：第 9 章，书 213–234 页（PDF 231–252 页）。式 (9.20)–(9.25) 的 MAP 分解与习题 1 的衰减滤波推导本章全量展开；习题 4/5 的数值已精确验算。

## 09.1 为什么"位姿已知"仍值得一章（原书 9.1）

**建图难在哪**：①**假设空间爆炸**——万格地图有 $2^{10000}$ 种可能，全地图后验 $p(m \mid z_{1:t}, x_{1:t})$ 逐点计算不可想象（这是贝叶斯滤波在定位上好用、在整图建图上"太稚嫩"的原因）；②**鸡生蛋**——建图需要位姿、定位需要地图，两件事纠缠即 SLAM（第 10–13 章）；难度还随**规模、噪声、感知模糊性、环形结构**（回环时里程计误差已积重难返）四因子增长。图 9.1 的对照一目了然：原始里程计激光点是团乱麻，建图算法给出整洁地图——且**把数据采集期间的行人滤掉了**。

**"神告知路径"的实用主义**：本章假设位姿精确已知，产出（概率化的、噪声滤除的、可导航的占用地图）正是后续 SLAM 章节估计出路径后的标准 downstream。

## 09.2 标准算法：把整图问题赌成分格独立（原书 9.2）

**① 赌注**：全地图后验 $p(m \mid z_{1:t}, x_{1:t})$（原书式 9.1）无法算，标准占用建图将其**因式分解为逐格边缘的乘积**（原书式 9.4）：

$$p(m \mid z_{1:t}, x_{1:t}) \approx \prod_i p(m_i \mid z_{1:t}, x_{1:t}). \tag{9.1}$$

每个 $m_i \in \{0, 1\}$ 的估计是**静态二值估计问题**——第 04 章程序 4.2 的二值贝叶斯滤波直接上任。代价即刻可见：格子间相关性（同一束测量扫过一片格子，它们显然不独立）被丢弃——这个赌注的账单在 09.4 结算。

**② log-odds 增量算法**（原书程序 9.1）：置信以对数几率存储（原书式 9.5，$l_{t,i} = \log\frac{p(m_i \mid \cdot)}{1 - p(m_i \mid \cdot)}$，sigmoid 反变换恢复概率，原书式 9.6）：

```text
Algorithm occupancy_grid_mapping( {l_{t-1,i}}, x_t, z_t ):
    for all cells m_i:
        if m_i 在 z_t 的感知域内:
            l_{t,i} = l_{t-1,i} + inverse_sensor_model(m_i, x_t, z_t) − l_0
        else:
            l_{t,i} = l_{t-1,i}          # 感知域外一字不动（省算力的关键行）
    return {l_{t,i}}
```

$l_0$ 是先验 log-odds（原书式 9.7，无信息时 $p(m_i) = 0.5 \Leftrightarrow l_0 = 0$）。**这一行 $\,- l_0$ 就是第 04 章 4.2 节反复强调的"先验只入账一次"**：反演模型内部含一次先验，不減则同一先验被每帧重复计入，log-odds 随时间无界漂移——实现中最常见的 bug（第 02 章习题 1、第 04 章 04.2 已两次埋线，此处收网）。

**③ 反演测量模型的最简实现**（原书程序 9.2）：对格子中心算极坐标 $(r, \phi)$，选最近束 $k$，三分支：

| 条件 | 返回 | 语义 |
|------|------|------|
| $r > \min(z_{\max},\, z_t^k + \alpha/2)$ 或 $|\phi - \theta_{k,\mathrm{sens}}| > \beta/2$ | $l_0$ | 视野之外 → 无证据 |
| $z_t^k < z_{\max}$ 且 $|r - z_t^k| < \alpha/2$ | $l_{\mathrm{occ}} > l_0$ | 命中带 → 占用证据 |
| $r \le z_t^k$ | $l_{\mathrm{free}} < l_0$ | 光路穿过 → 空闲证据 |

（$\alpha$ = 障碍物厚度参数、$\beta$ = 束宽；典型取值如 $l_{\mathrm{occ}} \approx +0.85$、$l_{\mathrm{free}} \approx -0.4$——占用证据比空闲证据"话语权"更大是工程惯例，防止幽灵空洞。）**两个工程增补**（原书明示）：①反演模型可在束边缘做得更精细（简单版在锥边"脆弱"）；②把**机器人自身足迹当作强负证据**（$x_t$ 周围格子返回大负数）——地图要能导航，机器人占的地方必须标空，人多的环境尤其有用。

**④ 多传感器融合**（原书 9.2.1）：把不同传感器的束都灌进**同一**格子滤波，看似自然，实则有毒——若障碍物 A 只对声呐可见、B 只对立体视觉可见，两类证据互相"投票"，格子是否占用竟取决于两类传感器**报告次数的比例**（荒谬）。原则做法：**每种传感器各自建图** $m^k$，再融合——测量独立时用德·摩根（噪声或 noisy-OR，原书式 9.9）：$p(m_i) = 1 - \prod_k (1 - p(m_i^k))$（任何一种传感器说占就倾向占，悲观融合）；或直接取最大（原书式 9.10）。

## 09.3 反演模型的系统化：从正演模型采样 + 监督学习（原书 9.3）

**① "反演"辨析**（原书 9.3.1，术语病灶再次出现）：$p(m_i \mid x, z)$ 之所以叫"反演"，是因为**由果推因**（由测量推环境）——与定位中"由因到果"的 $p(z \mid x, m)$ 方向相反。**它不是前向模型的数学逆**：由贝叶斯准则（原书式 9.11，附"位姿不提供地图信息"的 $p(m \mid x) = p(m)$ 简化）

$$p(m \mid x, z) = \eta\, p(z \mid x, m)\, p(m),$$

真正的障碍在逐格边缘化（原书式 9.12）——要对**所有地图**求和，不可计算。于是走学习路线。

**② 从正演模型造训练集**（原书 9.3.2）：正演模型 $p(z \mid x, m)$ 是可采样的（机器人仿真器即此物），四步造样本——采地图 $m \sim p(m)$（地图数据库）→ 均匀采位姿 $x$ → 采测量 $z \sim p(z \mid x, m)$ → 从 $m$ 抠出格子真值 $\mathrm{occ}(m_i)$；得训练三元组 $\{(\text{输入 } (x, z)\text{ 的编码}) \to \mathrm{occ}(m_i)\}$，用逻辑回归/神经网络拟合 $p(m_i \mid z, x)$。**四条不变性必须喂给模型**（原书的特征工程清单，每条都在砍假设空间）：①视野外格子无信息 → 只训练感知锥内格子、输入只放局部测量窗口；②传感器特性与绝对坐标无关 → 输入用**相对极坐标**（格子相对位姿的距离与角度，经旋转矩阵变换）；③邻近格子解读相似 → 一个共享函数而非逐格函数（平滑性）；④同型号传感器可交换 → 环阵共用一个模型。

**③ 交叉熵损失**（原书 9.3.3 推导展开）：参数 $W$、网络输出 $f(\mathrm{input}, W) \in [0, 1]$，按伯努利写出（原书式 9.17 的"指数选择"技巧——$m^{[k]} = 1$ 时第一项存活、第二项指数为 0，反之亦然）：

$$p(m^{[k]} \mid \mathrm{input}^{[k]}, W) = f^{m^{[k]}} (1 - f)^{1 - m^{[k]}} \ \Longrightarrow\ J(W) = -\sum_k \Big[ m^{[k]} \log f + (1 - m^{[k]}) \log (1 - f) \Big]. \tag{9.2}$$

即训练数据的负对数似然——现代术语的**交叉熵**，梯度下降可训。原书图 9.9 的超声波实例显示学到的模型连"单帧错误短读数"都处理得当（一个读数不足以断言障碍）。**升级路线**（原书 9.3.4）：训练数据不必来自仿真——在**已知地图**环境里跑马尔可夫定位，用真实记录数据 + 真实占用作训练对（真实数据优于仿真，因为正演模型本身就是近似）；甚至可以"用近似地图 → 学更好的模型 → 建更好的地图"迭代自举。

## 09.4 赌账清算：依赖性病灶与 MAP 建图（原书 9.4）

**① 因式分解何时错得离谱**（原书 9.4.1，图 9.10 是全书最直观的失败案例之一）：机器人面对一堵墙，收两束**无噪声**声呐。逐格算法把每束解读为"整条弧上都有障碍"（每格独立加占用证据），两弧重叠区证据冲突，只能靠正负证据的**次数对冲**勉强平账。而正确的解读只需"**障碍在锥内某一处**"（somewhere）——这是一个跨格子的联合约束，恰恰是式 (9.1) 丢掉的东西。

**② MAP 建图：不求后验、只求众数**（原书 9.4.2）。全后验仍不可算，但它的**对数最大值点**可以优化：

$$m^* = \arg\max_m \log p(m \mid z_{1:t}, x_{1:t}) = \arg\max_m \Big[ \underbrace{\sum_t \log p(z_t \mid x_t, m)}_{\text{正演模型！}} + \underbrace{l_0 \sum_i m_i}_{\text{先验}} \Big] \tag{9.3}$$

（推导链，原书式 9.21–9.25 全展开：贝叶斯 + 测量条件独立 → 似然对数按时间求和；先验按伯努利连乘分解 $\log p(m) = \text{const} + \sum_i m_i l_0$——$(1-p(m))^N$ 整体归入常数。）**注意立场的反转**：标准算法用反演模型 $p(m_i \mid z, x)$，MAP 用的是**真正的正演模型** $p(z \mid x, m)$——依赖性信息被保留了（一束测量是"锥内 somewhere 有障碍"的联合陈述）。优化用**坐标爬山**（原书程序 9.3）：反复对每格在 $\{0, 1\}$ 上取 argmax 直至收敛。

**③ 特性与局限**（原书明示清单）：先验 $p(m_i)$ 不可太接近 1（否则退化为全占用图）；爬山只保局部最优（实践中山头很少）；**批处理算法**（全数据在内存、无法增量——与标准算法的在线性互换了优劣势）；残余不确定性用**灵敏度分析**近似（逐格扰动看对数似然变化，原书也承认它偏乐观）。**图 9.11 的实战对比是本章高潮**：机器人经过一扇敞开的门，部分束打在门柱、部分束穿过门洞——标准算法把门洞"糊"上（每束独立投票），MAP 建图正确保留敞开的门（"somewhere" 联合解释无冲突）。**效率注脚**：每次更新格子 $m_i$ 只涉及涉它的少数测量——爬山内层不用遍历全部数据。

## 09.5 小结、术语表与书后习题全解

**要点回顾**：

1. 占用建图 = SLAM 的后处理；全地图后验不可算 → 因式分解为逐格静态二值估计（赌注）（09.2）；
2. log-odds 增量 $l_t = l_{t-1} + \mathrm{inverse} - l_0$；$\,-l_0$ 是"先验只入账一次"；感知域外一格不动；多传感器**分图再融**（noisy-OR/max），别混灌一个滤波器（09.2）；
3. 反演模型 ≠ 数学逆；系统化构建 = 正演模型采样 + 监督学习（交叉熵损失 9.2），不变性特征工程是灵魂（09.3）；
4. 因式分解的病灶 = 丢弃"锥内 somewhere"联合约束 → MAP 建图用正演模型 + 爬山，救回敞开的门；代价是批处理（09.4）。

**术语表（本章新增）**：位姿已知的建图（mapping with known poses）、占用栅格地图（occupancy grid map）、反演测量模型（inverse measurement model）、正演模型（forward model）、log-odds 占用值、噪声或融合（noisy-OR）、德·摩根融合、交叉熵损失（cross-entropy loss）、灵敏度分析（sensitivity analysis）、爬山法（hill climbing）、指数衰减（exponential decay）。

**书后习题全解指导**（原书 9.7 节，书 232–234 页）：

**习题 1（指数衰减：把"静态"假设拆掉）**——让格子占用可随时间漂移：对称二值转移 $p(m_t{=}1 \mid m_{t-1}{=}1) = p$、$p(m_t{=}1 \mid m_{t-1}{=}0) = 1 - p$（先验 0.5）。**精确算法**：在第 04 章静态二值滤波前插一个预测步，log-odds 形式为
$$\bar l_t = \log\!\big[p\,e^{l_{t-1}} + (1-p)\big] - \log\!\big[(1-p)\,e^{l_{t-1}} + p\big], \qquad l_t = \bar l_t + \mathrm{inverse} - l_0.$$
（把 $\pi = e^l/(1+e^l)$ 代入 $P(m_t{=}1) = p\pi + (1-p)(1-\pi)$ 再取 odds 的对数。）**乘性规则的来历**：在 $l = 0$ 处泰勒展开，$\bar l_t \approx (2p - 1)\, l_{t-1}$——题目要的指数衰减 $l_t \approx \alpha\, l_{t-1} + \mathrm{inverse} - l_0$ 正是**小信号线性化**，衰减因子 $\alpha = 2p - 1$（$\alpha = 0.99 \Leftrightarrow p = 0.995$）。**近似何时失效**：$|l|$ 大时精确解**饱和**于 $\pm\log\frac{p}{1-p}$（$p = 0.995$ 时 $\approx \pm 5.3$）——旧证据不会衰减到零，只是被压向与信道可靠性相称的上限；乘性规则则会无限遗忘。这是"正确性证明"该给出的边界条件。

**习题 2（伯努利参数的 ML 估计器 vs 二值贝叶斯滤波）**——序列 0,0,1,0,1,1,1,0,1,0 含 5 个 1：$\hat p_{\mathrm{ML}} = 0.5$。增量公式（运行均值）：
$$\hat p_t = \hat p_{t-1} + \frac{z_t - \hat p_{t-1}}{t}.$$
**与二值贝叶斯滤波的本质区别**：ML 估计器估计的是**传感器模型的参数** $p(z = 1 \mid m)$（发出 1 的倾向），无先验、无状态后验、答案可以是任意 $[0,1]$；二值贝叶斯滤波估计的是**状态后验** $p(m \mid z_{1:t})$，先验与似然经贝叶斯准则合成、答案被拉向 0/1。一个在学"传感器"，一个在猜"世界"。

**习题 3（低矮障碍：反演模型的盲区）**——(a) 水平声呐锥打在比传感器低 15 cm 的障碍上：近掠射角 → 镜面反射把回波送走 → 探测失败、报 $z_{\max}$（与第 06 章 $p_{\max}$ 分量的物理来源一致）；只有障碍恰在近处且锥的下边缘（半锥角内）勉强擦到其顶面时才可能检测。(b) 后果链：$z_{\max}$ 读数被反演模型解读为"整束光路空闲" → 低矮障碍所在格子持续累积 $l_{\mathrm{free}}$ → 地图 confidently 错误 → 机器人撞上去。马尔可夫层面：测量真值依赖未建模变量（障碍高度），静态假设被违反——02.5 的"未建模动态/结构"破坏者。(c) 改进：三分类地图（占用/空闲/**未知**，第 06 章似然域扩展的同款思路）——把"低于传感器高度带"的格子的 $l_{\mathrm{free}}$ 证据钳制为接近 0；或俯视/斜视传感器补盲区；或机器人足迹负证据的推广（"我的身体没撞到 = 该处空闲"这类主动验证）。

**习题 4（ML 测量模型）**——占用单元序列 1101011、0111001 合并 14 个读数含 9 个 1；空闲单元 0001000、1001000 含 3 个 1：
$$p(z = 1 \mid m = \mathrm{occ}) = \tfrac{9}{14} \approx 0.643, \qquad p(z = 1 \mid m = \mathrm{free}) = \tfrac{3}{14} \approx 0.214.$$
（ML = 分组计数比例；每单元各自的 ML 会是 5/7、4/7、1/7、2/7——合并是对的，因为模型假设同一 $m$ 值共享同一发射概率。）

**习题 5（跑一遍占用算法 + 调参）**——(a) 先验 0.5 → 先验 odds 1，逐读数乘似然比 $L = \frac{p(z=1 \mid \mathrm{occ})/p(z=0 \mid \mathrm{occ})}{p(z=1 \mid \mathrm{free})/p(z=0 \mid \mathrm{free})} = \frac{9/5}{3/11} = 6.6$：单元后验（本教程验算）：unit1 $(n_1{=}5, n_0{=}2)$：odds $= 6.6^3 = 287.5$ → **0.9965**；unit2 $(4, 3)$：odds $= 6.6$ → **0.868**；unit3 $(1, 6)$：odds $= 6.6^{-5}$ → **0.0001**；unit4 $(2, 5)$：odds $= 6.6^{-3}$ → **0.0035**。(b) 与真值（occ, occ, free, free）对照：方向全对但 unit2 的置信（0.868）远低于 unit1（0.9965）——**相同真值的两个单元因读数随机性得到悬殊后验**。调参方向：把 $p(z{=}1 \mid m)$ 的两组值推离中间值（更尖的传感器，如 0.9/0.1）会放大组间对比、让后验更快饱和，但也放大单次错误读数的破坏——"贴近度"可选 $\sum_i |p(m_i \mid z) - \mathbb{1}(\text{真值})|$，最优传感器强度在"收敛速度"与"单错鲁棒"间权衡（此题的深意：**传感器越尖不一定地图越好**，与第 08 章"膨胀噪声"的教训同源）。

**习题 6（概率形式 vs 对数形式）**——(a) 概率形式的更新就是 odds 的乘法链（第 04 章式 4.8 不取对数）：
$$\frac{p_t}{1 - p_t} = \frac{p_{t-1}}{1 - p_{t-1}} \cdot \frac{p(m_i \mid z_t, x_t)}{1 - p(m_i \mid z_t, x_t)} \Big/ \frac{p(m_i)}{1 - p(m_i)},$$
或等价地 $p_t = \dfrac{p_{t-1}\,L_t}{1 - p_{t-1} + p_{t-1}\,L_t}$，其中 $L_t = \frac{p(z_t \mid \mathrm{occ})/p(z_t \mid \mathrm{free})}{\text{先验比}}$。(b) 截断实例：设 $l_{\mathrm{free}} = -0.85$，几百帧空闲证据后 $p_{t-1} \to 10^{-16}$（双精度下溢）；此后一帧强占用证据需把概率乘以 $\sim 10^{3}$，但 $10^{-16} \times$ 有限倍率仍是 $10^{-13}$ 级——**概率实现被钉死在 0 附近，反向证据恢复极慢**；log-odds 实现中 $l \approx -37$，一帧 $+2.5$ 的占用证据立即可见。实践结论（原书"证明是否是实际应用存在的问题"）：动态环境（门开开关关、家具挪动）下**是**真问题——这正是 log-odds 成为行业默认的理由。
