# 第 04 章｜相机模型与特征提取

前两章解决了"状态怎么表示、噪声怎么融合"，本章补上感知这一环：机器人靠相机看到的，究竟是世界的什么信息。本章回答两个问题：一是 3D 世界如何被投影成 2D 图像——针孔相机模型（pinhole camera model）与畸变（distortion）模型给出像素与世界点的精确换算关系，它就是第 03 章观测模型 $h(\cdot)$ 的具体形式之一；二是从图像里提取**什么**作为观测——ORB 特征提供一组在不同视角、光照下稳定可重复匹配的局部特征，作为"视觉路标"候选。本章产出是第 05 章特征点法视觉里程计的直接输入；投影丢掉深度这一事实，也将在第 05 章三角化中再次出现。

## 04.1 针孔相机模型与内参

**① 问题场景**

世界是 3D 的（点 $\mathbf{p}_w \in \mathbb{R}^3$），照片是 2D 的（像素网格）。手头：相机位姿 $T_{cw}$（第 02 章）与一张图像；缺的：从 3D 点到像素的确定性映射——没有它，第 03 章的观测模型 $h(x_t)$ 写不出来，第 08 章的重投影误差也无从定义；想要：把投影写成可计算的公式，并弄清投影过程**丢掉了什么信息**。

**② 解决方法**

针孔相机模型：把镜头理想化为小孔，3D 点沿光线穿过光心（optical center）投到像平面，再用**内参矩阵**（intrinsic matrix）$K$——焦距 $f_x, f_y$ 与主点 $c_x, c_y$——把物理像面坐标换算到像素坐标，外参 $T_{cw} \in SE(3)$ 负责世界系到相机系的刚体变换。真实镜头在针孔模型之上叠加畸变（04.2）。

**③ 选型理由**

替代方案：完整射影相机模型（3×4 矩阵、11 自由度）更一般，但参数缺乏物理含义、不便离线标定后固定使用；鱼眼 / 全景相机破坏了中心投影假设，需要专门模型（如 Kannala–Brandt）。针孔 + 畸变参数是 SLAM 的标准选择：每个参数都有清晰几何含义（可出厂或离线标定），投影与反投影都是几行矩阵运算；ORB-SLAM 系列对常规相机与鱼眼相机分别采用针孔 + 畸变参数与鱼眼参数建模。代价：小孔是理想化——物理上不可能有无限小的光圈（衍射、像差不可避免），畸变只能参数化拟合，残差取决于标定质量。

**④ 理论依据**

欧氏几何的相似三角形；射影几何的齐次坐标（homogeneous coordinates）——把中心投影表示为线性矩阵乘法。出处：Hartley & Zisserman, *Multiple View Geometry in Computer Vision*（2nd ed.）第 1、6 章；《视觉 SLAM 十四讲》第 4 讲。

**⑤ 完整推导**

**第一步（刚体变换）。** 世界系下的点 $\mathbf{p}_w$ 变换到相机系 $c$（记号约定：$T_{cw}$ 表示世界系到相机系的变换，由第 02 章的 SE(3) 表示）：
$$\mathbf{p}_c = R_{cw}\,\mathbf{p}_w + \mathbf{t}_{cw} \triangleq (X, Y, Z)^\top. \tag{4.1}$$

**第二步（相似三角形）。** 设光心在相机系原点、光轴沿 $z$ 轴、像平面位于 $z = f$（$f$：焦距，focal length）。点 $\mathbf{p}_c = (X, Y, Z)$、光心 $O$ 与光线和像平面的交点 $\mathbf{p}' = (x, y, f)$ 三点共线；沿光轴方向长度被压缩为 $f/Z$ 倍（依据：三点共线的直线参数化与 $z = f$ 平面相交，等价于相似三角形），故
$$x = f\,\frac{X}{Z}, \qquad y = f\,\frac{Y}{Z} \qquad (Z > 0). \tag{4.2}$$
这一步已暴露投影的代价：$Z$ 只出现在分母——**深度信息被丢弃**。像面上一个点只确定一条射线（过光心与 $\mathbf{p}_c$ 的直线），线上所有 3D 点坍缩到同一像素；这正是第 05 章三角化必须用两帧、单目 SLAM 尺度不可观的根源。

**第三步（物理坐标 → 像素坐标）。** 像面坐标以米计，图像以像素计。设 $s_x, s_y$ 为 $u / v$ 方向上单位物理长度对应的像素数（pixels per meter），并设光轴穿过像面的点（**主点**，principal point）相对像素栅格原点偏移 $(c_x, c_y)$——制造公差使光轴一般不正好穿过栅格原点：
$$u = s_x\,x + c_x = f_x\,\frac{X}{Z} + c_x, \qquad v = s_y\,y + c_y = f_y\,\frac{Y}{Z} + c_y, \tag{4.3}$$
其中 $f_x = f\,s_x$、$f_y = f\,s_y$：**换算到像素单位的等效焦距**，量纲为像素。$f_x = f\,s_x$ 的物理含义：焦距 $f$（米）决定光线在像面上的会聚位置，$s_x$ 把这个位置换算成像素——二者相乘即"以像素计的焦距"；若像素是正方形则 $f_x = f_y$，否则二者之比刻画非方像素。

**第四步（齐次坐标与矩阵形式）。** 引入像素齐次坐标 $\tilde{\mathbf{u}} = (u, v, 1)^\top$ 与 3D 点齐次坐标 $\tilde{\mathbf{p}}_w = (\mathbf{p}_w^\top, 1)^\top$。把 (4.3) 两边同乘 $Z$（依据：逐行展开与 (4.3) 逐项相等，第三行是恒等式 $Z = Z$）：
$$Z \begin{pmatrix} u \\ v \\ 1 \end{pmatrix} = \begin{pmatrix} f_x & 0 & c_x \\ 0 & f_y & c_y \\ 0 & 0 & 1 \end{pmatrix} \begin{pmatrix} X \\ Y \\ Z \end{pmatrix} \triangleq K\,\mathbf{p}_c. \tag{4.4}$$
合并 (4.1) 与 (4.4)（依据：齐次坐标下刚体变换为 $\tilde{\mathbf{p}}_c = T_{cw}\,\tilde{\mathbf{p}}_w$，第 02 章的 4×4 形式）：
$$s\,\tilde{\mathbf{u}} = K\,T_{cw}\,\tilde{\mathbf{p}}_w, \qquad s = Z. \tag{4.5}$$
**齐次坐标的引入依据**：透视投影中的除法 $X/Z$ 不是线性运算，无法写成矩阵乘法；齐次坐标把"相差非零尺度因子视为同一点"（$\tilde{\mathbf{u}} \sim \lambda\tilde{\mathbf{u}}$）作为基本等价关系，使旋转、平移、投影、像素化**整条流水线合成一个线性映射 $K\,T_{cw}$**，唯一的非线性被隔离在最后一步"除以齐次坐标 $s$"（去齐次化）里。同时，尺度等价性精确编码了第二步的结论：$\tilde{\mathbf{u}}$ 只确定射线方向，深度 $s$ 天然不出现在方程可解的信息里——投影丢深度，在矩阵形式里表现为"等式只约束 $K T_{cw}\tilde{\mathbf{p}}_w$ 的方向"。

**反投影**（back-projection）：投影的逆不唯一——由 (4.5)，给定 $\tilde{\mathbf{u}}$ 只能恢复相机系下的一条射线，其方向为 $K^{-1}\tilde{\mathbf{u}}$（依据：(4.4) 对方向反解，深度 $Z$ 已丢失）；必须再补充深度 $Z$（单目由第 05 章三角化恢复，RGB-D 相机直接测得）才能还原 3D 点 $\mathbf{p}_w = T_{cw}^{-1}\,(Z\,K^{-1}\tilde{\mathbf{u}})$。这是"投影丢深度"在计算上的表现，也是后续章节反复出现的操作。

## 04.2 畸变模型（Distortion Model）

**① 问题场景**

用 (4.5) 检验真实镜头拍到的"世界上应为直线"的物体（门框、地砖缝）：像里的直线变弯了——广角镜头桶形弯曲、长焦枕形弯曲，且越靠图像边缘越明显。手头：带系统性弯曲的像素观测；缺的：对"理想针孔位置 ↔ 实际像素位置"这一偏差的参数化；想要：把观测"拉直"回针孔模型假设的坐标，使 (4.5)、标定与重投影误差计算仍然成立。

**② 解决方法**

在针孔模型上叠加畸变修正，分解为两类：**径向畸变**（radial distortion，绕光轴旋转对称，用 $r$ 的偶次多项式）与**切向畸变**（tangential distortion，透镜与传感器平面不平行所致）。使用顺序：像素 →（除以内参）归一化坐标 → 去畸变 →（乘内参）回到像素。

**③ 选型理由**

为何用"径向偶次多项式 + 切向二次多项式"（Brown–Conrady 模型）：参数少（常规镜头 5 个畸变参数足够）、每一项有物理来源、可用平面标定法（张正友标定，Zhang, *IEEE TPAMI* 2000）稳定估计；ORB-SLAM 相机参数即按此组织。代价：多项式在视场边缘大畸变场景（鱼眼，视场远超常规镜头）下外推失效，须换鱼眼模型（Kannala–Brandt 等）；且它是"拟合"而非"物理精确"，残差由标定质量决定。出处：Brown, *"Decentering Distortion of Lenses"*, 1966；Conrady (1919)；《视觉 SLAM 十四讲》第 5 讲。

**④ 理论依据**

泰勒展开（对光滑畸变场做低阶参数化）；旋转对称性论证（约束径向场的结构）；Brown (1966) 对偏心畸变的推导；尺度 / 坐标变换下内参可吸收低阶项的观察。

**⑤ 完整推导**

**归一化坐标。** 畸变发生在镜头内部（光心之后、感光之前），作用在几何光线上，与像素栅格无关；故先从 (4.4) 反解出与内参无关的归一化坐标（依据：(4.4) 移项）：
$$(x_n, y_n) = \left(\frac{u - c_x}{f_x},\ \frac{v - c_y}{f_y}\right). \tag{4.6}$$

**径向畸变。** 记 $r^2 = x_n^2 + y_n^2$。旋转对称的镜头决定畸变场必须满足三条结构约束：(a) 偏移方向处处沿径向（旋转对称系统中没有偏好的切向方向）；(b) 幅值只依赖到光轴的距离 $r$；(c) 光轴处无畸变。于是畸变偏移可写为 $\Delta\mathbf{x} = \rho(r^2)\,(x_n, y_n)^\top$，其中 $\rho$ 是光滑标量函数——沿一条射线，任何光滑的径向标量函数都可写成 $r^2$ 的函数（依据：$r \ge 0$，$r^2$ 与 $r$ 一一对应，且以 $r^2$ 为自变量保证偏移在 $(x_n, y_n) \to -(x_n, y_n)$ 时反号，符合中心对称）。约束 (c) 要求 $\rho(0) = 0$。对 $\rho(r^2)$ 在 0 处泰勒展开（依据：光滑函数的泰勒级数；常数项因 $\rho(0) = 0$ 为零），得**偶次幂级数**：
$$\rho(r^2) = k_1 r^2 + k_2 r^4 + k_3 r^6 + \cdots \;\Longrightarrow\; \mathbf{x}_d = \mathbf{x}_n\,\big(1 + k_1 r^2 + k_2 r^4 + k_3 r^6\big), \tag{4.7}$$
其中 $\mathbf{x}_n = (x_n, y_n)^\top$、$\mathbf{x}_d$ 为畸变后坐标（"$r$ 的偶次幂"即"$r^2$ 的各次幂"）。$k_1$ 主导近光轴区域，$k_2, k_3$ 修正大 $r$ 处；取到 6 次已是常规镜头的工程精度。

**切向畸变。** 来源：透镜与传感器平面不完全平行（装配偏心，decentering）。结构论证：若系统完全旋转对称，畸变场处处沿径向、切向分量必为零（依据：约束 (a)）；因此切向项是"打破对称"的偏心效应的最低阶补充。偏心后 2D 偏移场的一般泰勒展开中，**线性项可被内参吸收**——常数项由主点 $c_x, c_y$ 吸收、线性项等价于对像素栅格做仿射重参数化（依据：对坐标做可逆线性变换 $L$ 等价于把内参换成 $K' = K\,\mathrm{diag}(L)$ 形式的另一内参，标定中二者不可区分，见 Zhang 2000 的参数化）——故第一个**可辨识**的偏心项是二次项。Brown (1966) 由小倾角的薄棱镜近似解出二次项的系数结构：
$$\Delta_{tan} = \begin{pmatrix} 2 p_1 x_n y_n + p_2\,(r^2 + 2 x_n^2) \\[2pt] p_1\,(r^2 + 2 y_n^2) + 2 p_2 x_n y_n \end{pmatrix}. \tag{4.8}$$

**合并模型与像素坐标。** 径向 (4.7) 与切向 (4.8) 相加：
$$\begin{aligned} x_d &= x_n\,\big(1 + k_1 r^2 + k_2 r^4 + k_3 r^6\big) + 2 p_1 x_n y_n + p_2\,(r^2 + 2 x_n^2), \\ y_d &= y_n\,\big(1 + k_1 r^2 + k_2 r^4 + k_3 r^6\big) + p_1\,(r^2 + 2 y_n^2) + 2 p_2 x_n y_n, \end{aligned} \tag{4.9}$$
$$u = f_x\,x_d + c_x, \qquad v = f_y\,y_d + c_y. \tag{4.10}$$

**去畸变的迭代 / 一次近似。** 实际计算方向与建模方向相反：观测到的是畸变像素 $(u, v)$，需要的是理想坐标 $(x_n, y_n)$。由 (4.9) 得隐式方程（右端仍含未知的 $x_n, y_n$，无闭式解）：$(x_n, y_n) = \dfrac{(x_d, y_d) - \Delta_{tan}(x_n, y_n)}{1 + k_1 r^2 + k_2 r^4 + k_3 r^6}$。用**不动点迭代**（依据：压缩映射原理——畸变系数小时，右端算子是压缩的，迭代收敛到唯一不动点）：
$$(x_n, y_n)^{(0)} \leftarrow (x_d, y_d), \qquad (x_n, y_n)^{(j+1)} \leftarrow \frac{(x_d, y_d) - \Delta_{tan}\big((x_n, y_n)^{(j)}\big)}{1 + k_1 r_j^2 + k_2 r_j^4 + k_3 r_j^6}. \tag{4.11}$$
迭代至收敛（或达到次数上限）；工程上常只做**一次近似**（单步迭代），当 $|k_1| r^2, |k_2| r^4 \ll 1$ 时其误差是畸变系数的二阶小量（依据：泰勒一阶近似的截断误差为 $O(\text{系数}^2)$）。整幅图可预计算去畸变映射表（undistort map）一次性完成，此后按无畸变的 (4.5) 处理。

## 04.3 ORB 特征（Oriented FAST and Rotated BRIEF）

**① 问题场景**

运动估计（第 05 章）需要"同一物理点在两帧中的对应关系"。直接拿像素灰度做对应不可行：白墙、地板上相邻像素灰度几乎相同（孔径问题，aperture problem），视角一变整个窗口的灰度整体改变。手头：两帧有重叠区域的图像；缺的：一小组"视觉路标"候选点——在不同视角、光照下**稳定可重复地被检测到**（可重复性，repeatability）、且**彼此可区分**（描述子，descriptor）；想要：每帧数百个、毫秒级提取的局部特征。

**② 解决方法**

ORB（Oriented FAST and Rotated BRIEF，Rublee et al., ICCV 2011）三件套：**FAST** 角点检测（圆形 16 像素环上的连续性判定）找关键点（keypoint）；**图像金字塔**（image pyramid）逐层检测提供尺度层次；**BRIEF** 二进制描述子（邻域内固定像素对的亮度比较 → 256 位串）描述外观，并用灰度质心法给每个关键点定主方向、把描述子旋转到主方向（steered BRIEF / rBRIEF）。匹配 = 描述子间汉明距离（Hamming distance）最近者。

**③ 选型理由（重点）**

与 SIFT / SURF 逐项对比：
- **SIFT**（Lowe, *IJCV* 2004）：高斯差分（DoG）尺度空间 + 128 维浮点梯度直方图描述子；尺度 / 旋转 / 光照鲁棒性最好；代价是计算重（多尺度高斯卷积 + 直方图统计），且长期受专利限制（2020 年方到期），历史上无法自由商用。
- **SURF**（Bay et al., ECCV 2006）：积分图像 + 盒式滤波加速，仍为 64 维浮点描述子，同样受专利保护，速度仍难以支撑高频 SLAM 前端。
- **ORB**：描述子为 256 位串，距离是汉明距离——异或（XOR）+ 位计数（popcount）即可，现代 CPU 有专用指令，匹配比浮点欧氏距离快一个数量级以上；提取只含像素比较与查表，ORB 论文报告其比 SIFT 快约两个数量级、比 SURF 快约一个数量级；无专利；经灰度质心定向 + rBRIEF 获得旋转不变性。
- **代价**：尺度不变性只来自离散金字塔层（连续尺度空间的量化近似），对**大尺度变化**比 SIFT 敏感；256 位描述子区分性弱于 128 维 SIFT，误匹配更多，需比例测试与几何校验（第 05 章的 RANSAC）兜底。
ORB-SLAM 论文的工程判断印证了这一选择：跟踪、建图、重定位、回环全部任务复用同一 ORB 特征，"允许实时运行并对视角与光照变化保持良好不变性"（Mur-Artal et al., *IEEE T-RO* 2015，见配套阅读）。

**④ 理论依据**

Rublee, Rabaud, Konolige, Bradski, *"ORB: an efficient alternative to SIFT or SURF"*, ICCV 2011（[CVF 全文](https://openaccess.thecvf.com/content_iccv_2011/papers/Rublee_ORB_an_Efficient_ICCV_2011_paper.pdf)）；FAST 出自 Rosten & Drummond, ECCV 2006；BRIEF 出自 Calonder et al., ECCV 2010；灰度质心思想出自 Rosin (1999)；图像金字塔与尺度空间见 Lindeberg (1994)。

**⑤ 完整推导**

**(a) FAST 判定的定义级推导。** 设像素 $p$ 的灰度为 $I_p$，取以 $p$ 为圆心、半径 3 像素的圆环上 16 个像素（半径取 3 时 Bresenham 圆恰有 16 个互不相同的栅格点，再小则方向分辨不足）。判定：若存在**连续** $N$ 个环上像素，同时显著比 $I_p$ 亮或同时显著比 $I_p$ 暗（$T$ 为阈值）：
$$\exists\ \text{连续弧}\ S \subseteq \{1, \dots, 16\},\ |S| = N:\quad \forall q \in S,\ \big|I_q - I_p\big| > T\ \text{且同号}, \tag{4.12}$$
则 $p$ 为角点（corner）。含义论证：该条件刻画"局部亮度变化集中在某个方向楔形内"。对穿过圆心的理想直边缘，环上亮侧与暗侧各约占半圆，任一侧的连续亮（暗）段至多 8 个像素——因此要求 $N > 8$ 可排除纯边缘；原始 FAST 取 $N = 12$，ORB 采用 FAST-9（$N = 9$，配合非极大值抑制）。阈值 $T$ 的作用是给"显著变化"设噪底余量，排除噪声导致的伪响应。为保证可重复匹配，还需**非极大值抑制**（non-maximum suppression）：同一物理点邻域内只保留响应最强者，使两次检测得到的是同一个点而非它的邻居。FAST 只含比较运算、无梯度无卷积，这是其实时性的来源。

**(b) 灰度质心法：主方向推导。** 在关键点周围取半径 $R$ 的圆形邻域 $B$，定义图像矩（image moments）（依据：矩的标准定义）：
$$m_{pq} = \sum_{(x, y) \in B} x^p\, y^q\, I(x, y). \tag{4.13}$$
亮度加权的质心（intensity centroid）位置为（依据：质心 = 一阶矩 / 零阶矩，即"重心"公式的离散形式）：
$$\mathbf{C} = \left(\frac{m_{10}}{m_{00}},\ \frac{m_{01}}{m_{00}}\right). \tag{4.14}$$
主方向取"圆心指向质心"的方向：记 $\boldsymbol{\rho} = (m_{10}, m_{01})^\top$，因 $m_{00} > 0$ 是公共正尺度因子，方向仅由 $\boldsymbol{\rho}$ 决定（依据：$\boldsymbol{\rho} = m_{00}\,\mathbf{C}$，与 $\mathbf{C}$ 同向）；用 atan2 依象限取角，值域 $(-\pi, \pi]$ 覆盖全部方向：
$$\theta = \mathrm{atan2}\,(m_{01},\, m_{10}). \tag{4.15}$$

**旋转不变性论证。** 设图像内容绕邻域圆心旋转角 $\alpha$，即旋转后图像 $I_\alpha(x, y) = I\big(R_{-\alpha}(x, y)\big)$（$R_\alpha$ 为旋转矩阵）。做变量替换 $(x', y') = R_{-\alpha}(x, y)$：圆形邻域 $B$ 在旋转下不变、雅可比为 1（依据：换元积分与 $R_{-\alpha}^{-1} = R_{\alpha}$）：
$$\begin{pmatrix} m_{10}^{(\alpha)} \\ m_{01}^{(\alpha)} \end{pmatrix} = \sum_{(x', y') \in B} R_\alpha \begin{pmatrix} x' \\ y' \end{pmatrix} I(x', y') = R_\alpha \begin{pmatrix} m_{10} \\ m_{01} \end{pmatrix}. \tag{4.16}$$
把 $\boldsymbol{\rho}$ 写成极坐标 $\boldsymbol{\rho} = \|\boldsymbol{\rho}\|\,(\cos\theta, \sin\theta)^\top$，则 $R_\alpha\boldsymbol{\rho} = \|\boldsymbol{\rho}\|\,(\cos(\theta + \alpha), \sin(\theta + \alpha))^\top$（依据：旋转矩阵的定义），代入 (4.15) 得
$$\theta^{(\alpha)} = \theta + \alpha \quad (\mathrm{mod}\ 2\pi). \tag{4.17}$$
即**测得的主方向随图像内容同步旋转**。因此，若在计算描述子前把采样模式旋转 $-\theta$（steered BRIEF），两帧间任意相对旋转 $\alpha$ 都会被各自的 $-\theta$ 抵消，规范化后的邻域逐位一致 → 描述子不变 → 匹配对旋转鲁棒——这就是"把描述子旋转到主方向实现旋转不变性"的完整论证。（前提与代价：邻域内容须近似为整体刚体旋转，且亮度分布非对称——$m_{10}, m_{01}$ 不同时为零；高度对称结构的主方向不稳定。）

**(c) BRIEF 与汉明距离的性质。** 对平滑（高斯滤波去噪）后的补丁 $P$（ORB 用 31×31 补丁），取固定的像素对集合 $\{(\mathbf{a}_j, \mathbf{b}_j)\}_{j=1}^{n}$（$n = 256$），定义每一位的比较与描述子（依据：定义）：
$$\tau\big(P;\, \mathbf{a}_j, \mathbf{b}_j\big) = \begin{cases} 1, & I(\mathbf{a}_j) < I(\mathbf{b}_j) \\ 0, & \text{否则} \end{cases}, \qquad f(P) = \big(\tau_1, \dots, \tau_n\big) \in \{0, 1\}^n. \tag{4.18}$$
**匹配距离**取汉明距离：$d\big(f(P), f(Q)\big) = \#\{j : \tau_j(P) \neq \tau_j(Q)\}$，即按位异或后的计数。两条定义级性质：
- **光照鲁棒**：若两图间光照变化是严格单调映射 $I \to g(I)$，则所有不等式 $I(\mathbf{a}_j) < I(\mathbf{b}_j)$ 保持不变（依据：单调函数保序）→ 同一物理点的描述子逐位相同，距离为 0；
- **区分性的统计依据**：无关补丁的各位近似独立、取 0/1 等概率，则 $d \sim \mathrm{Binomial}(n, 1/2)$，期望 $n/2 = 128$、标准差 $\sqrt{n \cdot 1/4} = 8$；真匹配在噪声下每位以小概率 $p$ 翻转，期望距离 $n\,p$。于是"距离远小于 $n/2$"构成判定匹配的统计阈值（依据：二项分布的均值与方差）。
（改进项：steered BRIEF 使部分比特相关性上升、区分性下降，ORB 通过离线学习挑选相关性最低、方差最大的像素对（rBRIEF）——属操作流程，不含理论。）

**(d) 图像金字塔与尺度不变性。** 单尺度 FAST 有尺度盲区：物体远离后（像素尺寸减半）同一物理角点不再触发判定。解决：构建高斯金字塔，第 $L$ 层由第 0 层降采样 $s^L$ 倍（ORB-SLAM 默认 8 层、层间缩放因子 1.2），**每一层独立**跑 FAST。论证：降采样 $s^L$ 倍把层 0 上像素尺寸为 $\ell$ 的结构变为 $\ell / s^L$（依据：降采样的尺度缩放关系）；两帧间相对尺度变化 $s^{\Delta L}$ 的同一角点，会在相差 $\Delta L$ 层的金字塔层上被检测到——配准层号即可恢复近似尺度，即离散化的尺度不变性（scale invariance）。连续尺度被量化为有限层数，正是 ③ 中"对大尺度变化更敏感"的原因（依据：尺度空间理论，Lindeberg, 1994）。

**特征提取与匹配流程**（操作步骤，不含理论）：逐层金字塔 FAST-9 检测 → 非极大值 + 八叉树均匀分配控制数量与分布 → 灰度质心定向 (4.15) → rBRIEF 描述 (4.18) → 汉明距离最近邻 + 比例测试初匹配 →（第 05 章）对极几何 + RANSAC 剔除误匹配。ORB-SLAM 中同一组特征复用于跟踪、建图、重定位与回环。

## 本章要点

- 投影方程 $s\,\tilde{\mathbf{u}} = K\,T_{cw}\,\tilde{\mathbf{p}}_w$（式 4.5）是 SLAM 观测模型 $h(\cdot)$ 的具体形式；$s = Z$ 只出现在尺度因子中，表明**深度在投影中丢失**——单目尺度不可观的根源。
- 内参矩阵（式 4.4）：$f_x = f\,s_x$ 是像素单位的等效焦距，$(c_x, c_y)$ 是主点（光轴与像面交点的像素坐标）。
- 齐次坐标把透视除法隔离为最后一步去齐次化，整条投影流水线合成线性矩阵乘法 $K\,T_{cw}$（式 4.4–4.5）。
- 畸变模型（式 4.9）：径向偶次多项式源于"旋转对称 + 中心零畸变 + 泰勒展开"三条约束；切向二次项源于透镜–传感器不平行（Brown 1966），其线性项已被内参吸收；去畸变靠不动点迭代 (4.11) 或一次近似。
- FAST 角点判定（式 4.12）：连续 $N > 8$ 个环像素显著更亮 / 更暗，$N > 8$ 排除纯边缘；只含比较运算，是实时性的来源。
- 灰度质心方向 $\theta = \mathrm{atan2}(m_{01}, m_{10})$（式 4.15）在图像旋转 $\alpha$ 下满足 $\theta^{(\alpha)} = \theta + \alpha$（式 4.17）——描述子旋转 $-\theta$ 后获得旋转不变性。
- BRIEF 256 位串 + 汉明距离（式 4.18）：单调光照变换下距离为 0，无关对距离期望 $n/2$——匹配判据的统计依据。
- 金字塔（ORB-SLAM 默认 8 层、因子 1.2）把连续尺度量化为离散层，提供近似尺度不变性；代价是对大尺度变化更敏感。
