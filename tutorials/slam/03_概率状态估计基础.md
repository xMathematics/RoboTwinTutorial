# 第 03 章｜概率状态估计基础

上一章（第 02 章）解决了"位姿怎么表示"，但表示只是容器——机器人真正面对的是：轮式里程计（odometry）会打滑漂移，相机与激光的观测也带噪声，没有任何一次测量是单独可信的。本章回答的问题是：给定一串带噪声的运动信息与观测信息，如何把它们**递归地**融合成对当前状态的最优概率估计。我们搭三级台阶：先建立一般的递归贝叶斯估计框架，再在高斯假设下得到解析解——卡尔曼滤波（Kalman Filter, KF），最后推广到非线性模型——扩展卡尔曼滤波（Extended Kalman Filter, EKF）。本章是第 05 章视觉里程计（单次运动估计）与第 07 章后端（全局在线滤波）共同的理论地基，EKF 的三类误差还会成为第 07→08 章"后端换范式"因果链的起点。

## 03.1 递归贝叶斯估计（Recursive Bayesian Estimation）

**① 问题场景**

机器人每一步拿到两类信息：一是运动指令 / 里程计读数 $u_t$（"我按指令走了多远"），二是传感器观测 $z_t$（"我看到了什么"）。二者都不可单独信赖：里程计有累积漂移（轮子打滑、量化误差），走得越远误差越大，且漂移无法靠里程计自身消除；单次观测（如"看到一扇门在正前方 2 米"）也只给出模糊约束——测量有噪声、环境有歧义。手头：带噪声的 $u_t$ 与 $z_t$ 及其统计模型；缺的：真实状态 $x_t$（位姿、速度，乃至地图中路标 $\mathbf{m}_i$ 的位置）；想要：一个能随数据流**在线**更新、且不丢历史信息的"最优猜测"。

**② 解决方法**

用概率分布刻画"对 $x_t$ 的全部认知"——信念（belief）：维护 $\mathrm{bel}(x_t) = p(x_t \mid u_{1:t}, z_{1:t})$。每个时刻做两步：**预测**（prediction，用运动模型把旧信念"推"到当前时刻，得到先验）与**更新**（update，用观测模型对先验重新加权，得到后验）。预测使分布变宽（不确定性经运动累积），更新使其收窄（观测注入信息），循环往复。

**③ 选型理由**

递归 vs 批量（batch）：批量法把全部历史 $\{u_{1:t}, z_{1:t}\}$ 存下来，每次直接求整个分布——内存随时间线性增长，且新来一个观测就要对全部历史重算一遍，延迟随 $t$ 增长，机器人上无法在线。递归法的依据与代价：在马尔可夫假设下，$\mathrm{bel}(x_{t-1})$ 是全部历史的**充分统计量**（sufficient statistic）——每步只需存一个分布（固定内存）、只处理一个新观测（固定延迟），天然在线。代价有三：① 必须为噪声指定概率模型，模型错则估计系统性偏；② 马尔可夫假设在未建模动力学（打滑的尾部事件、外力）下不严格成立；③ "只信最近的信念"意味着历史信息被压缩进单一分布，早期线性化错误一旦固化便难回头——第 08 章图优化允许重线性化，正是为了找回这一点。

**④ 理论依据**

贝叶斯定理（Bayes' theorem）、全概率公式与 Chapman–Kolmogorov 方程、马尔可夫假设（Markov assumption：给定当前状态，未来与过去条件独立）与静态世界假设（环境不随时间自发变化）。出处：Thrun, Burgard, Fox, *Probabilistic Robotics*, MIT Press 2005, 第 2 章（递归贝叶斯滤波）与第 3 章（高斯滤波）；状态方程与观测方程的形式化定义见第 01 章。

**⑤ 完整推导**

带噪声的状态方程与观测方程（第 01 章的形式化定义；噪声记号沿用全教程约定 $\mathbf{w}, \mathbf{v}$，本章时间下标统一写作 $t$）：
$$x_t = f(x_{t-1}, u_t) + \mathbf{w}_t, \qquad z_t = h(x_t) + \mathbf{v}_t. \tag{3.1}$$
其中 $f$ 编码"控制如何改变状态"，$h$ 编码"状态如何决定观测"；两个噪声项零均值、分布已知（本节不假设具体形式）。定义两个待求对象：
$$\mathrm{bel}(x_t) \triangleq p(x_t \mid u_{1:t}, z_{1:t}), \qquad \mathrm{bel}^-(x_t) \triangleq p(x_t \mid u_{1:t}, z_{1:t-1}). \tag{3.2}$$
（$\mathrm{bel}$：融入第 $t$ 步观测后的后验；$\mathrm{bel}^-$：只用运动信息、尚未使用 $z_t$ 的先验。）

**预测步。** 对 $\mathrm{bel}^-(x_t)$ 展开：先用乘法公式 $p(a, b \mid \cdot) = p(a \mid b, \cdot)\, p(b \mid \cdot)$，再对 $x_{t-1}$ 边缘化（依据：全概率公式）：
$$\mathrm{bel}^-(x_t) = \int p(x_t \mid x_{t-1}, u_{1:t}, z_{1:t-1})\; p(x_{t-1} \mid u_{1:t}, z_{1:t-1})\; \mathrm{d}x_{t-1}. \tag{3.3}$$
对 (3.3) 的两个条件项逐一化简，每项指明"由哪个假设消掉哪些条件"：
- 第一项：**由马尔可夫假设**，给定 $x_{t-1}$ 后，$x_t$ 只经由最近的控制 $u_t$ 受影响——更早的控制 $u_{1:t-1}$ 与观测 $z_{1:t-1}$ 对 $x_t$ 不再提供额外信息 → $p(x_t \mid x_{t-1}, u_{1:t}, z_{1:t-1}) = p(x_t \mid x_{t-1}, u_t)$；
- 第二项：**由马尔可夫假设**，未来的控制 $u_t$ 不可能改变已经发生的状态 $x_{t-1}$ → $p(x_{t-1} \mid u_{1:t}, z_{1:t-1}) = p(x_{t-1} \mid u_{1:t-1}, z_{1:t-1}) = \mathrm{bel}(x_{t-1})$。

代回即得**预测公式**（其积分形式正是 Chapman–Kolmogorov 方程作用于马尔可夫转移核）：
$$\mathrm{bel}^-(x_t) = \int p(x_t \mid x_{t-1}, u_t)\; \mathrm{bel}(x_{t-1})\; \mathrm{d}x_{t-1}. \tag{3.4}$$

**更新步。** 由贝叶斯定理（以 $z_t$ 为"证据"）：
$$\mathrm{bel}(x_t) = p(x_t \mid z_t, u_{1:t}, z_{1:t-1}) = \frac{p(z_t \mid x_t, u_{1:t}, z_{1:t-1})\; p(x_t \mid u_{1:t}, z_{1:t-1})}{p(z_t \mid u_{1:t}, z_{1:t-1})}. \tag{3.5}$$
对 (3.5) 三项化简：
- 分子第一项：**由马尔可夫假设与静态世界假设**，观测只由当前状态决定 → $p(z_t \mid x_t, u_{1:t}, z_{1:t-1}) = p(z_t \mid x_t)$，即观测模型 / 似然（likelihood）；
- 分子第二项即预测步所得的 $\mathrm{bel}^-(x_t)$（式 3.4）；
- 分母与 $x_t$ 无关（依据：全概率公式 $p(z_t \mid u_{1:t}, z_{1:t-1}) = \int p(z_t \mid x')\,\mathrm{bel}^-(x')\,\mathrm{d}x'$，对 $x'$ 积分后不含 $x_t$），只起归一化作用，记其倒数为 $\eta$。

于是得到**更新公式**：
$$\mathrm{bel}(x_t) = \eta\; p(z_t \mid x_t)\; \mathrm{bel}^-(x_t). \tag{3.6}$$

(3.4) 与 (3.6) 构成**贝叶斯滤波器**：直观上，预测是用转移核 $p(x_t \mid x_{t-1}, u_t)$ 把旧信念"卷积摊开"，更新是用似然 $p(z_t \mid x_t)$ 对摊开结果"重新加权"。它对 $f, h$ 与噪声分布没有任何限制，因此是精确但不可计算的一般框架——连续状态下 (3.4) 的积分与 (3.6) 的乘积通常没有闭式解。接下来两级台阶，都是在"什么模型假设下这两式可以解析算出"上做文章。

## 03.2 卡尔曼滤波（Kalman Filter）：高斯世界下的解析解

**① 问题场景**

(3.4) 要求在连续状态空间上存储并传播一个**任意函数**——参数无穷多，计算不可行。手头：噪声化的线性传感器与运动模型；缺的：一种"有限参数、闭式传播"的信念表示；想要：把 (3.4)(3.6) 变成几条可执行公式，在机器人 CPU 上实时运行。

**② 解决方法**

做两条假设：(a) $f, h$ 线性、噪声为加性高斯；(b) 初始信念为高斯。此时信念在预测（高斯的仿射变换）与更新（高斯的贝叶斯乘法）下**始终是高斯**——只需传播均值与协方差两个有限对象，得到卡尔曼滤波五公式。

**③ 选型理由**

为何偏偏是高斯：① **运算封闭**——高斯是少数对仿射变换与条件化（贝叶斯更新）都封闭的常用分布族，递归链条不会"越算越复杂"；② **参数极简**——任意维度只需均值 + 协方差，内存不随历史增长；③ **全线性代数**——矩阵乘法与求逆，硬件友好、可实时。替代方案：直方图滤波（histogram filter，把状态网格离散化，精度与内存随维度指数冲突）；粒子滤波（particle filter，采样近似，可表达任意分布但计算量大，1960 年代硬件上不可行）。**代价**：高斯是单峰的，无法表达"机器人可能在走廊 A 也可能在走廊 B"这类多峰后验——这种歧义在 SLAM 中真实存在（数据关联不确定、回环前的位置模糊），为第 07 章的粒子滤波（FastSLAM，见配套阅读）埋下伏笔。出处：Kalman, *"A New Approach to Linear Filtering and Prediction Problems"*, ASME J. Basic Engineering, 1960。

**④ 理论依据**

高斯分布两条性质：对仿射变换 $y = Ax + b$ 封闭（$y \sim \mathcal{N}(A\mu + b,\ A\Sigma A^\top)$）；联合高斯的条件分布仍是高斯，且条件均值 / 协方差有显式公式（经分块求逆与 Schur 补得到）。出处：Kalman (1960)；Thrun ch3.2；条件公式另见 Bishop, *Pattern Recognition and Machine Learning* §2.3。

**⑤ 完整推导**

线性高斯模型（(3.1) 的特例；过程噪声协方差 $Q$、观测噪声协方差 $R$）：
$$x_t = A x_{t-1} + B u_t + \mathbf{w}_t,\quad \mathbf{w}_t \sim \mathcal{N}(0, Q); \qquad z_t = C x_t + \mathbf{v}_t,\quad \mathbf{v}_t \sim \mathcal{N}(0, R). \tag{3.7}$$
设上一时刻后验 $\mathrm{bel}(x_{t-1}) = \mathcal{N}(\mu_{t-1}, \Sigma_{t-1})$。

**第一步：预测。** 在 (3.7) 下 $p(x_t \mid x_{t-1}, u_t) = \mathcal{N}(A x_{t-1} + B u_t,\ Q)$——$x_t$ 是高斯 $x_{t-1}$ 的仿射变换再加独立高斯噪声。代入 (3.4)，均值与协方差分开算：
- 均值（依据：期望的线性性；$\mathbf{w}_t$ 零均值且与状态独立）：
$$\mu_t^- = A\,\mu_{t-1} + B u_t. \tag{3.8}$$
- 协方差：偏差为 $x_t - \mu_t^- = A(x_{t-1} - \mu_{t-1}) + \mathbf{w}_t$，交叉项 $E\big[A(x_{t-1}-\mu_{t-1})\mathbf{w}_t^\top\big] = A\,E[x_{t-1}-\mu_{t-1}]\,E[\mathbf{w}_t]^\top = 0$（依据：状态与噪声独立），故
$$\Sigma_t^- = A\,\Sigma_{t-1}\,A^\top + Q. \tag{3.9}$$
（依据：高斯经线性变换后 $\Sigma \to A\Sigma A^\top$；独立随机变量之和的协方差等于各自协方差之和。预测把旧协方差经 $A$ 传播后再加 $Q$——不确定性经运动放大。）

**第二步：引理——联合高斯的条件分布。** 更新需要"已知 $z_t$ 时 $x_t$ 的条件分布"，先推导一般引理。设
$$\begin{pmatrix} \mathbf{a} \\ \mathbf{b} \end{pmatrix} \sim \mathcal{N}\!\left( \begin{pmatrix} \mu_a \\ \mu_b \end{pmatrix},\ \begin{pmatrix} \Sigma_{aa} & \Sigma_{ab} \\ \Sigma_{ba} & \Sigma_{bb} \end{pmatrix} \right), \tag{3.10}$$
记精度矩阵 $\Lambda = \Sigma^{-1} = \begin{pmatrix} \Lambda_{aa} & \Lambda_{ab} \\ \Lambda_{ab}^\top & \Lambda_{bb} \end{pmatrix}$，并记 $S_a = \Sigma_{aa} - \Sigma_{ab}\Sigma_{bb}^{-1}\Sigma_{ba}$。分块求逆（Schur 补）给出 $\Lambda_{aa} = S_a^{-1}$、$\Lambda_{ab} = -S_a^{-1}\,\Sigma_{ab}\Sigma_{bb}^{-1}$（依据：标准分块求逆结果，见 Bishop §2.3；左上块可当场验证：$\Sigma_{aa}S_a^{-1} - \Sigma_{ab}\Sigma_{bb}^{-1}\Sigma_{ba}S_a^{-1} = S_a\,S_a^{-1} = I$ ✓）。

把联合密度的指数二次型按"是否含 $\mathbf{a}$"分类（依据：二次型展开，含 $\mathbf{a}$ 的部分为 $(\mathbf{a}-\mu_a)^\top\Lambda_{aa}(\mathbf{a}-\mu_a) + 2(\mathbf{a}-\mu_a)^\top\Lambda_{ab}(\mathbf{b}-\mu_b)$）。固定 $\mathbf{b}$ 时 $p(\mathbf{a} \mid \mathbf{b}) \propto p(\mathbf{a}, \mathbf{b})$（依据：条件概率定义，分母与 $\mathbf{a}$ 无关），对 $\mathbf{a}$ 配方（依据：向量完全平方，配出的附加项不含 $\mathbf{a}$）得
$$p(\mathbf{a} \mid \mathbf{b}) = \mathcal{N}\!\big(\underbrace{\mu_a + \Sigma_{ab}\Sigma_{bb}^{-1}(\mathbf{b} - \mu_b)}_{\text{条件均值}},\ \underbrace{\Sigma_{aa} - \Sigma_{ab}\Sigma_{bb}^{-1}\Sigma_{ba}}_{\text{条件协方差}}\big). \tag{3.11}$$
（细节：配方把指数凑成 $\big[\mathbf{a} - \mu_a + \Lambda_{aa}^{-1}\Lambda_{ab}(\mathbf{b}-\mu_b)\big]^\top \Lambda_{aa} \big[\mathbf{a} - \mu_a + \Lambda_{aa}^{-1}\Lambda_{ab}(\mathbf{b}-\mu_b)\big] + \text{与}\,\mathbf{a}\,\text{无关项}$；读出精度 $\Lambda_{aa}$ 与中心 $-\Lambda_{aa}^{-1}\Lambda_{ab}(\mathbf{b}-\mu_b) = \Sigma_{ab}\Sigma_{bb}^{-1}(\mathbf{b}-\mu_b)$。）

**第三步：构造 $(x_t, z_t)$ 的联合分布。** 由 (3.7)，$z_t = Cx_t + \mathbf{v}_t$ 是 $x_t$ 的仿射变换加独立噪声，逐项计算（依据同第一步）：
$$\begin{pmatrix} x_t \\ z_t \end{pmatrix} \sim \mathcal{N}\!\left( \begin{pmatrix} \mu_t^- \\ C\mu_t^- \end{pmatrix},\ \begin{pmatrix} \Sigma_t^- & \Sigma_t^- C^\top \\ C\Sigma_t^- & C\Sigma_t^- C^\top + R \end{pmatrix} \right). \tag{3.12}$$

**第四步：更新 = 条件化；增益 = 最优加权。** 把引理 (3.11) 用于 (3.12)（取 $\mathbf{a} = x_t$、$\mathbf{b} = z_t$）立得后验。为看清增益从哪来、并确认它最优，换一个等价角度：在一切线性估计器 $\hat{x}(z) = \mu_t^- + K\,(z - C\mu_t^-)$（$z - C\mu_t^-$ 称为新息，innovation——观测中超出预测可解释的部分）中，选 $K$ 使后验协方差的迹最小。把 $z = Cx + \mathbf{v}_t$ 代入，估计误差为 $e = x - \hat{x} = (I - KC)(x - \mu_t^-) - K\mathbf{v}_t$，由状态与噪声独立：
$$\Sigma(K) = (I - KC)\,\Sigma_t^-\,(I - KC)^\top + K R K^\top = \Sigma_t^- - KC\Sigma_t^- - \Sigma_t^-C^\top K^\top + K\,(C\Sigma_t^-C^\top + R)\,K^\top. \tag{3.13}$$
记 $S = C\Sigma_t^-C^\top + R$（新息协方差）。矩阵配方（依据：把 (3.13) 凑成 $K$ 的完全平方；$S \succ 0$，因 $R \succ 0$ 与 $C\Sigma_t^-C^\top \succeq 0$ 之和）：
$$\Sigma(K) = \big(K - \Sigma_t^-C^\top S^{-1}\big)\,S\,\big(K - \Sigma_t^-C^\top S^{-1}\big)^\top + \Sigma_t^- - \Sigma_t^-C^\top S^{-1}C\Sigma_t^-. \tag{3.14}$$
（验证：展开第一项得 $KS K^\top - K\Sigma_t^-C^\top - \Sigma_t^-C^\top K^\top + \Sigma_t^-C^\top S^{-1}C\Sigma_t^-$，其中末项与第二项相消，余项与 (3.13) 逐项相同。）第一项是 $K$ 的半正定二次型，故对一切 $K$ 有 $\Sigma(K) \succeq \Sigma(K^\*)$（Loewner 序，Loewner order；迹亦随之最小），当且仅当
$$K = \Sigma_t^- C^\top \big(C\,\Sigma_t^- C^\top + R\big)^{-1}. \tag{3.15}$$
代回 (3.14) 得后验协方差；后验均值即取最优 $K$ 的 $\hat{x}$：
$$\mu_t = \mu_t^- + K\,(z_t - C\mu_t^-), \qquad \Sigma_t = (I - KC)\,\Sigma_t^-. \tag{3.16}$$
该结果与引理 (3.11) 直接条件化所得完全一致——说明卡尔曼增益既是最小方差线性估计，在高斯假设下也就是完整的贝叶斯后验。

**卡尔曼滤波五公式**汇总（预测 (3.8)(3.9)，增益 (3.15)，更新 (3.16)）：
$$\begin{aligned} \text{预测：}\ & \mu_t^- = A\mu_{t-1} + Bu_t, && \Sigma_t^- = A\Sigma_{t-1}A^\top + Q; \\ \text{增益：}\ & K_t = \Sigma_t^-C^\top\big(C\Sigma_t^-C^\top + R\big)^{-1}; && \\ \text{更新：}\ & \mu_t = \mu_t^- + K_t\,(z_t - C\mu_t^-), && \Sigma_t = (I - K_tC)\,\Sigma_t^-. \end{aligned} \tag{3.17}$$
增益的直观含义：$R$ 大（观测噪声大）→ $K$ 小 → 更相信预测；$\Sigma_t^-$ 大（预测不确定性大）→ $K$ 大 → 更相信观测。

## 03.3 扩展卡尔曼滤波（Extended Kalman Filter, EKF）

**① 问题场景**

真实系统几乎都不满足 (3.7) 的线性假设：机器人走圆弧时旋转与平移耦合（$f$ 非线性），相机观测是透视投影（第 04 章将推导 $h$ 含除以深度的运算）。五公式 (3.17) 的前提被打破，直接套用没有理论依据。手头：非线性 $f, h$ 的解析式；缺的：让 (3.17) 继续适用的近似；想要：保住滤波框架的实时性与固定内存。

**② 解决方法**

扩展卡尔曼滤波（EKF）：在每个时刻，把 $f$ 在**上一时刻后验均值**处、把 $h$ 在**当前时刻先验均值**处做一阶泰勒展开，用雅可比矩阵（Jacobian matrix）$F_t, H_t$ 代替线性模型中的 $A, C$，然后原封不动套用 KF 五公式。

**③ 选型理由**

替代方案对比：精确非线性滤波在连续状态下没有闭式解（(3.4) 不可积）；粒子滤波可表达任意分布，但每帧需对每个粒子做一次传播，采样数不足时退化（第 07 章会在合适场景启用它）。EKF 保留了 KF 的全部工程优点——固定内存、纯线性运算、逐帧在线；代价是引入线性化误差，在非线性强、不确定性大时会低估协方差甚至发散（误差三条见下）。它是第 07 章 EKF-SLAM 的直接基础，其误差也构成第 07→08 章"后端换范式"因果链的起点。

**④ 理论依据**

多元函数一阶泰勒展开与雅可比矩阵；误差分析依据滤波文献的经典结论（EKF 的不一致性，inconsistency：Bailey et al., IROS 2006；Julier & Uhlmann, *Proc. IEEE* 2004）。出处：Thrun ch3.3。

**⑤ 完整推导**

非线性模型即 (3.1)。**运动模型线性化**：在当前最优估计——后验均值 $\mu_{t-1}$ 与已知控制 $u_t$——处泰勒展开、保留一阶项（依据：泰勒定理，余项为偏差的二阶小量）：
$$x_t = f(x_{t-1}, u_t) + \mathbf{w}_t \approx f(\mu_{t-1}, u_t) + \underbrace{\frac{\partial f}{\partial x}\Big|_{\mu_{t-1},\,u_t}}_{F_t}\,(x_{t-1} - \mu_{t-1}) + \mathbf{w}_t. \tag{3.18}$$
把它写成 $x_t = F_t x_{t-1} + \underbrace{\big(f(\mu_{t-1}, u_t) - F_t\mu_{t-1}\big)}_{\text{常数项}} + \mathbf{w}_t$，即关于偏差 $\delta x = x_{t-1} - \mu_{t-1}$ 的线性模型；套用预测公式 (3.8)(3.9)（依据：常数项只平移均值、不影响协方差）：
$$\mu_t^- = f(\mu_{t-1}, u_t), \qquad \Sigma_t^- = F_t\,\Sigma_{t-1}\,F_t^\top + Q. \tag{3.19}$$

**观测模型线性化**：在先验均值 $\mu_t^-$——此刻对 $x_t$ 的最好猜测——处展开：
$$z_t = h(x_t) + \mathbf{v}_t \approx h(\mu_t^-) + \underbrace{\frac{\partial h}{\partial x}\Big|_{\mu_t^-}}_{H_t}\,(x_t - \mu_t^-) + \mathbf{v}_t. \tag{3.20}$$
套用更新公式 (3.15)(3.16)（$C \to H_t$；新息相应变为 $z_t - H_t\mu_t^- - \big(h(\mu_t^-) - H_t\mu_t^-\big) = z_t - h(\mu_t^-)$，常数项恰好相消）：
$$K_t = \Sigma_t^- H_t^\top \big(H_t \Sigma_t^- H_t^\top + R\big)^{-1}, \qquad \mu_t = \mu_t^- + K_t\,\big(z_t - h(\mu_t^-)\big), \qquad \Sigma_t = (I - K_t H_t)\,\Sigma_t^-. \tag{3.21}$$

**线性化点的选取**：预测在 $(\mu_{t-1}, u_t)$、更新在 $\mu_t^-$ 处展开——均为当时可得的最优状态猜测。理由：泰勒余项与偏差 $(x - \mu)$ 的平方同阶，信念越紧（协方差越小）误差越小；反之，估计远离真值时，线性化就在错误的"工作点"上进行，模型本身失真。

**EKF 的三类误差**（按来源）：
1. **一阶截断误差**：被丢弃的二阶及以上项在曲率大、信念宽时不可忽略；它们的作用等同于额外的非高斯噪声，使滤波器低估自身不确定性；
2. **线性化点偏差**：展开点用的是估计值而非真值，估计有偏则线性模型本身失真，且随递归逐步累积；与批量优化（第 08 章）可在改进估计后**重新**线性化不同，滤波把每一步的线性化结果永久"烧"进先验，无法撤回；
3. **不一致性**：滤波器报告的协方差与真实误差不匹配（过度自信），且在 EKF-SLAM 中即使线性化点较好也可能系统性发生（Bailey et al., IROS 2006）；过度自信会错配后续观测的权重，直至发散。

这三条误差在第 07 章 EKF-SLAM（状态向量还需并入全部路标 $\mathbf{m}_i$，维度随地图增长）中被进一步放大，并在第 08 章成为改用图优化范式（批量重线性化、流形上迭代）的核心动机。

## 本章要点

- 贝叶斯滤波两步——预测 (3.4) 与更新 (3.6)——是一切滤波算法的母体；两步的化简分别依赖马尔可夫假设与"马尔可夫 + 静态世界"假设。
- 预测使信念变宽（$\Sigma_t^- = A\Sigma_{t-1}A^\top + Q$，式 3.9），更新使信念收窄；不确定性在"走"与"看"之间周期性涨落。
- 高斯近似的价值在于运算封闭与参数极简，代价是无法表达多峰后验——第 07 章粒子滤波（FastSLAM）的出发点。
- 联合高斯条件分布引理（式 3.11，分块求逆 + Schur 补）与"最小化后验协方差迹"（式 3.13–3.15）两条路线推出同一个卡尔曼增益 (3.15)。
- 卡尔曼滤波五公式汇总于 (3.17)：预测均值 / 协方差、增益、更新均值 / 协方差。
- EKF = 当前估计处的一阶泰勒展开 + 原封不动的五公式（式 3.18–3.21）；雅可比 $F_t, H_t$ 替代 $A, C$。
- EKF 三类误差（一阶截断、线性化点偏差、不一致性）是第 07 章滤波后端的固有隐患，也是第 08 章转向图优化的动机起点。
