# 第 10 章｜建图与系统实战

第 05、06 章的前端、第 07、08 章的后端、第 09 章的回环各自成立，本章把它们拼成真正能跑的完整系统，并回答定位之外的问题：如何产出机器人真正可用的地图。10.1 以 ORB-SLAM3 为蓝本给出三线程架构与"模块 ↔ 章节 ↔ 论文章节"对应表；10.2 推导本章理论主菜——IMU 预积分（preintegration，Forster et al., T-RO 2017），它让高频 IMU 与低频相机在图优化框架里无缝融合；10.3 以 VINS-Mono 为例把预积分因子与视觉重投影因子装进同一个紧耦合因子图，并论证单目 + IMU 的尺度可观性；10.4 简述稠密建图与神经隐式/高斯泼溅前沿；10.5 实战跑通 ORB-SLAM3。

## 10.1 ORB-SLAM3 三线程架构与理论对应表

**① 问题场景** 手头：第 05 章的跟踪估计、第 08 章的局部 BA、第 09 章的回环检测，每个模块单独推导都成立。缺什么：把它们拼成 30Hz 实时运行的系统——跟踪必须在每帧时间内完成（否则丢帧即漂移），局部 BA 与回环优化的耗时远超帧间隔，若三件事串行执行，实时性立即崩塌；此外跟踪一旦丢失（快速运动、遮挡、剧烈光照变化），单地图系统只能整体重启，前功尽弃。

**② 解决方法** ORB-SLAM3（Campos et al., T-RO 2021）的答案是三个并行线程 + 多地图（Atlas, 地图集）：Tracking（跟踪）线程逐帧定位、决定关键帧；Local Mapping（局部建图）线程维护局部共视图、三角化新路标、做局部 BA；第三线程集中处理所有基于词袋数据库的地点识别——回环检测、地图合并（map merging）、重定位（relocalization）。跟踪丢失时不再重启，而是新建一张活动地图继续运行；之后一旦通过重定位在 Atlas 的旧地图中认出旧地，第三线程执行地图合并（ORB-SLAM3 §III、§VI）。视觉-惯性（visual-inertial, VI）扩展：在视觉之外引入 IMU，用 10.2 的预积分把两关键帧之间的全部 IMU 测量合成为一条运动约束（§V）。

**③ 选型理由** 为什么按"轻—重"分线程：跟踪是实时硬约束，只能做轻量操作（特征提取匹配 + 运动更新）；BA 与回环是重操作，放后台线程异步执行，靠关键帧队列解耦（代价：线程同步与内存管理的工程复杂度）。为什么地点识别集中到一个线程：回环、合并、重定位依赖同一个 DBoW2 数据库查询（第 09 章 (9.3)），复用查询结果、避免三处重复计算。为什么多地图而不是"丢就重启"：重启丢掉全部历史信息，Atlas 用地图合并把中断的两段地图重新缝合，而合并是高风险操作，第 09 章 9.2 的多关键帧高精度验证正是为这种操作设计的。

**④ 理论依据** ORB-SLAM3：Campos et al., "ORB-SLAM3: An Accurate Open-Source Library for Visual, Visual-Inertial and Multimap SLAM", IEEE T-RO 2021；架构承接 ORB-SLAM（Mur-Artal et al., T-RO 2015）的三线程设计。

## 10.2 IMU 预积分：把高频测量压成与初值无关的相对量（本章主菜）

**① 问题场景** IMU（惯性测量单元，Inertial Measurement Unit）以约 200Hz 输出角速度与比力，相机只有约 30Hz——一个数量级的差距。若逐个 IMU 采样建状态节点，因子图规模爆炸；若把两关键帧之间的 IMU 测量在世界系下积分成一条约束，积分式（下文 (10.3)）右端显含积分起点状态 $R_i, \mathbf{v}_i, \mathbf{p}_i$——**初值锚定**：一旦后端优化修正了关键帧 $i$ 的位姿/速度（局部 BA、回环合并都会做这件事），以 $i$ 为起点的全部积分必须从头重算。200Hz 数据 × 后端频繁修正 = 不可承受的计算量。

**② 解决方法** 预积分（preintegration，Forster et al.）：把 $i \to j$ 之间的 IMU 积分**重定义为与初值无关的相对量** $\Delta\tilde{R}_{ij}, \Delta\tilde{\mathbf{v}}_{ij}, \Delta\tilde{\mathbf{p}}_{ij}$——只依赖 IMU 原始测量与偏置估计；它们随 IMU 数据到来增量更新、预计算并缓存；噪声协方差同步增量传播 (10.7)；后端对偏置的小修正用一阶雅可比修正 (10.8)，不触发重新积分。

**③ 选型理由** 与两个替代方案对比： 直接积分（把世界系积分式当约束，后端修正后重算）：数学最简单，但线性化点每次被修正都要重算全部积分——正是①中的死结； EKF 类滤波融合（如 MSCKF）：在线、快，但只线性化一次、历史不可撤回——第 07 → 08 章已经论证过滤波范式的精度上限； 预积分：测量模型 (10.5) 天然独立于状态初值，与图优化框架（第 08 章）无缝对接，噪声模型可在流形上精确推导。代价：一阶（小噪声）近似；偏置被当作分段常数（两关键帧之间），变化靠一阶修正 (10.8)；IMU 噪声参数（噪声密度、零偏随机游走）需标定准确。

**④ 理论依据** Forster, Carlone, Dellaert, Scaramuzza, "On-Manifold Preintegration for Real-Time Visual-Inertial Odometry", IEEE T-RO 2017（本地 PDF：arXiv-1512.02363；下文括注 Eq.(x) 均指该论文编号）；SO(3) 指数/对数映射与 BCH 一阶近似（第 02 章 (2.17)、(2.21)）。

**⑤ 完整推导**（每步括注依据）

第 1 步：IMU 测量模型。陀螺与加计读数含零偏（bias, $\mathbf{b}$）与加性噪声（Forster Eq.(27)）：

$$\hat{\boldsymbol{\omega}}_k = \boldsymbol{\omega}_k + \mathbf{b}^g_k + \boldsymbol{\eta}^g_k, \qquad \hat{\mathbf{a}}_k = \mathbf{a}_k + \mathbf{b}^a_k + \boldsymbol{\eta}^a_k, \tag{10.1}$$

其中 $\boldsymbol{\omega}_k = R_k^\top \dot{R}_k$ 为真实角速度（依据：第 02 章姿态运动学），$\mathbf{a}_k$ 为比力（proper acceleration，静止加计读出 $-\mathbf{g}$ 方向的支撑力）。反解真值：$\boldsymbol{\omega}_k = \hat{\boldsymbol{\omega}}_k - \mathbf{b}^g_k - \boldsymbol{\eta}^g_k$，$\mathbf{a}_k = \hat{\mathbf{a}}_k - \mathbf{b}^a_k - \boldsymbol{\eta}^a_k$。连续时间运动学（依据：陀螺测角速度、加计测"运动加速度 − 重力加速度"，$\mathbf{g}$ 为重力加速度矢量、竖直向下）：

$$\dot{R} = R\big(\hat{\boldsymbol{\omega}} - \mathbf{b}^g - \boldsymbol{\eta}^g\big)^{\wedge}, \qquad \dot{\mathbf{v}} = R\big(\hat{\mathbf{a}} - \mathbf{b}^a - \boldsymbol{\eta}^a\big) + \mathbf{g}, \qquad \dot{\mathbf{p}} = \mathbf{v}. \tag{10.2}$$

第 2 步：世界系积分及其初值依赖。把 (10.2) 在关键帧 $i \to j$ 之间的全部 IMU 采样上迭代积分（矩形法，Forster Eq.(31)→Eq.(32)，依据：每个采样间隔内姿态近似不变，高采样率下近似误差可忽略），得完整积分式：

$$R_j = R_i \prod_{k=i}^{j-1} \mathrm{Exp}\!\Big( (\hat{\boldsymbol{\omega}}_k - \mathbf{b}^g_k - \boldsymbol{\eta}^g_k)\,\Delta t \Big),$$
$$\mathbf{v}_j = \mathbf{v}_i + \mathbf{g}\,\Delta t_{ij} + \sum_{k=i}^{j-1} R_k\big(\hat{\mathbf{a}}_k - \mathbf{b}^a_k - \boldsymbol{\eta}^a_k\big)\,\Delta t,$$
$$\mathbf{p}_j = \mathbf{p}_i + \mathbf{v}_i\,\Delta t_{ij} + \frac{1}{2}\mathbf{g}\,\Delta t_{ij}^2 + \sum_{k=i}^{j-1} R_k\big(\hat{\mathbf{a}}_k - \mathbf{b}^a_k - \boldsymbol{\eta}^a_k\big)\,\frac{\Delta t_k^2}{2}, \tag{10.3}$$

其中 $\Delta t_{ij} = \sum_k \Delta t_k$。观察右端：每个 $R_k$ 都经 $R_k = R_i \cdot (R_i^\top R_k)$ 传导 $R_i$，速度式含 $\mathbf{v}_i$，位置式含 $\mathbf{p}_i$——**初值锚定问题在公式层面的呈现**：一改 $R_i, \mathbf{v}_i, \mathbf{p}_i$，全部乘积与求和项都要重算。

第 3 步：关键变量替换——右乘消去初始姿态。定义相对量（Forster Eq.(33)）：

$$\Delta R_{ij} \triangleq R_i^\top R_j, \qquad \Delta\mathbf{v}_{ij} \triangleq R_i^\top\big(\mathbf{v}_j - \mathbf{v}_i - \mathbf{g}\,\Delta t_{ij}\big), \qquad \Delta\mathbf{p}_{ij} \triangleq R_i^\top\Big(\mathbf{p}_j - \mathbf{p}_i - \mathbf{v}_i\,\Delta t_{ij} - \frac{1}{2}\mathbf{g}\,\Delta t_{ij}^2\Big). \tag{10.4}$$

把 (10.3) 代入 (10.4) 逐项验证解耦。旋转：$R_i^\top R_j = R_i^\top \cdot R_i \cdot \prod_k \mathrm{Exp}(\cdot) = \prod_k \mathrm{Exp}(\cdot)$（依据：矩阵乘法结合律与 $R_i^\top R_i = I$），$R_i$ 被右乘消去。速度：$\mathbf{v}_j - \mathbf{v}_i - \mathbf{g}\Delta t_{ij} = \sum_k R_k(\cdot)\Delta t$，左乘 $R_i^\top$ 后 $R_i^\top R_k = \prod_{m<k}\mathrm{Exp}(\cdot) = \Delta R_{ik}$（依据：(10.3) 旋转式的逐点代入），$R_i$ 消失。位置：同理化为 $\Delta R_{ik}$ 的函数，且 $\mathbf{p}_i, \mathbf{v}_i$ 在 (10.4) 定义中被显式减掉。结论（Forster §VI 的原话化用）：$\Delta\mathbf{v}_{ij}$ 与 $\Delta\mathbf{p}_{ij}$ 已不是物理上的速度/位置变化量，而是**为使右端只依赖 IMU 测量而定义的数学量**——右端只剩 IMU 读数与相对旋转 $\Delta R_{ik}$，与 $R_i, \mathbf{v}_i, \mathbf{p}_i$ 完全解耦。（符号约定注：本推导按 Forster 取 $\mathbf{g}$ 为重力加速度矢量、竖直向下，故 (10.4) 的 $\Delta\mathbf{p}$ 中为 $-\tfrac{1}{2}\mathbf{g}\Delta t^2$，对应论文 Eq.(38)；若把 $\mathbf{g}$ 定义为竖直向上的"重力补偿矢量"（静止加计读数方向），式中相应变为 $+\tfrac{1}{2}\mathbf{g}\Delta t^2$——两版只差 $\mathbf{g}$ 的符号约定，读文献时勿混淆。）

第 4 步：噪声分离与预积分量定义。把噪声从测量中剥离：对旋转用指数映射一阶展开 $\mathrm{Exp}(-\boldsymbol{\eta}^{\wedge}) \approx I - \boldsymbol{\eta}^{\wedge}$（依据：第 02 章 (2.17) 的一阶截断）与噪声右移的邻域交换（依据：第 02 章 BCH 一阶近似 (2.21)），Forster Eq.(35) 得

$$\Delta R_{ij} = \Delta\tilde{R}_{ij}\,\mathrm{Exp}\big(-\delta\boldsymbol{\phi}_{ij}\big), \qquad \Delta\tilde{R}_{ij} \triangleq \prod_{k=i}^{j-1} \mathrm{Exp}\Big( (\hat{\boldsymbol{\omega}}_k - \mathbf{b}^g_i)\,\Delta t \Big),$$

再把 $\delta\boldsymbol{\phi}_{ij}$ 代回 (10.4) 的速度、位置式，仅保留一阶噪声项（Forster Eq.(36)–(37)，依据：$\mathrm{Exp}(-\delta\boldsymbol{\phi}^{\wedge}) \approx I - \delta\boldsymbol{\phi}^{\wedge}$ 展开），定义

$$\Delta\tilde{\mathbf{v}}_{ij} = \sum_{k=i}^{j-1} \Delta\tilde{R}_{ik}\big(\hat{\mathbf{a}}_k - \mathbf{b}^a_i\big)\,\Delta t, \qquad \Delta\tilde{\mathbf{p}}_{ij} = \sum_{k=i}^{j-1} \Big[ \Delta\tilde{\mathbf{v}}_{ik}\,\Delta t + \frac{1}{2}\,\Delta\tilde{R}_{ik}\big(\hat{\mathbf{a}}_k - \mathbf{b}^a_i\big)\,\Delta t_k^2 \Big].$$

带波浪线的三个量只含 IMU 测量与偏置估计——这就是**可在 IMU 数据到来时增量计算并缓存**的预积分量（preintegrated measurements）；每个新采样只需更新乘积/求和的末项，无需重算历史。

第 5 步：预积分测量模型。把第 4 步的三个分离式代回定义 (10.4)（依据：(10.4) 本身），得测量模型（Forster Eq.(38)）：

$$\Delta\tilde{R}_{ij} = R_i^\top R_j\,\mathrm{Exp}\big(\delta\boldsymbol{\phi}_{ij}\big),$$
$$\Delta\tilde{\mathbf{v}}_{ij} = R_i^\top\big(\mathbf{v}_j - \mathbf{v}_i - \mathbf{g}\,\Delta t_{ij}\big) + \delta\mathbf{v}_{ij},$$
$$\Delta\tilde{\mathbf{p}}_{ij} = R_i^\top\Big(\mathbf{p}_j - \mathbf{p}_i - \mathbf{v}_i\,\Delta t_{ij} - \frac{1}{2}\mathbf{g}\,\Delta t_{ij}^2\Big) + \delta\mathbf{p}_{ij}. \tag{10.5}$$

形式为"复合测量 = 状态的函数 + 小噪声"——与第 03 章观测方程 $\mathbf{z} = h(\mathbf{x}) + \mathbf{v}$ 同构，可直接作为因子图的测量模型。

第 6 步：噪声协方差的线性递推。预积分噪声 $\boldsymbol{\eta}^{\Delta}_{ij} = [\delta\boldsymbol{\phi}_{ij}^\top, \delta\mathbf{v}_{ij}^\top, \delta\mathbf{p}_{ij}^\top]^\top$ 近似为零均值高斯 $\mathcal{N}(\mathbf{0}, \Sigma_{ij})$（Forster Eq.(39)）。对旋转噪声重复一阶近似（Forster Eq.(40)–(42)，依据：右雅可比 $J_r$ 在小噪声下接近单位阵的一阶展开），得线性表达：

$$\delta\boldsymbol{\phi}_{ij} \simeq \sum_{k=i}^{j-1} \Delta\tilde{R}_{k+1,j}^\top\, J_r^k\, \boldsymbol{\eta}^g_k\,\Delta t, \tag{10.6}$$

$\delta\mathbf{v}_{ij}$、$\delta\mathbf{p}_{ij}$ 同理是加计噪声 $\boldsymbol{\eta}^a_k$ 与旋转噪声 $\delta\boldsymbol{\phi}_{ik}$ 的线性组合（Forster Eq.(43)）。既然 $\boldsymbol{\eta}^{\Delta}_{ij}$ 是逐采样噪声的线性函数，其协方差按一阶线性传播增量更新（依据：线性化 + 高斯协方差传递，与第 03 章 EKF 预测协方差 (3.9) $\Sigma^- = A\Sigma A^\top + Q$ 完全同构）：

$$\Sigma_{ij} \leftarrow A\,\Sigma_{ij}\,A^\top + B\,\Sigma_{\eta}\,B^\top, \tag{10.7}$$

其中 $\Sigma_{\eta}$ 是单个采样噪声协方差（由数据手册的噪声密度与采样率换算，Forster §V），$A, B$ 为 (10.6) 及其速度/位置对应式对各噪声项的雅可比块，随每个新采样更新（Forster 附录 IX-A 的迭代形式，其线性模型见论文 Eq.(62)）——无需存储历史测量。

第 7 步：偏置修正的一阶雅可比（概要）。预积分时假设偏置在两关键帧间恒定（Forster Eq.(34)），但优化过程中偏置估计会更新 $\mathbf{b} \leftarrow \bar{\mathbf{b}} + \delta\mathbf{b}$。重新积分代价高，Forster 改用一阶泰勒展开直接修正预积分量（Forster Eq.(44)）：

$$\Delta\tilde{R}_{ij}(\mathbf{b}^g_i) \simeq \Delta\bar{R}_{ij}\,\mathrm{Exp}\Big( \frac{\partial\Delta\bar{R}_{ij}}{\partial\mathbf{b}^g}\,\delta\mathbf{b}^g \Big), \qquad \Delta\tilde{\mathbf{v}}_{ij} \simeq \Delta\bar{\mathbf{v}}_{ij} + \frac{\partial\Delta\bar{\mathbf{v}}_{ij}}{\partial\mathbf{b}^g}\,\delta\mathbf{b}^g + \frac{\partial\Delta\bar{\mathbf{v}}_{ij}}{\partial\mathbf{b}^a}\,\delta\mathbf{b}^a, \quad \Delta\tilde{\mathbf{p}}_{ij} \text{ 同理}, \tag{10.8}$$

各雅可比在预积分时可同步预计算（Forster 附录 IX-B），故偏置更新只改一阶项、不触发重新积分——②承诺的"只在 IMU 数据到来时增量更新"至此闭环。

## 10.3 VINS-Mono 与紧耦合因子图

**① 问题场景** 单目视觉恢复的运动与地图带有任意尺度因子（第 05 章三角化的尺度不确定性；第 09 章正是为吸收它才引入 Sim(3)），而机器人导航与控制需要米制尺度和重力方向。手头：单目相机 + IMU（10.2 已把 IMU 压成预积分量）；想要：把视觉观测、IMU 约束、历史信息放进**同一个**优化问题联立求解，且计算量有界。

**② 解决方法** VINS-Mono（Qin, Li & Shen, IEEE T-RO 2018）：滑动窗口（sliding window）内的紧耦合（tightly-coupled）因子图。状态向量 = 窗口内每帧的 $[\mathbf{p}, \mathbf{v}, R, \mathbf{b}^a, \mathbf{b}^g]$ + 各路标的逆深度（inverse depth）$\lambda$。三类因子：IMU 预积分因子（10.2）、视觉重投影因子（第 08 章重投影误差 (8.1) 的逆深度参数化版）、边缘化（marginalization）先验因子；另加 DBoW2 回环因子做全局校正。窗口移出最老帧时对其边缘化、测量化为先验，窗口计算量恒定。

**③ 选型理由** 紧耦合 vs 松耦合：松耦合让视觉里程计与惯性里程计各自独立估计再融合，IMU 信息无法帮助视觉特征匹配与外点剔除，信息利用不充分；紧耦合把原始观测（预积分量已是"压缩过的原始量"）放进同一目标函数，精度更高。优化 vs 滤波：滑窗图优化每次重新线性化，比 EKF 的一次线性化更准；滑窗 + 边缘化保证复杂度有界。逆深度参数化：数值稳定且可表达无穷远点。代价：先验基于旧的线性化点，一致性需以一估雅可比（first-estimate Jacobians）维持（工程细节，定性了解）。

**④ 理论依据** Qin, Li, Shen, "VINS-Mono: A Robust and Versatile Monocular Visual-Inertial State Estimator", IEEE T-RO 2018；Forster 预积分（10.2）；第 08 章因子图、重投影误差 (8.1)、边缘化/Schur 补。

**⑤ 完整推导**

第 1 步：联合目标函数。滑窗内做最大后验估计（依据：各因子独立高斯噪声下，后验 (第 03 章 (3.6)) 的负对数 = 马氏范数之和）：

$$\min_{\mathcal{X}} \; \Bigg\{ \underbrace{\sum_{(i,j) \in \mathcal{I}} \big\| \mathbf{r}_{\mathcal{I}}\big(\tilde{\mathbf{z}}^{\Delta}_{ij}, \mathcal{X}\big) \big\|^2_{\Sigma_{ij}}}_{\text{IMU 预积分因子}} + \underbrace{\sum_{(l, i) \in \mathcal{C}} \big\| \mathbf{r}_{\mathcal{C}}\big(\mathbf{z}^{c_i}_l, \mathcal{X}\big) \big\|^2_{\Sigma^{c_i}_l}}_{\text{视觉重投影因子}} + \underbrace{\big\| \mathbf{r}_{\mathcal{P}} \big\|^2_{H_{\mathcal{P}}}}_{\text{边缘化先验因子}} \Bigg\}. \tag{10.9}$$

第 2 步：IMU 预积分因子残差。由测量模型 (10.5) 移项（依据：残差 = 测量 − 模型预测；旋转项必须取对数映射，保证残差在向量空间中定义，回引第 02 章 (2.25)）：

$$\mathbf{r}_{\Delta R_{ij}} = \mathrm{Log}\Big( \big( \Delta\tilde{R}_{ij}\,\mathrm{Exp}\big( \tfrac{\partial\Delta\bar{R}_{ij}}{\partial\mathbf{b}^g}\,\delta\mathbf{b}^g \big) \big)^{\!\top} R_i^\top R_j \Big)^{\vee}, \qquad \mathbf{r}_{\Delta\mathbf{v}_{ij}} = R_i^\top\big(\mathbf{v}_j - \mathbf{v}_i - \mathbf{g}\,\Delta t_{ij}\big) - \Delta\tilde{\mathbf{v}}_{ij} - \frac{\partial\Delta\bar{\mathbf{v}}_{ij}}{\partial\mathbf{b}}\,\delta\mathbf{b}, \tag{10.10}$$

$\mathbf{r}_{\Delta\mathbf{p}_{ij}}$ 同理。视觉因子残差：把第 08 章重投影误差 (8.1) 中路标的 XYZ 参数换成"首帧观测像素坐标 + 逆深度 $\lambda$"（依据：投影由第 04 章相机模型完成，参数化只改路标的表示、不改残差结构），故第 08 章的雅可比、Hessian 稀疏性与正规方程 (8.5) 全部沿用。

第 3 步：单目 + IMU 为何尺度可观（可观性论证概要）。纯单目情形：对整条轨迹与地图做相似变换 $\mathbf{x} \to s\mathbf{x}$（$s > 0$）后所有投影不变（依据：齐次投影对整体尺度不敏感，第 04–05 章投影方程），尺度是规范自由度（gauge freedom，单目共 4 维：全局 yaw + 全局平移 + 尺度）中视觉观测无法钉死的一维——第 09 章需要 Sim(3) 本身就是证据。加入 IMU 后：预积分因子 (10.10) 右端的 $\Delta\tilde{\mathbf{v}}_{ij}, \Delta\tilde{\mathbf{p}}_{ij}$ 由加计读数积分而来，带物理单位（m/s、m）；若把轨迹缩放 $s$ 倍，视觉项不变而 IMU 残差被放大 $s$ 倍——方程组不再自洽，尺度 $s$ 因此唯一确定；同理重力矢量 $\mathbf{g}$ 的大小与方向出现在 (10.10) 中，把世界系的滚转与俯仰对齐重力。结论（VINS-Mono §V 可观性分析）：单目 VIO 不可观的只剩 4 自由度——全局 yaw 与 3 个平移；尺度与横滚/俯仰（roll/pitch）均由 IMU 钉住。

第 4 步：边缘化维持滑窗。移出最老帧时，把与它相连的全部因子按第 08 章 Schur 补边缘化，得到剩余状态上的先验因子（依据：第 08 章边缘化结论——消元后信息矩阵相加；VINS-Mono §IV-D 明确"marginalization is carried out using the Schur complement"）：

$$p(\mathbf{x}_{\mathrm{remain}}) \;\propto\; \exp\Big( -\frac{1}{2}\big\| \mathbf{r}_{\mathcal{P}} + H_{\mathcal{P}}\,\delta\mathbf{x} \big\|^2 \Big). \tag{10.11}$$

先验因子 (10.11) 作为一条边留在因子图中，历史信息不丢失而窗口规模恒定——与第 09 章位姿图"只留位姿节点"是同一思想（先边缘化，再小规模优化）。

## 10.4 稠密建图与前沿（简短）

**① 问题场景** 特征法 SLAM 的地图只有稀疏路标——定位够用，但导航避障、机械臂抓取需要稠密或半稠密几何。

**② 解决方法** 两条路：ORB-SLAM2 起提供可选的稠密输出线程——对每个关键帧按深度/视差反投影并融合成稠密（RGB-D）或半稠密（单目）点云，与定位线程并行；RGB-D 配置下更进一步的标准做法是 TSDF（截断符号距离场，Truncated Signed Distance Field）融合，把逐帧深度图累积成连续表面，系统推导与实现见 [3D 重建教程第 04 章](../3d_reconstruction/04_RGB-D融合与TSDF.md)。

**③ 选型理由** 显式 TSDF：增量融合、内存可截断控制、几何可直接查询，但表示分辨率受体素限制；神经隐式（NeRF 系）与 3D 高斯（3DGS 系）：把地图变成可微表示，渲染质量高、支持新视角合成，但更新与内存代价大（定性对比，详见下表各论文）。

**④ 理论依据** TSDF 体素融合（Curless & Levoy, SIGGRAPH 1996）；3D 高斯泼溅（Kerbl et al., SIGGRAPH 2023）；ORB-SLAM2 稠密输出（Mur-Artal & Tardós, T-RO 2017）。

**⑤ 路线归纳**（**导读性内容，不含理论推导——豁免**）前沿七篇各代表一条路线：

| 论文（本地 PDF 见 papers/slam/frontier/） | 路线一句话 |
|---|---|
| DROID-SLAM | 端到端可微 BA：循环神经网络迭代更新稠密光流场与位姿，把第 08 章 BA 装进可微优化层 |
| NeRF-SLAM | 几何 SLAM（DROID-SLAM）负责跟踪 + 神经隐式特征体素场负责稠密建图，实时单目 |
| GS-SLAM | 3D 高斯泼溅做显式辐射场地图，随跟踪结果自适应扩展高斯，RGB-D / 单目 |
| SplaTAM | 以单颗高斯为地图原子（反投影点 + 各向同性协方差），光度残差跟踪、逐高斯增长地图 |
| MonoGS | 可微渲染同时服务跟踪与建图：位姿与高斯在同一渲染损失下联合优化 |
| MASt3R-SLAM | 用学习型两视图 3D 重建先验（MASt3R 点图）替代手工几何，实时单目稠密 SLAM |
| VGGT-GS SLAM | 前馈 3D 几何基础模型（VGGT）提供几何先验 + 3DGS 增量建图 |

共同趋势：把"局部几何与外观"交给可微表示或基础模型，把传统 SLAM 的因子图/位姿图保留为全局一致性的骨架——第 08、09 章的内容并未过时，而是被当作骨架复用。

## 10.5 实战：跑通 ORB-SLAM3（EuRoC）

**操作步骤，不含理论**（§3.4 豁免）。依赖（OpenCV、Eigen、Pangolin 等）的版本要求随仓库更新变动，以下为通用流程，细节以仓库 README 为准。

1. **克隆与编译**：

```bash
git clone https://github.com/UZ-SLAMLab/ORB_SLAM3.git ORB_SLAM3
cd ORB_SLAM3
chmod +x build.sh
./build.sh
```

`build.sh` 先编译 `Thirdparty/` 下的 DBoW2 与 g2o——正是第 09 章 (9.1)–(9.3) 词袋与第 08 章 (8.5)、第 09 章 (9.8) 图优化的库实现——再 CMake 主工程。若在较新的 OpenCV/Pangolin 版本上编译报错，按仓库 issue 区的兼容性补丁微调。

2. **下载 EuRoC MAV 数据集**（如 `MH_01_easy`，ASL 格式 zip），解压后保持 `mav0/` 目录结构（相机、IMU 与时间戳子目录不可改名）。

3. **运行**（单目-惯性示例；双目-惯性等入口见 `Examples/` 各子目录的 `.sh` 脚本，参数顺序以脚本为准）：

```bash
./Examples/Monocular/mono_euroc \
    Vocabulary/ORBvoc.txt \
    Examples/Monocular/EuRoC.yaml \
    <EuRoC路径>/MH_01_easy \
    <EuRoC路径>/MH_01_easy/mav0/cam0/data
```

4. **观察三件事**：Pangolin 窗口中三线程的协同（跟踪逐帧更新、局部地图增长、回环/合并触发时的地图整体跳变——对应 10.1 表）；终端结束打印的平均轨迹误差（ATE）——EuRoC 上为厘米级（精确数字以论文 §VII 表格为准）；跟踪丢失时 Atlas 新建地图、重定位成功后合并的过程（对应 10.1 多地图机制）。

5. **代码模块 ↔ 各章理论对应表**（与 10.1 表互为镜像，供走读源码时定位）：

## 本章要点

- ORB-SLAM3 = Tracking + Local Mapping + (Loop Closing & Map Merging) 三线程 + Atlas 多地图；模块 ↔ 章节 ↔ 论文章节对应见 10.1 表。
- IMU 预积分核心思想：世界系积分 (10.3) 初值锚定 → 重定义为相对量 (10.4) → 与初值无关、可增量计算的测量模型 (10.5)（Forster Eq.(27)、(32)、(33)、(38)）。
- 预积分噪声协方差按一阶线性递推 (10.7)，与 EKF 协方差传播（第 03 章 (3.9)）同构；偏置变化用一阶雅可比修正 (10.8)（Forster Eq.(44)），避免重新积分。
- 紧耦合因子图目标 (10.9)：IMU 预积分因子 (10.10) + 视觉重投影因子（第 08 章 (8.1)）+ 边缘化先验 (10.11)。
- 单目 + IMU 的可观性：加计提供比力大小与重力方向 → 尺度、roll/pitch 可观，仅剩 4 自由度（全局 yaw + 平移）gauge。
- 滑窗边缘化（第 08 章 Schur 补）维持计算量有界，先验因子保住历史信息。
- 稠密地图：ORB-SLAM2 稠密线程与 TSDF 融合（[3D 重建教程第 04 章](../3d_reconstruction/04_RGB-D融合与TSDF.md)）；前沿七篇（DROID-SLAM、NeRF-SLAM、GS-SLAM、SplaTAM、MonoGS、MASt3R-SLAM、VGGT-GS SLAM）把可微表示/基础模型嫁接在传统 SLAM 骨架上。
