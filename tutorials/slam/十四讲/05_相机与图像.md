## 5.1 本章定位

第 2 讲的观测方程 $z_{k,j} = h(\mathbf{y}_j, x_k) + \mathbf{v}$ 中，$h$ 一直是黑盒。
本讲把它打开：相机如何把三维世界压成二维像素。这条投影链是第 7 讲对极几何、
第 8 讲直接法、第 10 讲 BA 共同的物理基础；同时看清单目"深度丢失"的本质——
它解释了为什么需要三角化（讲 7）、双目/RGB-D（本讲）、以及稠密重建（讲 13）。

## 5.2 学习目标

1. 逐步推出针孔模型与内参矩阵 $K$（D5-1），并指出 (2.2) 中 $h$ 的显式形式；
2. 写出径向/切向畸变模型，解释"畸变发生在归一化平面"（D5-2）；
3. 推导双目视差–深度关系 (5.6)（D5-3）；
4. 了解 RGB-D 两类测距原理及图像在内存中的表示方式。

## 5.3 问题场景（五步法①）

**手头**：三维世界里一个点 $\mathbf{P}_w$（第 2 讲的路标 $\mathbf{y}_j$）、相机在世界中的位姿
（第 3 讲的 $T_{cw}$）。
**缺**：从 $\mathbb{R}^3$ 到图像平面的映射规则——光穿过透镜发生什么？
**想要**：能写入 (2.2) 的显式 $h(\cdot)$，及其逆过程（供第 7 讲三角化反解深度）。

## 5.4 核心内容

### 5.4.1 D5-1：针孔相机模型与内参矩阵（五步法）

**② 解决方法**：针孔（小孔成像）近似——忽略透镜物理，只保留几何投影。
**③ 选型理由**：透镜真实成像（薄透镜公式）在小孔近似下误差远小于像素量化误差，
且模型仅 5 个参数，可标定；代价是不含失焦与畸变（畸变单独建模，见 D5-2）。
**④ 理论依据**：中心投影（透视）几何 + 相似三角形。

**⑤ 完整推导。**

**第一步（世界系 → 相机系，外参）。** 设相机位姿 $T_{cw} = \begin{bmatrix}R & \mathbf{t}\\\mathbf{0}^\top&1\end{bmatrix}$
（世界系到相机系的变换，下标次序约定：$T_{cw}$ 把世界坐标变为相机坐标）：

$$\mathbf{P}_c = R\,\mathbf{P}_w + \mathbf{t} = [X,\ Y,\ Z]^\top$$

（依据：D3-2 刚体变换；$Z > 0$ 为相机前方，约定光轴指向 $+Z$。）

**第二步（相机系 → 归一化平面）。** 过光心的光线与 $Z = 1$ 平面的交点
（依据：相似三角形——三角形 $(O, (X, Y, Z))$ 与 $(O, (x, y, 1))$ 相似，比例 $1/Z$）：

$$\mathbf{x}_{nor} = \Big[\frac{X}{Z},\ \frac{Y}{Z}\Big]^\top \tag{5.1}$$

这一步**丢掉 $Z$**——深度的第一处丢失，也是单目尺度不确定的根源。

**第三步（归一化平面 → 像素平面）。** 单位距离对应的像素数 = 焦距 $f$（单位：像素/米），
光学中心在图像中的位置 = 主点 $(c_x, c_y)$（依据：传感器像元排列 + 光轴落点）：

$$u = f_x\,\frac{X}{Z} + c_x, \qquad v = f_y\,\frac{Y}{Z} + c_y \tag{5.2}$$

（$f_x = f\,s_x$、$f_y = f\,s_y$：像元物理尺寸 $s_x, s_y$ 可能不等，故分开记。）

**第四步（合并为矩阵形式）。** 用齐次坐标吸收 $1/Z$（依据：齐次坐标下除以末分量等价于
逐分量除）：

$$\tilde{\mathbf{P}}_{uv} = \begin{bmatrix}u\\v\\1\end{bmatrix} = \frac{1}{Z}\begin{bmatrix}f_x & 0 & c_x\\0 & f_y & c_y\\0&0&1\end{bmatrix}\begin{bmatrix}X\\Y\\Z\end{bmatrix} = \frac{1}{Z}\,K\,\mathbf{P}_c, \qquad
K = \begin{bmatrix}f_x & 0 & c_x\\0 & f_y & c_y\\0&0&1\end{bmatrix} \tag{5.3}$$

$K$ 即**内参矩阵**（相机出厂 + 标定决定；外参 $R, \mathbf{t}$ 则随位姿变化）。

**第五步（全链与 $h$ 的显式形式）。** 合并两步：

$$\tilde{\mathbf{P}}_{uv} = \frac{1}{Z}\,K\,\big(R\,\mathbf{P}_w + \mathbf{t}\big)$$

记 $\pi(\mathbf{P}_c) = \big[f_x X/Z + c_x,\ f_y Y/Z + c_y\big]^\top$，则第 2 讲的观测模型为

$$z_{k,j} = \pi\big(K,\ T_{k,cw},\ \mathbf{y}_j\big) + \mathbf{v}_{k,j}$$

第 7 讲（对极几何归一化坐标）、第 8 讲（直接法投影求导）、第 10 讲（BA 重投影误差）
都从这条链出发。

**讨论**：① 主点不必在图像中心（装配公差）；② $Z \le 0$ 的点在相机"背后"，
投影无物理意义——第 7 讲 cheirality 检查的由来；③ 鱼眼/广角超出针孔适用范围，
用等距投影等模型（OpenCV `fisheye` 模块，概念级）。

### 5.4.2 D5-2：畸变模型（五步法）

**① 问题场景**：真实透镜不是理想针孔——直线拍出来变弯（径向）、成像整体有"歪斜"
（切向）。若不建模，第 7 讲的对极约束会系统性失配。

**② 解决方法**：在**归一化平面**上叠加多项式修正（先去畸变，再走 (5.2)(5.3)）。

**③ 选型理由**：为什么在归一化平面建模？畸变由光线穿过透镜的几何偏差造成，
发生在"角度域"——归一化平面正是角度的线性表示；若在像素平面建模，模型会随 $f$、分辨率变化，
失去可移植性。多项式取前几阶即可把残余误差压到亚像素。

**④ 理论依据**：径向——关于光轴旋转对称的偏差只能依赖 $r = \sqrt{x^2+y^2}$ 的偶次幂；
切向——透镜与成像平面不平行，一阶近似即薄棱镜（light rays 偏转）模型。

**⑤ 完整推导（模型本身是物理近似，推导 = 论证各项的来源）。**

**径向畸变**（桶形/枕形，透镜研磨形状所致）：对称性 ⟹ 修正量 $\propto \mathbf{x}\,g(r^2)$，
取 $g(r^2) = k_1 r^2 + k_2 r^4$：

$$x_d = x\,(1 + k_1 r^2 + k_2 r^4), \qquad y_d = y\,(1 + k_1 r^2 + k_2 r^4) \tag{5.4}$$

**切向畸变**（装配不平行所致，薄棱镜模型给出 $\propto (r^2 + 2x^2, r^2 + 2y^2)$ 的偶对称形式）：

$$x_d = x + 2p_1\,xy + p_2\,(r^2 + 2x^2), \qquad y_d = y + p_1\,(r^2 + 2y^2) + 2p_2\,xy \tag{5.5}$$

（依据：(5.4)(5.5) 为畸变的**正向**模型——从理想坐标到带畸变坐标。）

**去畸变流程**（依据：与成像过程相反的链）：
像素 $\tilde{\mathbf{P}}_{uv}$ → (5.3) 的逆得带畸变的归一化坐标 $(x_d, y_d)$ → 解 (5.4)(5.5) 的
反问题得 $(x, y)$（纯径向时可逐次迭代 $x \leftarrow (x_d)/(1 + k_1 r^2 + k_2 r^4)$ 收敛；
一般用查表 LUT 一次完成）→ (5.2)(5.3) 正向投影。

### 5.4.3 D5-3：双目相机模型（五步法）

**① 问题场景**：单目一张图定不出深度（(5.1) 丢 $Z$）。
**② 解决方法**：两个平行光轴的相机水平相隔基线 $b$——同一 3D 点在两幅图中的
横坐标不同（视差），由几何反解深度。
**③ 选型理由**：被动、实时、无外同步需求（对比 RGB-D）；代价是视差对远处趋零、
需标定/校正使光轴严格平行。
**④ 理论依据**：三角测距（相似三角形）。

**⑤ 推导。** 设左相机系下点坐标 $(X, Y, Z)$。左相机投影（依据：(5.2)）：
$u_L = f\tfrac{X}{Z} + c_x$。右相机原点在左相机 $-X$ 方向偏移 $b$（约定右相机在左相机
"$-b$ 处"，也可取 $+b$，符号随约定），故右相机系下 $X_R = X - b$：

$$u_R = f\,\frac{X - b}{Z} + c_x$$

两式相减（依据：代数），主点项相消：

$$d \equiv u_L - u_R = \frac{f\,b}{Z} \quad\Longrightarrow\quad \boxed{\ Z = \frac{f\,b}{d}\ } \tag{5.6}$$

**读数**：深度与视差成**反比**。视差测量误差 $\delta d$ 引起深度误差
$\delta Z = \frac{fb}{d^2}\,\delta d$——近处（$d$ 大）准、远处（$d \to 0$）爆炸；
且 $Z \to \infty$ 时 $d \to 0$，视差到达亚像素以下即不可测。这解释了：
双目测距的有效量程（写作时给 $Z$–$d$ 曲线图）、以及讲 13 稠密重建在远处的困难。

### 5.4.4 RGB-D 相机（概念，无推导）

两类原理（依据：物理测距器件，非几何推算）：
- **结构光**（如 Kinect v1）：向场景投射已知编码图案，由图案形变按三角测距反算深度
  （室内精度好；室外红外干扰、多机互扰）；
- **ToF**（飞行时间，如 Kinect v2）：测量光脉冲往返时间差，直接得距离
  （与纹理无关；存在多径/材质反射误差）。
输出 = 彩色图 + 逐像素深度图，配准后每个像素即一个 3D 点——为讲 8 直接法、讲 13 稠密建图
提供"现成深度"。

### 5.4.5 图像在计算机中的表示（背景知识）

- 图像 = 二维网格：`rows × cols`，每格 1（灰度）或 3–4（BGR/RGBA）通道，8/16 位；
- 内存布局按行主序连续存储；`row = v`、`col = u`——**行列与 $u,v$ 的对应**是实践第一坑；
- 相机以 30 Hz 产图，处理需考虑时间戳与曝光（第 8 讲灰度不变假设的现实约束）。

## 5.5 实践任务

- **操作步骤，不含理论**（豁免声明）：书 §5.3/5.4——OpenCV 读写与遍历、
  图像去畸变（`cv::initUndistortRectifyMap` + `remap`）、五张 RGB-D 拼成点云（PCL/自写）。
- 关键代码骨架（对照 (5.3) 与 (5.4)(5.5)）：

```cpp
// 像素 -> 归一化平面 -> 去畸变 -> 3D 点（拼接点云的核心三行）
double xd = (u - cx) / fx, yd = (v - cy) / fy;          // (5.3) 的逆：像素到"带畸变"归一化平面
double r2 = xd*xd + yd*yd;                               // r^2
double x = xd*(1 + k1*r2 + k2*r2*r2) + 2*p1*xd*yd + p2*(r2 + 2*xd*xd);   // (5.4)(5.5) 反解（一次近似）
double Z = depth.at<unsigned short>(v, u) / 1000.0;      // 深度（毫米 -> 米）
P << x*Z, y*Z, Z;                                        // 相机系 3D 点
```

  `projects/3d_reconstruction/`（点云与深度图处理）。

## 5.6 易错点与高频疑问

1. **外参方向**：$T_{cw}$（世界→相机）还是 $T_{wc}$？投影用前者，反投影用后者；
   书与本系列统一 $T_{cw}$。
2. **去畸变的平面**：在归一化平面做，不是在像素平面（D5-2 ③）；
3. **$f_x \ne f_y$**：像元非正方形时二者不等，$K$ 不能用单一 $f$；
4. **双目基线符号**：视差 $d$ 的定义与 $b$ 的方向绑定，负视差说明点在相机后方或标定有误；
5. **深度图的无效值**（0 或 65535）：拼接点云前必须过滤，否则出现"拉丝"。

## 5.8 本章要点

- 投影链：外参（刚体变换）→ 归一化平面 (5.1) → 像素 (5.2) → 矩阵形式 (5.3)；
  这就是 (2.2) 中 $h$ 的显式形式。
- 畸变 (5.4)(5.5) 发生在归一化平面；去畸变后所有几何（第 7 讲起）都假设针孔模型成立。
- 双目：$Z = fb/d$ (5.6)，深度精度随距离平方衰减。
- 单目尺度不确定 = (5.1) 丢失 $Z$ 的必然——全书后续一切"恢复深度"的手段
  （三角化/双目/RGB-D/深度滤波）都在补这一步的窟窿。
