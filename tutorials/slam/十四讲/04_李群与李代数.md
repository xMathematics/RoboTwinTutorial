## 4.1 本章定位

第 3 讲回答了"旋转怎么**表示**"，但优化问题（第 6 讲起）需要的是"旋转怎么**求导**"：
对 $R$ 做梯度下降、对 $T\mathbf{p}$ 求雅可比。障碍：$SO(3)$ 不是向量空间——
$R + \Delta$ 一般不再是旋转。本讲建立通道：

$$\underbrace{SO(3)/SE(3)}_{\text{弯曲的群}} \xrightleftharpoons[\ln]{\exp} \underbrace{\mathfrak{so}(3)/\mathfrak{se}(3)}_{\text{平直的向量空间}}$$

所有"对位姿的求导"都搬进右边的向量空间完成，再用指数映射搬回去。

## 4.2 学习目标

1. 复述群与李代数的公理，写出 so(3)、se(3) 的具体形态与括号运算（D4-1）；
2. 从幂级数出发推导 SO(3)/SE(3) 的指数映射（D4-2/D4-3）；
3. 说清 BCH 一阶近似解决什么问题，写出 $J_l/J_r$ 及其小角度形式（D4-4）；
4. **独立推导扰动模型雅可比 (4.10)(4.11)**（D4-5）——本书最重要的两行公式。

## 4.3 问题场景（五步法①）

**手头**：一个含旋转的待优化量，如"调整位姿 $R$ 使重投影误差最小"。
**缺**：梯度下降需要一个能做加法的变量空间，而 $R$ 上 $R_1 + R_2 \notin SO(3)$
（验证：$R^\top R = I$ 是非线性约束，加法破坏它）；直接对 9 个元素独立优化还会破坏 $\det = 1$。
**想要**：一个与 $SO(3)$ 一一对应（局部）、结构平直的参数空间，以及两个空间之间
光滑互转的机制与求导规则。

## 4.4 核心内容

### 4.4.1 D4-1：群、李代数与 so(3)/se(3)（五步法）

**② 解决方法**：先承认 $SO(3)$ 是**李群**（有光滑流形结构的群），然后用它在**单位元处的切空间**
（一个普通的向量空间！）配上"括号"运算，得到李代数。

**③ 选型理由**：为什么选切空间而不是别的参数化？切空间天然绑定单位元、随群结构自带
微分机制（第 4.4.5 节的求导规则全部由它导出），且维数最小（3 / 6 维）。

**④ 理论依据**：李群–李代数对应定理（任何有限维李群的单位元切空间配括号构成李代数，
反之亦然；参考 Varadarajan, *Lie Groups, Lie Algebras, and Their Representations*）。

**⑤ 推导。**

**群公理**（书 §4.1.1）：集合 $G$ 配运算 $\cdot$ 满足：封闭、结合、幺元、逆。
$SO(3)$、$SE(3)$ 对矩阵乘法逐条满足（D3-2 已验证 SE(3)）；对**加法**不满足
（$R_1 + R_2$ 不正交）——所以要做乘法群，不做加法群。

**李代数公理**（书 §4.1.3）：向量空间 $V$ 配双线性运算 $[\cdot,\cdot]$ 满足：
自反性 $[X,X]=0$；Jacobi 恒等式 $[X,[Y,Z]] + [Y,[Z,X]] + [Z,[X,Y]] = 0$。

**so(3) 的具体形态**。$SO(3)$ 单位元处的切空间由正交条件微分得到：
对曲线 $R(t) \in SO(3)$，$R(0) = I$，求导 $R^\top R = I$：
$\dot{R}^\top R + R^\top\dot{R} = 0$，在 $t=0$（$R=I$）处 $\dot{R}^\top + \dot{R} = 0$
（依据：正交性对每时刻成立，逐时间求导）——切向量是**反对称矩阵**。
三维反对称矩阵与 $\mathbb{R}^3$ 同构（$\wedge/\vee$ 记号）：$\mathfrak{so}(3) = \{\boldsymbol{\phi}^{\wedge}\}$。

**括号 = 叉积**。李代数需要括号 $[\Phi, \Psi] = \Phi\Psi - \Psi\Phi$。对两个叉积矩阵：

$$\big[\boldsymbol{\phi}^{\wedge},\ \boldsymbol{\psi}^{\wedge}\big] = (\boldsymbol{\phi}\times\boldsymbol{\psi})^{\wedge} \tag{4.1}$$

*推导*：两边作用于任意 $\mathbf{c}$。左边 $= \boldsymbol{\phi}\times(\boldsymbol{\psi}\times\mathbf{c}) - \boldsymbol{\psi}\times(\boldsymbol{\phi}\times\mathbf{c})$；
用**二重叉积展开公式** $\mathbf{a}\times(\mathbf{b}\times\mathbf{c}) = \mathbf{b}(\mathbf{a}\cdot\mathbf{c}) - \mathbf{c}(\mathbf{a}\cdot\mathbf{b})$（依据：向量恒等式，可由分量展开验证）：

$$\text{左边} = \big[\mathbf{b}\text{ 式代入}\big] = \boldsymbol{\psi}(\boldsymbol{\phi}\cdot\mathbf{c}) - \mathbf{c}(\boldsymbol{\phi}\cdot\boldsymbol{\psi}) - \boldsymbol{\phi}(\boldsymbol{\psi}\cdot\mathbf{c}) + \mathbf{c}(\boldsymbol{\psi}\cdot\boldsymbol{\phi}) = \boldsymbol{\psi}(\boldsymbol{\phi}\cdot\mathbf{c}) - \boldsymbol{\phi}(\boldsymbol{\psi}\cdot\mathbf{c}) = (\boldsymbol{\phi}\times\boldsymbol{\psi})\times\mathbf{c} = \text{右边}$$

（末步再次使用二重叉积公式，注意 $(\boldsymbol{\phi}\times\boldsymbol{\psi})\times\mathbf{c} = -\mathbf{c}\times(\boldsymbol{\phi}\times\boldsymbol{\psi})$ 反向代入。）
由 $\mathbf{c}$ 任意，矩阵相等。**so(3) 的括号就是三维叉积**——Jacobi 恒等式即叉积的
$[\mathbf{a}\times,\mathbf{b}\times]$ 循环和，自动成立。

**se(3)**（书 §4.1.5）：$SE(3)$ 的切空间配平移分量：

$$\boldsymbol{\xi} = \begin{bmatrix}\boldsymbol{\rho}\\ \boldsymbol{\phi}\end{bmatrix} \in \mathbb{R}^6, \qquad
\boldsymbol{\xi}^{\wedge} = \begin{bmatrix}\boldsymbol{\phi}^{\wedge} & \boldsymbol{\rho}\\ \mathbf{0}^\top & 0\end{bmatrix} \in \mathbb{R}^{4\times4}, \qquad \mathfrak{se}(3) = \{\boldsymbol{\xi}^{\wedge}\}$$

（依据：对曲线 $T(t) = \begin{bmatrix}R(t)&\mathbf{t}(t)\\\mathbf{0}^\top&1\end{bmatrix}$ 在单位元求导，
$\dot{T}(0) = \begin{bmatrix}\dot{R}(0)&\dot{\mathbf{t}}(0)\\\mathbf{0}^\top&0\end{bmatrix}$，旋转块为反对称。）

### 4.4.2 D4-2：SO(3) 上的指数映射（五步法）

**① 问题场景**：有了 $\mathfrak{so}(3)$，需要一个从"向量"回"旋转"的光满射。
**② 解决方法**：矩阵指数 $\exp$。
**③ 选型理由**：指数映射是李群理论给出的**唯一**与李代数兼容的映射（它把"加法方向"
变为"乘法方向"，且满足一阶 $\exp(\boldsymbol{\phi}^{\wedge}) \approx I + \boldsymbol{\phi}^{\wedge}$）。
**④ 理论依据**：矩阵指数 + 正交矩阵的幂关系。

**⑤ 完整推导。**

**第一步（定义）。** $R = \exp(\boldsymbol{\phi}^{\wedge}) = \sum_{k=0}^{\infty} \dfrac{(\boldsymbol{\phi}^{\wedge})^k}{k!}$。

**第二步（幂关系）。** 归一化 $\boldsymbol{\phi} = \theta\mathbf{n}$，$\|\mathbf{n}\| = 1$。
对任意 $\mathbf{x}$：$\mathbf{n}^{\wedge 2}\mathbf{x} = \mathbf{n}\times(\mathbf{n}\times\mathbf{x})
= \mathbf{n}(\mathbf{n}\cdot\mathbf{x}) - \mathbf{x}(\mathbf{n}\cdot\mathbf{n}) = (\mathbf{n}\mathbf{n}^\top - I)\mathbf{x}$（依据：二重叉积公式），
故

$$\mathbf{n}^{\wedge 2} = \mathbf{n}\mathbf{n}^\top - I, \qquad
\mathbf{n}^{\wedge 3} = \mathbf{n}^{\wedge}\big(\mathbf{n}\mathbf{n}^\top - I\big) = \underbrace{(\mathbf{n}\times\mathbf{n})}_{\mathbf{0}}\mathbf{n}^\top - \mathbf{n}^{\wedge} = -\mathbf{n}^{\wedge} \tag{4.2}$$

**第三步（奇偶分治）。** 由 (4.2) 对 $m$ 归纳（每次乘一个 $\mathbf{n}^{\wedge 2}$）：
$\mathbf{n}^{\wedge 2m} = (-1)^m(I - \mathbf{n}\mathbf{n}^\top)$，$\mathbf{n}^{\wedge(2m+1)} = (-1)^m\mathbf{n}^{\wedge}$。
代回级数并按奇偶重组：

$$R = \underbrace{\sum_m \frac{(-1)^m\theta^{2m}}{(2m)!}}_{\cos\theta}(I - \mathbf{n}\mathbf{n}^\top) + \underbrace{\sum_m \frac{(-1)^m\theta^{2m+1}}{(2m+1)!}}_{\sin\theta}\mathbf{n}^{\wedge}$$

（依据：$\cos$、$\sin$ 的 Taylor 级数逐项对号。）

$$\boxed{\ R = \cos\theta\, I + (1 - \cos\theta)\,\mathbf{n}\mathbf{n}^\top + \sin\theta\,\mathbf{n}^{\wedge}\ } \tag{4.3}$$

与第 3 讲 Rodrigues 公式 (3.3) 一致——幂级数自然重推出了它。

**第四步（闭合性：$\exp$ 确实落在 $SO(3)$ 里）。** 由 (4.3)：
$R^\top R$：对称项 $\cos\theta I + (1-\cos\theta)\mathbf{n}\mathbf{n}^\top$ 与自身乘积展开
（利用 $\mathbf{n}\mathbf{n}^\top$ 幂等），反对称项交叉相消：

$$R^\top R = \big(\cos^2\theta + \sin^2\theta\big)\big(I - \mathbf{n}\mathbf{n}^\top\big) + \mathbf{n}\mathbf{n}^\top = I$$

$\det R$：$R$ 的特征值为 $\{1, e^{\pm i\theta}\}$（不动轴 $\mathbf{n}$ 与 (4.3) 在正交补平面上的
旋转角 $\theta$，依据：D3-3 第一步），故 $\det R = 1$。

**第五步（对数映射）。** 反向通道直接复用第 3 讲 (3.4)(3.5)：
$\theta = \arccos\big(\tfrac{\operatorname{tr}R - 1}{2}\big)$，$\mathbf{n} = (R - R^\top)^{\vee}/(2\sin\theta)$。

### 4.4.3 D4-3：SE(3) 上的指数映射（五步法⑤）

**第一步（矩阵幂的归纳）。** 记 $A = \boldsymbol{\xi}^{\wedge} = \begin{bmatrix}\boldsymbol{\phi}^{\wedge}&\boldsymbol{\rho}\\\mathbf{0}^\top&0\end{bmatrix}$。
$k=1$ 成立；设 (4.4) 对 $k$ 成立，则

$$A^{k+1} = \begin{bmatrix}(\boldsymbol{\phi}^{\wedge})^k & (\boldsymbol{\phi}^{\wedge})^{k-1}\boldsymbol{\rho}\\ \mathbf{0}^\top&0\end{bmatrix}\begin{bmatrix}\boldsymbol{\phi}^{\wedge}&\boldsymbol{\rho}\\\mathbf{0}^\top&0\end{bmatrix}
= \begin{bmatrix}(\boldsymbol{\phi}^{\wedge})^{k+1} & (\boldsymbol{\phi}^{\wedge})^{k}\boldsymbol{\rho}\\\mathbf{0}^\top&0\end{bmatrix} \tag{4.4}$$

（依据：分块乘法——右上块 $= (\boldsymbol{\phi}^{\wedge})^k\boldsymbol{\rho} + (\boldsymbol{\phi}^{\wedge})^{k-1}\boldsymbol{\rho}\cdot 0$。）

**第二步（求和）。** $\exp(A) = \sum_k A^k/k!$：左上块 $= \exp(\boldsymbol{\phi}^{\wedge})$（即 (4.3)）；
右上块 $= \sum_{k\ge1}\frac{(\boldsymbol{\phi}^{\wedge})^{k-1}}{k!}\boldsymbol{\rho} = \Big(\sum_{m\ge0}\frac{(\boldsymbol{\phi}^{\wedge})^m}{(m+1)!}\Big)\boldsymbol{\rho}$（换元 $m = k-1$）。
对 $m$ 奇偶分离（依据：D4-2 第三步同法，$\frac{(\boldsymbol{\phi}^{\wedge})^m}{(m+1)!} = \frac{\theta^m}{(m+1)!}\cdot\frac{\boldsymbol{\phi}^{m\wedge}}{\theta^m}$）：

$$J(\boldsymbol{\phi}) = \frac{\sin\theta}{\theta} I + \Big(1 - \frac{\sin\theta}{\theta}\Big)\mathbf{n}\mathbf{n}^\top + \frac{1-\cos\theta}{\theta}\,\mathbf{n}^{\wedge} \tag{4.5}$$

**结论**：$\exp(\boldsymbol{\xi}^{\wedge}) = \begin{bmatrix}\exp(\boldsymbol{\phi}^{\wedge}) & J\boldsymbol{\rho}\\\mathbf{0}^\top&1\end{bmatrix} = T$。
**关键读数**：平移分量必须经过 $J(\boldsymbol{\phi})$ 加权，**不能**把 $\boldsymbol{\rho}$ 直接当 $\mathbf{t}$
——新手最常见错误；$\theta\to 0$ 时 $J \to I$，小旋转下才退化成立。
注意 (4.5) 的 $J$ 与下节 $J_l$ 是**同一个函数**（4.7）——这不是巧合，第 4.4.5 节会用到。

### 4.4.4 D4-4：BCH 近似与左右雅可比（五步法）

**① 问题场景**：优化是"加增量"：$R \leftarrow R \oplus \Delta R$。若把增量搬到李代数做加法
$\boldsymbol{\phi} + \Delta\boldsymbol{\phi}$，两端指数化后是否还原 $\exp(\Delta\boldsymbol{\phi}^{\wedge})\exp(\boldsymbol{\phi}^{\wedge})$？
——不还原（旋转不可交换）。需要精确刻画"李群乘法在李代数上加法中长什么样"。

**② 解决方法**：BCH（Baker–Campbell–Hausdorff）公式给出
$\ln(\exp(A)\exp(B))$ 的完整级数；SLAM 只用**对 $B$ 的一阶截断**。

**③ 选型理由**：高阶项在增量场景（$\Delta$ 小）中是 $O(\|\Delta\|^2)$，截断一次已足够；
截断公式让"乘一个增量"完全变成"李代数上加一个修正向量"——优化的全部语法。

**④ 理论依据**：BCH 公式（Campbell–Baker–Hausdorff 定理）；微分方程法（书 §4.3.1）。

**⑤ 推导（微分方程法框架，中间恒等式逐一具名）。**

**第一步（设置）。** 令
$$F(t) = \ln\big(\exp(\boldsymbol{\Delta}^{\wedge})\exp(t\boldsymbol{\phi}^{\wedge})\big), \qquad F(0) = \boldsymbol{\Delta}^{\wedge}$$
目标是 $F(1)$（$\boldsymbol{\Delta}$ 为小量，$\boldsymbol{\phi}$ 固定）。

**第二步（右平凡化导数恒等式）。** 对曲线 $\exp(X(t))$：
$$\frac{\mathrm{d}}{\mathrm{d}t}\exp(X) = \exp(X)\,\big(J_r(X)\,X'\big)^{\wedge}
\ \Longrightarrow\ J_r(F)F' = \exp(-F)\,\frac{\mathrm{d}}{\mathrm{d}t}\exp(F)$$
（依据：矩阵指数的右平凡化微分公式，见 Varadarajan 或书 §4.3.1 的引出。）

**第三步（乘积求导 + 伴随）。** $\exp(F) = \exp(\boldsymbol{\Delta}^{\wedge})\exp(t\boldsymbol{\phi}^{\wedge})$ 求导
（乘积法则）：$\frac{\mathrm{d}}{\mathrm{d}t}\exp(F) = \exp(F)\boldsymbol{\phi}^{\wedge} + \boldsymbol{\Delta}^{\wedge}\exp(F)$，
故
$$J_r(F)F' = \boldsymbol{\phi}^{\wedge} + \exp(-F)\,\boldsymbol{\Delta}^{\wedge}\exp(F) = \boldsymbol{\phi}^{\wedge} + \mathrm{Ad}_{\exp(-F)}\,\boldsymbol{\Delta}^{\wedge}$$
（依据：伴随共轭 $gXg^{-1} = \mathrm{Ad}_g\,X$；伴随的指数表示 $\mathrm{Ad}_{\exp(X)} = \exp(\mathrm{ad}_X)$，
其中 $\mathrm{ad}_X Y = [X, Y]$。）

**第四步（对小量 $\boldsymbol{\Delta}$ 的一阶保留）。** 零阶：$F = t\boldsymbol{\phi}^{\wedge} + O(\boldsymbol{\Delta})$，
且恒等式 $J_r(X)X = X$（由 $\exp(X)\exp(-X) = I$ 求导即得）给出零阶解 $F' = \boldsymbol{\phi}^{\wedge}$。
一阶修正：代入 $F \approx t\boldsymbol{\phi}^{\wedge}$、$\mathrm{Ad}_{\exp(-F)} = \exp(-t\,\mathrm{ad}_{\boldsymbol{\phi}})$：

$$F'(t) \approx \boldsymbol{\phi}^{\wedge} + J_r(t\boldsymbol{\phi})^{-1}\,e^{-t\,\mathrm{ad}_{\boldsymbol{\phi}}}\,\boldsymbol{\Delta}^{\wedge}$$

积分 $t\in[0,1]$ 并使用级数 $J_r(t\boldsymbol{\phi})^{-1} = \dfrac{t\,\mathrm{ad}_{\boldsymbol{\phi}}}{e^{t\,\mathrm{ad}_{\boldsymbol{\phi}}} - 1}$
（依据：右雅可比逆的算子级数，由 $\ln(\exp(X)\exp(\delta)) = X + \frac{\mathrm{ad}_X}{e^{\mathrm{ad}_X}-1}\delta + O(\delta^2)$ 逐项比较系数得到；
被积函数化简 $t\,\mathrm{ad}\,e^{t\,\mathrm{ad}}/(e^{t\,\mathrm{ad}}-1) = \dfrac{t\,\mathrm{ad}}{1 - e^{-t\,\mathrm{ad}}}$），得

$$F(1) = \boldsymbol{\phi}^{\wedge} + \underbrace{\Big[\int_0^1 \frac{t\,\mathrm{ad}_{\boldsymbol{\phi}}}{1 - e^{-t\,\mathrm{ad}_{\boldsymbol{\phi}}}}\,\mathrm{d}t\Big]}_{\text{算子级数 } =\, \mathrm{ad}_{\boldsymbol{\phi}}/(1 - e^{-\mathrm{ad}_{\boldsymbol{\phi}}})}\ \boldsymbol{\Delta}^{\wedge} + O(\|\boldsymbol{\Delta}\|^2)$$

（积分算子级数 $\dfrac{\mathrm{ad}}{1 - e^{-\mathrm{ad}}} = 1 + \tfrac12\mathrm{ad} + \tfrac1{12}\mathrm{ad}^2 - \tfrac1{720}\mathrm{ad}^4 + \cdots$
——Bernoulli 数级数，逐项可由 $\frac{x}{1-e^{-x}}$ 的 Laurent 展开核对。）

**第五步（读出结论）。** 重新指数化：

$$\exp(\boldsymbol{\Delta}^{\wedge})\,\exp(\boldsymbol{\phi}^{\wedge}) = \exp\Big(\big(\boldsymbol{\phi} + J_l(\boldsymbol{\phi})^{-1}\boldsymbol{\Delta}\big)^{\wedge}\Big) + O(\|\boldsymbol{\Delta}\|^2) \tag{4.6}$$

其中系数算子定义为**左雅可比的逆**：

$$J_l(\boldsymbol{\phi})^{-1} = I - \tfrac12\boldsymbol{\phi}^{\wedge} + \tfrac1{12}(\boldsymbol{\phi}^{\wedge})^2 + \cdots \quad\Longleftrightarrow\quad J_l(\boldsymbol{\phi}) = \frac{\sin\theta}{\theta} I + \Big(1-\frac{\sin\theta}{\theta}\Big)\mathbf{n}\mathbf{n}^\top + \frac{1-\cos\theta}{\theta}\mathbf{n}^{\wedge} \tag{4.7}$$

（闭式与 (4.5) 的 $J$ 同形——把 (4.7) 的闭式展开为 $\boldsymbol{\phi}$ 的级数
$I + \tfrac12\boldsymbol{\phi}^{\wedge} + \tfrac16(\boldsymbol{\phi}^{\wedge})^2 + \tfrac1{24}(\boldsymbol{\phi}^{\wedge})^3 + \cdots$（即 $\sum_k\frac{\boldsymbol{\phi}^{k\wedge}}{(k+1)!}$）
再求逆，与上面算子级数逐项吻合；右雅可比 $J_r(\boldsymbol{\phi}) = J_l(-\boldsymbol{\phi})$，
小量在**右**侧时 $\exp(\boldsymbol{\phi}^{\wedge})\exp(\boldsymbol{\delta}^{\wedge}) = \exp((\boldsymbol{\phi} + J_l\boldsymbol{\delta})^{\wedge})$、
$J_r^{-1} = I + \tfrac12\boldsymbol{\phi}^{\wedge} + \tfrac1{12}(\boldsymbol{\phi}^{\wedge})^2 + \cdots$——写作与读代码时务必分清小量在哪侧。）

**小角度形式**（依据：$\frac{\sin\theta}{\theta} = 1 - \frac{\theta^2}{6} + \cdots$、
$1 - \frac{\sin\theta}{\theta} = O(\theta^2)$、$\frac{1-\cos\theta}{\theta} = \frac{\theta}{2} - \frac{\theta^3}{24} + \cdots$）：

$$J_l \approx I + \tfrac12\boldsymbol{\phi}^{\wedge}, \qquad J_r \approx I - \tfrac12\boldsymbol{\phi}^{\wedge} \tag{4.8}$$

### 4.4.5 D4-5：李代数求导与扰动模型（五步法，本讲落脚点）

**① 问题场景**：求 $\dfrac{\partial (R\mathbf{p})}{\partial \boldsymbol{\phi}}$——第 6 讲 GN 的
$\mathbf{J}$、第 7/8/10 讲所有残差雅可比的基本积木。

**② 解决方法**：两条路线——对李代数自身加增量的"求导模型"，与把增量定义在李群
一侧的"扰动模型"。

**③ 选型理由**：求导模型结果里多一个 $J_l$ 因子、随工作点变化；扰动模型的雅可比
**不含 $J_l$**、与工作点无关——工程上一律用扰动模型。

**④ 理论依据**：BCH 一阶近似（4.6）+ 一阶泰勒。

**⑤ 完整推导。**

**路线一（求导模型）。** 给 $\boldsymbol{\phi}$ 加 $\Delta\boldsymbol{\phi}$。先用 (4.6) 换序——
把 $\exp\big((\boldsymbol{\phi}+\Delta\boldsymbol{\phi})^{\wedge}\big)$ 写成"小增量 × 原旋转"：
在 (4.6) 中令右端李代数为 $\boldsymbol{\phi} + \Delta\boldsymbol{\phi}$，则左因子
$= \exp\big((J_l(\boldsymbol{\phi})\,\Delta\boldsymbol{\phi})^{\wedge}\big)$（依据：(4.6) 移项，令 $J_l^{-1}\boldsymbol{\Delta}' = \Delta\boldsymbol{\phi}$）。于是

$$\exp\big((\boldsymbol{\phi}+\Delta\boldsymbol{\phi})^{\wedge}\big)\mathbf{p}
= \exp\big((J_l\Delta\boldsymbol{\phi})^{\wedge}\big)\,R\mathbf{p}
\approx \big(I + (J_l\Delta\boldsymbol{\phi})^{\wedge}\big)R\mathbf{p}
= R\mathbf{p} + (J_l\Delta\boldsymbol{\phi})\times(R\mathbf{p})$$

$$= R\mathbf{p} - (R\mathbf{p})^{\wedge}\,J_l(\boldsymbol{\phi})\,\Delta\boldsymbol{\phi}
\ \Longrightarrow\ \frac{\partial(R\mathbf{p})}{\partial\boldsymbol{\phi}} = -(R\mathbf{p})^{\wedge}\,J_l(\boldsymbol{\phi}) \tag{4.9}$$

（依据：一阶 $\exp(\boldsymbol{\varepsilon}^{\wedge}) \approx I + \boldsymbol{\varepsilon}^{\wedge}$；
$\mathbf{a}\times\mathbf{b} = -\mathbf{b}^{\wedge}\mathbf{a}$。$J_l$ 因子随工作点变化，不便。）

**路线二（扰动模型，左乘）。** 把扰动定义为**作用在李群左侧**：
$R' = \exp(\delta\boldsymbol{\phi}^{\wedge})\,R$——即"先做一个微小旋转，再做原旋转"。

$$R'\mathbf{p} = \big(I + \delta\boldsymbol{\phi}^{\wedge}\big)R\mathbf{p}
= R\mathbf{p} + \delta\boldsymbol{\phi}\times(R\mathbf{p})
= R\mathbf{p} - (R\mathbf{p})^{\wedge}\,\delta\boldsymbol{\phi}$$

$$\boxed{\ \frac{\partial\,(R\mathbf{p})}{\partial\,\delta\boldsymbol{\phi}} = -\,(R\mathbf{p})^{\wedge}\ } \tag{4.10}$$

（依据：同上；**无 $J_l$**——雅可比是把旋转后的点变成反对称矩阵的线性算子，
形式与工作点无关。）注：对"点坐标"求导时左右扰动结果相同；对位姿自身增量求导时
左右形式经伴随矩阵换算（[第 08 章](../08_后端-ii图优化与-ba.md)与第 11 讲处理该情形）。

**SE(3) 扰动模型。** $T' = \exp(\delta\boldsymbol{\xi}^{\wedge})\,T$，
$\delta\boldsymbol{\xi} = [\delta\boldsymbol{\rho}^\top,\ \delta\boldsymbol{\phi}^\top]^\top$。
记 $\mathbf{q} = T\mathbf{p} = R\mathbf{p} + \mathbf{t} = [q_1, q_2, q_3]^\top$，分块展开
（依据：$\boldsymbol{\xi}^{\wedge}$ 定义 + (4.10) 的机制）：
$\delta\boldsymbol{\rho}$ 直接平移点（左上块 $I$）；
$\delta\boldsymbol{\phi}$ 绕原点旋转点（叉积块，即 (4.10)）：

$$T'\mathbf{p} = \mathbf{q} + \delta\boldsymbol{\rho} + \delta\boldsymbol{\phi}\times\mathbf{q} = T\mathbf{p} + \delta\boldsymbol{\rho} - \mathbf{q}^{\wedge}\,\delta\boldsymbol{\phi}$$

$$\boxed{\ \frac{\partial\,(T\mathbf{p})}{\partial\,\delta\boldsymbol{\xi}} = \Big[\ I\ \Big|\ -(T\mathbf{p})^{\wedge}\ \Big]\ \in \mathbb{R}^{3\times6}\ } \tag{4.11}$$

## 4.6 易错点与高频疑问

1. **$J_l$ vs $J_r$**：由"小量在乘积的哪一侧"决定，不由"叫什么"决定。判别口诀：
   小量在左 ⟹ (4.6) 用 $J_l^{-1}$；小量在右 ⟹ 用 $J_l$（或等价地 $J_r^{-1}$ 的 ⊞ 形式）。
   第 11 讲位姿图雅可比是 $\pm J_r^{-1}$，正来自小量在右的 ⊞ 展开。
2. **SE(3) 平移漏乘 $J$**：$\exp(\boldsymbol{\xi}^{\wedge})$ 的平移是 $J\boldsymbol{\rho}$（(4.5)），
   不是 $\boldsymbol{\rho}$。
3. **扰动模型里又乘 $J_l$**：(4.10) 的干净形式正是扰动模型存在的理由；
   若推导结果冒出 $J_l$，检查是否把"求导模型"的增量混进了"扰动模型"。
4. **$(R\mathbf{p})^{\wedge}$ 的符号**：结果里是**负**号（$\mathbf{a}\times\mathbf{b} = -\mathbf{b}^{\wedge}\mathbf{a}$），
   抄错符号会使 GN 收敛到镜像解。
5. **"$\boldsymbol{\phi}$ 能当普通向量优化吗"**：不能直接加（超过小角度后 (4.8) 失效）；
   正确语法是"李代数增量 + 指数映射回李群"，这正是 (4.6) 提供的。

4. 手推 (4.9) 的两行，再手推 (4.10)——指出 $J_l$ 因子在哪一步消失。
5. 证明 (4.11)：分别计算 $\delta\boldsymbol{\rho}$、$\delta\boldsymbol{\phi}$ 对 $T\mathbf{p}$ 的作用。
6. （数值）用差分验证 (4.10)(4.11)，并画出截断误差 (4.6) 随 $\|\boldsymbol{\Delta}\|$ 的对数图——斜率应为 2。

## 4.8 本章要点

- 李群李代数：$SO(3)/SE(3)$ 是群非向量空间；切空间 + 括号 = $\mathfrak{so}(3)/\mathfrak{se}(3)$，
  so(3) 的括号即叉积 (4.1)。
- 指数映射：(4.3)（由 (4.2) 幂关系 + 级数重组）；SE(3) 版本带平移加权 (4.5)。
- BCH 一阶 (4.6)：李群乘法 → 李代数加法的桥梁；$J_l/J_r$ (4.7)(4.8)；
  小量在左/右侧决定用 $J_l^{-1}$ 还是 $J_l$（$J_r^{-1}$）。
- **扰动模型 (4.10)(4.11)**：全书所有对位姿的雅可比由此出发，无 $J_l$ 因子。
