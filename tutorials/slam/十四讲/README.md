## 与其他资源的关系

- **主题教程（10 章）**：[../README.md](../README.md) 从概率机器人视角组织同一内容，
  推导更深的场合（连通性论证、边缘化守恒、IMU 预积分）指向那边，不重复；
- **论文精读（18 篇）**：[../精读/README.md](../精读/README.md)，各讲"配套阅读"给出对应篇目；
- **代码**：[projects/slam/](../../../projects/slam/README.md)（纯 numpy 教学实现，
  公式与本系列编号逐一对应）与 [slambook2](https://github.com/gaoxiang12/slambook2)（书配套 C++）。

## 建议读法

1. 顺序通读讲 2–7（最短主干），再按需进入 8–13；讲 4 的 (4.10)(4.11) 必须吃透——
   后续所有雅可比都是它的代换；
2. 每讲先看"问题场景"，再读推导，最后用"自检题"闭卷验收；
3. 关键公式在 `projects/slam/` 中都有可运行对应（如 (4.10) ↔ `core/lie.py`、
   (10.10)–(10.11) ↔ `photoba/` 的 Schur 求解、(11.2) ↔ `vins/` 位姿图），建议对照跑通。
