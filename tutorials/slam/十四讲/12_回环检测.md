## 12.1 本章定位

前端只看"相邻几帧"，误差因此累积成漂移——局部对、全局歪。
回环检测是唯一能提供**长程约束**的模块：走回走过的地方时"认出来"，
给第 11 讲的位姿图插上一条高信息量的边，漂移被一次性拉平。
本章解决三个问题：怎么评价（P-R）、怎么认（词袋）、认错了怎么办（验证）。

## 12.2 学习目标

1. 推导准确率/召回率 (12.1)，并论证 SLAM 场景下 P 优先于 R；
2. 说清词袋的建模动机（丢什么、换什么）与字典的 $k$ 叉树结构；
3. 会计算 TF-IDF 权重 (12.2) 与 L1 相似度 (12.3)，并解释每项的构成；
4. 列出检测后验证的机制及其针对的失效模式。

## 12.3 问题场景（五步法①）

**手头**：当前帧 + 历史关键帧库（数百到数千帧）。
**缺**：快速判断"当前场景是否见过"的手段——用特征点做几何匹配太慢
（$O(N^2)$ 对匹配）且视角/光照变化下不可靠。
**想要**：毫秒级、对视角有一定鲁棒性的"眼熟度"打分；误报必须极少
（认错地方 = 破坏地图）。

## 12.4 核心内容

### 12.4.1 D12-1：回环的意义与评价（五步法）

**② 解决方法**：外观法——比较图像的"内容指纹"，不做几何匹配。
**③ 选型理由**：几何法（拿当前特征与历史特征一一配对验证）准但慢且依赖初值；
外观法（词袋）$O(\log W)$ 查询、视角鲁棒；代价：丢弃空间信息 ⟹ 必须后置几何验证
（D12-2 第五步）。
**④ 理论依据**：检测理论（混淆矩阵）、信息检索（词袋模型源于文本检索）。

**⑤ 推导（评价指标）。** 对每个"当前帧–历史帧"判定，相对真值分四种：
TP（真回环判为回环）、FP（**误报**：新地方判为旧地）、FN（漏报）、TN。
按定义：

$$\text{准确率 } P = \frac{TP}{TP + FP}, \qquad \text{召回率 } R = \frac{TP}{TP + FN} \tag{12.1}$$

**SLAM 语境的不对称性（本讲最重要的论证）**：FP 的代价是把位姿图"焊死"到错误位置——
**破坏**整张地图；FN 只是有一次漂移没被纠正。两者代价极端不对称 ⟹
阈值选择偏向高准确率（宁漏勿错），评价看 **P–R 曲线**而非单点
（写作时给不同字典规模/阈值下的 P-R 曲线示例，书 §12.5 的实验）。
漂移的代数形态（依据：前端误差叠加）：$\hat{x}_k = x_k + \epsilon_k$，$\epsilon_k$
近似随机游走——每条回环边等价于给 (11.1) 加一个 $\|\mathbf{e}_{ij}\|$ 很小但
信息量很大的约束，把 $\epsilon_k$ 的累积"归零"。

### 12.4.2 D12-2：词袋模型、字典与相似度（五步法）

**② 解决方法**：三步——把图像离散成"单词集合"（视觉单词）；
离线聚类建字典；在线查字典生成稀疏向量并打分。

**③ 选型理由**：丢弃空间/顺序信息（换来旋转、视角、局部遮挡的鲁棒性）；
用"单词有无 + 频度"代替几何匹配（换来对数复杂度）；代价：
外观相似的**不同**地点（两间一样的办公室）会撞车——几何验证不可省。

**④ 理论依据**：文本信息检索的词袋模型（Bag-of-Words）+ TF-IDF 加权；
聚类树索引。

**⑤ 推导与建模细节。**

**第一步（视觉单词）。** 每个局部特征（如 ORB 描述子）= 一"单词"；
图像 = 单词的无序袋。旋转不变性由描述子继承（第 7 讲灰度质心 BRIEF）。

**第二步（字典：$k$ 叉树）。** 对海量描述子做层次 $k$-means：根节点分 $k$ 簇，
每簇递归 $d$ 层 ⟹ $W = k^d$ 个叶节点，每个叶 = 一个单词（依据：聚类中心即
"原型描述子"）；查找沿树 $O(\log W)$（依据：树深 $d$）。离线构建一次，
在线只查不改（增量更新是进阶话题，书 §12.5 讨论）。

**第三步（TF-IDF 权重）。** 图像 $j$ 的单词 $i$ 权重：

$$\eta_i = n_{ij}\cdot\log\Big(\frac{N}{f_j}\Big) \tag{12.2}$$

两项的构成依据：
- **TF 项** $n_{ij}$（词频）：单词 $i$ 在图像 $j$ 出现 $n_{ij}$ 次——出现越多，
  越能代表这张图像（一张图全是"墙"单词，说明它确实是一面墙）；
- **IDF 项** $\log(N/f_j)$（逆文档频率）：$N$ 帧语料中仅 $f_j$ 帧含单词 $i$——
  越罕见区分度越高；无处不在的词（如通用的"边缘"单词）权重趋零。
  （两者相乘 = "这张图特有、且别处少见"的单词才显著——信息检索的标准论证。）

**第四步（相似度）。** 每幅图像表示为 $\mathbf{v} = \{\eta_i\}$，按 L1 归一化
$\|\mathbf{v}\|_1 = 1$（依据：消除图像内单词总数差异）。相似度：

$$s(A, B) = 1 - \tfrac12\,\|\mathbf{v}_A - \mathbf{v}_B\|_1 \in [0, 1] \tag{12.3}$$

*推导（值域与端点）*：同一图像 → 差向量 $\mathbf{0}$ → $s = 1$；
支撑集完全不相交（两图无公共单词）→ $\|\mathbf{v}_A - \mathbf{v}_B\|_1
= \|\mathbf{v}_A\|_1 + \|\mathbf{v}_B\|_1 = 2$ → $s = 0$；单调性显然。
（写作时补一句：$L1$ 而非 $L2$ 的选型依据——词袋向量高度稀疏，$L1$ 对
稀疏分布的差异更敏感、且无平方放大效应。）

**第五步（实用化四件套，书 §12.5——每条针对一种失效）**：

| 机制 | 规则 | 针对的失效 |
|------|------|-----------|
| 字典规模试验 | $k, d$ 网格试验，看 P-R 曲线选型 | 字典太大泛化差（同物不同词）、太小区分差（异物同词） |
| 组归一化 | 与历史 $s$ 的均值比较（$\bar{s}$ 相对量） | 光照/纹理整体波动导致绝对阈值漂移 |
| 关键帧密度控制 | 相近帧不重复入库；回环后一段时间抑制 | 连环误报；同一段路反复触发 |
| **检测后验证** | 时间一致性（连续多帧命中同一历史帧）+ 几何验证（对匹配特征 RANSAC 求解 PnP/对极约束，检查内点数） | FP——外观撞车（重复结构、相似房间） |

其中**几何验证是防 FP 的最后闸门**：词袋只负责"提名候选"，
"是否真回环"由几何一致性裁决——内点数达标才生成 (11.1) 的回环边并进位姿图。
（回引：验证用的 PnP = 第 7 讲 D7-4，信息矩阵 = 第 10 讲 Ω 的语义。）

## 12.6 易错点与高频疑问

1. **只看词袋分数**：外观撞车是常态不是意外，几何验证是必需品；
2. **字典与特征不配套**：ORB 字典（ORB 描述子聚类）配 BRISK 特征 = 全部单词查不到；
3. **绝对阈值**：不同数据集的 $s$ 分布差异大，组归一化 + P-R 曲线选阈值才可移植；
4. **回环边信息矩阵乱给**：与验证环节的几何不确定度脱节，位姿图要么过刚要么过软；
5. **"词袋 = 深度学习特征吗"**：不是——经典词袋用手工描述子聚类；
   现代变体（NetVLAD 等）用学习特征，接口不变（第 14 讲展望）。

- P-R (12.1)：SLAM 中 P 优先（FP 破坏地图）；评价看曲线。

  TF-IDF (12.2) 加权 + L1 相似度 (12.3)。
