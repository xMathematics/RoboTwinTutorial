## 7.1 本章定位

前端第一课：从两帧图像恢复相机运动与 3D 结构。按"对应关系长什么样"分三类问题，
每类有专门解法——这是本讲的骨架：

| 问题 | 已知 | 求解 | 方法 |
|------|------|------|------|
| 2D-2D | 两帧匹配点 | 相对运动 + 初始化 | 对极几何（本讲 D7-1/2） |

| 3D-3D | 两组 3D 点（RGB-D/已三角化） | 位姿 | ICP（D7-5） |

## 7.3 问题场景（五步法①）

**手头**：相邻两帧图像 + 一堆像素坐标对 $\{\mathbf{p}_1, \mathbf{p}_2\}$（怎么来的见 §7.4.1）。
**缺**：相机运动 $R, \mathbf{t}$ 与匹配点的 3D 位置。
**想要**：每帧毫秒级地估计 $\Delta T$，并把新观测的地图点插入地图——这就是视觉里程计。

## 7.4 核心内容

### 7.4.1 特征点与 ORB（原理级，书 §7.1）

匹配的前提是"同一物理点在不同视角下能被重复找到"——特征点需满足**可重复性、
可区分性、局部性、高效**。ORB = 三件套（依据：Rublee et al., ORB, ICCV 2011）：

1. **FAST 角点**：以像素 $p$ 为圆心、半径 3 的圆周上 16 个像素，若有连续 $N \ge 9$ 个
   显著亮于（或暗于）中心（超过阈值 $t$），判定为角点（依据：角点 = 各方向都有灰度突变；
   $N=9$ 由统计选优）。解决"哪里是好点"。
2. **图像金字塔（尺度不变）**：对图像做高斯金字塔，在每层提 FAST——目标出现在
   远/近时落在不同层，匹配跨层完成。解决"远近不变"。
3. **灰度质心法 + Steer BRIEF（旋转不变）**：定义图像矩
   $m_{pq} = \sum_{x,y \in \mathcal{B}} x^p y^q I(x, y)$（依据：图像矩定义，$\mathcal{B}$ 为小块），
   质心相对形心的方向角 $\theta = \operatorname{atan2}(m_{01}, m_{10})$ 作为主方向；
   BRIEF 描述子（随机点对灰度比较 → 二进制串）按 $\theta$ 旋转采样模式后生成——
   旋转同一物体得到相同描述子。解决"怎么描述与匹配"（Hamming 距离 + 最近邻 +
   比值检验剔除歧义匹配）。

特征匹配后即得本讲全部求解器的输入。

### 7.4.2 D7-1：对极约束、本质矩阵与基础矩阵（五步法）

**① 问题场景**：2D-2D——两组像素坐标对，求 $R, \mathbf{t}$。
**② 解决方法**：对极几何——同一 3D 点的两次投影与两光心共面，该约束只含 $R,\mathbf{t}$ 不含深度。
**③ 选型理由**：约束与深度无关 ⟹ 可从纯 2D 对应中"滤出"运动；代价：单目尺度不确定
（见 ⑤ 第六步读数）。
**④ 理论依据**：中心投影 + 共面条件。
**⑤ 完整推导（每一步的依据见行内标注）。**

**第一步（去内参）。** 由第 5 讲 (5.3) 的逆，把像素坐标变为归一化坐标
（依据：$\mathbf{x} = K^{-1}\mathbf{p}$，前提：已去畸变）：

$$\mathbf{x}_1 = K^{-1}\mathbf{p}_1, \qquad \mathbf{x}_2 = K^{-1}\mathbf{p}_2$$

**第二步（同一 3D 点的坐标关系）。** 设该点在相机 1 系下深度为 $s_1$（即坐标 $s_1\mathbf{x}_1$）。
它在相机 2 系下的坐标 = 相机 1 系坐标经刚体变换 $(R, \mathbf{t})$（依据：第 3 讲 D3-2，
相机 2 的原点与轴向相对相机 1 的位姿），而在相机 2 系下它又可写为 $s_2\mathbf{x}_2$：

$$s_2\,\mathbf{x}_2 = s_1\,R\,\mathbf{x}_1 + \mathbf{t} \tag{7.1}$$

**第三步（左乘 $\mathbf{t}^{\wedge}$ 消平移）。**

$$s_2\,\mathbf{t}^{\wedge}\mathbf{x}_2 = s_1\,\mathbf{t}^{\wedge}R\,\mathbf{x}_1 + \underbrace{\mathbf{t}^{\wedge}\mathbf{t}}_{\mathbf{0}} = s_1\,\mathbf{t}^{\wedge}R\,\mathbf{x}_1 \tag{7.2}$$

（依据：$\mathbf{t}^{\wedge}\mathbf{t} = \mathbf{t}\times\mathbf{t} = \mathbf{0}$——**平移项被精确消去**，
这正是"约束不含深度与 3D 点"的机制。）

**第四步（左乘 $\mathbf{x}_2^\top$ 消深度）。**

$$s_2\,\mathbf{x}_2^\top\mathbf{t}^{\wedge}\mathbf{x}_2 = s_1\,\mathbf{x}_2^\top\mathbf{t}^{\wedge}R\,\mathbf{x}_1$$

左侧 $= s_2\,\mathbf{x}_2\cdot(\mathbf{t}\times\mathbf{x}_2) = 0$（依据：混积含公共向量必为零）；
$s_1 \ne 0$ 约去：

$$\boxed{\ \mathbf{x}_2^\top\,\mathbf{t}^{\wedge}R\,\mathbf{x}_1 = 0\ }\qquad
E := \mathbf{t}^{\wedge}R \tag{7.3}$$

**第五步（像素坐标版本）。** 代回 $\mathbf{x} = K^{-1}\mathbf{p}$（依据：转置逆 $(K^{-1})^\top = K^{-\top}$）：

$$\mathbf{p}_2^\top\,K^{-\top}E\,K^{-1}\,\mathbf{p}_1 = 0 \qquad F := K^{-\top}E\,K^{-1} \tag{7.4}$$

$E$ = **本质矩阵**（相机系），$F$ = **基础矩阵**（像素系）。
几何解读：给定 $\mathbf{p}_1$，(7.4) 是 $\mathbf{p}_2$ 平面上的一条直线方程——**极线**；
匹配搜索从 2D 降为 1D（第 13 讲极线搜索直接复用）。

**第六步（$E$ 的自由度与秩，逐条推导）。**
- 3×3 = 9 个元素；尺度等价（$\mathbf{x}_2^\top(cE)\mathbf{x}_1 = c\cdot 0 = 0$，约束为零齐次 ⟹
  $E$ 与 $cE$ 等价）⟹ −1；秩 2（$\det E = \det\mathbf{t}^{\wedge}\cdot\det R = 0 \cdot 1 = 0$，
  依据：叉积矩阵有一个零特征值）⟹ −1。合计 **5 自由度**（五点法的理论下限；
  八点法用 8+ 对点线性解且忽略秩约束后投影修正）。

### 7.4.3 D7-2：八点法、E→R,t 分解与单应矩阵（五步法⑤）

**八点法（线性求解 $F/E$）。**
1. 展开约束为线性形式：$\mathbf{p}_2^\top F\mathbf{p}_1 = 0$ 按元素展开
   （依据：逐项乘开）：

$$\big[u_2u_1,\ u_2v_1,\ u_2,\ v_2u_1,\ v_2v_1,\ v_2,\ u_1,\ v_1,\ 1\big]\,\mathbf{f} = 0, \qquad \mathbf{f} = \mathrm{vec}(F) \in \mathbb{R}^9$$

2. ≥8 对点堆叠 $A\mathbf{f} = \mathbf{0}$；解 = $A$ 最小奇异值对应的右奇异向量
   （依据：齐次线性方程在 $\|\mathbf{f}\| = 1$ 下的最小二乘解即最小右奇异向量 / Rayleigh 商）；
   把 $\mathbf{f}$ 重排为矩阵，SVD 强制秩 2（置最小奇异值为零后重构）。
3. **归一化八点法**：先平移缩放坐标到 $[-1,1]^2$（$\tilde{\mathbf{p}} = T\mathbf{p}$，解 $T^{-\top}FT^{-1}$）
   （依据：像素量级 $10^3$ 使 $A$ 各列量级悬殊、条件数恶化；归一化后数值稳定——Hartley 建议的标准流程）。

**E → (R, t) 分解。** 设 $E = U\Sigma V^\top$（SVD），令
$W = \begin{bmatrix}0&-1&0\\1&0&0\\0&0&1\end{bmatrix}$（绕 z 轴 +90°）。四个候选
（依据：$W$ 正交且 $\det W = +1$，保证 $R$ 候选正交且 $\det = +1$；$U\,W\Sigma\,U^\top$
保持反对称——写作时给一行验证 $W\mathbf{z}^\wedge W^\top = (W\mathbf{z})^\wedge$ 型对易关系）：

$$R \in \{UWV^\top,\ UW^\top V^\top\}, \qquad \mathbf{t}^{\wedge} \in \{\,UW\Sigma U^\top,\ UW^\top\Sigma U^\top\,\} \quad \text{（与 } R \text{ 配对）} \tag{7.5}$$

**筛选两道闸**：① $\det R = +1$（物理旋转；不满足者丢弃或取负修正）；
② 对每个幸存候选做三角化（D7-3），取**所有匹配深度为正**的唯一解
（依据：cheirality——真实点必在两相机前方，$Z > 0$，第 5 讲已埋）。

**读数（尺度不确定性）**：$E$ 的尺度等价 ⟹ $\mathbf{t}$ 只差一个尺度因子——
**单目初始化时 $\|\mathbf{t}\|$ 任意约定（通常取 1）**，后续轨迹与地图都继承这个尺度。
另两个失效场景：纯旋转（$\mathbf{t} = \mathbf{0} \Rightarrow E = \mathbf{0}$）与纯平面上观测
→ 用下面的 $H$。

**单应矩阵 H（书 §7.3.3）。** 场景：3D 点落在平面 $\mathbf{n}^\top P = 1$ 上
（世界尺度归一到平面方程，依据：平面方程齐次可缩放）。由 (7.1)（把 $\mathbf{x}$ 换成
相机系坐标 $s_1\mathbf{x}_1$ 推导）：

$$s_2\,\mathbf{x}_2 = s_1\,R\,\mathbf{x}_1 + \mathbf{t} = s_1\,R\,\mathbf{x}_1 + \mathbf{t}\,\underbrace{\mathbf{n}^\top(s_1\mathbf{x}_1)}_{=1} \ \Longrightarrow\ \mathbf{x}_2 \propto \big(R + \mathbf{t}\mathbf{n}^\top\big)\,\mathbf{x}_1 \tag{7.6}$$

$$H := R + \mathbf{t}\,\mathbf{n}^\top \quad (\text{9 元素} - 1\text{ 尺度} = 8\ \text{自由度}，\ 4\ \text{对点线性解})$$

纯旋转 $\mathbf{t} = \mathbf{0}$ 时 $H = R$ 自然覆盖。**E vs H 实战选择**：两者都算，
按 RANSAC 内点数择优（依据：E 隐含"非平面"假设，H 隐含"平面"假设，
错误假设下内点率塌陷——选型理由）。

### 7.4.4 D7-3：三角测量（五步法）

**① 问题场景**：已有 $R, \mathbf{t}$（来自 D7-2 或里程计），要补匹配点的深度——建图必需。
**② 解决方法**：两条视线已知，交点即 3D 点。
**③ 选型理由**：线性最小二乘，无迭代；代价：远处交角小 → 病态（见 ⑤ 第三步）。
**④ 理论依据**：线性代数最小二乘。
**⑤ 推导。** 出发点 (7.1)。左乘 $\mathbf{x}_2^{\wedge}$（依据：$\mathbf{x}_2^{\wedge}\mathbf{x}_2 = \mathbf{0}$ 消左侧）：

$$s_1\,\mathbf{x}_2^{\wedge}R\,\mathbf{x}_1 + \mathbf{x}_2^{\wedge}\mathbf{t} = \mathbf{0} \tag{7.7}$$

这是关于 $s_1$ 的线性方程组（3 行秩 2——每行都与 $\mathbf{x}_2$ 正交平面上；
依据：反对称左乘的性质），最小二乘逐分量解：

$$s_1 = \big(\mathbf{x}_2^{\wedge}\mathbf{t}\big) \oslash \big(\mathbf{x}_2^{\wedge}R\,\mathbf{x}_1\big) \quad \text{（按分量相除，取有效分量；也可堆叠成 } \mathbf{a}s_1 = \mathbf{b}\text{ 最小二乘）} \tag{7.8}$$

**有效性讨论**：噪声使两视线不严格相交 ⟹ 深度有不确定度；两条视线的夹角
（视锥张角）随深度增大而变小 ⟹ 交点位置对噪声越来越敏感——**远处三角化天然病态**
（写作配视锥示意图）。这是第 13 讲"深度滤波器要多次观测融合"的原因。

### 7.4.5 D7-4：PnP 三条路线（五步法）

**① 问题场景**：3D-2D——已有地图（3D 点），当前帧看到它们的投影（2D），求当前位姿。
比 2D-2D 少一半不确定度（深度已知），且无尺度问题——**VO 跟踪的主力**。
**②–④**：三条路线——线性（DLT）/ 几何闭式（P3P）/ 非线性精化（BA 形式）；
理论依据分别为线性代数、余弦定理、第 6 讲 GN/LM。

**⑤ 推导。**

**路线一：DLT（直接线性变换）。** 记 $T$ 的 $3\times4$ 投影阵
$T = \begin{bmatrix}\mathbf{t}_1^\top\\ \mathbf{t}_2^\top\\ \mathbf{t}_3^\top\end{bmatrix}$（12 元素，尺度等价 ⟹ 11 自由度）。
投影 $s\,\tilde{\mathbf{u}} = T\,\tilde{\mathbf{P}}$，即
$s u = \mathbf{t}_1^\top\tilde{\mathbf{P}}$、$s v = \mathbf{t}_2^\top\tilde{\mathbf{P}}$、$s = \mathbf{t}_3^\top\tilde{\mathbf{P}}$。
用第三式除前两式消 $s$（依据：代数）：

$$\big(u\,\mathbf{t}_3^\top - \mathbf{t}_1^\top\big)\tilde{\mathbf{P}} = 0, \qquad \big(v\,\mathbf{t}_3^\top - \mathbf{t}_2^\top\big)\tilde{\mathbf{P}} = 0 \quad (\text{每对点 } 2 \text{ 个独立线性方程})$$

≥6 对点堆叠 $A\,\mathbf{t} = \mathbf{0}$ → SVD 取最小奇异向量 → $T$ 的左 3×3 做 SVD
投影回 $SO(3)$（依据：Frobenius 范数下最近正交阵 $= UV^\top$，并验 $\det = +1$）。

**路线二：P3P（几何闭式，书 §7.7.2）。** 输入 3 个不共线的 3D 点 $A,B,C$ 及其投影
$\mathbf{a},\mathbf{b},\mathbf{c}$ + 1 个验证点。中心投影保持射线夹角：投影三角形内角
$\langle\mathbf{a},\mathbf{b}\rangle = \angle APB$ 等可从图像算出（依据：投影角 = 射线角，
与深度无关）。记 $x = |PA|$、$u = |PB|/x$、$v = |PC|/x$，对三对射线写余弦定理：

$$x^2 + u^2x^2 - 2\,u\,x^2\cos\langle\mathbf{a},\mathbf{b}\rangle = |AB|^2$$
$$x^2 + v^2x^2 - 2\,v\,x^2\cos\langle\mathbf{a},\mathbf{c}\rangle = |AC|^2$$
$$u^2x^2 + v^2x^2 - 2\,uv\,x^2\cos\langle\mathbf{b},\mathbf{c}\rangle = |BC|^2 \tag{7.9}$$

三式两两相除消去 $x^2$（依据：代数），得关于 $(u, v)$ 的两个方程；继续消元化为
$u$ 的**四次多项式**（书 §7.7.2 给出系数展开与代入化简的逐行过程）——解析解出
2–4 组 $(u,v)$，即 2–4 个候选位姿；用第 4 个点的投影一致性剔除歧义。
定位：闭式快、适合初值；噪声下不稳，需路线三精化。

**路线三：BA 形式（非线性优化）。** 投影误差（依据：第 5 讲投影链 + 第 4 讲李代数参数化）：

$$\min_{\boldsymbol{\xi}}\ \sum_i \big\|\,\mathbf{u}_i - \pi\big(K,\ \exp(\boldsymbol{\xi}^{\wedge}),\ \mathbf{P}_i\big)\,\big\|^2$$

用第 6 讲 GN/LM 迭代；雅可比 $\partial\mathbf{e}/\partial\delta\boldsymbol{\xi}$ 由
(4.11) × 投影导数拼装（完整展开放第 10 讲 D10-4，此处引用编号不重复）。
**工程流程**：P3P/EPnP 给初值 → g2o/Ceres 投影 BA 精化（依据：闭式解进凸域，
迭代解保精度）。

### 7.4.6 D7-5：ICP 的 SVD 解（五步法）

**① 问题场景**：3D-3D——两组已配对的 3D 点（RGB-D 深度 + 匹配，或前后两帧地图点）。
**② 解决方法**：先解旋转平移（SVD 闭式）；配对未知时外层套"配对 ↔ 求解"迭代。
**③ 选型理由**：闭式、无初值依赖（对比：把 ICP 当非线性问题用李代数迭代——作为扩展，
书 §7.9.2）；代价：需要可靠配对（外点用 RANSAC 滤）。
**④ 理论依据**：矩阵迹的最优化（Von Neumann 迹不等式的初等版本）。
**⑤ 完整推导。**

目标（$R \in SO(3)$，$\mathbf{t} \in \mathbb{R}^3$）：

$$\min_{R,\,\mathbf{t}}\ \sum_i \big\|R\,\mathbf{p}_i + \mathbf{t} - \mathbf{q}_i\big\|^2 \tag{7.10}$$

**第一步（解平移）。** 展开为 $\sum\|R\mathbf{p}_i - \mathbf{q}_i\|^2 + 2\mathbf{t}^\top\sum(R\mathbf{p}_i - \mathbf{q}_i) + N\|\mathbf{t}\|^2$，
对 $\mathbf{t}$ 求偏导置零（依据：$\partial\|\mathbf{t}\|^2/\partial\mathbf{t} = 2\mathbf{t}$）：

$$\mathbf{t}^* = \bar{\mathbf{q}} - R\,\bar{\mathbf{p}} \qquad (\bar{\mathbf{p}}, \bar{\mathbf{q}}\ \text{为质心})$$

**第二步（去质心）。** 代回，$\mathbf{t}$ 消失（依据：代入整理，
$\sum(R\mathbf{p}_i - R\bar{\mathbf{p}} - \mathbf{q}_i + \bar{\mathbf{q}}) = R\sum\mathbf{p}_i' - \sum\mathbf{q}_i' = \mathbf{0}$，
其中 $\mathbf{p}_i' = \mathbf{p}_i - \bar{\mathbf{p}},\ \mathbf{q}_i' = \mathbf{q}_i - \bar{\mathbf{q}}$）：

$$\min_R \sum_i \big\|R\,\mathbf{p}_i' - \mathbf{q}_i'\big\|^2$$

**第三步（化为迹最大化）。** 展开平方（依据：$\|R\mathbf{p}'\| = \|\mathbf{p}'\|$ 保范数）：

$$\sum_i\Big(\|\mathbf{p}_i'\|^2 + \|\mathbf{q}_i'\|^2 - 2\,\mathbf{q}_i'^\top R\,\mathbf{p}_i'\Big)$$
前两项与 $R$ 无关；第三项用迹的循环性质 $\mathbf{q}'^\top R\mathbf{p}' = \operatorname{tr}\big(R\,\mathbf{p}'\mathbf{q}'^\top\big)$：

$$\max_R\ \operatorname{tr}\big(R\,H\big), \qquad H = \sum_i \mathbf{p}_i'\,\mathbf{q}_i'^\top \tag{7.11}$$

**第四步（SVD 求解）。** $H = U\Lambda V^\top$，则
$\operatorname{tr}(RH) = \operatorname{tr}\big((V^\top R\,U)\,\Lambda\big)$；令 $Q = V^\top R\,U$
——正交矩阵的对角元满足 $|Q_{ii}| \le 1$（依据：正交矩阵各列单位范数，
每元素 = 两单位向量内积），故

$$\operatorname{tr}(Q\Lambda) = \sum_i Q_{ii}\lambda_i \le \sum_i \lambda_i, \qquad \text{等号} \iff Q = I$$

$$\boxed{\ R^* = V\,U^\top\ }\tag{7.12}$$

**第五步（反射检查）。** 若 $\det R^* = -1$（点云近似共面时可能发生），该解是反射不是旋转
（依据：$SO(3)$ 要求 $\det = +1$）——丢弃该配对集或翻转对应最小奇异值的方向后重构。
**第六步（非线性 ICP，书 §7.9.2）**：位姿用李代数增量 $\exp(\boldsymbol{\xi}^{\wedge})$ 参数化，
误差 $\mathbf{e}_i = R\mathbf{p}_i + \mathbf{t} - \mathbf{q}_i$，雅可比拼 (4.10)(4.11)，
GN 迭代（回引 (6.6)）——与 SVD 法数值等价但可扩展权重/鲁棒核。

## 7.6 易错点与高频疑问

1. **先去畸变**：对极约束假设针孔模型——畸变未除，(7.4) 系统性失配；
2. **八点法跳过归一化**：能跑但精度差一个量级（D7-2 第 3 步的条件数论证）；
3. **四解筛选漏深度检查**：$\det R = +1$ 的解有两个，只靠它不够，必须 cheirality；
4. **ICP 忘记去质心**：直接对 (7.10) 做 SVD 会把平移混进 $H$，结果错——平移必须先解出；
5. **三角化的病态**：两帧基线太短或点太远 ⟹ 深度不可信，工程上设"三角化角度下限"；
6. **"特征匹配对数越多越好吗"**：误匹配（outlier）比少匹配更致命——RANSAC/比值检验是标配。

## 7.7 自检题

1. 不看书写出 (7.1)→(7.3) 的四步，并解释每步"消去了什么"。
2. 推导 $E$ 的自由度（9 − 尺度 − 秩 2），并说明为什么五点法理论上够、八点法更常用。
3. 手推 (7.6)：把平面约束代入 (7.1) 的每一步。
4. 推导 (7.11)(7.12)，并解释 $\det R^* = -1$ 时为何翻转最小奇异方向能修复。
5. 用 DLT 的"两方程/点"推出最少需要 6 对点，而 P3P 只要 3+1——代价各是什么？
6. （数值）对带噪声的模拟点云跑 SVD-ICP，观察 $\det R^*$ 何时变 $-1$（把点云压扁到近平面试试）。

## 7.8 本章要点

- 对极约束 (7.3)(7.4)：共面条件消去深度与平移的推导机制；$E$ 5 自由度、秩 2、尺度等价。
- 八点法 = 归一化 + SVD；$E \to R,\mathbf{t}$ 四解 + cheirality 筛选；平面/纯旋转用 $H$ (7.6)。
- 三角测量 (7.7)(7.8)：远处病态——为第 13 讲深度滤波埋伏笔。
- PnP：DLT（线性）/P3P（闭式初值）/BA（LM 精化）三段式；ICP SVD (7.12)：去质心 → 迹最大化。
- 单目尺度不确定从本讲起贯穿全书——第 10 讲 BA 也解不了它，只有双目/RGB-D/IMU 能定尺度。
