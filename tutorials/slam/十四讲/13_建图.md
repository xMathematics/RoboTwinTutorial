## 13.1 本章定位

第 7 讲的三角化只给"特征点"的深度——导航、避障、场景理解需要**成片**的深度。
本讲从稀疏走到稠密：单目稠密重建 = 对每个像素反复"极线搜索 + 块匹配"拿观测，
用**深度滤波器**融合成稳定估计；最后对比三种地图形态（点云/八叉树/TSDF）。

## 13.2 学习目标

1. 说明极线搜索如何把 2D 匹配降为 1D，写出 NCC (13.1) 及其光照不变性；
2. **推导两高斯融合公式 (13.3)**，说明深度滤波器的收敛判据与逆深度参数化；
3. 对比点云/八叉树/TSDF 的存储、概率表达与更新方式（含 log-odds (13.4)）。

## 13.3 问题场景（五步法①）

**手头**：一段带位姿的图像序列（位姿来自 VO/BA）。
**缺**：每像素深度——(5.1) 已把深度丢掉；三角化只处理特征点。
**想要**：稠密（或半稠密）深度图 + 每个深度的可信度，进而拼成地图。

## 13.4 核心内容

### 13.4.1 D13-1：极线搜索与块匹配（五步法）

**② 解决方法**：两阶段——先用几何把搜索空间从 2D 压到 1D（极线），
再在极线上做小块相关打分（块匹配）。
**③ 选型理由**：对比特征点法——不挑"特征"，任何像素都能测深度；
代价：纹理弱处 NCC 峰平坦 → 不确定度大（这正是深度滤波器要处理的对象）。
**④ 理论依据**：对极约束（第 7 讲 (7.4)）+ 相关打分。

**⑤ 推导。**

**第一步（极线搜索）。** 给定左图像素 $\mathbf{p}_L$ 与相对位姿 $(R, \mathbf{t})$：
右图对应点必落在该点的**极线**上（依据：(7.4)——约束只留一条直线方程；
位姿已知时该直线可逐点画出）。匹配从 $W \times H$ 的 2D 搜索降为沿极线的 1D 搜索。

**第二步（块匹配打分）。** 沿极线滑动右图窗口，与左图窗口比较——单个像素太脆
（噪声/非朗伯表面），用整块。打分用归一化互相关：

$$\mathrm{NCC}(a, b) = \frac{\sum_i (a_i - \bar{a})(b_i - \bar{b})}{\sqrt{\sum_i (a_i - \bar{a})^2 \sum_i (b_i - \bar{b})^2}} \in [-1, 1] \tag{13.1}$$

**光照不变性（一行推导）**：对线性光照变换 $I \to \alpha I + \beta$，
分子分母同时乘 $\alpha$（中心化使 $\beta$ 消失：$\overline{\alpha a + \beta} = \alpha\bar{a} + \beta$）——
NCC 不变，取最大值处为匹配（依据：标准化协方差的相关系数）。

**第三步（产出与衔接）。** 峰值位置 → 视差 → 深度观测
（依据：D5-3 (5.6) 或对应单目情形的三角化）；**峰的宽度** → 该观测的不确定度 $\tau$
——定量版本即 D7-3 的"远处病态"：$\delta Z/Z \approx \delta d/d$。

### 13.4.2 D13-2：深度滤波器（五步法）

**① 问题场景**：一次块匹配只给一个带噪声的观测 $\mathcal{N}(\nu, \tau^2)$；
同一像素会随相机移动被**反复**观测——怎么把一串观测融合成稳定估计？
**② 解决方法**：每个像素维护一个深度的概率分布，按贝叶斯法则逐次融合（一维滤波）。
**③ 选型理由**：单变量一维滤波，公式极简、逐像素可并行；高斯–均匀混合
天然表达"未初始化"。与 KF（第 10 讲）的关系：同一"两高斯融合"数学，
只是这里没有运动方程、状态就是深度本身。
**④ 理论依据**：贝叶斯更新 + 高斯乘积（附录 A.2.2）。

**⑤ 完整推导。**

**第一步（先验建模——高斯–均匀混合）。**

$$p(d) = \xi\,\mathcal{N}(d;\ \mu, \sigma^2) + \gamma\,\mathcal{U}(d_{\min}, d_{\max}), \qquad \xi + \gamma = 1 \tag{13.2}$$

依据：已有估计用高斯刻画（$\mu$ = 当前值，$\sigma$ = 可信度）；
从未见过的像素用均匀分量表达"只知道在合理量程内"——$\gamma$ 随融合逐步衰减
（每次有支持性观测，$\gamma$ 减小）。

**第二步（两高斯融合——配方完整推导）。** 新观测 $d_{obs} \sim \mathcal{N}(\nu, \tau^2)$，
高斯部分按贝叶斯乘积融合。展开联合指数（依据：$\log$ 乘积 = 指数相加）：

$$-\frac{(d - \mu)^2}{2\sigma^2} - \frac{(d - \nu)^2}{2\tau^2}
= -\frac12\Big[\underbrace{\Big(\frac{1}{\sigma^2} + \frac{1}{\tau^2}\Big)}_{:=\,1/\sigma_f^2}\,d^2 - 2\underbrace{\Big(\frac{\mu}{\sigma^2} + \frac{\nu}{\tau^2}\Big)}_{:=\,\mu_f/\sigma_f^2}\,d + \text{const}\Big]$$

对照二次型 $-\frac{(d - \mu_f)^2}{2\sigma_f^2} = -\frac{1}{2\sigma_f^2}d^2 + \frac{\mu_f}{\sigma_f^2}d - \cdots$，
逐系数读出（依据：配方法；$\sigma_f^2$ = 精度之和的倒数，$\mu_f$ = 精度加权平均）：

$$\boxed{\ \mu_{fuse} = \frac{\sigma^2\,\nu + \tau^2\,\mu}{\sigma^2 + \tau^2}, \qquad
\sigma^2_{fuse} = \frac{\sigma^2\,\tau^2}{\sigma^2 + \tau^2}\ } \tag{13.3}$$

*核验*：$\sigma_f^2 = \frac{1}{1/\sigma^2 + 1/\tau^2} < \min(\sigma^2, \tau^2)$——
融合后方差单调不增（观测只增信息，同 KF 更新步的直觉）。

**第三步（收敛判据与完整滤波循环）。** 每帧对每个"正在观测"的像素：
极线搜索 + NCC → $(\nu, \tau)$ → (13.3) 更新 → 若 $\sigma < \sigma_{max}$
（不确定性足够小）⟹ 定点：输出 $\mu$，该像素转为"已确定"；若观测与当前估计冲突
（$|\mu - \nu|$ 过大）⟹ 判外点，剔除或重置（依据： outlier 不应污染 (13.3)）。
伪代码：

```
for 每帧:
  for 每个未定点像素 p:
    (ν, τ) = 极线搜索 + NCC            # D13-1
    if τ < τ_max:  μ,σ = fuse(μ,σ,ν,τ) # (13.3)
    if 冲突(μ,ν):  重置/剔除
    if σ < σ_max: 标记定点 → 输出深度 μ
```

**第四步（逆深度参数化，书 §13.4.2）。** 改以 $\rho = 1/d$ 为滤波变量。论证：
1. **远场景**：$d \to \infty$ 时 $\rho \to 0$——有限值可表示"无穷远"
   （直接参数化下 $d$ 要表示 $\infty$，数值上无界）；
2. **线性化更均匀**：块匹配的视差误差对 $\rho$ 近似常数尺度（$\delta\rho \approx \delta d/d^2$
   对应真实误差模型），深度误差随距离自然放大——与 (5.6) 的 $\delta Z \propto Z^2$ 一致，
   滤波假设（近似高斯）在 $\rho$ 上更成立；
3. 工程惯例：LSD-SLAM/REMODE 等系统均用逆深度（精读
   [LSD-SLAM](../精读/LSD-SLAM_ECCV2014.md)）。

**第五步（像素梯度问题，书 §13.4.1）。** 论证：NCC 峰的尖锐度由局部纹理决定——
弱梯度区域似然曲线平坦 → $\tau$ 大 → (13.3) 收敛慢甚至不收敛；
强梯度（边缘/角点）区域峰尖 → 快速定点。**这与第 8 讲半稠密直接法"只选梯度明显
像素"同根同源**：信息量在梯度里，全图稠密只是理论能力，实践按梯度筛。

### 13.4.3 D13-3：三类地图形态（五步法，概念 + 关键公式）

**② 三种解决方法对比（本讲产出表）**：

| 地图 | 存什么 | 概率表达 | 更新方式 | 空洞处理 | 代表 |
|------|--------|---------|---------|---------|------|
| 点云 | 3D 点集 | 无 | 追加 | 不处理（重叠难消） | 第 5 讲拼接结果 |
| 八叉树 | 递归立方体网格，叶节点存占用概率 | 有（每节点） | 概率贝叶斯更新 | 未观测不存储（天然稀疏） | OctoMap |
| TSDF | 均匀体素，存到表面的截断符号距离 | 隐式（权重平均） | 多帧加权融合 | 体素全覆盖（内存大） | KinectFusion |

**八叉树的 log-odds 更新**（教程补充公式；书为概念介绍）：节点占用概率 $p$ 经
logit 变换 $l = \log\frac{p}{1-p}$ 后，贝叶斯更新退化为加法
（依据：概率乘法在对数域化为加法，且避免边界 $p \approx 0, 1$ 的数值下溢）：

$$l \leftarrow l + \underbrace{\log\frac{p_{hit}}{1 - p_{hit}}}_{\text{观测到占用（击中）}}, \qquad
l \leftarrow l + \log\frac{p_{miss}}{1 - p_{miss}} \quad\text{(穿过=空闲)} \tag{13.4}$$

**TSDF 与 Fusion 系列**（书 §13.6，概念级）：每体素存"到最近表面的符号距离"，
只在表面附近 $\pm\delta$ 内有效（截断——远离表面无意义且省更新）；
多帧深度按权重平均融入；重建 = 提取零等值面（Marching Cubes）。
公式与实现展开在 [3D 重建 04 章](../../3d_reconstruction/04_RGB-D融合与TSDF.md)，
此处互链不重复。

## 13.6 易错点与高频疑问

1. **极线方向算反**：极线由两光心与 $\mathbf{p}_L$ 决定，内参/外参任何一个转置错都会
   "沿错误方向搜索"且不报错——先用合成数据验证；
2. **纯高斯先验**：丢掉均匀分量 (13.2) 后，远处像素会"假收敛"到错误 $\mu$；
3. **正深度/量程检查**：$\mu, \nu$ 先过 $[d_{min}, d_{max}]$ 再融合；
4. **在 $d$ 空间直接套 (13.3)**：若系统按逆深度组织观测，融合应在 $\rho$ 空间做；
5. **点云当"概率地图"用**：点云没有占用信息，机器人无法用它判断"这里可通行"——
   需要八叉树/ESDF（导航场景）。

## 13.8 本章要点

- 极线搜索（(7.4) 的 1D 化）+ NCC (13.1)（光照不变）= 深度观测的产生器；
- 深度滤波器：高斯–均匀先验 (13.2) + 两高斯融合 (13.3)（配方推导）+
  收敛判据；逆深度参数化（远处有限、误差模型匹配）；梯度决定信息量。
- 地图三形态：点云（无概率）/ 八叉树（逐节点概率，log-odds (13.4)）/
  TSDF（截断符号距离，见 3D 重建 04 章互链）。
