## 1.1 本章定位

本讲不产公式。它回答三件事：这本书讲什么、按什么顺序读、需要准备什么环境。
读完应能画出全书依赖图（下图），并明白每一讲"理论章 / 实践章 / 综述章"的身份。

```
第一阶段 数学地基（讲1–6）        第二阶段 前端（讲7–9）
讲2 初识SLAM（数学表述）    ───→  讲7 VO1 特征点法
讲3 刚体运动 ─→ 讲4 李群李代数     讲8 VO2 直接法
讲5 相机与图像                    讲9 实践：设计前端
         讲6 非线性优化 ←─ 讲4 的雅可比 + 讲2 的概率表述
                          │
第三阶段 后端与回环（讲10–12）     第四阶段 系统与前沿（讲13–14）
讲10 后端1 KF/EKF + BA            讲13 建图（稠密/八叉树/TSDF）
讲11 后端2 位姿图/因子图  ←─ 讲12 回环检测
                                  讲14 现在与未来（VIO/语义）
```

## 1.2 学习目标

1. 说出 SLAM 要解决的问题与四阶段路线（详见 [第 2 讲](02_初识SLAM.md)）；
2. 搭好可编译书例代码的环境，跑通 hello_SLAM 与 useEigen；
3. 知道每个第三方库在哪一讲出场、承担什么角色。

## 1.3 环境准备清单

| 工具/库 | 出场讲次 | 角色 | 版本提示 |
|---------|---------|------|---------|
| Ubuntu 18.04/20.04 + 终端 | 全书 | 开发环境 | 新版亦可，注意源码编译路径变化 |
| CMake | 全书 | 构建系统 | ≥3.10 |
| Eigen | 3–6、10–11 | 矩阵/几何运算（仅头文件） | ≥3.3 |
| OpenCV | 5、7、8、13 | 图像读写、特征提取 | 3.x 与 4.x API 有差异（`CV_LOAD_IMAGE` → `cv::IMREAD` 等） |
| Sophus | 4 | 李群李代数（模板库，配合 Eigen） | 用书仓库的 fork 更稳（非官方发布版） |
| Ceres | 6、10 | 非线性优化（自动求导） | ≥14.0；依赖 protobuf/eigen |
| g2o | 6、9–11 | 图优化（顶点/边抽象） | 与 Ceres 无冲突但依赖重，建议源码装到独立目录 |
| DBoW3 | 12 | 词袋字典 | 书仓库自带源码 |

安装命令与逐条排坑（`cmake ..` 参数、`make -j`、动态库 `ldconfig` 等）见书 §2.4 与
配套仓库 [slambook2](https://github.com/gaoxiang12/slambook2) 的 3rdparty 说明——属操作步骤，此处不重复。

不想装 C++ 环境的读者：本仓库 [projects/slam/](../../../projects/slam/README.md) 提供
纯 numpy 教学实现（对极几何、BA、位姿图、词袋回环等，公式与本系列编号逐一对应），
零依赖即可复现算法核心，边读边跑。

## 1.4 如何使用本书与本教程

- **每讲结构**（书与本教程一致）：理论部分（概念 + 推导）→ 实践部分（代码）→ 小结。
  本教程把理论部分按五步法（问题场景 → 解决方法 → 选型理由 → 理论依据 → 完整推导）重排，
  推导从已知出发、每步注明依据；
- **读法建议**：顺序通读讲 2–7 即可获得最短主干（讲 4 的扰动模型雅可比
  (4.10)(4.11) 是后续所有章的支点）；讲 9–13 可按需进入；
- **公式编号约定**：本系列公式编号 (讲.序)，如 (4.10)。书页码/书式号在需要对照原书时以
  "书 §节号"标注；
- **大作业**：读完讲 10、12 后，把讲 9 的前端 + 讲 10 的后端 + 讲 12 的回环
  拼成一个迷你视觉 SLAM（见 [第 9 讲](09_实践章设计前端.md) 末尾的任务卡）。
