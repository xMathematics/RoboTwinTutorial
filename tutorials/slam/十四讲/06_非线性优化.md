## 6.1 本章定位

第 2 讲结尾留的钩子——$P(x, y \mid u, z)$ 没有解析解——在本讲兑现：
高斯噪声 + 最大后验（MAP）准则下，它**精确地**变成一个非线性最小二乘问题；
再用迭代法（GN/LM）数值求解。本讲是后端（第 10、11 讲）的全部理论，
也是前端（第 7、8 讲）姿态估计的求解引擎。

## 6.2 学习目标

1. 从后验分布出发**每一步有依据地**推导出最小二乘目标 (6.2)；
2. 推导并比较 GD / Newton / GN / LM 四种迭代法（(6.3)–(6.7)）；
3. 写出图优化的顶点–边–Hessian 结构 (6.8)，说出它与 (6.2) 的一一对应。

## 6.3 问题场景（五步法①）

**手头**：第 2 讲的 (2.1)(2.2)——带高斯噪声的运动方程与观测方程，
数据 $\{u_k\}, \{z_{k,j}\}$。
**缺**：把"求后验"落地为可数值求解的算法——后验是高维非凸函数的分布，
直接采样/积分不可行。
**想要**：一个能迭代求解、每步计算量可控、且在工程库（Ceres/g2o）里可声明的优化问题。

## 6.4 核心内容

### 6.4.1 D6-1：从最大后验到最小二乘（五步法）

**② 解决方法**：MAP 准则 + 高斯噪声的指数形式 + 取负对数。
**③ 选型理由**：MAP 相比最大似然额外利用位姿先验（如运动学约束）；
负对数把"连乘"变"连加"、把指数变二次型——计算可行性的关键一跃。
**④ 理论依据**：贝叶斯定理、马尔可夫假设、高斯分布、单调变换保极值。

**⑤ 完整推导。**

**第一步（贝叶斯定理 + 马尔可夫分解）。**

$$P(x, \mathbf{y} \mid z, u) \propto P(x, \mathbf{y})\,P(z, u \mid x, \mathbf{y})$$

（依据：贝叶斯定理，分母与状态无关故省略。）把似然按数据逐项分解
（依据：条件概率链式法则 + 马尔可夫假设——$u_k$ 只依赖 $x_{k-1}$，$z_{k,j}$ 只依赖 $x_k, \mathbf{y}_j$）：

$$P(x, \mathbf{y} \mid z, u) \propto \prod_{k=1}^{N} P(u_k \mid x_{k-1}) \prod_{k=1}^{N}\prod_{j \in \mathcal{O}(k)} P(z_{k,j} \mid x_k, \mathbf{y}_j) \tag{6.1}$$

**第二步（高斯噪声代入）。** 由 (2.1)(2.2) 与噪声假设：
$P(u_k \mid x_{k-1}) = \mathcal{N}\big(x_k;\, f(x_{k-1},u_k),\, R_k\big)$，
$P(z_{k,j} \mid x_k, \mathbf{y}_j) = \mathcal{N}\big(z_{k,j};\, h(\mathbf{y}_j,x_k),\, Q_{k,j}\big)$。

**第三步（MAP → 负对数）。** 最大化 (6.1) ⟺ 最小化其负对数（依据：$\log$ 单调，
$\arg\max \log P = \arg\max P$）。高斯密度的对数
$\log \mathcal{N}(\mathbf{e};\, 0, \Sigma) = -\tfrac12\,\mathbf{e}^\top\Sigma^{-1}\mathbf{e} - \tfrac12\log|2\pi\Sigma|$：
指数展开成马氏范数 $\|\mathbf{e}\|^2_{\Sigma^{-1}} := \mathbf{e}^\top\Sigma^{-1}\mathbf{e}$；
常数项（$-\tfrac12\log|2\pi\Sigma|$）与状态无关，最小化中丢弃。于是：

$$\boxed{\ \min_{x,\,\mathbf{y}}\ \sum_{k} \big\| x_k - f(x_{k-1}, u_k) \big\|^2_{R_k^{-1}} + \sum_{k}\sum_{j} \big\| z_{k,j} - h(\mathbf{y}_j, x_k) \big\|^2_{Q_{k,j}^{-1}}\ } \tag{6.2}$$

**第四步（结构解读——与图优化的一一对应）。** (6.2) 的每一项 = 一条**边**：
"运动边"连接 $x_{k-1}$ 与 $x_k$，"观测边"连接 $x_k$ 与 $\mathbf{y}_j$；
权重 = 信息矩阵（协方差之逆）——噪声越大的数据权重越小。
特例：无运动项 → 纯观测最小化（第 7 讲 BA 形式的 PnP）；线性高斯时 (6.2) 有闭式解
= 卡尔曼滤波（第 10 讲 D10-2 证明）。

### 6.4.2 D6-2：迭代法——一阶与二阶梯度法（五步法）

**① 问题场景**：(6.2) 对状态非线性（$f, h$ 非线性），无闭式解。
**② 解决方法**：从当前点出发，反复"局部近似 + 解近似问题的解 + 更新"。
**③ 选型理由**：利用导数信息的迭代法比无导数方法（单纯形等）在高维下快几个量级。
**④ 理论依据**：多元泰勒展开。

**⑤ 推导。** 记目标 $F(\mathbf{x})$，在当前点展开到二阶：

$$F(\mathbf{x} + \Delta\mathbf{x}) \approx F(\mathbf{x}) + \mathbf{J}\,\Delta\mathbf{x} + \tfrac12\,\Delta\mathbf{x}^\top H\,\Delta\mathbf{x} \tag{6.3}$$

（$\mathbf{J} = \partial F/\partial\mathbf{x}$ 为 $1 \times n$ 梯度行向量，$H$ 为 Hessian。）

- **梯度下降**：取一阶项最速下降方向 $\Delta\mathbf{x} = -\lambda\,\mathbf{J}^\top$（依据：一阶近似下
  负梯度方向使 $F$ 下降最快；步长 $\lambda$ 靠线搜索/经验）。一阶信息收敛慢（锯齿行进）。
- **牛顿法**：对 (6.3) 右端关于 $\Delta\mathbf{x}$ 求导置零（依据：二次函数的驻点即极小点）：

$$H\,\Delta\mathbf{x} = -\mathbf{J}^\top \tag{6.4}$$

  二阶信息收敛快，但 $H$ 要算 $F$ 的全部二阶导（高维昂贵），且不定/病态时步子乱飞。

### 6.4.3 D6-3：Gauss–Newton（五步法）

**② 解决方法**：利用最小二乘的**特殊结构** $F = \tfrac12\|\mathbf{f}(\mathbf{x})\|^2$，
用 $\mathbf{J}^\top\mathbf{J}$ 代替 $H$。
**③ 选型理由**：$\mathbf{J}$（残差一阶导）反正要算；$\mathbf{J}^\top\mathbf{J}$ 自动半正定、
免算二阶导；代价：残差大/非线性强时近似差。
**④ 理论依据**：残差向量的泰勒展开。

**⑤ 推导。** 一阶展开残差：$\mathbf{f}(\mathbf{x}+\Delta\mathbf{x}) \approx \mathbf{f} + \mathbf{J}\Delta\mathbf{x}$，
平方展开：

$$F(\mathbf{x}+\Delta\mathbf{x}) \approx \tfrac12\|\mathbf{f}\|^2 + \mathbf{f}^\top\mathbf{J}\Delta\mathbf{x} + \tfrac12\,\Delta\mathbf{x}^\top\mathbf{J}^\top\mathbf{J}\,\Delta\mathbf{x} \tag{6.5}$$

*与 (6.3) 对照看近似*：真 Hessian $H = \mathbf{J}^\top\mathbf{J} + \sum_i f_i\,H_i(\mathbf{f})$
（把 $\partial^2\tfrac12\|\mathbf{f}\|^2$ 逐项展开即得）——GN 恰好**丢弃了含 $f_i$ 的二阶导项**
$\sum_i f_i H_i$。依据：残差接近零时该项贡献小（这正是"数据拟合得好"的收敛目标态）。

对 (6.5) 关于 $\Delta\mathbf{x}$ 求导置零（依据：二次型驻点）：

$$\boxed{\ \big(\mathbf{J}^\top\mathbf{J}\big)\,\Delta\mathbf{x} = -\,\mathbf{J}^\top\mathbf{f}\ }\tag{6.6}$$

迭代流程：给定初值 → 求 $\mathbf{J}, \mathbf{f}$ → 解 (6.6)（Cholesky/LDLT/SVD）→
$\mathbf{x} \leftarrow \mathbf{x} + \Delta\mathbf{x}$ → 判收敛。风险：$\mathbf{J}^\top\mathbf{J}$ 半正定，
接近奇异时 $\Delta\mathbf{x}$ 爆炸 → 需要 LM。

### 6.4.4 D6-4：Levenberg–Marquadt（五步法）

**② 解决方法**：给 (6.6) 加正定阻尼，把"线性近似有多可信"编码为 $\lambda$：

$$\big(H + \lambda\,D^\top D\big)\,\Delta\mathbf{x} = -\mathbf{J}^\top\mathbf{f}, \qquad D \succeq 0 \text{（常取 } D = \mathrm{diag}\sqrt{H_{ii}}\text{）} \tag{6.7}$$

**③ 选型理由**：$\lambda \to 0$ 退化为 GN（快）；$\lambda$ 大退化为小步梯度下降（稳）——
两端的好处都要；代价：每轮要调 $\lambda$。
**④ 理论依据**：置信域（trust region）方法。

**⑤ 推导（$\lambda$ 的自适应依据）。** 定义**近似增益比**：

$$\rho = \frac{F(\mathbf{x}) - F(\mathbf{x} + \Delta\mathbf{x})}{\mathbf{f}^\top\mathbf{J}\Delta\mathbf{x} + \tfrac12\Delta\mathbf{x}^\top\lambda D^\top D\,\Delta\mathbf{x}}$$

分母 = 线性化模型预测的下降量（取 (6.5) 型展开 + 阻尼项；推导：模型预测下降
$= F(\mathbf{x}) - [\text{模型在 } \Delta\mathbf{x} \text{ 处的值}]$，代入即得上式分母）。
- $\rho$ 大（接近 1 或更大）：线性模型准 → 采纳 $\Delta\mathbf{x}$，**减小 $\lambda$**（下一步更大胆）；
- $\rho$ 小或负：模型不准 → 不采纳，**增大 $\lambda$**（收缩步长）重解 (6.7)。
（依据：置信域方法的经典更新策略。）

**四法对照表（本讲产出）**：

| 方法 | 步长方程 | 每步代价 | 收敛性 | 备注 |
|------|---------|---------|--------|------|
| GD | $\Delta\mathbf{x} = -\lambda\mathbf{J}^\top$ | 低 | 慢、锯齿 | 只用一阶 |
| Newton | (6.4) | 高（算 $H$） | 快 | $H$ 可能不定 |
| GN | (6.6) | 中 | 近零残差时快 | $\mathbf{J}^\top\mathbf{J}$ 可奇异 |
| LM | (6.7) | 中 + 调 $\lambda$ | 稳健 | SLAM 后端默认 |

### 6.4.5 D6-5：图优化（五步法）

**① 问题场景**：(6.2) 的求和项数巨大（每帧 × 每路标），直接展开 (6.6) 的 $\mathbf{J}$
维度高；需要一种能把"哪项误差涉及哪些变量"组织起来的结构。
**② 解决方法**：图优化——顶点 = 状态量，边 = 一项误差 + 信息矩阵；线性化后
Hessian 按"边"累加，天然**稀疏**。
**③ 选型理由**：与 (6.2) 一一对应（声明式建模）；稀疏性可被第 10 讲的 Schur 补
进一步利用；g2o/Ceres/gtsam 生态成熟。
**④ 理论依据**：因子图的优化视角（第 11 讲 §11.3 给概率侧）。

**⑤ 推导（Hessian 累加）。** 每条边 $i$：误差 $\mathbf{e}_i(\mathbf{x}_{\mathcal{V}_i})$ 只依赖
它连接的顶点集 $\mathcal{V}_i$，信息阵 $\Omega_i$。目标 $= \sum_i \mathbf{e}_i^\top\Omega_i\mathbf{e}_i$。
对每条边独立线性化 $\mathbf{e}_i \approx \mathbf{e}_i + \mathbf{J}_i\Delta\mathbf{x}$
（$\mathbf{J}_i$ 只在 $\mathcal{V}_i$ 对应列非零），代入并逐边对 $\Delta\mathbf{x}$ 求导置零后求和：

$$H = \sum_i \mathbf{J}_i^\top\,\Omega_i\,\mathbf{J}_i, \qquad \mathbf{g} = \sum_i \mathbf{J}_i^\top\Omega_i\,\mathbf{e}_i \tag{6.8}$$

（依据：求和的导数 = 导数的和；各边只改写自己触及的块——**多顶点边的雅可比按
$\mathbf{J}_i = [\cdots | \mathbf{J}_{i,v_1} | \cdots | \mathbf{J}_{i,v_k} | \cdots]$ 摆块**，
其余列为零。）$H$ 的稀疏模式 = 顶点共边关系——第 10 讲 D10-5 从这里出发推 Schur 补。

**实践框架对比**（操作豁免，选型表）：Ceres——自动求导（定义残差 functor 即可）、
工程通用、鲁棒核内建；g2o——顶点/边抽象贴合 SLAM 语义、位姿图/BA 模板现成；
本仓库 `projects/slam/core/solver.py` 给出 (6.6)(6.7) 的纯 numpy 实现，用于看穿库的黑盒。

## 6.6 易错点与高频疑问

1. **"GN 是不是牛顿法"**：不是——GN 用 $\mathbf{J}^\top\mathbf{J}$ 近似 $H$，
   丢掉了 $\sum_i f_i H_i$ 项（D6-3 ⑤ 中那行对照）。
2. **信息矩阵与协方差**：$\Omega = \Sigma^{-1}$；目标里的权重是 $\Omega$，
   噪声大 ⟹ $\Omega$ 小 ⟹ 权重低，方向别弄反。
3. **$H\Delta\mathbf{x} = \mathbf{g}$ 的负号**：注意 (6.6) 右端是 $-\mathbf{J}^\top\mathbf{f}$
   而 (6.8) 把它记作 $\mathbf{g}$ 时符号约定要自洽（本系列 $\mathbf{g} = -\sum\mathbf{J}_i^\top\Omega_i\mathbf{e}_i$
   或保持 (6.8) 并写 $H\Delta\mathbf{x} = -\mathbf{g}$，写代码前先对符号）。
4. **LM 的 $\lambda$ 不重置**：每轮迭代按 $\rho$ 更新 $\lambda$，收敛前勿固定；
5. **把优化变量的"更新"写成加法**：位姿要按第 4 讲 (4.6) 的李代数增量 $\exp(\delta\boldsymbol{\xi}^{\wedge})T$
   更新，不是 $T + \delta$（第 7 讲起实践）。

## 6.8 本章要点

- (6.2)：MAP + 高斯 = 带信息矩阵权重的非线性最小二乘，每项对应一条边。
- GN (6.6)：$\mathbf{J}^\top\mathbf{J}\Delta\mathbf{x} = -\mathbf{J}^\top\mathbf{f}$，
  核心近似 = 丢弃 $\sum_i f_i H_i$；LM (6.7)：加阻尼 + 按 $\rho$ 自适应。
- 图优化 (6.8)：$H = \sum\mathbf{J}^\top\Omega\mathbf{J}$ 按边累加，稀疏模式 = 共边关系。
- 位姿更新走第 4 讲的 $\exp(\delta\boldsymbol{\xi}^{\wedge})T$——第 4 讲与第 6 讲在此合流。
