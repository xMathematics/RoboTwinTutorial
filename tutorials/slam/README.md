## 教程主线（一句话）

机器人进入**无 GPS** 的未知环境，只靠自身传感器（相机 / IMU / 激光），
在**边走边建图**的同时确定"我在哪"——这两个问题互为前提（定位需要地图，建图需要定位），
SLAM 就是把它们放进同一个概率估计框架里联立求解。

## 各章架构明细

### 01｜SLAM 问题定义与全景

- **问题场景**：室内 / 地下 / 水下等 GPS 拒止环境中，移动机器人既需要地图来定位，又需要位姿来建图，鸡生蛋问题如何打破。
- **解决方法概览**：联立定位与建图的状态估计问题；传感器选型对比（视觉 / 激光 / IMU / 多传感器融合）。
- **理论依据**：概率机器人学（Thrun et al., *Probabilistic Robotics*）第 1、2 章。
- **推导产出**：SLAM 的形式化定义——状态方程 + 观测方程（含噪声）。
- **配套阅读**：[papers/slam/README.md](../../papers/slam/README.md)——已收录经典 10 篇 + 前沿 7 篇，按章对应。

### 02｜三维刚体运动：旋转与位姿

- **问题场景**：描述相机的旋转和位姿是 SLAM 一切计算的地基；欧拉角在特定姿态下丢失一个自由度（万向锁）。
- **解决方法概览**：旋转矩阵（无歧义但冗余）、四元数（紧凑、插值好）、李代数（把旋转上的优化变成向量上的优化）。
- **选型理由**：优化环节为何必须用李代数——旋转矩阵不构成向量空间，直接对其加增量会破坏正交性。
- **理论依据**：李群李代数（SO(3)、SE(3)）、BCH 近似；Murray et al., *A Mathematical Introduction to Robotic Manipulation*。
- **推导产出**：旋转矩阵性质 → 李群定义 → 指数映射 → BCH 一阶近似 → 扰动模型（左乘/右乘扰动）→ SE(3) 变换。

### 03｜概率状态估计基础

- **问题场景**：里程计有漂移、观测有噪声，单次测量不可信，如何融合"预测"与"观测"两类信息得到最优估计。
- **解决方法概览**：递归贝叶斯估计；高斯假设下解析可解 → 卡尔曼滤波。
- **选型理由**：为何工程上普遍用高斯近似——解析可解、计算线性；代价是无法表达多峰分布（引出后文粒子滤波对比）。
- **理论依据**：贝叶斯定理、马尔可夫假设、高斯分布的乘积与边缘化。
- **推导产出**：先验 → 预测步 → 更新步的完整贝叶斯推导 → 线性化 → KF 五公式 → 非线性扩展 EKF（雅可比线性化及其误差来源）。

### 04｜相机模型与特征提取

- **问题场景**：图像是 2D 的，世界是 3D 的，投影过程丢了什么信息；两张图的重叠区域里，哪些点在不同视角下稳定可重复匹配。
- **解决方法概览**：针孔模型 + 畸变参数描述投影；可重复性强的局部特征（角点 + 描述子）作为"视觉路标"候选。
- **选型理由**：为何选 ORB（FAST 角点 + 改进 BRIEF）而非 SIFT/SURF——实时性与无专利；代价是对大尺度变化更敏感。
- **理论依据**：射影几何、相机内参外参、图像金字塔与尺度空间。
- **推导产出**：针孔投影方程 → 径向/切向畸变模型 → 内参矩阵各元素的几何含义；ORB 提取与匹配流程（操作性，附代码走读）。

### 05｜视觉里程计 I：特征点法

- **问题场景**：已知两帧图像的匹配点对（2D-2D）、或匹配点与地图点（3D-2D / 3D-3D），如何求出相机运动。
- **解决方法概览**：2D-2D 用对极几何求本质矩阵再分解；3D-2D 用 PnP；3D-3D 用 ICP。
- **选型理由**：三种情形分别对应初始化 / 跟踪 / 精配准三个阶段，各有几何约束可利用。
- **理论依据**：对极约束、RANSAC 鲁棒估计、EPnP、非线性 ICP。
- **推导产出**：对极约束 $x'^\top F x = 0$ 的推导 → E/K 矩阵关系与 SVD 分解恢复 R, t → 三角化恢复深度（为何单目初始化有尺度不确定性）。

### 06｜视觉里程计 II：直接法

- **问题场景**：白墙、弱纹理区域提取不到稳定特征点，特征法直接失效；且特征提取本身耗时。
- **解决方法概览**：跳过特征，直接基于灰度不变假设最小化光度误差。
- **选型理由**：对弱纹理更鲁棒、省去特征计算；代价是依赖灰度不变假设（对曝光变化敏感）、需较好的初值。
- **理论依据**：光流（LK）、非线性最小二乘（Gauss-Newton / LM）。
- **推导产出**：亮度恒常假设 → 光流约束方程（灰度对时间、空间偏导的 PDE）→ 稀疏/半稠密/稠密直接法的目标函数与 GN 迭代推导。

### 07｜后端 I：滤波与增量估计

- **问题场景**：前端逐帧给出运动估计，误差只增不减；需要一种能在线运行、把全部历史信息累积利用的估计器。
- **解决方法概览**：EKF-SLAM 把全部路标塞进一个联合高斯，预测-更新循环在线维护。
- **选型理由**：在线、低延迟；代价是状态维度随路标线性增长（协方差矩阵二次增长），大规模场景不可扩展——这正是第 08 章换范式的动机。
- **理论依据**：EKF（承接第 03 章）、信息矩阵与稀疏性。
- **推导产出**：SLAM 状态向量与协方差的构造 → EKF-SLAM 预测/更新完整推导 → 复杂度分析（引出稀疏性问题）。

### 08｜后端 II：图优化与 BA

- **问题场景**：路标数万时 EKF 协方差矩阵不可维护；且滤波只线性化一次即不可撤回，历史信息被"烧掉"。
- **解决方法概览**：把状态估计写成最小二乘问题（因子图），批量/滑窗重线性化求解，光束法平差（BA）为其特例。
- **选型理由**：利用问题天然的稀疏结构（每个观测只涉及一个位姿和一个路标），Hessian 稀疏可分解，规模可扩展；代价是需要好初值与更长求解时间。
- **理论依据**：非线性最小二乘（Gauss-Newton、LM）、稀疏 Cholesky、Schur 补、流形上的优化。
- **推导产出**：重投影误差目标函数 → 残差线性化 → $H=J^\top J$ 稀疏结构分析 → Schur 补边缘化位姿块 → 增量在李代数上求解的完整推导（为何必须在流形上迭代）。

### 09｜回环检测

- **问题场景**：无论前端后端多精，累计误差随路径单调增长；只有"识别出回到了旧地"，才能把误差拉回。
- **解决方法概览**：把每帧图像压缩成视觉词袋向量，靠向量相似度做快速的基于外观的检测，检出后触发位姿图优化。
- **选型理由**：直接帧间两两比对是 O(n²) 且受视角光照影响大；词袋 + 倒排索引把查询降到近似 O(1)；代价是感知混淆（假阳性回环），需几何校验兜底。
- **理论依据**：TF-IDF、BoW 模型、DBoW2（Gálvez-López & Tardós, 2012）、位姿图优化。
- **推导产出**：词袋向量构造与相似度评分 → 回环候选的几何验证（Sim3）→ 位姿图优化目标函数与求解。

### 10｜建图与系统实战

- **问题场景**：把 02–09 章的模块拼成完整系统：ORB-SLAM3 三线程架构如何协作；定位之外如何产出机器人真正可用的稠密地图。
- **解决方法概览**：稀疏特征地图 → 半稠密 / 稠密地图（RGB-D 深度融合、TSDF）；单目 + IMU 紧耦合（VINS-Mono）解决尺度不可观。
- **理论依据**：ORB-SLAM3（Campos et al., T-RO 2021）、VINS-Mono（Qin et al., 2018）、IMU 预积分。
- **推导产出**：IMU 预积分的完整推导（为何积分可预计算、协方差如何传播）；多传感器融合的因子图构造。
- **实战产出**：跑通 ORB-SLAM3（EuRoC 数据集），给出代码模块与各章理论的一一对应表。
