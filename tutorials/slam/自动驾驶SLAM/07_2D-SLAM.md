## 7.1 本章定位

这是全书第一个**完整系统**：前端（扫描匹配）+ 地图（占据栅格）+ 管理
（子地图）+ 后端（回环闭环）四件套，200 行级模块各司其职。它也是理解
3D 系统的沙盘——第 8–10 讲的每个概念（配准、局部地图、回环验证、位姿图）
都能在这里找到 2D 版的 simplest form。视点先立住：**2D SLAM = 在 SE(2)
上把"当前扫描对齐地图"做到极致**。

## 7.2 学习目标

1. 复述 2D ICP 三种残差的收敛域排序（点对点 < 点对线 < 似然场）及其原因；
2. **独立复现 D7-1、D7-2**：两种雅可比的完整推导（SE(2) 比李群简单，
   适合把扰动雅可比的手感练出来）；
3. 复现 D7-3：从贝叶斯滤波推 log-odds 更新；
4. 说清子地图为什么要存在（局部一致 vs 全局修正的分工）；
5. 跑通 `test_2d_mapping`，并手动制造一个回环观察位姿图修正传播。

## 7.3 问题场景（五步法①）

**手头**：2D 激光（10 Hz，数百点/帧）+ 轮速里程计（可选）。
**想要**：机器人的连续轨迹 + 一张一致的全局占据栅格图。
**缺**：① 单帧扫描只给"距离-角度"极坐标序列，帧间没有对应关系；
② 里程计漂移会让"逐帧对齐"的轨迹首尾不闭合——需要回环；
③ 全局栅格图随时间无界增长——需要子地图分治。

## 7.4 核心内容

### 7.4.1 系统框架与 SE(2) 记号（书 §6.1）

位姿 $T = (\theta, t_x, t_y) \in SE(2)$，$R(\theta) = \begin{bmatrix}\cos\theta & -\sin\theta\\ \sin\theta & \cos\theta\end{bmatrix}$，
扰动向量 $\boldsymbol\xi = (\delta\theta, \delta t_x, \delta t_y)$。
框架（`mapping_2d.h` 的 `sad::Mapping2D::AddScan`）：

```
扫描 → [前端] 在当前子地图内扫描匹配 → 关键帧 → 子地图滚动
     → [后端] 多分辨率回环检测 → 位姿图优化 → 修正传播到全部子地图
```

### 7.4.2 扫描匹配 I：点到点与点到线（书 §6.2.1–6.2.4）

**点到点 ICP**：目标扫描（地图）建 Kd 树（第 6 讲），源扫描每个点找最近邻
得对应 $(\mathbf{p}_i \to \mathbf{q}_i)$，最小化 $\sum\|R(\theta)\mathbf{p}_i + \mathbf{t} - \mathbf{q}_i\|^2$。
闭式解 = 十四讲讲 7 的 ICP-SVD 结果（质心对齐 + $2\times2$ SVD，含反射检查
$\mathrm{diag}(1, \det(VU^\top))$），此处直接引用。
**实现取高斯-牛顿**（§6.2.2，`Icp2d::AlignP2P`）：单点残差
$\mathbf{e}_i = R\mathbf{p}_i + \mathbf{t} - \mathbf{q}_i$，由 (2.8) 的 2D 版本
$\partial(R\mathbf{p})/\partial\delta\theta = R\mathbf{p}^{\perp}$（$\mathbf{p}^\perp = (-p_y, p_x)^\top$，
依据：$R'(\theta)\mathbf{p} = R(\theta)\mathbf{p}^\perp$）得 $H = \sum \mathbf{J}_i^\top\mathbf{J}_i$。

**点到线（D7-1）**：点到点残差沿"对应点连线"方向不提供信息（**滑动退化**：
平坦边界上匹配可沿切向滑动不增加代价），把残差投影到目标点法向 $\mathbf{n}_i$
（法向由邻域 PCA 取第 6 讲 (6.5)）：

$$\mathbf{e}_i = \mathbf{n}_i^\top\big(R\mathbf{p}_i + \mathbf{t} - \mathbf{q}_i\big), \qquad
\mathbf{J}_i = \Big[\ \mathbf{n}_i^\top R\,\mathbf{p}_i^{\perp},\ \ n_{ix},\ \ n_{iy}\ \Big] \tag{7.1}$$

（推导：链式法则，$\partial\mathbf{e}_i/\partial\delta\theta = \mathbf{n}_i^\top R\mathbf{p}_i^\perp$、
$\partial/\partial\mathbf{t} = \mathbf{n}_i^\top$；⑤依据：(2.8) 一维化 + 标量投影。）
点到线的**收敛域显著更大**：法向投影把"切向滑动"从代价函数里去掉，
初值差半米也能拉回——ICP 系算法选残差形式的第一原则：**让残差只看
约束最强的方向**。

### 7.4.3 似然场方法（书 §6.2.5–6.2.7，D7-2）

**① 问题场景**：点到线仍依赖"最近邻对应"——对应找错则雅可比全错。
**② 解决方法**：把目标扫描**预处理成一个可导的场**：占据点用高斯核卷积，
似然场 $F(\mathbf{x})$ 在占据点附近呈钟形、处处有定义。匹配 = 令源点落在
场值最低处，对应关系隐式在场里。
**④ 依据**：likelihood field（概率机器人占据栅格观测模型的连续化）。

**D7-2 推导（双线性插值与梯度）**。场按网格 $h$ 采样，查询点 $\mathbf{x}$ 落在
格 $(i,j)$ 内，分数坐标 $\mathbf{u} = \mathbf{x}/h - (i,j)$：

$$F(\mathbf{x}) = (1-u)(1-v)F_{00} + u(1-v)F_{10} + (1-u)v F_{01} + uv F_{11} \tag{7.2}$$

对 $\mathbf{x}$ 的偏导只通过 $(u, v)$ 进入（格点值固定）：

$$\frac{\partial F}{\partial \mathbf{x}} = \frac1h\begin{bmatrix}
-(1-v)F_{00} + (1-v)F_{10} - v F_{01} + v F_{11}\\
-(1-u)F_{00} - u F_{10} + (1-u)F_{01} + u F_{11}
\end{bmatrix} \tag{7.3}$$

残差 $\mathbf{e}_i = F(T\mathbf{p}_i)$ 的雅可比由链式法则合成：

$$\mathbf{J}_i = \Big[\ \nabla F^\top R\,\mathbf{p}_i^{\perp},\ \ \partial F/\partial x,\ \ \partial F/\partial y\ \Big] \tag{7.4}$$

（⑤依据：(7.2)(7.3) + 2D 扰动雅可比；实现 `likelihood_field.cc` 的
`AlignG2O`/`g2o_types.h` 的自定义边——场值与梯度在 BuildModel 阶段预计算，
匹配时只有查表。）
**与 Cartographer 的关系**：这正是 Cartographer 前端的 core scan matcher；
书中另给 g2o 版（§6.2.7）——同一个残差装进自定义顶点/边，展示"工程框架
不改变数学"。

### 7.4.4 占据栅格地图（书 §6.3，D7-3）

**① 问题场景**：扫描匹配只回答"位姿"，建图还要把扫描变成一张**一致的概率
地图**：同一个格子被多次观测，如何融合？
**② 解决方法**：二值贝叶斯滤波的 log-odds 形式。
**④ 依据**：静态世界假设 + 独立观测 + 贝叶斯法则
（主题教程 [../10_建图与系统实战.md](../10_建图与系统实战.md) 有完整推导）。

**D7-3 推导**。格子占据概率 $p_k = P(\mathrm{occ} \mid z_{1:k})$；对
$l_k = \ln\frac{p_k}{1-p_k}$ 取对数后，贝叶斯更新（分子分母同除先验几率）
恰好变成**加法**：

$$l_k = l_{k-1} + \underbrace{\ln\frac{p(\mathrm{occ}\mid z_k)}{p(\mathrm{free}\mid z_k)}}_{\text{hits: } +l_{occ}\ /\ \text{misses: } -l_{free}} - \underbrace{\ln\frac{p(\mathrm{occ})}{p(\mathrm{free})}}_{\text{先验项，常取 } 0} \tag{7.5}$$

（$p_{occ} = 0.7 \Rightarrow l_{occ} \approx 0.85$，$p_{free} = 0.4 \Rightarrow l_{free} \approx 0.41$；
恢复概率 $p = \sigma(l_k)$。）**哪些格子 hit / miss**：沿"雷达原点 → 回波点"
的射线，途经格子 miss、终点格子 hit——逐格步进即 **Bresenham 光栅化**
（§6.3.2，整数增量算法，误差 ≤ 半格）。
**模板法加速（§6.3.3）**：2D 雷达角度分辨率固定，"第 $j$ 束、距离 $d$"
的射线覆盖格子集合是**确定**的——按（线束号，距离桶）预生成射线模板，
建图时查表盖章，替代每点每帧重跑 Bresenham（`occupancy_map.cc` 的模板
插入路径）。加速比数十倍，思想同查表卷积。

### 7.4.5 子地图（书 §6.4）

**① 问题场景**：全局一张栅格图 + 每帧在全局图上匹配——图越大匹配越慢，
且一次误匹配永久污染全图。
**② 解决方法（§6.4.1）**：**子地图分治**——每张子地图只累积有限关键帧
（`submap.h` 的 `sad::Submap`：局部占据栅格 + 似然场），前端扫描匹配只在
**当前子地图**内做（保证局部一致、开销恒定）；子地图滚出窗口后冻结，
其位姿由后端位姿图统一修正（③理由：把"逐帧一致"与"全局一致"解耦，
Cartographer 的核心架构）。书中用 current/last 两张子地图滚动。

### 7.4.6 回环检测与闭环（书 §6.5）

**多分辨率回环检测（§6.5.1，`multi_resolution_likelihood_field`）**：
判据——当前关键帧与某张历史子地图"对得上"。困难：漂移后初值差可达数米，
单分辨率似然场收敛域不够。解法：**金字塔粗到细**——粗分辨率场（米级栅格）
先拉回大致位姿、细分辨率（分米级）精配，逐层收敛域接力；配准评分低于
门限则拒绝。这正是第 6 讲"收敛域"讨论的直接应用，也是 Cartographer
分支定界回环的简化版。

**基于子地图的回环修正（§6.5.2，`loop_closing.h` 的 `sad::LoopClosing`）**：
位姿图 = 顶点（关键帧 SE(2) 位姿）+ 边（相邻关键帧的扫描匹配相对位姿 +
回环相对位姿），目标函数与雅可比即十四讲讲 11 的位姿图结果 (11.1)(11.2)
在 SE(2) 的退化版（$J_r = I$，公式最简形态）；求解后把修正量按子地图归属
传播（§6.5.3 讨论：与 gmapping（RB 粒子滤波）、karto（图优化）、
Cartographer（子地图 + 分支定界）同构性对照）。

## 7.6 易错点与高频疑问

1. **ICP 对应点不剔除**：初值差时最近邻大量错配——必须配距离门限 +
   迭代间重算对应（`icp_2d` 的实现顺序：找对应 → GN 一步 → 重找）；
2. **似然场分辨率与雷达噪声不匹配**：核宽应 ≥ 雷达单点噪声（约 3 cm），
   否则场值在真值附近抖动；
3. **占据栅格"hit 邻域"当 miss**：终点附近的格子不要标 miss——回波
   常落在障碍表面稍前（距离门限保护，模板法里尤其注意盖章范围）；
4. **回环边信息矩阵拍脑袋**：应取多分辨率精配的**协方差估计**（评分
   曲面曲率），过刚/过软分别表现为"闭合抖动"与"闭不上"（十四讲讲 11
   易错点 4 的呼应）；
5. **以为 2D 系统是玩具**：它的四个模块（匹配/栅格/子地图/回环）与
   Cartographer 同构，第 9–11 讲的 3D 系统只是把每个模块升级——
   先在 2D 里把调试手感练出来。

## 7.7 自检题

1. 推导 $\partial(R(\theta)\mathbf{p})/\partial\theta = R\mathbf{p}^\perp$，并用它重推 (7.1)。
2. 证明"点到点 ICP 在长直墙前有沿墙方向的零空间"：写出该情形的 $H$ 阵
   并求其零空间。
3. 由 (7.2) 推 (7.3)；解释为什么格点值 $F_{ij}$ 不参与求导。
4. 从二值贝叶斯滤波完整推 (7.5)（主题教程 10 章的浓缩版）。
5. 多分辨率回环中，若粗层就配错了，细层能救回来吗？从"收敛域"角度
   论证，并设计一个失败实验。
6. 子地图尺寸（关键帧数/覆盖范围）的极限各有什么后果？（太小：匹配
   退化成帧对帧；太大：局部图管理与回环修正变重。）

## 7.8 本章要点

- 扫描匹配三式：点到点（简单、收敛域小）→ 点到线 (7.1)（去切向退化）→
  似然场 (7.2)–(7.4)（对应关系隐式化，Cartographer 同款）；
- log-odds 更新 (7.5) 是贝叶斯滤波在"格子独立"假设下的加法特例；
- 子地图 = 局部一致性与全局一致性的分治接口；回环 = 多分辨率粗到细
  验证 + SE(2) 位姿图；
- 本讲的调试范式（初值扰动测收敛域、删子地图测回环）在第 9–11 讲直接复用。
