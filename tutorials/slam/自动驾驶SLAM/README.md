## 建议读法

1. 最短主干：讲 2 → 4 → 8 → 9（数学 → 滤波 → 配准 → 里程计），再按需进入
   5（优化路线）、10（紧耦合）、11–12（系统）；
2. 每讲先看"问题场景"，再读推导，最后用"自检题"闭卷验收；
3. 母公式三件套务必吃透：(2.8)（扰动雅可比）、D4-1（误差状态运动学）、
   (10.3)（IEKF 迭代）——全书解析雅可比几乎都是它们的代换；
4. 配套代码按 `src/ch2–ch10` 组织，与 12 讲一一对应；建议每讲跑通对应
   模块再进入下一讲（无数据集时用各 `test_*` 仿真入口）。
