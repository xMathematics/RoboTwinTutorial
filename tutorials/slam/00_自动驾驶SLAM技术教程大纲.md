## 0. 总体设计

### 0.1 书籍信息与定位

- **作者**：高翔（半闲居士，《视觉 SLAM 十四讲》作者）等；电子工业出版社，2023 年 7 月。
- **配套代码**：`gaoxiang12/slam_in_autonomous_driving`（C++17，Ubuntu 20.04，依赖 Eigen / PCL / g2o / yaml-cpp，统一命名空间 `sad::`）。
- **数据集**：密歇根 NCLT、法国 UTBM、中国香港 UrbanLoco（ULHK），书中设计统一接口；全套测试数据约 270 GB（作者建议预留 100 GB 以上磁盘）。
- **定位**：《视觉 SLAM 十四讲》的姊妹篇与续作——十四讲以视觉 SLAM 为主，本书聚焦**激光 SLAM 与多传感器融合定位**（IMU + GNSS/RTK + 激光雷达），理论推导 + 可运行代码并重。作者自评："大部分书是用来看的，本书是用来运行的。"
- **读者假设**：已具备十四讲前 6 讲水平的李群李代数与非线性优化基础；本教程沿用仓库既有十四讲讲义作为前置引用，不重复推导。

### 0.2 全书主线一句话

自动驾驶车辆要在高精地图上定位、在没有地图处建图：用 **IMU 高频递推**补运动，用 **GNSS/RTK** 给绝对约束，用**激光雷达配准**给局部约束——状态估计工具（ESKF / 预积分 + 图优化）把三类信息融合，先做**组合导航**（第 3–4 章），再做**激光里程计与 SLAM**（第 5–8 章），最后落到**离线建图**与**在线定位**两个工程系统（第 9–10 章）。

## 第一部分 基础数学知识（第 1–4 章）

### 讲 1　自动驾驶中的定位与建图（第 1 章）

- **目标**：说清"L4 为什么离不开高精定位建图"，建立全书问题意识。
- **知识点**：自动驾驶能力分级（L0–L5）、L2 辅助驾驶与 L4 之别（§1.1）；L4 典型业务形态（Robotaxi 等，§1.1.2）；定位建图在 L4 中的作用——地图作为"超视距传感器"、传感器融合定位链路（§1.2.1）；高精地图的内容（车道级拓扑、语义要素）与生产流程（采集 → 点云建图 → 要素提取，§1.2.2）；本书内容组织顺序（§1.3）。
- **场景锚点**：坐在一辆 Robotaxi 里，车如何知道"我在哪条车道、离下一个路口多远"？
- **实践任务**：浏览配套代码仓库目录结构，跑通任一数据集的 README 示例（或至少完成代码编译）。
- **易错点**：把"定位"等同于"GNSS 给坐标"——隧道/城市峡谷下 GNSS 退化正是全书的出发点。

### 讲 2　基础数学回顾（第 2 章）

- **目标**：统一全书的数学语言：李群视角的位姿与运动学 + 滤波/优化两大求解框架。
- **知识点**：坐标系定义与内外参（§2.1.1）；SO(3)/SE(3) 李群李代数、指数对数映射（§2.1.2）；SO(3) 上 BCH 线性近似式（§2.1.3）；李群视角运动学（反对称阵 Ω，§2.2.1）；四元数视角运动学 $\dot q = \tfrac12 q\otimes\omega$（§2.2.2）；四元数 ↔ 旋转矢量转换（§2.2.3）；其他运动学表达（§2.2.4）；线速度与加速度（§2.2.5）；扰动模型与雅可比（§2.2.6）；圆周运动验证（§2.3）；状态估计问题与最小二乘、卡尔曼滤波五公式、非线性处理（EKF/迭代）、图优化（§2.4）。
- **核心推导要点**：
  - D2-1：BCH 一阶近似下 $\exp(\phi+\delta\phi)\approx\exp(\phi)\exp(J_l\delta\phi)$，$J_l$ 的来源与适用条件；
  - D2-2：李代数运动学 $\dot T = T\Omega^\wedge$ 与四元数微分等价性的对照；
  - D2-3：左右扰动雅可比的定义差异及"何时用哪个"。
- **实践任务**：复跑书中圆周运动实验，数值验证运动学公式（书中代码 `ch2` 圆周积分）。
- **易错点**：BCH 只取一阶时要求 $\|\delta\phi\|$ 小；四元数左/右乘约定混用导致旋转轴错位；把李代数运动学当"精确微分方程"而忽略它本身就是切空间线性化。
- **互链**：大幅引用十四讲讲 3–4，只补"运动学"视角（十四讲偏静态变换）。

### 讲 3　IMU 与惯性导航（§3.1–3.3）

- **目标**：从 IMU 的物理测量出发，建立"噪声是怎么进来的、递推能撑多久"的直觉。
- **知识点**：IMU 测量值的解释（比力 + 角速度，§3.1.1）；测量方程噪声模型（加性白噪声 + 零偏随机游走，§3.1.2）；离散时间噪声模型（连续谱密度 → 离散协方差，含采样率因子，§3.1.3）；现实 IMU 规格与 Allan 方差（§3.1.4）；短时航迹推算与代码实验（§3.2）；GNSS 分类与供应商（§3.3.1）；RTK 载波相位差分原理与实装（§3.3.2）；常用世界坐标系（ECEF/ENU/经纬度，§3.3.3）；RTK 数据解析与显示（§3.3.4）。
- **核心推导要点**：
  - D3-1：从运动学方程推出 IMU 递推式，指出"姿态误差 → 两次积分变位置误差"的发散链条；
  - D3-2：连续白噪声/随机游走参数 $\sigma_a,\sigma_{ba}$ 到离散协方差 $Q_k$ 的转换（平方因子易错）。
- **实践任务**：书中 IMU 递推实验——对比"IMU 纯递推 vs RTK 真值"的发散曲线，标定噪声参数的量级感。
- **易错点**：把零偏当常值（实为随机游走）；离散化噪声时漏乘/错乘采样周期；混淆 ENU 与世界系导致重力方向错。

### 讲 4　ESKF 组合导航（§3.4–3.6）

- **目标**：完整推导并实现误差状态卡尔曼滤波（ESKF），得到第一个可运行的多传感器融合系统 GINS（GNSS+INS）。
- **知识点**：名义状态 + 误差状态的双状态设计动机（旋转量在原点附近线性化、参数化无奇异，§3.4.1）；离散时间 ESKF 运动方程（§3.4.2）；预测过程（§3.4.3）；更新过程（§3.4.4）；误差状态注入与协方差重置（§3.4.5）；实现：导航类结构、预测、RTK 观测、初始化（静止 IMU 初始化）、运行与调参（§3.5.1–3.5.5）；附加速度观测（里程计，§3.5.6）。
- **核心推导要点**：
  - D4-1：误差状态运动学 $\delta\dot\theta = -\omega^\wedge\delta\theta - \delta b_g - n_g$ 的逐项推导（含 $R\tilde\omega^\wedge R^\top$ 反对称不变性）；
  - D4-2：预测协方差传播 $P \leftarrow F P F^\top + Q$ 中 $F$ 的分块含义；
  - D4-3：观测更新后误差注入（$\theta \leftarrow \mathrm{Exp}(\delta\theta)\,\theta$）与 $G$ 阵协方差投影。
- **实践任务**：跑通书中 ESKF-GINS；做消融——去 RTK、去速度观测分别看漂移。
- **易错点**：误差重置时忘投影响协方差；姿态误差用欧拉角参数化引入奇异；初始化时重力对准不做，位置先稳后漂。
- **互链**：`精读/`中 ESKF 原论文（Sola《Quaternion kinematics for the error-state Kalman filter》）可作扩展阅读。

### 讲 5　预积分学与图优化 GINS（第 4 章）

- **目标**：掌握预积分这条"优化路线"的惯性融合方案，与讲 4 的滤波路线形成对照。
- **知识点**：预积分动机——线性化点变化免重积分（§4.1.1）；预积分测量模型 $\Delta R_{ij},\Delta\hat v_{ij},\Delta\hat p_{ij}$（§4.1.2）；噪声传播与协方差递推（§4.1.3）；零偏更新的一阶修正（§4.1.4）；归结为图优化因子（§4.1.5）；预积分对零偏的雅可比（§4.1.6）；实现：预积分类、图优化顶点/边、基于 g2o 的 GINS（§4.2）。
- **核心推导要点**：
  - D5-1：从 IMU 递推式出发做变量替换得预积分定义式；
  - D5-2：$\Delta R$ 噪声传播 $\eta^{ij}\leftarrow \mathcal{A}\eta + \mathcal{B}\eta_g$ 的协方差递推；
  - D5-3：零偏修正 $\Delta\tilde p_{ij}\approx\Delta\hat p_{ij}+J^g\delta b_g+\dots$ 各雅可比的来历；
  - D5-4：预积分因子残差与信息矩阵在 g2o 边中的组织。
- **实践任务**：跑通书中预积分 GINS，与讲 4 的 ESKF-GINS 在同一数据上比精度/耗时，写对照结论。
- **易错点**：预积分是在**两关键帧间**的相对量，别当绝对状态用；零偏变化时必须重积分或一阶修正，直接沿用旧雅可比会发散；协方差递推初值与信息矩阵求逆的数值稳定性。
- **互链**：[精读/IMU-Preintegration_TRO2017.md](精读/IMU-Preintegration_TRO2017.md)（Forster 补因子推导）、[精读/VINS-Mono_RAM2018.md](精读/VINS-Mono_RAM2018.md)、`projects/slam/preint`（numpy 实现）。

## 第二部分 激光雷达的定位与建图（第 5–8 章）

### 讲 6　基础点云处理（第 5 章）

- **目标**：补齐激光 SLAM 的三块地基——点云表达、最近邻检索、几何拟合；亲手实现一棵可用的 Kd 树。
- **知识点**：机械式激光雷达数学模型（距离/垂直角/水平角 → 点，§5.1.1）；点云表达（PCL 点云，§5.1.2）；Packet（按发射单元组织）表达（§5.1.3）；俯视图与距离图（range image，§5.1.4）；其他表达（§5.1.5）；最近邻问题总览（§5.2）：暴力法（§5.2.1）、栅格/体素（§5.2.2）、二分树与 Kd 树（构建 + BBF 最近邻 + k 近邻，§5.2.3）、四叉树/八叉树（§5.2.4）、其他树结构（§5.2.5）；拟合问题：平面拟合（SVD，§5.3.1–5.3.2）、直线拟合（§5.3.3–5.3.4）。
- **核心推导要点**：
  - D6-1：Kd 树递归构建与"轴垂直分割面"最近邻回溯（BBF 剪枝依据：查询点到分割面距离 vs 当前最优）；
  - D6-2：平面拟合的最小二乘解 = 点云协方差最小特征向量（SVD 视角）。
- **实践任务**：实现 Kd 树并做 1M 点规模基准测试（书中 `ch5` 单元测试）；对比暴力/栅格/Kd 树耗时。
- **易错点**：Kd 树最坏退化 O(n)（平衡树只保均值）；最近邻与 k 近邻的剪枝条件不同；平面拟合别用"最小奇异值向量"与"最小特征值向量"混肴（约定要看 SVD 排序方向）。
- **互链**：`projects/slam/core`（若有空间索引实现则互引）。

### 讲 7　2D SLAM（第 6 章）

- **目标**：用一张 2D 栅格地图把 SLAM 全流程（前端配准 → 子地图 → 回环 → 闭环优化）完整走一遍——小系统，全要素。
- **知识点**：2D SLAM 基本原理与框架（§6.1）；扫描匹配：点到点 ICP（SVD 解 + 高斯-牛顿实现，§6.2.1–6.2.2）、点到线 ICP（高斯-牛顿，§6.2.3–6.2.4）、似然场方法（高斯-牛顿实现 + g2o 实现，§6.2.5–6.2.7）；占据栅格地图：log-odds 原理（§6.3.1）、Bresenham 光栅化建图（§6.3.2）、模板法加速（§6.3.3）；子地图：原理与实现（keyframe 管理，§6.4）；回环检测与闭环：多分辨率回环检测（§6.5.1）、基于子地图的回环修正（位姿图优化，§6.5.2）、讨论（与 Cartographer/gmapping/karto 对照，§6.5.3）。
- **核心推导要点**：
  - D7-1：点对线残差 $r = n^\top(Tp_i - q_i)$ 对 $\xi$ 的链式雅可比（李代数左扰动）；
  - D7-2：似然场的双线性插值梯度——为什么可导、与最近邻残差相比好在哪；
  - D7-3：占据栅格 log-odds 更新 $l \leftarrow l + l_{\mathrm{occ}}$ 与概率还原。
- **实践任务**：跑通书中 2D SLAM 全流程；实现三种扫描匹配的精度/耗时对比表。
- **易错点**：ICP 初值差时陷入局部极小（需 odom 先验）；似然场分辨率与激光噪声匹配；子地图坐标变换方向（子图系 ↔ 世界系）写反导致回环修正发散。
- **互链**：[09_回环检测.md](09_回环检测.md)、`projects/slam/loam2d`（同为 2D 前端，可对照"特征法 vs 直接配准"）。

### 讲 8　3D 配准：ICP 与 NDT（§7.1–7.2）

- **目标**：把 2D 的配准思想升维到 3D，掌握多线雷达数据特点与两大配准范式（ICP / NDT）。
- **知识点**：机械旋转式激光雷达工作原理（§7.1.1）；固态雷达（非重复扫描，Livox 类，§7.1.2）；点到点 ICP（SVD + 高斯-牛顿，§7.2.1）；点到线、点到面 ICP（高斯-牛顿，含法向估计，§7.2.2）；NDT：体素内高斯建模、目标函数、优化（§7.2.3）；与 PCL 内置方法的对比实验（§7.2.4）。
- **核心推导要点**：
  - D8-1：3D 点对点 ICP 的 SVD 闭式解推导（质心对齐 + `JacobiSVD`）；
  - D8-2：点到面残差雅可比 $J = [ (R p_i)\times n_i \;\; n_i ]$（左右扰动下）；
  - D8-3：NDT 负对数似然目标 $-\sum\ln(\rho \exp(-\tfrac12 d^T\Sigma^{-1}d))$ 及高斯退化防护（最小协方差阈值）。
- **实践任务**：书中 `ch7` 配准基准——点对点/点到线/点到面/NDT 在同一帧对上的收敛性与耗时。
- **易错点**：法向方向不定导致点到面残差符号跳变；NDT 体素过小→高斯退化、过大→分辨率不足；固态雷达运动畸变比机械式更显著。
- **互链**：[精读/LOAM_RSS2014.md](精读/LOAM_RSS2014.md)（特征法将在讲 9 展开，此处先建 ICP 地基）。

### 讲 9　3D 里程计与松耦合 LIO（§7.3–7.6）

- **目标**：从"单帧配准"走到"连续里程计"与"IMU 融合的松耦合 LIO"——系统的第一个完整形态。
- **知识点**：直接法里程计：用 NDT 构建里程计（frame-to-map，§7.3.1）、增量 NDT 里程计（局部地图滚动更新，§7.3.2）；特征法里程计：特征提取（曲率，§7.4.1）、基于线束的特征提取（§7.4.2）、实现（§7.4.3）、特征 LOAM 式里程计（§7.4.4）；松耦合 LIO：坐标系说明（§7.5.1）、运动与观测方程（ESKF + 配准结果作为观测，§7.5.2）、数据准备（运动补偿，§7.5.3）、主要流程（§7.5.4）、配准部分（§7.5.5）。
- **核心推导要点**：
  - D9-1：frame-to-map vs frame-to-frame 的信息组织差异与漂移来源；
  - D9-2：LOAM 特征残差（点到线/点到面）与线性插值雅可比；
  - D9-3：松耦合中"配准位姿 = 带协方差观测"在 ESKF 更新中的注入方式（与讲 4 的 RTK 观测同构）。
- **实践任务**：跑通书中 NDT 里程计与特征法里程计，对比两者的漂移率与 CPU 占用；再开松耦合 LIO 看提升。
- **易错点**：增量 NDT 局部地图不裁剪导致内存/耗时膨胀；特征提取在稀疏线束上退化；运动补偿（去畸变）用的位姿插值次序写反。
- **互链**：[精读/LOAM_RSS2014.md](精读/LOAM_RSS2014.md)、`projects/slam/loam2d`。

### 讲 10　紧耦合 LIO（第 8 章）

- **目标**：理解"紧耦合到底紧在哪"——把观测从"配准结果"推进到"原始点云"，掌握 IEKF 与预积分两条实现路线。
- **知识点**：紧耦合原理与优点（在线估计运动畸变、避免配准信息损失，§8.1）；基于 IEKF 的 LIO：状态变量与运动方程（§8.2.1）、观测方程中的迭代过程（IEKF 与 EKF 之别，§8.2.2）、高维观测的等效处理（点云整体一次更新、卡方/NIS 门限，§8.2.3）；实现基于 IEKF 的 LIO（点到面残差、ikd-tree 式局部地图，§8.3）；基于预积分的 LIO：原理（图优化：预积分因子 + 点云因子，§8.4.1）、代码实现（§8.4.2）。
- **核心推导要点**：
  - D10-1：IEKF 迭代更新 $x\leftarrow x\oplus\delta x$ 收敛条件与 EKF 单步更新的关系；
  - D10-2：点到面紧耦合残差对状态的雅可比组装（IMU 前向传播 + 外参）；
  - D10-3：高维观测等效为一次更新的信息矩阵拼接（与逐点更新等价的条件）。
- **实践任务**：跑通书中 IEKF-LIO 与预积分-LIO；与讲 9 松耦合在同序列上比轨迹误差；观察退化场景（长走廊）下两者表现。
- **易错点**：IEKF 迭代不收敛时的发散防护（步长/迭代上限）；局部地图 Kd 树增量维护的正确性；预积分 LIO 中关键帧划分过密导致图过大。
- **互链**：[精读/VINS-Mono_RAM2018.md](精读/VINS-Mono_RAM2018.md)（紧耦合思想同源）、`projects/slam/vins`、`projects/slam/preint`；可引 FAST-LIO / LIO-SAM 作扩展阅读对照。
