## 8.2 环境搭建（Anaconda / conda）

> 本教程配套实现使用 **conda 环境 `llm_env`**（已安装 torch 2.11.0 + numpy + imageio + scipy + tqdm）。VS Code 的 Python 解释器已通过 `.vscode/settings.json` 指向该环境。

```bash
# 1. 激活 conda 环境
conda activate llm_env

# 2. 若缺依赖（正常情况下已装好）
pip install -r projects/nerf/requirements.txt

# 3. 验证
python -c "import torch, numpy, imageio, scipy; print(torch.__version__)"
```

> 💡 想为项目单独建环境？`conda create -n nerf_env python=3.10 && conda activate nerf_env && pip install -r projects/nerf/requirements.txt`，然后在 `.vscode/settings.json` 中把 `python.defaultInterpreterPath` 改为 `nerf_env` 的 python 路径即可。

> 🛠️ VS Code 使用提示：安装扩展 `ms-python.python` 后，`.vscode/launch.json` 提供了"训练/测试/渲染"三个调试配置；`tasks.json` 提供同名任务（`Ctrl+Shift+B` 或终端菜单运行）。

## 8.4 训练

```bash
# 标准配置：batch 1024、粗64+细128、200k 步
python run_nerf.py --config data/lego --mode train \
    --exp lego_full --steps 200000

# 快速验证（CPU 或小显存）：batch 256、步数少、分辨率低
python run_nerf.py --config data/lego --mode train \
    --exp lego_smoke --tiny
```

> ⏱️ 参考耗时：V100 上标准配置约 6~10 小时；`--tiny` 模式 5 分钟内可看到损失下降，用于验证代码正确性。

## 8.5 渲染与评估

```bash
# 渲染测试集新视角 + 计算 PSNR/SSIM/LPIPS
python run_nerf.py --config data/lego --mode test --exp lego_full \
    --ckpt logs/lego_full/latest.pt

# 渲染一条相机轨迹的视频帧
python run_nerf.py --config data/lego --mode render --exp lego_full \
    --ckpt logs/lego_full/latest.pt --frames 120
```

**输出**：
- 测试视角的 RGB 图 → `logs/<exp>/test/`
- 逐图 PSNR/SSIM → 终端 + `logs/<exp>/metrics.json`
- 视频帧 → `logs/<exp>/video/`

## 8.6 训练监控与调参建议

| 现象 | 可能原因 | 建议 |
|------|---------|------|
| 损失不降 | 学习率过高/过低 | 检查 lr 起始 $5\times10^{-4}$ |
| 图像模糊 | 缺少位置编码或 $L$ 太小 | 确认 `--l_xyz 10` |
| 高光缺失 | 无方向输入 | 确认 `use_viewdirs=True` |
| 显存不足 | batch 太大 | 减小 `--batch_size` |
| 背景渲染错 | 未归一化/边界错误 | 检查 `--near/--far` 与 `ndc` 开关 |

## 8.7 动手练习

1. 跑通 `--tiny` 冒烟训练，确认损失单调下降。
2. 对比"开启/关闭位置编码"两版训练后渲染的锐度差异。
3. 修改 `--batch_size` 从 256→1024，观察单步耗时与损失收敛速度的变化。
