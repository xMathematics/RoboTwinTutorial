|------|------|------|

对应的中文解读见 [`tutorials/`](../tutorials/)，相关代码实现见 [`projects/`](../projects/)。

## 添加新论文

1. 在本目录下新建 `<主题>/` 子目录
2. 放入论文源码或 PDF，命名保留 arXiv 编号
3. 在 `tutorials/<主题>/` 下建立对应教程
4. 更新本表与根 README
